## 1. 这一期补的是什么

P0~P2 把「一题 → 一章 → 一项目」这条链修通了：错题变怪物、三关由作答派生、依赖图给出下一章、
NextAction 只推一件事。但它有一个结构性缺口——**所有目标都由进度触发**。

于是玩家的节奏完全绑在自己的推进速度上：想快就能一直快，想停就一直停，系统里没有任何
"今天不做就会过去"的东西。周 BOSS 与幕旁白补的正是这一层：

| 补的东西 | 解决的问题 | 落点 |
|---|---|---|
| 周 BOSS | 没有周期性目标；一周里没有"悬着的一件事" | `lib/weekly.ts` + 首页卡 |
| 幕旁白 | 学完一章后"记住的东西"没被压缩成一句话；已写好的 153 条台词零消费 | `data/story.ts` + 剧情页 / 章节详情 |

## 2. 周 BOSS（S4）

### 规则

- **周期**：ISO 周（周一 00:00 本地时间换周），周编号形如 `2026-W44`。
- **目标章节**：从「有题目的章节」里按本周编号稳定哈希挑一章，**优先挑"概念关已过、BOSS 还没过"** 的
  —— 那是主线上真正差临门一脚的地方。整库退化：有进度的章 → 全库。
- **题单**：该章最硬的 3 道（hard → medium → easy，同档按 id 升序，保证确定）。
- **门槛**：本周答对 ≥ 6 题。数字来自 `answers` 里 `at` 落在本周且 `ok=true` 的记录，
  **不是按钮**——这就是方案 §7 要求的「门槛可检查」。
- **通关**：3 道全对。奖励 150 结晶 + 2 碎片，一次性（`claimed` 落盘）。
- **答错**：不撤销、不降难度，那道题留在原地可以重打。

### 三个实现决定

1. **门槛判定不在 reducer 里，只在 UI 里**。
   reducer（`applyWeekly`）只认"这一题属于本周题单"，不判断"你够不够资格"。
   两处都判的话，阈值一旦不同步就会出现「按钮亮了但 reducer 不认」。
   门槛是展示规则，写入口不该重复它。

2. **题单要落盘，不能每次现算**。
   现算意味着用户一改进度，题单就换一套，"我昨天打过一道"的记忆和界面对不上。
   落盘后只校验 `week` 与 `qids` 是否仍存在——题库改版时自愈，正常时稳定。

3. **门槛没到就禁用按钮，而不是隐藏**。
   隐藏会让"这周要打什么"看不见；禁用 + 一行进度条既保留了目标感，又不给
   "点了却没算"的错觉。禁用态还上了 `:disabled` 样式，避免它看起来像能点。

### 一个顺带修掉的死胡同

验证时发现：新用户选「数据分析」，首页大卡推的是**签到**。原因是 `data-ch01` 的前置是
`py-ch03`（跨学科），前 5 档全部落空，于是落到第 6 档。签完到，第二天还是签到。

`nextAction` 因此加了第 **5b** 档：本科目一章都开不了时，指名"还差哪一章前置"，
并带上那一章的学科，让 CTA 能跨学科打开（`HomePage` 里 `setSubject` + `focusChapter`）。
现在首屏是「还有一章前置挡着：Python 基础」+「去学那一章」。

## 3. 幕旁白（C4）

- 数据源：`content/_story/acts.json`（手写，153 条 / 35 幕 / 13 学科），
  经 `scripts/gen_story_data.py` 生成 `frontend/src/data/story.ts`。
  每条都锚在一章的 `goals.md` 认知点上（`anchor` 字段），改内容时须同步核对。
- 落点两处：
  1. **剧情页**「幕 · 旁白」：13 学科可切换，逐幕展开，顶部显示 `已解锁 / 153`。
  2. **学习页章节详情**：本章一句话旁白。
- 可见性（`isTeaser`）：
  - `pitfall` / `scene` / `field` —— 未完成也能读。它说的是"我当初怎么想错的"，提前读是钩子，不构成剧透。
  - `archive` —— 掌握度 ≥ 60% 才给看。它已经给出半个答案，没学过的人读到只会记住结论、不理解为什么。
- 未解锁时不显示"……"糊弄，而是明说「完成本章（掌握度 ≥ 60%）后解锁」。

## 5. 已知边界

- 周 BOSS 只有"通关/未通关"两态，没有累计伤害、没有排名——私人自用没有比较对象，做排行只是装饰。
- 旁白是"读"的内容，没有做朗读、没有做收藏/点赞；153 条已全部可用，够读很久。
- 周 BOSS 的目标章节按哈希挑，**不考虑**"这一章是不是本周在学"。想要更贴合的可以改成
  "本周作答最多的章节"，但那会让题单变得可预测性太低（每天打开可能换目标），先不做。
