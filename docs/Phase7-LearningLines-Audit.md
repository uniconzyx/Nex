## 四、独立性设计（为什么"每条线都能单独学"）

1. **首章无前置**：13/13 条线的第一章均无 `prerequisites`，任何一条线都能从零起步。
2. **软前置机制**：跨学科先修一律记入 `soft_prerequisites`（形如 `{"id": "py-ch01", "note": "若已掌握可跳过"}`），**不进** `prerequisites`，因此不构成硬依赖、不阻断学习。本轮将 3 处原硬前置降级：
   - `data-ch01` → `py-ch01`（Python 语法基础，可跳过）
   - `data-ch05` → `py-ch01`
   - `spring-ch06` → `java-ch04`（Java 集合与泛型，可跳过）
   `data-ch01/goals.md` 同步补了「软前置（可选，不阻断学习）」说明段。
3. **自足资源**：每条线自带 `resources`（GitHub 最高 star 仓库 + 教材 + 平台题链接），不依赖其他线的资源。
4. **自足八股**：13 条线各有 `_bagua.json`（3~6 类，12~24 题），就业向复习不需要跨线检索。
5. **章节链闭合**：每条线的章节按 `order` 从入门到实战顺序排列，线内先修关系完整（`prerequisites` 只引用**本线**章节）。

| 4 | `clang-u06` 3 个 concept **完全没有三视角解析章节** | 按主题补写（编译四阶段 / Makefile 规则模型 / 增量依赖与并行） |
| 5 | 门禁只按中文关键词检测三视角，**掩盖了上述标记漂移与缺失** | `validate_content.py` 新增「标记规范性」报告项：同时检测规范标记（含 emoji 与 `###`）并单列 `marker_drift` |
