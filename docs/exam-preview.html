单项选择题

1单项选择题 · 5 分

递归式 T(n) = 2T(n/2) + n·log n 的时间复杂度是（　）

  1. AΘ(n log n)
  2. BΘ(n log² n)
  3. CΘ(n²)
  4. DΘ(n)

解题框架

  1. 写出 a（子问题个数）、b（规模缩小倍数）、f(n)（分解与合并代价）
  2. 算 n^(log_b a)
  3. f(n) 更小 → Θ(n^(log_b a))；同阶 → 乘一个 log n；更大且满足正则条件 → Θ(f(n))
  4. 不符合主定理形式（如 T(n)=T(n−1)+n）改用展开法
  5. 最后只保留最高阶，去掉常数

容易错在把 a、b 认反（a 是分支数，不是缩小倍数）

解决思路

套主定理：a=2、b=2，n^(log₂2)=n，而 f(n)=n log n 与 n 同阶但多一个 log 因子。

知识点

  • 主定理T(n)=aT(n/b)+f(n)，与 n^(log_b a) 比较：小则取后者，同阶则乘 log n，大则取 f(n)。易错：把 f(n)=n log n 直接当成 n²，选 Θ(n²)；或忽略 log 因子选 Θ(n log n)。

详细解法

a=2，b=2，log_b a = 1，故 n^(log_b a) = n。f(n) = n log n 比 n 大一个 log 因子，属于主定理第二类的扩展情形，结果在 n 上再乘一个 log：Θ(n log² n)。
对照：若 f(n)=n，结果是 Θ(n log n)；若 f(n)=n²，结果是 Θ(n²)。

2单项选择题 · 5 分

下列函数中增长最慢的是（　）

  1. Alog n
  2. B√n
  3. Cn
  4. Dn log n

解题框架

  1. 先明确问的是单次最坏、平均还是摊还
  2. 最坏找最不利输入（快排已排序、散列全冲突）
  3. 平均要说明输入分布假设
  4. 摊还看一串操作的总代价除以操作数
  5. 答题时写出结论 + 一句理由

容易错在把平均当最坏

解决思路

比较阶：log n < √n < n < n log n，取 n=10⁶ 代入即可直观看出。

知识点

  • 摊还分析一串操作的总代价除以操作次数，动态数组扩容的摊还代价是 O(1)。易错：认为 √n 比 log n 小——多项式增长总快于对数增长。

详细解法

令 n=10⁶：log₂n ≈ 20，√n = 1000，n = 10⁶，n log n ≈ 2×10⁷。故增长最慢的是 log n。记忆顺序：log n < √n < n < n log n < n² < 2ⁿ。

3单项选择题 · 5 分

动态数组（容量不足时翻倍扩容）的 push 操作，摊还时间复杂度是（　）

  1. AO(1)
  2. BO(log n)
  3. CO(n)
  4. DO(n log n)

解题框架

  1. 先明确问的是单次最坏、平均还是摊还
  2. 最坏找最不利输入（快排已排序、散列全冲突）
  3. 平均要说明输入分布假设
  4. 摊还看一串操作的总代价除以操作数
  5. 答题时写出结论 + 一句理由

容易错在把平均当最坏

解决思路

摊还看总代价：n 次 push 的扩容总代价为 1+2+4+…+n < 2n，平均到每次是常数。

知识点

  • 摊还分析一串操作的总代价除以操作次数，动态数组扩容的摊还代价是 O(1)。易错：把单次扩容的 O(n) 当成每次 push 的复杂度。

详细解法

n 次 push 中，扩容发生在容量 1,2,4,…,2^k 时，拷贝总次数为 1+2+…+2^k < 2n，加上 n 次写入，总代价 O(n)，摊还到每次为 O(1)。
注意：单次最坏仍是 O(n)，摊还与最坏是两个不同口径。

填空题

4填空题 · 5 分

递归式 T(n) = 2T(n/2) + n 的解为 ______。

解题框架

  1. 写出 a（子问题个数）、b（规模缩小倍数）、f(n)（分解与合并代价）
  2. 算 n^(log_b a)
  3. f(n) 更小 → Θ(n^(log_b a))；同阶 → 乘一个 log n；更大且满足正则条件 → Θ(f(n))
  4. 不符合主定理形式（如 T(n)=T(n−1)+n）改用展开法
  5. 最后只保留最高阶，去掉常数

容易错在把 a、b 认反（a 是分支数，不是缩小倍数）

解决思路

主定理：n^(log₂2)=n 与 f(n)=n 同阶，结果要乘 log n。

知识点

  • 主定理T(n)=aT(n/b)+f(n)，与 n^(log_b a) 比较：小则取后者，同阶则乘 log n，大则取 f(n)。易错：写成 Θ(n)，漏掉同阶情形要乘的 log 因子。

详细解法

a=2，b=2，log_b a=1，n^(log_b a)=n，与 f(n)=n 同阶，由主定理第二类得 T(n)=Θ(n log n)。这正是归并排序的递归式。

解答题

5解答题 · 10 分

用主定理求 T(n) = 2T(n/2) + n² 的渐进复杂度，并写出判断过程。

解题框架

  1. 写出 a（子问题个数）、b（规模缩小倍数）、f(n)（分解与合并代价）
  2. 算 n^(log_b a)
  3. f(n) 更小 → Θ(n^(log_b a))；同阶 → 乘一个 log n；更大且满足正则条件 → Θ(f(n))
  4. 不符合主定理形式（如 T(n)=T(n−1)+n）改用展开法
  5. 最后只保留最高阶，去掉常数

容易错在把 a、b 认反（a 是分支数，不是缩小倍数）

解决思路

先算 a、b 与 n^(log_b a)，再与 f(n)=n² 比较大小，确定属于主定理哪一类。

知识点

  • 主定理T(n)=aT(n/b)+f(n)，与 n^(log_b a) 比较：小则取后者，同阶则乘 log n，大则取 f(n)。易错：只写结果不写比较过程；或把 n^(log_b a) 算成 n²。

详细解法

a = 2，b = 2，log_b a = log₂2 = 1，故 n^(log_b a) = n。
f(n) = n² 比 n 高阶（多项式意义上大），且满足正则条件 a·f(n/b) = 2·(n/2)² = n²/2 ≤ c·f(n)（取 c = 1/2 < 1）。
属于主定理第三类，故 T(n) = Θ(f(n)) = Θ(n²)。
对照记忆：f 小取 n^log，同阶乘 log，f 大取 f。

复杂度与渐进分析 · 本专题 5 题

本专题常见问法：给递归式求时间复杂度；问某种操作的时间复杂度。看到这类问法先归到本专题，再套下面的固定步骤，不要从题目细节重新想。

固定步骤

  1. 写出 a（子问题个数）、b（规模缩小倍数）、f(n)（分解与合并代价）
  2. 算 n^(log_b a)
  3. f(n) 更小 → Θ(n^(log_b a))；同阶 → 乘一个 log n；更大且满足正则条件 → Θ(f(n))
  4. 不符合主定理形式（如 T(n)=T(n−1)+n）改用展开法
  5. 最后只保留最高阶，去掉常数

技巧

主定理

同阶情形最容易漏乘 log n，例如 T(n)=2T(n/2)+n 的结果是 Θ(n log n)。

摊还分析

摊还不是「每次最坏 O(1)」，单次扩容仍是 O(n)。

陷阱

  • 把 a、b 认反（a 是分支数，不是缩小倍数）
  • 同阶情形忘记乘 log n
  • 递归式有减号还硬套主定理
  • 把平均当最坏

排序 · 本专题 7 题

本专题常见问法：比较各排序的复杂度、稳定性、适用场景；写出快排一趟划分结果或归并过程。看到这类问法先归到本专题，再套下面的固定步骤，不要从题目细节重新想。

固定步骤

  1. 先分类：比较排序还是非比较排序
  2. 写出最好/平均/最坏三档
  3. 判断稳定性：相等元素相对次序是否改变
  4. 看空间：归并 O(n)，快排 O(log n) 栈，堆排 O(1)
  5. 按题目条件选：要求稳定选归并，要求原地选堆排

技巧

比较排序下界

计数排序能到 O(n+k) 是因为不比较，不是突破了下界。

稳定性与原地性

多关键字排序常要求稳定：先按次要关键字排，再按主要关键字稳定排序。

陷阱

  • 把快排平均 O(n log n) 当成最坏
  • 认为堆排稳定（实际不稳定）
  • 对已有序数据仍选快排且取首元素为枢轴
  • 划分时指针移动顺序写反导致死循环

查找与散列 · 本专题 3 题

本专题常见问法：判断二分能否使用，或求第一个/最后一个位置；分析散列查找长度或选择冲突处理方式。看到这类问法先归到本专题，再套下面的固定步骤，不要从题目细节重新想。

固定步骤

  1. 确认数组有序且可随机访问
  2. 统一区间写法（左闭右开或左闭右闭），全程不混用
  3. 找第一个 ≥ target：命中后继续收缩右边界
  4. 循环结束条件与返回值要和区间写法匹配
  5. 用 n=1、target 不存在两种边界自测

技巧

二分查找

找边界时命中不能立即返回，要继续收缩区间。

散列与冲突

开放定址删除要打标记，直接置空会截断探测链。

陷阱

  • 区间开闭混用导致死循环或漏解
  • 命中就返回，找边界时只能得到任意一个
  • 对链表使用二分（无法 O(1) 随机访问）
  • 认为散列查找恒为 O(1)

递归与分治 · 本专题 4 题

本专题常见问法：把问题拆成子问题并给出合并方式；用分治统计跨区间的贡献。看到这类问法先归到本专题，再套下面的固定步骤，不要从题目细节重新想。

固定步骤

  1. 确认子问题与原问题同型且相互独立
  2. 确定拆分点（中点、按位、按值域）
  3. 写出合并步骤及其代价
  4. 列递归式并用主定理求复杂度
  5. 检查递归出口

技巧

分治三步骤

子问题重叠时应改用动态规划，否则重复计算导致指数级。

跨区间贡献

只统计半边是最常见的漏解，跨中点的部分必须单独算。

陷阱

  • 子问题有重叠却仍用分治（应改 DP）
  • 合并代价算漏，导致复杂度估低
  • 递归出口缺失或写错
  • 只统计半边，漏掉跨中点的情况

动态规划 · 本专题 7 题

本专题常见问法：给问题建模，写出状态与转移方程；填表求最优值，或把二维压成一维。看到这类问法先归到本专题，再套下面的固定步骤，不要从题目细节重新想。

固定步骤

  1. 用一句话定义 dp 下标的含义（必须能复述）
  2. 想「最后一步」：最优解的最后一次决策是什么
  3. 由最后一步反推转移方程
  4. 确定边界（空串、容量 0、长度为 0）
  5. 确定计算顺序，保证依赖项先算

技巧

状态与转移

状态定义含糊时，转移方程一定写不对，先复述状态再动笔。

背包与序列问题

0-1 背包正序更新会重复使用同一物品，等价于完全背包。

陷阱

  • 状态含义说不清，转移必然出错
  • 边界漏写导致越界或初值错
  • 0-1 背包用正序更新（变成完全背包）
  • 填表顺序与依赖方向相反

贪心 · 本专题 5 题

本专题常见问法：选择贪心指标并说明为什么最优；判断某策略是否总能得到最优解。看到这类问法先归到本专题，再套下面的固定步骤，不要从题目细节重新想。

固定步骤

  1. 明确每一步的贪心指标（最早结束、最小权值、最大单位价值）
  2. 用交换论证证明：任意最优解都能改成含贪心选择且不更差
  3. 确认剩余子问题与原问题同型
  4. 给出反例会立刻暴露错误策略
  5. 写复杂度：排序 + 一次扫描

技巧

贪心选择性质

只说「显然」不得分，必须写出交换的那一步。

贪心失效

反例优先构造小规模、数值不规整的例子，一眼能看出差异。

陷阱

  • 只说「显然最优」，没有交换论证
  • 贪心指标选错（区间调度按开始时间）
  • 把 0-1 背包当成分数背包用贪心
  • 用大规模例子，反而看不清差异

图算法 · 本专题 4 题

本专题常见问法：选择最短路算法并手算距离；求 MST 或判断连通性；判断 DAG 并给出拓扑序。看到这类问法先归到本专题，再套下面的固定步骤，不要从题目细节重新想。

固定步骤

  1. 先看有无负权：有负权用 Bellman-Ford/SPFA
  2. 无权图用 BFS
  3. Dijkstra 每次取未确定点中 dist 最小的，松弛邻边
  4. 记录前驱以便回溯路径
  5. 多源最短路用 Floyd O(n³)

技巧

最短路算法选择

Dijkstra 一旦确定某点最短就不能再更新，负权会破坏这个前提。

最小生成树

MST 不唯一（等权边可换），但总权值唯一。

陷阱

  • Dijkstra 用于负权图
  • 松弛时忘记取 min
  • 把边数当顶点数，复杂度写错
  • 选边时未判环

字符串匹配 · 本专题 5 题

本专题常见问法：求 next/π 数组，或说明匹配过程；选择字符串数据结构或分析复杂度。看到这类问法先归到本专题，再套下面的固定步骤，不要从题目细节重新想。

固定步骤

  1. 先明确题目用哪种定义（π 还是 next）
  2. π[0]=0；递推时用上一个 π 值回退
  3. 失配时 j = π[j−1] 继续比较，不回退主串
  4. 匹配成功后可继续用 π 找重叠出现
  5. 复杂度 O(n+m)

技巧

KMP 与前缀函数

π 与 next 差一位，做题前先看题目给的定义。

哈希与 Trie

单哈希可能被构造冲突，重要场合用双哈希。

陷阱

  • π 与 next 混用，差一位导致全错
  • 失配时主串指针回退，退化成朴素匹配
  • π 计算时忘记 while 回退
  • 单哈希在大数据下被卡
