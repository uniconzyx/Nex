3.4 移动语义与右值引用
C++11 · 概念讲解 · 掌握度 45
🎯 学习目标📖 概念 ⚠️ 避坑💻 示例🎤 面试
🎯 本节目标
① 说出左值/右值的判定规则 ② 理解移动构造函数为何能「偷资源」 ③ 会用 std::move 写出零拷贝的返回 ④ 区分移动语义与拷贝语义的开销
📖 核心概念
移动语义的本质是资源所有权的转移：把临时对象内部的堆指针「偷」过来，避免一次深拷贝。
class Buffer { public: // 移动构造：偷走指针，置空来源 Buffer(Buffer&& other) noexcept : data_(other.data_), size_(other.size_) { other.data_ = nullptr; // ★ 关键：来源置空 other.size_ = 0; } private: int* data_; size_t size_; };
注意喵：std::move 本身不移动任何东西，它只是把左值「转换」成右值引用。移动之后别再使用原对象！
