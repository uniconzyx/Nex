# dm-ch02 学习目标：集合、关系与函数（离散世界的"名词"与"动词"）

> 一句话引出：命题逻辑把"话"写成了公式；这一章把"东西"和"东西之间的关系"写成对象——集合是容器，关系是容器之间的对应，函数是带"唯一确定性"的特殊关系。

## 一、知识目标

1. 掌握集合的两种表示（列举法 / 描述法）、元素与集合的属于关系、子集/真子集/幂集（$2^n$ 个元素）、笛卡尔积 $A×B$ 的序对结构。
2. 掌握四种基本运算（并、交、差、补）与对称差，能用文氏图辅助推理，能由容斥原理推出 $|A∪B|=|A|+|B|-|A∩B|$ 并推广到三集合。
3. 理解关系作为 $A×B$ 的子集：会判关系的性质（自反、对称、反对称、传递），会把等价关系拆成等价类并对应到一个划分，理解偏序与哈斯图。
4. 掌握函数作为"单值、全域"的特殊关系：单射 / 满射 / 双射的判别，复合 $f∘g$ 与逆 $f^{-1}$ 的存在条件（双射才有逆函数）。
5. 建立基数（势）直觉：有限集、可数无限（$\mathbb{N},\mathbb{Z},\mathbb{Q}$）、不可数（$\mathbb{R}$），能用康托尔对角线法证明 $\mathbb{R}$ 不可数，理解"是否存在比可数更大的无穷"。

## 二、能力目标

- 拿到"某集合有多少子集""多少个满射"这类计数题，能拆成容斥 / 乘法原理 / 斯特林数，不靠乱凑。
- 能给定一个关系矩阵或关系图，机械化地判出自反/对称/传递并据此归类（等价 or 偏序）。
- 能区分"关系是函数吗""是单射吗""有逆吗"三连问，并在代码里用哈希/数组快速验证（如判数组元素互异 = 判单射）。
- 能用 C 实现幂集枚举、关系闭包、等价类划分、双射判定这四类小程序（本章 examples 全部可编译运行）。

## 四、前置

- `dm-ch01` 命题逻辑与谓词逻辑（把"谓词"落到集合上：谓词 $P(x)$ 的论域就是一个集合，满足 $P$ 的元素构成子集）
- 后续衔接：
  - `dm-ch03` 图论（关系是边的集合，函数是特殊的边集合）
  - `data-ch06` 数据分析建模（集合运算对应 pandas 的交并差、去重、分组聚合）
  - `database` 关系代数（并/差/笛卡尔积/选择/投影就是本章集合运算的数据库版本）
