# 关系与性质：等价、偏序与闭包

## 1. 背景/动机

"关系"描述两个集合元素之间如何对应。程序里的"外键""依赖""关注/被关注""小于等于"全是关系。把关系当成 $A×B$ 的子集来看，性质就可以机械判定，不用靠感觉。

工程上最常被问的是两类：哪些是"等价"（能分组去重）、哪些是"偏序"（能排依赖、做拓扑排序）。判错一类，分组逻辑或构建顺序就全乱。

## 2. 定义/要点

关系是离散数学里"动词"的部分——它描述两个集合的元素之间"谁连着谁"。把关系想成 `A×B` 的一个子集，就立刻有了可计算的抓手：用 0/1 矩阵存、用邻接表存、用并查集存，全看关系的规模和你要做什么运算。自反/对称/反对称/传递这四个性质，本质上是在问"这个关系长什么样"：自反要求每个元素都和自己相连；对称要求"连了就互相连"；反对称恰恰相反，要求"若 a 连 b 且 b 连 a，则 a=b"；传递要求"连串的间接连接也要直接连上"。等价关系和偏序是其中最重要的两类：等价关系（自反+对称+传递）把全集切成互不相交的等价类，构成一个划分；偏序（自反+反对称+传递）允许"不可比"的元素共存，是任务调度、依赖管理的数学语言。闭包则是"缺什么补什么"——自反闭包、对称闭包、传递闭包分别把缺失的性质补满，其中传递闭包（Warshall 算法）在工程里用得最多。

### 2.1 关系即子集

$R\subseteq A×B$。常用三种表示：
- 集合：$\{(1,1),(1,2)\}$
- 矩阵（$n×m$，$R_{ij}=1$ 表示 $a_i$ 与 $b_j$ 相关）
- 有向图（顶点是元素，边是序对）

### 2.2 自反 / 对称 / 反对称 / 传递

对关系 $R$ 在集合 $A$ 上：

| 性质 | 形式化条件 | 直觉 |
|---|---|---|
| 自反 | $\forall x\in A,\ (x,x)\in R$ | 每个点都有自环 |
| 对称 | $(x,y)\in R\Rightarrow(y,x)\in R$ | 边双向 |
| 反对称 | $(x,y),(y,x)\in R\Rightarrow x=y$ | 异点之间至多单向 |
| 传递 | $(x,y),(y,z)\in R\Rightarrow(x,z)\in R$ | 路径可压缩 |

注意**对称与反对称不矛盾**：相等关系两者都满足（只有自环）；空关系两者都满足（没有任何异点边）。

### 2.3 等价关系 → 等价类 → 划分

- **等价关系** = 自反 + 对称 + 传递。
- 元素 $a$ 的**等价类** $[a]=\{x\mid (a,x)\in R\}$，所有等价类两两不交、并起来是整个 $A$——即一个**划分**。
- 等价类的个数 = 划分的块数。这正是"按某属性分组"的数学本质。

### 2.4 偏序与哈斯图

- **偏序** = 自反 + 反对称 + 传递（记作 $\preceq$）。
- **哈斯图**：省略自环（自反）和传递推导出的长边（传递），只画"直接覆盖"的边，于是层次一目了然。
- 偏序上的**极大/极小元、最大/最小元、上界/下界、上确界/下确界**是依赖排序（拓扑）的理论基础。

### 2.5 闭包

- 自反闭包 $r(R)$：补上所有缺失的自环。
- 对称闭包 $s(R)$：补上每条边的反向边。
- 传递闭包 $t(R)$：反复加"可压缩"的边直到稳定（Warshall 算法 $O(n^3)$）。

```text
R = {(1,2),(2,3)}          传递闭包 t(R) 还要补上 (1,3)
因为 (1,2)∧(2,3) ⇒ (1,3)
```

传递闭包的 Warshall 算法把"间接可达"逐层补全，核心是一句三重循环：用第 k 个节点做"中转"，只要 `i→k` 且 `k→j` 可达，就把 `i→j` 标记可达。

```c
/* Warshall：reach[i][j]=1 表示 i 可达 j；原地更新也能正确求值 */
void warshall(int r[4][4], int n) {
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (r[i][k] && r[k][j]) r[i][j] = 1;
}
/* 注意 k 必须是最外层：先让所有"经 1 步中转"稳定，再开放"经 2 步中转"，否则会漏掉间接路径 */
```

## 3. 可运行代码

下面两段代码分别演示"用矩阵判关系性质"和"用并查集做等价类划分"。第一段把关系存成 0/1 矩阵，按定义逐项检查自反（对角线全 1）、对称（`R[i][j]==R[j][i]`）、传递（任意 i,j,k 若 `R[i][j]` 且 `R[j][k]` 则 `R[i][k]`）。第二段用并查集把"互相连通"的元素归到同一代表元——这正是等价类的动态维护版，注意 `find` 必须爬到根，否则会漏掉间接等价（见本章 exercises 的 fix_error 题）。

### 3.1 用矩阵判关系性质（C）

```c
/* 给定 n×n 关系矩阵 m，判定自反/对称/传递。
   传递用"找 (i,j),(j,k) 却缺 (i,k)"的暴力法，n 小即可 */
#include <stdio.h>
int m[4][4], n = 4;
int reflexive(){ for(int i=0;i<n;i++) if(!m[i][i]) return 0; return 1; }
int symmetric(){ for(int i=0;i<n;i++) for(int j=0;j<n;j++)
                   if(m[i][j]!=m[j][i]) return 0; return 1; }
int transitive(){
    for(int i=0;i<n;i++) for(int j=0;j<n;j++) if(m[i][j])
        for(int k=0;k<n;k++) if(m[j][k] && !m[i][k]) return 0;
    return 1;
}
int main(void){
    printf("reflexive=%d symmetric=%d transitive=%d\n",
           reflexive(), symmetric(), transitive());
    return 0;
}
```

### 3.2 等价类划分（Python）

```python
def equivalence_classes(rel, A):
    # rel: set of (x,y)，假设已确认等价关系
    parent = {x: x for x in A}
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]; x = parent[x]
        return x
    for x, y in rel:
        parent[find(x)] = find(y)        # 并查集合并
    groups = {}
    for x in A:
        groups.setdefault(find(x), []).append(x)
    return list(groups.values())

print(equivalence_classes({(1,1),(2,2),(3,3),(1,2),(2,1)}, {1,2,3}))
# -> [[1, 2], [3]]   : 1 与 2 等价，3 自成一类
```

## 三视角解析

### 🧑‍💻 程序员视角
等价类 = `GROUP BY`（按某列分组），偏序 = 任务依赖（拓扑排序决定执行顺序），传递闭包 = 可达性（`Floyd`/`Warshall`）。一个真实坑：只比较"直接父节点"就判断等价，会漏掉间接等价——并查集的 `find` 必须爬到根。权限系统里"相同权限的角色"就是等价类，可以合并成模板减少冗余（见本章 project）。

### 🎓 博士生视角
等价类构成**商集** `A/R`，是范畴论中余等化子（coequalizer）的雏形；偏序集（poset）上的上/下确界则通向格论（lattice）。划分与等价是一体两面：一个等价关系唯一决定一个划分，反之亦然。

### 📚 考研者视角
四类性质判定、等价类个数、偏序的哈斯图是常考；闭包尤其爱考 Warshall（手算传递闭包的步骤必须熟）。注意"反对称"不等于"不对称"，很多题就栽在这。
