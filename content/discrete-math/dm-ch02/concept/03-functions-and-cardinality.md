# 函数与基数：单射满射、复合逆与无穷的层级

## 1. 背景/动机

函数是"每个输入恰好对应一个输出"的特殊关系——"单值性"把一般关系收紧成可计算对象。程序员写的每个函数、每个哈希映射、每个字典查表，都是函数。而"基数"（势）回答一个反直觉的问题：两个无穷哪个更大？这是计算机科学里"可计算/不可判定"的理论地基。

## 2. 定义/要点

函数是一段"确定性映射"：每个输入恰好对应一个输出。把它看成关系，就是要求"单值"（一个 x 不能连出两个不同的 y）且"全域"（每个 x 都有 y 接住）。单射/满射/双射是函数的三种"满不满、重不重"体检：单射（injective）保证不同输入映射到不同输出，工程上就是"判数组元素互异"；满射（surjective）保证值域每个元素都被覆盖，对应"测试覆盖了所有分支"；双射（bijective）既单又满，于是存在逆映射——这正是无损编码、序列化能"原样还原"的底层原因。复合 `f∘g` 把两个映射串起来，逆 `f⁻¹` 只在双射时干净存在（否则要么没覆盖、要么多对一）。基数（势）把"多少元素"推广到无穷：有限集比大小看数字，无穷集比大小要看"能否一一对应"——`N,Z,Q` 都能和自然数一一对应（可数），`R` 不能（不可数），康托尔对角线法正是那个"构造一个注定不在列表里"的巧妙证明，而康托尔定理进一步说明"没有最大的无穷"。

### 2.1 函数 = 单值 + 全域的关系

$f: A\to B$ 要求：① 全域（每个 $a\in A$ 都有像）；② 单值（每个 $a$ 只有唯一像 $f(a)$）。多了"单值"这一条，关系才变成函数。

### 2.2 单射 / 满射 / 双射

| 类型 | 条件 | 直觉 |
|---|---|---|
| 单射（一一） | $f(x)=f(y)\Rightarrow x=y$ | 不同输入映射到不同输出（不撞车）|
| 满射 | $\forall b\in B,\exists a,\ f(a)=b$ | 值域铺满整个 $B$ |
| 双射 | 单射且满射 | 两集合"一样大"，存在逆 |

有限集上：若存在单射 $A\to B$ 则 $|A|\le|B|$；双射存在当且仅当 $|A|=|B|$。

### 2.3 复合与逆

- 复合 $(f\circ g)(x)=f(g(x))$，注意顺序：先 $g$ 后 $f$。
- **逆函数存在 $\Leftrightarrow f$ 是双射**。非双射（如非单射）的逆不存在，因为反推会得到"一对多"。

### 2.4 基数谱：可数 vs 不可数

- **可数无限**：能与 $\mathbb{N}$ 建立双射（一一列举）。$\mathbb{N},\mathbb{Z},\mathbb{Q}$ 都可数。
- **不可数**：$\mathbb{R}$ 不可数——比可数"更大"。
- **康托尔对角线法**：假设 $(0,1)$ 可数，列出所有小数 $r_1,r_2,\dots$；构造 $x$ 使第 $i$ 位 $\neq r_i$ 的第 $i$ 位，则 $x$ 不在列表中，矛盾。故 $(0,1)$ 不可数。

```text
r1 = 0.1 3 5 7 ...
r2 = 0.2 4 6 8 ...
r3 = 0.9 1 1 1 ...
         ↓ 每位取"不等于对角线上的数字"
x  = 0.2 5 2 ...   （保证 x ≠ 任一个 r_i）
```

### 2.5 康托尔定理：没有最大的基数

对任意集合 $A$，$|\mathcal{P}(A)| > |A|$（不存在 $A\to\mathcal{P}(A)$ 的满射，用"对角线"同构证明）。所以基数层级 $\aleph_0 < 2^{\aleph_0} < 2^{2^{\aleph_0}}<\dots$ 无限上升。

"可数"不是纸上谈兵——只要能写出 `N→Z` 的双射，就证明了整数可数。下面这个配对把每个整数映射到唯一的自然数（$0→0, 1→1, -1→2, 2→3, -2→4, \dots$）。

```c
/* 整数到自然数的双射枚举（第 i 个整数）*/
int zigzag(int i) {            /* i: 0,1,2,3,4,5 ... */
    return i % 2 ?  (i+1)/2 : -(i/2);   /* 0→0,1→1,2→-1,3→2,4→-2,5→3 ... */
}
/* 反过来每个整数也有唯一自然数编号，这就是"可数"的构造性证明 */
```

## 3. 可运行代码

下面两段代码分别演示"判单射/满射/双射"和"康托尔对角线"。第一段用"是否所有输出都被占用、是否有两个输入撞同一个输出"来判定函数类型：输出有重复 → 非单射；输出没覆盖全部值域 → 非满射；两者都满足 → 双射。第二段按"第 i 行第 i 位取反"构造一个新串，它注定和列表里每一行都不同，从而证明实数不可数。

### 3.1 判单射/满射/双射（C）

```c
/* 给定 f[0..n-1] 把域 {0..n-1} 映到 {0..m-1}，判定三类。
   单射用"值出现次数≤1"；满射用"每个目标值都被命中" */
#include <stdio.h>
int f[] = {0,1,2,0};          /* 非单射（0 重复），非满射（缺 3）*/
int n = 4, m = 4;
int main(void){
    int seen[8]={0}, hit[8]={0}, inj=1, sur=1;
    for(int i=0;i<n;i++){ if(seen[f[i]]++) inj=0; hit[f[i]]=1; }
    for(int b=0;b<m;b++) if(!hit[b]) sur=0;
    printf("injective=%d surjective=%d bijective=%d\n", inj, sur, inj&&sur);
    return 0;
}
```

### 3.2 康托尔对角线（Python 演示"构造一个不在列表里的数"）

```python
def diagonal_escape(rows):
    # rows: 每个是 0/1 串；返回与所有行都不同的串
    return ''.join('1' if r[i] == '0' else '0' for i, r in enumerate(rows))

print(diagonal_escape(["0101", "1100", "1010", "1111"]))
# -> "0010"  第 i 位保证与第 i 行第 i 位不同 → 不在原列表中
```

## 三视角解析

### 🧑‍💻 程序员视角
哈希函数追求"近似单射"（少碰撞）；字典查表本身就是函数（键→值）；只有双射才能无损编解码——Base64、游程编码、压缩能还原，靠的就是编/解码互为逆函数。一个真实坑：哈希几乎不可能是真单射（桶数远小于可能 key 数），于是工程上用链地址/开放寻址兜底碰撞，而不是假装碰撞不存在。

### 🎓 博士生视角
可数/不可数之分直接通向"图灵机可枚举 vs 实数不可枚举"，是判定性理论的入口：实数不可数 ⇒ 存在图灵机永远枚举不到的实数。康托尔定理 `|A| < |P(A)|` 还暗含了"不存在最大基数"，与罗素悖论同源地提醒我们"全体集合的集合"不能成集。

### 📚 考研者视角
单射/满射/双射计数是高频大题：比如"从 n 元集到 m 元集的满射数"要用容斥去减掉"漏掉某个目标"的情况；"双射数"则是 `m!`（当 n=m）。这些题本质都是把计数套回本章的集合与容斥工具。
