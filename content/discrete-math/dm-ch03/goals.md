# dm-ch03 学习目标：图论（离散世界的"关系网络"）

> 一句话引出：集合与关系是"点与点之间"的二元对应；图论把这些对应画成"顶点 + 边"，把"可达性 / 最短 / 连通 / 环"变成可计算的对象——它是社交网络、路由、调度、依赖分析的数学底座。

## 一、知识目标

1. 掌握图的基本要素（顶点、边、有向/无向、加权）、度数与**握手定理**（无向图度数和 = 2×边数），以及三种存储（邻接矩阵 / 邻接表 / 边表）的取舍。
2. 理解路径、回路、连通性：能区分连通 / 强连通 / 弱连通，会用 DFS 求连通分量，理解"可达性"如何变成矩阵闭包。
3. 掌握欧拉图（一笔画：连通且所有顶点偶度）与哈密顿图（经过每点恰好一次）的区别，知道欧拉有充要条件、哈密顿只有充分条件（无高效判定）。
4. 掌握树与森林、最小生成树（Kruskal 贪心 + 并查集 / Prim 加点）、单源最短路（Dijkstra 非负权 / Bellman-Ford 可负权）、拓扑排序（DAG 线性化），并能在代码里实现。
5. 了解平面图与四色定理、二分图的判定（二染色），以及图论如何落地到路由、编译依赖、社交网络等工程场景。

## 二、能力目标

- 拿到邻接矩阵 / 邻接表，能机械化地算出每个顶点度数，并立刻用握手定理验证"度数和是不是偶数"。
- 给定一个图，能判断它有几个连通分量、是否是欧拉图、是否二分，并用 BFS/DFS 写出对应程序（本章 examples 全部可编译运行）。
- 面对"路由最短路 / 网络最小连通代价 / 任务依赖排序"这类问题，能把它建模成最短路 / 最小生成树 / 拓扑排序，而不是手写一堆 if。
- 能用 C 实现 DFS 连通分量、BFS 最短距离、Dijkstra、Kruskal（并查集）、拓扑排序、二分染色、环检测这七类小程序。

## 三、三视角导航

| 视角 | 本章重点 |
|---|---|
| 🧑‍💻 程序员 | 邻接矩阵 vs 邻接表（空间/遍历取舍）；DFS/BFS 是图算法的"hello world"；Dijkstra 路由、Kruskal 骨干网、拓扑排序 = 依赖/DAG、二分染色 = 冲突分组 |
| 🎓 博士生 | 欧拉 vs 哈密顿是 P vs NP 的微型预演（欧拉有线性判定、哈密顿是 NP 完全）；平面图四色定理与对偶图；图同构为何至今无高效算法 |
| 📚 考研者 | 握手定理、连通分量数、欧拉图判定、最小生成树与最短路径的模板题都是固定送分；常与 ch01 的逻辑、ch02 的关系/函数串联 |
