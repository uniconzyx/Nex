# 路径、连通性与欧拉/哈密顿：图里的"走法"

## 1. 背景/动机

知道了"图长什么样"，下一步自然要问：从一个点能走到另一个点吗？最少走几步？能不能不重复地走完所有边（一笔画）？能不能不重复地经过所有点（旅行商）？这一节就是图论里最经典的"可走性"问题——连通性决定"能不能到达"，欧拉/哈密顿决定"怎么走才漂亮"。

工程映射极直接：DFS/BFS 是爬虫与可达性分析的基础，连通分量是"孤岛社区"检测，欧拉图是"邮差送信不走回头路"的模型，哈密顿则是"访问每个城市恰好一次"的 TSP。

## 2. 定义/要点

"可达性"是连通性的内核：若从 u 能顺着边走到 v，就说 v 从 u 可达。把"可达"关系做传递闭包（见 ch02 Warshall），就得到一张"谁到得了谁"的矩阵。连通分量则是"互相都可达"的最大顶点集合——社交网络里的"孤岛小圈子"就是连通分量。欧拉和哈密顿是两种"走遍"目标，但难度天差地别：欧拉要求"每条边恰好一次"，有**漂亮的充要条件**（连通且全偶度），能被线性判定；哈密顿要求"每个顶点恰好一次"，至今**没有高效判定算法**（它是 NP 完全问题的原型之一）。这个对比是理解 P vs NP 最直观的入口：同一个"走遍"的直觉，一种有公式、一种只能暴力。

### 2.1 路径、回路与连通性

- **路径**：顶点序列 `v₀,v₁,…,v_k`，相邻两点有边；**长度**=边数 k。
- **简单路径**：顶点不重复；**回路**：`v₀=v_k` 且长度 ≥1。
- **连通（无向）**：任意两点间都有路径。**连通分量**=极大的连通子图。
- **强连通（有向）**：任意两点互相可达；**弱连通**=忽略方向后连通。

### 2.2 连通分量与强连通

DFS/BFS 每从"未访问点"出发一次，就扫出一个连通分量。有向图的强连通分量（SCC）用 Kosaraju 或 Tarjan 算法，是编译（基本块）、依赖环检测的基石。分量数 = "图中互不连通的岛屿数"，社交网络去重、孤岛检测都靠它。

```text
例：6 顶点，边 (0-1)(1-2)(3-4)，顶点 5 孤立
连通分量 = {0,1,2}、{3,4}、{5}  → 共 3 个
```

### 2.3 欧拉图与一笔画

- **欧拉回路**：从某点出发、每条边恰走一次、回到起点。**欧拉图判定（无向）**：图连通且每个顶点度数为偶数。
- **欧拉路径（非回路）**：恰有一个起点奇度、一个终点奇度、其余偶度。
- 有向图条件：基图弱连通，且每个顶点 `出度 = 入度`（回路）或恰一个 `入=出+1`、一个 `出=入+1`（路径）。

"七桥问题"就是这个：柯尼斯堡七座桥无法一笔画，因为四个顶点全是奇度。

### 2.4 哈密顿图与旅行商

- **哈密顿回路**：经过每个顶点恰好一次并回到起点。**没有简洁充要条件**，只有充分条件（如 Dirac：n≥3 且每点度数 ≥ n/2 则必含哈密顿回路）。
- **旅行商问题 TSP**：在带权完全图上求最短哈密顿回路，是 NP 完全的典型代表——只能近似或暴力，无法保证高效精确解。
- 欧拉 vs 哈密顿：前者"管边"有公式，后者"管点"无公式，是 P 与 NP 难度的微型对照。

## 3. 可运行代码

下面两段代码把"DFS 求连通分量"和"拓扑排序（DAG 线性化，见 ch02 §2.4 偏序）"落到可运行程序。重点看"递归/队列如何把'可达性'变成机器能算的东西"：DFS 用递归栈顺边蔓延，拓扑排序用 Kahn 算法按入度剥洋葱。所有输出来自真实编译/运行，可对照本章 exercises 的连通性 / 拓扑题。

### 3.1 DFS 连通性 / 连通分量（C）

```c
/* ex-style：DFS 数连通分量。6 顶点, 边 (0-1)(1-2)(3-4), 顶点5孤立 → 3 个分量 */
#include <stdio.h>
int adj[6][6]={0}, vis[6]={0};
void dfs(int u, int n){
    vis[u]=1;
    for(int v=0;v<n;v++) if(adj[u][v] && !vis[v]) dfs(v,n);
}
int main(void){
    int n=6;
    int e[][2]={{0,1},{1,2},{3,4}};
    int m=3;
    for(int k=0;k<m;k++){ adj[e[k][0]][e[k][1]]=1; adj[e[k][1]][e[k][0]]=1; }
    int comp=0;
    for(int i=0;i<n;i++) if(!vis[i]){ comp++; dfs(i,n); }
    printf("components=%d\n", comp);
    return 0;
}
```

### 3.2 拓扑排序（Kahn，Python）

```python
from collections import deque
n = 6
adj = {0:[1,2], 1:[3], 2:[3,5], 3:[4], 4:[], 5:[]}
deg = {i:0 for i in range(n)}
for u in adj:
    for v in adj[u]:
        deg[v] += 1
q = deque([i for i in range(n) if deg[i]==0])
order = []
while q:
    u = q.popleft(); order.append(u)
    for v in adj[u]:
        deg[v] -= 1
        if deg[v] == 0:
            q.append(v)
print("topo:", order)   # [0, 1, 2, 3, 5, 4]（结果不唯一）
```

## 三视角解析

### 🧑‍💻 程序员视角

DFS/BFS 是图算法的"hello world"，它们的差别在"栈 vs 队列"：DFS 一杆子扎到底（找环、连通分量、回溯搜索），BFS 层层扩散（最短路、分层遍历）。拓扑排序 = 任务依赖的合法顺序，只要图有环就排不出来（构建系统报"循环依赖"就是它）。连通分量检测在代码里就是"从每个未访问点 BFS/DFS 一次"，计数器 +1。

### 🎓 博士生视角

欧拉与哈密顿的对比是计算复杂性理论最直观的引子：前者属于 P（有线性判定），后者是 NP 完全的始祖之一（哈密顿回路 ∈ NPC）。强连通分量把有向图压成 DAG，是"化简后再分析"的典范。TSP 的不可近似下界（除非 P=NP）也是从这里延伸出去的。

### 📚 考研者视角

欧拉图判定（连通 + 全偶度）是必考送分题；哈密顿只考充分条件、不考必要。连通分量数、拓扑排序结果是否唯一、DFS/BFS 的层数与路径长度关系，都是固定题型。常与 ch01 的逻辑（可满足/不可满足）、ch02 的偏序（拓扑排序即偏序线性化）串成综合题。
