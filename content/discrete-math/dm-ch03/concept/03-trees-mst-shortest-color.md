# 树、最小生成树与最短路：图里的"最优化"

## 1. 背景/动机

连通性回答"能不能到"，最优化回答"怎么到最好"。本章三件套——树（无环连通结构）、最小生成树（用最小总代价把大家连起来）、最短路径（从源头到各处怎么走最近）——是图论在工程里最值钱的部分：骨干网布线、地图导航、依赖调度、资源分配全都是它们的变体。

树还把"层次 / 父子 / 递归"这种无处不在的结构统一了：文件系统、DOM、组织架构成、决策树，本质都是树。

## 2. 定义/要点

树是无环连通图的"最小骨架"：n 个顶点恰好 n−1 条边，删任何一条就不连通、加任何一条就成环——这种"恰好卡在临界"的性质让树成为"连接一切的最低代价结构"。最小生成树（MST）则是把"用最小总边权连通所有点"变成可计算：Kruskal 按边权从小到大贪心、用并查集跳过成环边（正是 ch02 等价类/并查集的复用）；Prim 从一点出发不断"摘最便宜的相邻边"。两者都属于贪心，且对 MST 这种问题贪心恰好最优（拟阵结构保证）。最短路径里 Dijkstra 是"非负权版 BFS 升级"——把队列换成按距离出队的优先队列；一旦允许负权，就必须用 Bellman-Ford 反复松弛（并顺便抓负环）。二分图染色则把"能否两两不冲突分组"变成二染色问题（着色数 ≤2）。

### 2.1 树与森林

- **树**：连通且无环的无向图；等价刻画：n 顶点 n−1 边、任意两点唯一路径、删任一边不连通。
- **森林**：若干棵树的并（每个连通分量都是树）。
- **生成树**：原图的生成子图且是树；**最小生成树（MST）**：边权之和最小的生成树。
- 应用：组织架构、语法树、Huffman 编码树、并查集的底层结构。

### 2.2 最小生成树（Kruskal / Prim）

- **Kruskal**：边按权升序，逐条加入，若成环（两端已在同一并查集）则跳过；加到 n−1 条为止。`O(E log E)`。
- **Prim**：从任意点开始，每次摘"连接已选集合与未选集合的最小权边"。`O(E log V)`（二叉堆）。
- MST 唯一性：当所有边权互异时 MST 唯一；否则可能有多棵，但**总权相同**。

### 2.3 最短路径（Dijkstra / Bellman-Ford）

- **Dijkstra**（非负权）：维护"已确定最短路的顶点集"，每次取距离最小的未确定点松弛其邻居；本质是带权 BFS。`O((V+E) log V)`。
- **Bellman-Ford**（可负权）：对所有边松弛 V−1 轮，第 V 轮还能松弛则说明有**负权环**。`O(VE)`。
- **Floyd-Warshall**：所有点对最短路，基于传递闭包思想（见 ch02 §2.5），`O(V³)`。

```text
例：5 顶点，边 0-1:4, 0-2:1, 2-1:2, 1-3:1, 2-3:5, 3-4:3
Dijkstra 从 0：dist = [0, 3, 1, 4, 7]
```

### 2.4 平面图与四色定理

- **平面图**：能画在平面上使边互不相交的图；**欧拉公式** `V − E + F = 2`（V 顶点、E 边、F 面）。
- **四色定理**：任何平面图的区域可用至多 4 种颜色着色使相邻区域不同色（1976 年靠计算机辅助证明）。
- **二分图**：可用 2 色着色的图（二染色），等价于"不含奇数长度环"。判定用 BFS/DFS 二染色即可。

## 3. 可运行代码

下面两段代码把"Kruskal（并查集）"和"Dijkstra"落到可运行程序。重点看"贪心 + 并查集"如何把"最小连通代价"变成机械步骤，以及"优先取最近点"如何把 BFS 推广到带权图。所有输出来自真实编译/运行，可对照本章 exercises 的 MST / 最短路题。

### 3.1 Kruskal 与并查集（C）

```c
/* ex-style：Kruskal 求 MST。6 顶点, 边(权)见下, 并查集跳过成环边 */
#include <stdio.h>
int parent[6];
int find(int x){ while(parent[x]!=x) x=parent[x]; return x; }
int main(void){
    int n=6;
    int edges[][3]={{0,1,4},{0,2,4},{0,3,1},{1,3,2},{2,4,3},{3,4,2},{3,5,3},{4,5,1}};
    int m=8;
    for(int i=0;i<n;i++) parent[i]=i;
    for(int i=0;i<m;i++) for(int j=i+1;j<m;j++)
        if(edges[i][2]>edges[j][2]){ int t[3]; for(int k=0;k<3;k++){t[k]=edges[i][k];edges[i][k]=edges[j][k];edges[j][k]=t[k];} }
    int total=0, cnt=0;
    for(int i=0;i<m && cnt<n-1;i++){
        int u=edges[i][0],v=edges[i][1],w=edges[i][2];
        int ru=find(u),rv=find(v);
        if(ru!=rv){ parent[ru]=rv; total+=w; cnt++; printf("(%d,%d,%d) ",u,v,w); }
    }
    printf("\nMST weight=%d\n", total);
    return 0;
}
```

### 3.2 Dijkstra（Python）

```python
import heapq
n = 5
g = {0:[(4,1),(1,2)], 1:[(1,3)], 2:[(2,1),(5,3)], 3:[(3,4)], 4:[]}
dist = [float('inf')] * n
dist[0] = 0
pq = [(0, 0)]
while pq:
    d, u = heapq.heappop(pq)
    if d > dist[u]:
        continue
    for w, v in g[u]:
        if d + w < dist[v]:
            dist[v] = d + w
            heapq.heappush(pq, (dist[v], v))
print("dist from 0:", dist)   # [0, 3, 1, 4, 7]
```

## 三视角解析

### 🧑‍💻 程序员视角

Kruskal 是"并查集的最佳广告"——判环就是判两端是否在同一个集合（见 ch02 ex05 等价类）。Dijkstra 是路由协议 OSPF 的核心、地图 App 的底层；一旦有负权（如"绕路返现"）就必须换 Bellman-Ford。二分染色在代码里就是"BFS 交替标色，撞色即非二分图"，用来检测冲突分组（如课程排课、寄存器分配）。

### 🎓 博士生视角

MST 的贪心最优性由**拟阵（matroid）**结构保证，这是"何时贪心一定对"的通用框架。四色定理是数学史上第一个大规模依赖计算机证明的定理，引发过"这算不算证明"的哲学争论。二分图的二染色与"图是奇数环-free"的等价，是结构图论里最干净的对偶之一。

### 📚 考研者视角

MST 的 Kruskal/Prim 模板、Dijkstra 的松弛步骤、二分图判定都是算法/离散固定大题，且常与 ch02 的并查集、偏序联动。常考变体：求"次小生成树""最短路的条数""判断二分图"——套模板加一点变通即可，务必把并查集和优先队列写熟。
