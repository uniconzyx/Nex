# clang-u01 · 易错点

1. **把数组名当指针用 `sizeof`** —— `sizeof(a)` 在数组所在作用域得整个数组大小（如 20），但一旦 `a` 退化为函数参数，`sizeof(a)` 变成指针大小（8）。**正确写法**：把长度作为参数显式传入 `void f(int *a, size_t n)`。

2. **混淆 `a`、`&a`、`&a[0]` 的步长** —— 三者地址值相同，但 `&a` 的类型是 `int (*)[N]`，`&a + 1` 会跳过**整个数组**（N 个元素），而 `a + 1` 只跳过 1 个元素。**正确写法**：需要逐元素遍历用 `a + i`；需要「跳到数组之后」用 `&a + 1`。

3. **二维数组用 `int **` 接收** —— `int m[3][4]` 的内存是连续的「数组的数组」，不是「指针的指针」。`int **p = m;` 类型不兼容且解引用会错。**正确写法**：用数组指针 `int (*p)[4] = m;`，或函数参数写 `void f(int p[][4])`。

4. **free 之后不置 NULL** —— `free(p)` 只是归还内存，`p` 的值不变，仍指向已释放区域；再次 `free(p)` 就是 double free，会破坏分配器。**正确写法**：`free(p); p = NULL;`——`free(NULL)` 是安全空操作。

5. **返回局部变量地址** —— `int *f(void){ int x = 1; return &x; }` 返回后栈帧失效，得到悬垂指针。**正确写法**：返回**值**（拷贝）、返回 `static`（注明不可重入）、或让调用方传入缓冲区。

6. **把 `char *s = "abc"` 当可写缓冲** —— 字符串字面量位于**只读段**，`s[0] = 'X'` 会触发段错误。**正确写法**：需要修改就用数组副本 `char buf[] = "abc";`（栈上可写），只读场景声明为 `const char *s = "abc";`。

7. **用指针相减求字节数** —— 指针相减得到的是**元素个数**（类型 `ptrdiff_t`），不是字节数。`&a[4] - &a[1]` 是 `3`。**正确写法**：要字节数先转 `char *`：`(char*)&a[4] - (char*)&a[0]`。

8. **跨对象比较指针大小** —— `p < q` 只在两者指向**同一数组**（含尾后位置）时有定义，否则是 UB。**正确写法**：不同对象之间只用 `==` / `!=` 判断是否同一对象，不要比大小。

9. **`int (*fp)(int)` 漏写括号** —— 漏掉括号就变成「返回 `int*` 的函数声明」。**正确写法**：记住括号不可省，并用 `typedef int (*fp_t)(int);` 化简。

10. **把 `volatile` 当线程同步用** —— `volatile` 只阻止编译器优化读写，**不保证原子性、不保证内存序**。多线程共享变量应用 C11 `<stdatomic.h>` 的 `atomic_int` 或互斥量。
