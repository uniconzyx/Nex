# clang-u01 · 指针与地址运算 · 学习目标

> **先修**：无（本单元是 C 语言独立模块的入口，只需基础语法与变量概念）。
> **衔接**：clang-u02 动态内存（malloc/free）、clang-u03 结构体（结构体指针与 `->`）、clang-u07 多文件与链接。
> **面试权重**：★★★★★ —— 指针是 C 面试的绝对核心，几乎每场必问。

## 学完你能做到

1. **说清「指针是什么」**：指针是「存放地址的变量」，其值是一个内存地址，类型决定了从这个地址读多少字节、按什么方式解释。
2. **区分 `a`、`&a`、`&a[0]`**：理解数组名退化（decay）的规则与例外，能准确说出三者的类型与步长差异。
3. **手算指针运算**：`p + n` 实际前进 `n * sizeof(*p)` 字节；能计算指针相减、指针比较、跨类型指针转换的结果。
4. **不靠背结论判断 `sizeof`**：能解释为什么 `sizeof(arr)` 在函数内失效（参数已退化为指针）。
5. **写正确的多级指针与函数指针**：能独立写出 `int *(*fp)(int *)` 这类声明，并用 `typedef` 化简。
6. **用 const 精确表达意图**：区分 `const int *p`、`int *const p`、`const int *const p` 三种语义。
7. **识别并规避指针安全隐患**：野指针、悬垂指针、越界访问、返回局部变量地址。

## 博士视角（要理解到什么程度）

- **地址空间是抽象**：进程看到的是虚拟地址，由 MMU + 页表映射到物理页；指针的值只是虚拟地址，非法解引用触发缺页或被 SIGSEGV 终止，而不是「直接读到物理内存」。
- **指针类型不是装饰**：`int*` 与 `char*` 的机器表示完全一样（都是 64 位整数），差别只在**编译期语义**——解引用宽度、指针算术步长、别名分析（type-based alias analysis）。这解释了为什么强转指针是「零成本但危险」。
- **数组不是指针**：C 标准中数组类型是独立类型，只在表达式中「退化」。`sizeof` 与 `&` 是唯二不退化的上下文。

## 程序员视角（要能用出来）

- 传数组给函数**长度会丢失**，必须同时传 `n`（或约定哨兵值）；这是 C 没有原生边界检查的必然代价。
- 指针算术是**无边界检查**的裸操作，越界是 UB（不是「一定崩溃」）——可能静默损坏数据，用 ASan 在 CI 里兜住。
- 早期返回与错误分支是内存/指针 bug 的高发地；用「单一出口」或清晰的所有权约定降低风险。
