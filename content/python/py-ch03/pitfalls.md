# py-ch03 · 内置数据结构：易错点（Pitfalls）

本章坑的根因高度集中：**容器里存的是引用（指针）**，而"复制容器"默认**不复制元素对象**。

---

1. **`[[0]] * 3` 是共享引用，不是三个新列表**
   ```python
   a = [[0]] * 3
   a[0].append(1)
   print(a)   # [[0, 1], [0, 1], [0, 1]]  <- 全被改
   ```
   **原理**：`*` 把同一个对象的指针复制 n 份。对不可变元素（`[0]*3`）无害，对可变元素就是灾难。
   **正解**：`a = [[0] for _ in range(3)]`（每次迭代新建）。同理 `dict.fromkeys(keys, [])` 也有此坑。

2. **浅拷贝后原地改子对象，原容器跟着变**
   ```python
   a = [[1, 2], [3, 4]]
   b = a[:]              # 或 list(a) / copy.copy(a)
   b[0].append(99)
   print(a)              # [[1, 2, 99], [3, 4]]
   ```
   **原理**：浅拷贝只新建一层"指针数组"，槽位仍指向同一批子对象。**替换槽位**（`b[0] = [9]`）只影响 b；**原地改子对象**（`b[0].append`）会同时影响 a。
   **正解**：要完全独立用 `copy.deepcopy(a)`；或手工构造新对象（大对象图时更快更可控）。

3. **遍历容器时修改它（最隐蔽的 bug）**
   ```python
   # 列表：会跳过元素
   a = [1, 2, 3, 4]
   for x in a:
       if x % 2 == 0: a.remove(x)
   print(a)   # [1, 3] 看起来对，但 [1,2,3,4,5,6] 会得到 [1,3,5]? 实际 [1,3,5] 之外还可能漏
   # 字典：直接报错
   d = {'a':1, 'b':2}
   for k in d:
       if k == 'a': del d[k]   # RuntimeError: dictionary changed size during iteration
   ```
   **原理**：迭代器按内部索引/表槽推进，删除会让后续元素前移或表重建。
   **正解**：遍历**副本**——`for x in a[:]`、`for k in list(d)`；或用推导式重建 `[x for x in a if x % 2]`、 `{k:v for k,v in d.items() if k != 'a'}`。

4. **用 `is` 比较数值 / 字符串**
   ```python
   a, b = 256, 256; a is b   # True（小整数缓存 -5~256）
   a, b = 257, 257; a is b   # False（不要依赖！同一行常量折叠时可能又变 True）
   ```
   **原理**：`is` 比对象标识（`id`），`==` 比值。CPython 缓存小整数与部分短字符串（驻留）。
   **正解**：数值/字符串比较一律用 `==`；只有与 `None` / `True` / `False` 比较时用 `is`（单例，且避免触发自定义 `__eq__`）。

5. **可变对象当 dict 键 / 定义了 `__eq__` 却忘了 `__hash__`**
   ```python
   {[1, 2]: 'x'}              # TypeError: unhashable type: 'list'
   class P:
       def __eq__(self, o): return True
   {P(): 1}                   # TypeError: unhashable type: 'P'
   ```
   **原理**：定义 `__eq__` 会把 `__hash__` 隐式置为 `None`。且哈希必须基于**不可变字段**——改了字段后探测位置变化，元素就"消失"在哈希表里。
   **正解**：同时定义 `__hash__`（用不可变字段，如 `hash((self.x,))`）；可变对象就不要进 set/dict。

6. **在 list 头部频繁增删（`pop(0)` / `insert(0, x)`）**
   **原理**：list 是连续指针数组，头部操作要 `memmove` 搬移全部 n 个指针 → O(n)。循环里做就是 O(n²)。
   **正解**：用 `collections.deque`（两端 O(1)）；或先 `reverse()` 再从尾部处理。

7. **把生成器当列表用（一次性耗尽）**
   ```python
   g = (x for x in range(3))
   print(list(g))   # [0, 1, 2]
   print(list(g))   # []   <- 已耗尽
   ```
   **原理**：生成器是惰性的一次性迭代器，消费完就停。
   **正解**：需多次遍历就转 `list(g)` 保存，或重新构造生成器（用生成器**函数**而非表达式，可重复调用）。

8. **用 `x in some_list` 做大量成员判断**
   **原理**：list 的 `in` 是线性扫描 + 逐个 `__eq__`，O(n)；循环里判断就是 O(n²)。
   **正解**：把待查集合转 `set` / `dict`（平均 O(1)）——这是最常见的性能优化手段，往往一行改动带来数量级提升。

9. **误以为 `sort()` 返回新列表**
   ```python
   b = a.sort()      # sort() 原地排序并返回 None！
   print(b)          # None
   ```
   **正解**：原地用 `a.sort()`；要新列表用 `sorted(a)`（返回新列表，原表不变）。`sort` 是**稳定排序**，支持 `key=` 与 `reverse=`。

## 速记表

| 陷阱 | 一句话原理 | 防御写法 |
|---|---|---|
| `[[0]]*3` | `*` 复制引用 | `[[0] for _ in range(3)]` |
| 浅拷贝改子对象 | 只复制一层容器 | `deepcopy` 或手工重建 |
| 遍历中修改 | 迭代器按索引推进 | 遍历副本 / 用推导式重建 |
| `is` 比数值 | 比标识非比值 | 用 `==`，None 才用 `is` |
| 可变对象作键 | 哈希须基于不可变字段 | 补 `__hash__`，可变对象不入 set |
| `pop(0)` 循环 | 头部搬移 O(n) | `collections.deque` |
| 生成器复用 | 一次性 | 转 list 或用生成器函数 |
| `in` list | O(n) 线性扫描 | 转 set/dict |
| `sort()` 返回 | 原地返回 None | `sorted()` 要新列表 |
