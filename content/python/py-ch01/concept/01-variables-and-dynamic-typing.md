# 01 · 变量与动态类型

Python 是**动态强类型**语言：变量无需声明类型（动态），但运算不会偷偷做危险隐式转换（强类型）。变量本质是一个"名字"，绑定到对象；对象本身有类型且分**可变 / 不可变**。

- 不可变对象：`int`、`float`、`str`、`tuple`、`frozenset`、`bytes`
- 可变对象：`list`、`dict`、`set`、`bytearray`

```python
a = 1        # a 绑定到整数对象 1
b = a        # b 也绑定到同一个对象
a = a + 1    # 重新绑定 a 到新对象 2，b 不受影响
print(a, b)  # 2 1

xs = [1, 2]
ys = xs      # ys 与 xs 指向同一列表
xs.append(3) # 原地修改，ys 可见
print(ys)    # [1, 2, 3]
```

要点：`is` 比的是对象身份（id），`==` 比的是值；小整数（-5~256）会被缓存复用，不要依赖该细节判断 `is`。

---

## 三视角解析

### 🧑‍💻 程序员视角
- 变量是**贴在对象上的名字**，赋值是「绑定」而不是「装箱」；因此 `a = b` 之后两者指向同一对象，改其中一个共享的可变对象会互相影响。
- 判断相等用 `==`；`is` 比较的是身份（地址）。小整数缓存（−5 到 256）和字符串驻留会让 `is` 偶尔「看起来能用」，但**永远不要依赖它**。
- 类型注解（`x: int`）只是提示，运行时不强制——想做运行时校验得靠 `pydantic` / `beartype` 之类。

### 🎓 博士生视角
- CPython 中每个对象都有 `ob_refcnt`（引用计数）与 `ob_type`（类型指针）头部，变量只是指向 `PyObject*` 的名字绑定。**类型属于对象，不属于名字**——这就是「动态类型」的形式化表述。
- 引用计数是**即时回收**，但无法处理循环引用，因此必须有分代 GC 兜底；`sys.getrefcount` 能观察到引用计数（注意它自身会 +1）。
- 名字与对象的分离带来「同一对象多个名字」的别名语义，这与 C 的「变量即内存地址」模型根本不同；工程上这就是「可变对象默认参数」等陷阱的根源。

### 📚 考研者视角
- 与计组的「变量 = 存储单元的符号化地址」形成对照：C 中变量绑定的是**地址**，Python 中名字绑定的是**对象引用**。
- 若专业课含程序设计语言原理，常考「值语义 vs 引用语义」「静态类型 vs 动态类型」的分类与优劣。
- 记忆锚点：**变量是「标签」不是「盒子」**；**`==` 比值、`is` 比身份**。
