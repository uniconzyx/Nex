# 03 · 内建容器与推导式

四种常用容器：

- `list` 有序可变：`[1, 2, 3]`，支持切片、append、推导式
- `tuple` 有序不可变：`(1, 2)`，适合异构固定结构
- `dict` 键值映射：`{"a": 1}`，键须可哈希
- `set` 无序去重：`{1, 2}`，集合运算

```python
nums = [1, 2, 3, 2]
uniq = set(nums)
print(uniq)                  # {1, 2, 3}

sq = [x * x for x in range(1, 4)]
print(sq)                    # [1, 4, 9]

d = {f"k{i}": i for i in range(2)}
print(d)                     # {'k0': 0, 'k1': 1}

s = "hello"
print(s[1:4])                # ell（切片左闭右开）
```

要点：推导式比手写 `for + append` 更 Pythonic；切片 `[start:stop:step]`；字典推导/`set` 推导写法类似，注意去重与键唯一性。

---

## 三视角解析

### 🧑‍💻 程序员视角
- 推导式比显式 `for + append` 更快（少了属性查找与函数调用开销），可读性也更好；但**嵌套超过两层就该退回循环**，否则可读性崩坏。
- 大数据集用**生成器表达式**（`(... for ...)`）而非列表推导式，能省下整份内存。
- `dict` 在 3.7+ **保序是语言保证**（此前只是 CPython 实现巧合）；`set` 无序且不能按下标取。

### 🎓 博士生视角
- 列表推导式会被编译成**独立的代码对象**（有自己的作用域与局部变量表），并走专用字节码（`LIST_APPEND`），避免了每次迭代的函数调用与属性查找——这是它快的根本原因，而非「语法糖」。
- `list` 是**动态指针数组**：元素是 `PyObject*` 引用而非值本身，扩容采用约 `n + n>>3` 的过度分配策略（**不是 2 倍**），从而让 `append` 均摊 O(1)。
- `dict` 自 3.6 起采用**紧凑表示**（稀疏的 `indices` 表 + 密集的 `entries` 数组），既省内存又让插入顺序天然可迭代——「保序」是实现优化的副产品被提升为语言保证。

### 📚 考研者视角
- 与 408 的**顺序存储、哈希表**直接对应：`list` ↔ 顺序表（随机访问 O(1)、中间插入 O(n)）；`dict`/`set` ↔ 哈希表（关注装填因子与冲突处理）。
- 常见考法：给定哈希函数与关键字序列，手算装填因子与平均查找长度（ASL）；与 Python 对照能加深理解。
- 记忆锚点：**list 扩容约 1.125 倍（不是 2 倍）**；**dict 保序是 3.7+ 的语言保证**。
