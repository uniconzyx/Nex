# 数据清洗与质量体检

清洗不是"把 NaN 填掉"，而是**先诊断、再决策**。诊断错了，后面所有结论都建立在沙子上。

## 一、质量体检清单：六项必查

### 🧑‍💻 程序员视角

拿到任何一份表，按固定顺序跑一遍，产出"问题清单 + 处置方案"：

| 维度 | 检查什么 | 常见处置 |
|---|---|---|
| **完整性** | 每列缺失率、缺失是否成块（同一行多列同时缺） | 填 / 删 / 保留并加标记列 |
| **唯一性** | 主键重复、近似重复（大小写、空格、全半角） | 去重、标准化后去重 |
| **有效性** | 类型是否正确（数字存成字符串）、格式是否统一（`2026/1/1` vs `2026-01-01`） | 类型转换、格式归一 |
| **一致性** | 同义异名（`北京` / `北京市` / `BJ`）、单位不统一（元 / 万元） | 建立映射字典 |
| **准确性** | 越界值（年龄 200、价格负数）、精度异常 | 置为缺失或截断，**保留原始列** |
| **时效性** | 时间范围是否覆盖预期、有无未来时间、时区是否统一 | 过滤、时区统一 |

一条纪律：**清洗必须留痕**。原始列不要就地覆盖，新增 `xxx_clean` 或保留原始表——否则无法回溯"这个结论是基于哪版数据得出的"。

### 🎓 博士生视角

质量维度可形式化为一组**约束集合**：完整性 = 非空约束，唯一性 = 键约束，有效性 = 类型约束，一致性 = 等价类约束（值域归一）。
清洗过程就是**在约束下做最小修正**——"最小"很重要：每一次修正都是一次**信息注入**（填充的值不是观测到的值），注入越多，下游结论越偏离真实。

这解释了为什么"清洗报告"必须与数据同行：**结论的可信度上限由数据质量决定**，而不是由模型复杂度决定。这是数据科学里最反直觉、也最贵的一条。

### 📚 考研者视角

关联考点：**数据清洗与 ETL** 的基本环节（抽取 → 清洗 → 转换 → 装载）。
答题要点是"**诊断先于处置**"：先说清有哪些问题维度，再说每种问题的处置选项及其代价。
易错口径：**"去重"不等于"删重复行"**——重复可能是业务上的多条记录（如同一用户多次下单），要先定义"什么算同一条"。

## 二、缺失值：先判断机制，再决定动作

### 🧑‍💻 程序员视角

三种缺失机制，决定你能不能用"删"：

| 机制 | 含义 | 例子 | 删除的后果 |
|---|---|---|---|
| **MCAR** | 完全随机缺失，与任何变量无关 | 传感器偶发丢包 | 只损失样本量，**不引入偏差** |
| **MAR** | 缺失与**其他已观测变量**有关 | 高收入人群更不愿填收入 | 若用其他变量填充可缓解 |
| **MNAR** | 缺失与**缺失值本身**有关 | 收入越高越不填收入 | **删除必然引入偏差**，且无法从数据内部检验 |

**MNAR 无法用数据自证**——这是最重要的认知。你只能靠业务知识判断"缺失本身是否携带信息"。
工程上最稳的兜底：**保留缺失并加一列 `xxx_is_missing` 标记**，让模型自己决定这个信号是否有用。

填充策略的取舍：

| 策略 | 适用 | 代价 |
|---|---|---|
| 删除行 / 列 | MCAR 且缺失很少（<5%） | 损失样本；列缺失多时丢维度 |
| 均值 / 中位数 | 数值列，MCAR | **压缩方差**，削弱相关性与回归斜率 |
| 众数 | 类别列 | 放大多数类 |
| 前向填充 | 时间序列 | 产生"阶梯"，不宜对有趋势的量长期使用 |
| 分组统计量 | MAR | 更合理，但需保证分组变量自身可靠 |
| 模型填充 | MAR，特征充分 | 计算贵，且有**泄漏风险**（见 concept 02） |

### 🎓 博士生视角

均值填充的偏差可以精确刻画：设真实方差 $\sigma^2$，填充后样本方差变为 $\frac{n_{obs}}{n}\sigma^2$（$n_{obs}$ 为观测数），即**方差被系统性低估**，
相关系数的绝对值也随之被**衰减**（attenuation）。中位数填充在偏态分布下更稳健，但同样压缩离散度。

MNAR 的形式化：设缺失指示 $R$ 与变量 $Y$ 的取值相关，则 $P(R=1\mid Y)$ 非常数，此时**观测样本分布不等于总体分布**，
任何基于观测样本的估计量都是有偏的。检验 MNAR 需要**建模缺失机制本身**（如 Heckman 选择模型）或引入外部数据，属于"不可仅由数据解决的识别问题"。

### 📚 考研者视角

配套考点：**用统计量描述数据集中趋势与离散程度**（均值 / 中位数 / 众数 / 方差 / 标准差 / 变异系数）。
高价值答题点：说清"**均值对极端值敏感、中位数稳健**"，并据此解释"收入分布用中位数描述更合理"。

易错口径：**填充后必须说明口径**——"填充后的均值"不等于"真实均值"。答题时区分"观测值的统计量"与"填充值的统计量"会显著加分。

## 三、异常检测：三种判据及其假设

### 🧑‍💻 程序员视角

| 方法 | 判据 | 假设 | 适用 |
|---|---|---|---|
| **Z-score** | $\lvert z\rvert > 3$，$z=(x-\mu)/\sigma$ | 近似正态 | 分布对称、无重尾 |
| **IQR** | $x < Q_1-1.5\,IQR$ 或 $x > Q_3+1.5\,IQR$ | 无分布假设 | **推荐默认**，对偏态稳健 |
| **分位数截断** | 取 1% / 99% 之外 | 无假设，需人为定比例 | 长尾数据、需要固定比例时 |

三条纪律：
1. **先看分布再选方法**。右偏（如金额、时长）用 Z-score 会把大量正常大值判为异常。
2. **异常 ≠ 错误**。异常可能是真信号（欺诈、故障、爆款），先看业务含义再决定删还是留。
3. **保留原始值**。截断/替换要新增列，原始列留着，便于事后核对。

### 🎓 博士生视角

IQR 规则的 1.5 系数**不是统计推导的结果**，而是 Tukey 的经验选择：正态分布下，落在 $[Q_1-1.5IQR,\ Q_3+1.5IQR]$ 之外的概率约 **0.7%**，
所以它的"严格程度"与 Z-score 的 $|z|>2.7$ 接近。这说明 IQR 的价值不在"更正确"，而在**对分布形态不敏感**——它用分位数替代了均值和标准差这两个受极端值影响的量。

Z-score 的失效机制很明确：$\mu$ 与 $\sigma$ 都由全部样本计算，**异常值本身会拉大 $\sigma$**（俗称掩蔽效应），
导致极端点反而不超阈值。所以在重尾分布上，应改用 **Robust Z-score**（用中位数与 MAD 替代均值与标准差）。

### 📚 考研者视角

配套考点：**箱线图（box plot）的五数概括**——最小值、$Q_1$、中位数、$Q_3$、最大值，以及 IQR = $Q_3-Q_1$。
标准问法："箱线图如何识别异常值"→ 答"超出 $Q_1-1.5IQR$ 与 $Q_3+1.5IQR$ 的点"。

易错口径：**箱线图的"须"不代表最小/最大值**，而是**须端点内最远的观测点**（各实现略有差异），只答"须就是最大最小"是常见错答。

## 四、去重与一致性：最容易被低估的一步

### 🧑‍💻 程序员视角

精确重复用 `drop_duplicates()`；但真实数据里更多是**近似重复**：
- 空白差异：`"北京 "` vs `"北京"`；
- 大小写与全半角：`"ABC"` vs `"abc"`、`"ＡＢＣ"`；
- 标点与后缀：`"某公司"` vs `"某公司（有限）"`；
- 号码格式：`138-0000-0000` vs `13800000000`。

处置方式：**先归一化再比对**（`str.strip` → `str.lower` → 全角转半角 → 去标点），比对键用归一化结果，**但保留原始值展示**。

### 🎓 博士生视角

去重本质是**等价类划分**：先定义等价关系（什么算同一条），再对每个等价类选一个代表元。
关键难点在于"等价关系"的**传递性不一定成立**（`A≈B`、`B≈C` 未必 `A≈C`，如"某公司"、"某公司有限"、"某公司有限公司"），
此时"两两去重"会得到依赖处理顺序的结果——正确做法是用**并查集**做连通分量归并。

这也是实体消解（entity resolution）问题的核心：需要**相似度度量 + 聚类阈值**，而非简单的相等判断。

### 📚 考研者视角

配套考点：**关系模式的规范化与函数依赖**——去重的合法性最终由函数依赖决定（候选键相同即视为同一实体）。
答题时把"去重键"与"候选键"挂钩，说明"选择哪些字段构成去重键"是需要业务论证的，会比只说"用 `drop_duplicates`"更有深度。

## 三视角解析

### 🧑‍💻 程序员视角
清洗 pipeline 固定四段：**体检报告 → 处置方案（逐条有理由）→ 实施（新增列不覆盖）→ 复检（体检指标前后对比）**。
"复检"最常被省，但它能抓住"清洗后缺失率反而升高"这类自伤。

### 🎓 博士生视角
清洗的每个动作都等价于对数据分布做一次**有意的扰动**。把"我做了什么清洗"当作**建模假设的一部分**写进报告——因为下游结论既依赖模型，也依赖清洗。

### 📚 考研者视角
本章开放题得分点：**诊断维度齐全 + 处置有代价说明 + 结论标注口径**。三段齐全才是完整答案。
