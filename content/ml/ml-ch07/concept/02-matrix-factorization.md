# 矩阵分解：把「用户×物品」压成两个小矩阵

> 协同过滤要在稀疏矩阵上找邻居，矩阵分解换了一条路：
> **假设这张矩阵近似低秩**——用户的偏好由少数几个潜在因子（latent factor）决定，
> 物品也只是在这几个因子上的取值。于是预测变成两个低维向量的内积，
> 参数量从 `m×n` 降到 `(m+n)×k`，泛化来自「因子共享」而不是「邻居共享」。
> 这一讲把目标函数、SGD、ALS、隐式反馈与 BPR 全部拆开。

## 1. 隐语义模型：从「邻居」到「因子」

### 1.1 模型形式

```
r̂_ui = μ + b_u + b_i + p_uᵀ q_i
        └──── baseline ────┘   └ 交互 ┘

p_u ∈ ℝ^k：用户 u 的隐向量
q_i ∈ ℝ^k：物品 i 的隐向量
k ≪ min(m, n)：隐维度（常见 8~128）
```

直觉：`p_u` 的每一维可以理解为「动作片偏好」「文艺片偏好」「对新片的容忍度」……
但这些维度**不可命名**，它们是数据学出来的，不能按列解释成「第 1 维=喜剧」。
这是隐语义模型与内容画像最重要的区别：**因子是统计产物，不是语义标签**。

### 1.2 为什么不能直接对评分矩阵做 SVD

标准 SVD 要求矩阵**稠密且完整**：`R = UΣVᵀ`。但 `R` 有 95% 以上是缺失值。
两种常见的错误做法：

1. **把缺失填 0 再做 SVD**：0 被当成「真实评分」，模型学到的是「大部分物品都很差」，
   预测系统性偏低。这不是小误差，是**目标函数被改了**。
2. **只对观测项做「SVD」**：那不是 SVD，观测模式不规则时正交性不成立，
   得到的分解不唯一，也无法用 `np.linalg.svd` 直接算。

正确的做法是**只对观测集合 Ω 定义损失**，把分解当成带正则的优化问题：

```
min_{P,Q,b}  Σ_{(u,i)∈Ω} (r_ui − μ − b_u − b_i − p_uᵀq_i)²
             + λ( ‖p_u‖² + ‖q_i‖² + b_u² + b_i² )
```

这就是 FunkSVD / 带偏置的 MF。**它没有闭式全局解**（P、Q 双线性耦合），但有两个好用的解法。

### 1.3 几何直觉

```
       物品因子空间 (k=2)
            q_b
             │        ● 动作片
             │      ●
             │   ●
             │            ● 文艺片
             └──────────────── q_a
                  p_u ● ← 用户向量；内积大 = 偏好高
```

用户向量指向哪个方向，就对那个方向的物品打高分；`p_uᵀq_i` 是「投影长度」。
**用户的偏好被表示成一个方向，而不是一组邻居**——这是 MF 比 kNN 更省参数、更能泛化的原因。

## 2. 目标函数与正则化

### 2.1 逐样本损失与正则

```
L = Σ_{(u,i)∈Ω} e_ui² + λ(‖P‖_F² + ‖Q‖_F² + ‖b‖²),    e_ui = r_ui − r̂_ui
```

三个必须注意的点：

- **只对观测项求和**。缺失项不进入损失，这是「矩阵补全」与「矩阵回归」的分水岭。
- **正则会收缩未观测方向的因子**。没有正则时，只要某用户只评过一个物品，
  他的 `p_u` 可以任意大而损失不变（`p_uᵀq_i` 固定即可）——解不唯一、方差爆炸。
- **λ 要按用户/物品的交互数分层**。交互多的用户正则应弱一些；统一 λ 会让重度用户欠拟合。
  工程近似：`λ_u = λ_0 · (|I_u| / median(|I|))^β`，`β ∈ [0, 0.5]`。

### 2.2 非凸，但双凸

`L` 对 `(P,Q)` 联合不是凸的（`p_uᵀq_i` 是双线性项）。
但**固定 Q 时，对每个 p_u 是凸二次；固定 P 时，对每个 q_i 是凸二次**。
这个结构带来两个直接结论：

1. ALS 可以交替求**全局最优**（对单侧），因此目标单调不增；
2. 联合问题仍可能有多组等价解（旋转/缩放不变性：`P→PR`、`Q→QR⁻ᵀ` 内积不变），
   所以「因子绝对值」没有意义，只有内积和相对几何有意义。

## 3. SGD：一次一个观测，逐样本更新

对单个观测 `(u,i)`，梯度：

```
∂L/∂p_u = −2 e_ui q_i + 2λ p_u
∂L/∂q_i = −2 e_ui p_u + 2λ q_i
∂L/∂b_u = −2 e_ui + 2λ b_u
∂L/∂b_i = −2 e_ui + 2λ b_i
```

更新式（把常数 2 吸收进学习率 η）：

```
e  = r_ui − μ − b_u − b_i − p_uᵀq_i
b_u ← b_u + η(e − λ b_u)
b_i ← b_i + η(e − λ b_i)
p_u ← p_u + η(e · q_i − λ p_u)
q_i ← q_i + η(e · p_u − λ q_i)
```

**伪代码**：

```
初始化 P, Q ~ N(0, 0.01), b = 0
for epoch in 1..T:
    shuffle(Ω)
    for (u, i, r) in Ω:
        e = r - (μ + b_u + b_i + p_u·q_i)
        b_u += η (e - λ b_u);  b_i += η (e - λ b_i)
        p_u += η (e q_i - λ p_u)
        q_i += η (e p_u - λ q_i)     # 注意：q_i 用的是更新前的 p_u
    if epoch % 5 == 0: 计算验证 RMSE，早停
```

**两个工程细节**：

- **更新顺序**。上面先算 `e` 再同时更新，`p_u` 与 `q_i` 的更新用的是**同一个 e**。
  如果先更新 `p_u` 再用新 `p_u` 算 `q_i`，等价于坐标法，收敛行为不同（也可用，但要一致）。
- **学习率衰减**。固定 η 在后期会在最优点附近抖动；用 `η_t = η_0 / (1 + decay·t)`
  或按 epoch 衰减 0.9。η 太大（>0.05）会发散，太小（<1e-4）跑不完。

**SGD 的优点**：实现十行、能在线增量、对稀疏数据友好（每个样本只碰两个向量）。
**缺点**：样本间强相关（同一用户连续出现）导致方差大；无法向量化利用 BLAS；调参敏感。

## 4. ALS：固定一侧，另一侧有闭式解

### 4.1 单行推导

固定 `Q` 与所有偏置，只优化 `p_u`。把该用户所有观测写成矩阵形式：

```
L_u = ‖r_u − Q_u p_u‖² + λ‖p_u‖² + const
      （Q_u 是 |I_u|×k 的子矩阵，r_u 是对应残差）
```

对 `p_u` 求导令零：

```
−2 Q_uᵀ(r_u − Q_u p_u) + 2λ p_u = 0
⟹ (Q_uᵀQ_u + λI) p_u = Q_uᵀ r_u
⟹ p_u = (Q_uᵀQ_u + λI)⁻¹ Q_uᵀ r_u
```

**这就是 ALS 的全部核心**。对每个用户独立解一个 `k×k` 线性系统，
再对每个物品解 `(P_iᵀP_i + λI) q_i = P_iᵀ r_i`，交替直到收敛。

```
ALS 一轮
┌──────────────────────────────────────────────┐
│ for u in 1..m:  p_u ← (Q_uᵀQ_u + λI)⁻¹ Q_uᵀ r_u │
│ for i in 1..n:  q_i ← (P_iᵀP_i + λI)⁻¹ P_iᵀ r_i │
└──────────────────────────────────────────────┘
每步都是「固定另一侧后的全局最优」→ 目标单调不增
```

### 4.2 复杂度与工程取舍

| | SGD | ALS |
|---|---|---|
| 每步代价 | O(k) / 观测 | O(k³ + k²·nnz_u) / 用户 |
| 并行性 | 差（样本相关，需 Hogwild 加锁） | **好**（用户之间完全独立） |
| 收敛 | 前期快，后期抖 | 每轮单调降，轮数少但每轮贵 |
| 隐式反馈 | 需负采样 | **天然支持**（加权全矩阵，见下） |
| 增量更新 | 容易 | 难（需重解） |
| 调参 | η、λ 敏感 | 主要调 λ、k |

**选择判据**：显式评分 + 需要快速迭代 → SGD；隐式反馈 + 多机并行 → ALS（Hu et al., 2008 的
`implicit ALS` 是工业界标配）；需要在线学习 → SGD/FTRL。

### 4.3 隐式反馈的 ALS：把「没交互」当负样本但降权

隐式场景没有 0~5 分，只有「有没有行为」。Hu 等人把矩阵变成**置信度 + 偏好**：

```
p_ui = 1  若 r_ui > 0（有行为）
p_ui = 0  若 r_ui = 0（无行为）

c_ui = 1 + α·r_ui     （行为越强，置信度越高；α 常取 40）
```

目标变成**全矩阵加权**（不再只对观测求和）：

```
min Σ_{u,i} c_ui (p_ui − p_uᵀq_i)² + λ(‖P‖² + ‖Q‖²)
```

关键技巧：虽然求和是全矩阵（m×n 巨大），但 `c_ui = 1` 的部分可以提出常数，
剩下只与「有行为的项」有关，于是每行仍可写成 `(Qᵀ C_u Q + λI)⁻¹ Qᵀ C_u p_u`，
其中 `C_u` 是对角矩阵，计算量 `O(k²·nnz + k³)`，可并行。**这是隐式 ALS 能落地的原因**。

## 5. 隐式反馈与 BPR：优化排序而不是评分

### 5.1 为什么回归损失是错的

隐式数据只有正样本（点击/购买），负样本是「未观测」。若把未观测当 0 做平方损失：

- 模型被大量「假负例」主导（未点击可能只是没曝光）；
- 优化目标变成「预测交互强度」，而业务要的是「把用户最可能点的排前面」；
- 平方损失对「已经排对的正样本」继续推高分数，边际收益递减，排序不变。

### 5.2 BPR 的 pairwise 似然

对用户 `u`，正样本 `i`（有行为）、负样本 `j`（采样得到），定义：

```
x̂_ui = p_uᵀq_i,   x̂_uj = p_uᵀq_j

P(i ≻_u j) = σ(x̂_ui − x̂_uj)
```

最大化对数似然 + 正则：

```
L_BPR = Σ_{(u,i,j)} −log σ(x̂_ui − x̂_uj) + λ(‖p_u‖² + ‖q_i‖² + ‖q_j‖²)
```

梯度（`σ'(z) = σ(z)(1−σ(z))`，令 `δ = 1 − σ(x̂_ui − x̂_uj)`）：

```
∂L/∂p_u = −δ(q_i − q_j) + 2λ p_u
∂L/∂q_i = −δ p_u        + 2λ q_i
∂L/∂q_j = +δ p_u        + 2λ q_j
```

**读法**：`δ` 是「排序错得有多离谱」。当正样本已经比负样本高很多，`σ→1`，`δ→0`，
梯度消失——模型自动把精力放在「排错的 pair」上，这正是排序损失想要的行为。

### 5.3 负采样

BPR 的效果高度依赖负样本分布。三种做法：

| 策略 | 分布 | 特点 |
|---|---|---|
| 均匀采样 | `j ~ Uniform(I \ I_u)` | 简单；但大多数负样本太「容易」，梯度小 |
| 按流行度采样 | `j ∝ pop(j)^0.75` | 更难负样本，收敛快；但会放大热门偏差 |
| 硬负采样 | 用当前模型 top-k 中挑 | 最有效但易训练不稳定，需课程学习 |

**必须排除用户已交互的物品**（否则把正样本当负样本，模型学反）。
工业界常用 `pop^0.75`（Word2Vec 的经验指数），在大规模场景兼顾难度与稳定性。

### 5.4 BPR vs 回归 MF 的口径差异

```
评分回归 MF：  最小化 ‖r − r̂‖²      → 指标看 RMSE/MAE
BPR：         最大化 P(正 ≻ 负)      → 指标看 AUC/Recall@K/NDCG@K
```

**两者不可直接比数值**。用 BPR 训练后去报 RMSE 通常更差（它根本不拟合评分），
但它在线上的点击率/转化率往往更好。这是「目标函数必须与业务指标对齐」的最典型例子。

## 6. 超参：隐维度、正则、学习率

| 超参 | 常用范围 | 影响 | 调法 |
|---|---|---|---|
| 隐维度 k | 8~128（小数据 8~32） | 太小欠拟合、太大过拟合且内存涨 | 从 8 起，按验证指标翻倍扫 |
| 正则 λ | 1e-4~1e-1 | 太小因子爆炸，太大退化为 baseline | 对数网格，按交互数分层 |
| 学习率 η | 0.001~0.02（SGD） | 太大发散，太小不收敛 | 先跑 1 个 epoch 看 loss 是否下降 |
| 迭代轮数 | 10~100 + 早停 | 过多过拟合 | 每轮验证，patience=3~5 |
| 负采样数 | 1~10 / 正样本 | 越多越稳但越慢 | BPR 常用 1~4 |

**调参顺序**（按影响力）：`k → λ → η → 迭代数`。
先固定 `λ=0.01, η=0.005`，扫 `k`；确定 `k` 后扫 `λ`；最后微调 `η`。
不要一上来做四维网格——指数爆炸且大部分组合没有信息量。

**一个常被忽略的超参：初始化**。MF 是非凸的，`N(0, 0.01)` 与 `N(0, 0.1)` 的最终指标
可能差 1~2 个点。固定种子、报告多次运行的中位数，是负责任的做法。

## 三视角解析

### 🧑‍💻 程序员视角

- **先做 baseline，再做 MF**。`μ + b_u + b_i` 就能解释 60%~80% 的评分方差；
  很多「MF 涨点」其实是 baseline 没做。先跑通 baseline，再确认隐因子带来的是增量。
- **只对观测项算 loss**。这是实现 MF 最容易写错的地方：用 `np.where(mask, ...)` 或
  稀疏 COO 遍历，绝不能 `(R - Rhat)**2` 全矩阵求和——那等于把缺失当 0。
- ALS 的 `Q_uᵀQ_u + λI` 是 `k×k`，`k=64` 时每个用户解一个 64×64 系统，
  用 `np.linalg.solve` 批量做（`np.linalg.solve` 支持 batched）比 Python 循环快一个数量级。
- **数值稳定**：`Q_uᵀQ_u` 可能病态，加 `λI` 后条件数改善；`λ` 别小于 1e-6，
  否则 `float32` 下可能出现 `LinAlgError`。用 `float64` 训练，导出时再转 `float32`。
- 线上只存 `p_u`、`q_i`、`b_u`、`b_i`。用户向量要支持**近实时更新**：
  用户刚点了一个物品，用一次 SGD 把他的 `p_u` 往前推一步（FTRL/在线 MF），
  比等 T+1 全量重训的体验好得多。
- 冷启动的 item 没有 `q_i`，可以用**内容向量做回归初始化**：
  `q_i ≈ W·content_i`，再用少量交互微调。比随机初始化收敛快，也避免「新物品永远 0 曝光」。

### 🎓 博士生视角

- MF 是**低秩矩阵补全**的非凸参数化。理论上的精确恢复条件（Candès & Recht, 2009）要求
  观测数 `|Ω| ≳ n·r·log(n)` 且矩阵满足不相干性；现实推荐系统的密度远低于此，
  所以 MF 的成功更多来自**分布假设（低秩 + 噪声）**而非精确恢复保证。
- 双线性模型的**可辨识性**只在旋转/缩放意义下成立：`(P,Q)` 与 `(PR, QR⁻ᵀ)` 等价。
  因此不能比较两次训练的因子坐标，也不能把「第 3 维」解释成某个语义。要做解释，
  得用内容特征做**回归对齐（regression alignment）**，而不是看因子本身。
- SGD 在 MF 上收敛到的是**局部极小或鞍点**。由于目标双凸，鞍点通常是「严格鞍点」，
  加小扰动或使用随机初始化即可逃离；ALS 的单调性保证不会震荡，但会停在块坐标的驻点。
- BPR 的 pairwise 似然等价于**RankNet 的成对损失**；它与 ListNet/ListMLE 的差别在于
  只建模成对比较，忽略了列表级归一化。AUC 正是成对排序指标，所以 BPR 直接优化 AUC 的
  凸代理；但 AUC 对 Top-K 不敏感（把最相关的排到 1000 名外，AUC 仍然很高），
  这也是为什么工业界更看 NDCG@K / Recall@K。
- 隐式 ALS 的加权最小二乘可以看成**高斯潜变量模型 + 置信度方差**：
  `c_ui` 是精度的倒数。它假设「未交互」是真实的负反馈（低置信），
  在曝光机制未知时这个假设仍然有偏；因果推荐（IPS/deconfounding）正是来补这一刀的。

### 📚 考研者视角

- 高频计算题：**写出 MF 的目标函数并推导 SGD 更新式**。注意三点：
  只对观测求和、正则作用于 P/Q（是否含偏置看题目）、梯度里的负号与系数 2。
- **ALS 闭式解必背**：`p_u = (Q_uᵀQ_u + λI)⁻¹ Q_uᵀ r_u`。推导是「最小二乘 + L2」的标准套路，
  和岭回归的正规方程完全同构——可以把这一条当作岭回归在推荐里的实例来记。
- 概念辨析：**FunkSVD / SVD / SVD++ 的区别**。
  SVD 要求稠密矩阵；FunkSVD 只拟合观测项（工程上常直接叫 MF）；
  SVD++ 在 MF 上加入「隐式反馈项」`|N(u)|^{-1/2} Σ y_j`。答题时按「输入 → 目标 → 是否建模隐式」三层说。
- 易错口径：**BPR 不是「一种矩阵分解」**，它是一种**损失函数/学习目标**；
  可以用 MF 打分函数，也可以用神经网络的打分函数。考试若问「BPR 的优点」，
  要答「直接优化排序、只需正负对、不需要负样本的绝对标签」，而不是「能降维」。
