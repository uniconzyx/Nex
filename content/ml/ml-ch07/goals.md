## 本章目标

学完你应该能：

1. **写出 user-based / item-based 协同过滤的完整预测式**：选对相似度（余弦、中心化余弦、Pearson、Jaccard），
   说明为什么工业界召回更偏 item-based，并解释评分矩阵稀疏带来的邻居不可靠问题。
2. **推导均值归一化为什么必要**：把「用户偏置 + 物品偏置 + 隐因子」拆开，
   用公式说明不中心化时余弦相似度会被打分尺度污染，预测会被「爱打高分的人」带偏。
3. **从零推导矩阵分解的 SGD 与 ALS**：写出带偏置的目标函数、SGD 更新式、
   ALS 的单行闭式解 `p_u = (QᵀQ + λI)⁻¹Qᵀr_u`，并说清两者在并行性/收敛性上的取舍。
4. **解释隐式反馈为什么要换损失**：把「未点击」当 0 的回归是错的，
   能写出 BPR 的 pairwise 损失、负采样分布与梯度，并说明它优化的是排序而非评分。
5. **算清排序指标的口径**：手算 Recall@K、NDCG@K、MAP，
   区分「全库评测 / 候选集评测 / 单用户平均 vs 全局平均」，并指出离线涨点而线上不涨的五类原因。
6. **给出冷启动与流行度偏差的工程方案**：内容特征融合、置信度加权混合、IPS 去偏、探索/多样性重排，
   并能说明每种方案的代价与适用边界。

## 关键认知（本章最值钱的三句）

- **协同过滤的本质是「用交互矩阵的低秩结构做填充」，不是「找相似的人」**。
  user-based / item-based 是它的两种邻域近似，矩阵分解是它的参数化近似；
  三者共享同一个假设：**相似用户对相似物品的偏好相近**。假设不成立时，换算法没用。
- **显式反馈优化评分误差（RMSE），隐式反馈优化排序（AUC/NDCG）——目标函数选错，模型越准线上越差**。
  未点击不等于不喜欢，它只是「没有曝光」或「没被注意到」。
- **离线指标是线上收益的有偏代理**。召回集、曝光机制、位置偏差、反馈延迟任何一环与线上不一致，
  Recall@K 的提升都可能是假的；所以离线只用来**筛掉坏模型**，不用来承诺涨幅。
## 与「深度学习」的分界

本章只用**隐因子与双线性内积**表达用户-物品交互，属于经典矩阵分解的范畴；
不展开神经协同过滤（NCF）、双塔网络的训练细节与反向传播——那属于 `content/ai` 的表示学习部分。
本章会给出「什么时候必须上深度学习」的判据：当交互特征包含文本/图像、或需要高阶非线性交叉时，
矩阵分解的表达上限就到了；否则在稀疏表格场景，MF/BPR 仍是极难打败的基线。
