# 偏差、方差与泛化：为什么「训练集上更准」可能是更差

## 1. 分解的完整推导（这一步必须会写）

设真实机制 `y = f*(x) + ε`，`E[ε]=0`、`Var(ε)=σ²`，训练集 `S` 从分布 D 独立抽取，
学习算法输出 `f_S`。对**固定的测试点 x** 定义期望测试误差：

```
Err(x) = E_S E_{y|x}[ (y − f_S(x))² ]
```

令 `f̄(x) = E_S[f_S(x)]`（同一个 x 上，模型在不同训练集上的平均预测）。把括号里加减 `f̄(x)`：

```
y − f_S(x) = (y − f*(x)) + (f*(x) − f̄(x)) + (f̄(x) − f_S(x))
                └─ 噪声 ε ─┘   └── 偏差 ──┘   └── 方差项 ──┘
```

展开平方并取期望。三个交叉项为什么消失，要能说清：
- `E[ε] = 0` 且 ε 与 S 独立 → 噪声与另外两项的交叉项为 0；
- `E_S[f̄(x) − f_S(x)] = 0`（按 `f̄` 的定义）→ 偏差项与方差项的交叉项为 0。

于是：

```
Err(x) = σ²                      不可约噪声
       + ( f*(x) − f̄(x) )²        偏差²：算法的系统性偏离
       + E_S[ ( f_S(x) − f̄(x) )² ] 方差：对训练集抽样的敏感度
```

**三条必须点明的性质**：
1. 分解是对**同一个 x、对训练集分布**求期望，**不是**对 x 求平均；
2. 只对**平方损失**成立。0-1 损失没有这样的恒等式，分类里的「偏差-方差」是类比而非恒等；
3. `σ²` 是下界——任何模型都无法突破（除非数据本身无噪声）。

## 2. 从分解到工程：三个可控项

```
误差
 │        ┌──────── 总误差
 │      ╱   ╲
 │    ╱       ╲            ← 最优点：偏差与方差之和最小
 │  ╱  偏差²    ╲ 方差
 │╱              ╲
 └──────────────────────── 模型复杂度 →
```

| 现象 | 偏差 | 方差 | 训练误差 | 验证误差 | 处置 |
|---|---|---|---|---|---|
| 欠拟合 | 高 | 低 | 高 | 高 | 加特征/加容量/减正则/训练更久 |
| 过拟合 | 低 | 高 | 低 | 高 | 加数据/加正则/早停/降容量/集成 |
| 正常 | 适中 | 适中 | 略低于验证 | 与训练接近 | — |

**这套表格的价值在于：它把「调什么」变成了诊断而不是猜测。**
训练误差高 → 先别正则化（会更高）；训练低验证高 → 别再加特征。

## 3. 过拟合的五种成因（不止「模型太复杂」）

1. **容量型**：假设空间过大（高次多项式、无限深的树、参数量远超有效样本）。
2. **样本型**：样本少、标签噪声大、样本间高度相关（有效样本量 ≪ 行数）。
3. **优化型**：训练轮数过多（早停能救）、学习率过大导致记住噪声。
4. **选择型**：用同一份验证集反复调参、用测试集选模型 → **选择性偏差**，验证误差变乐观。
5. **泄漏型**：预处理/目标编码/时间穿越把验证集信息带进训练 → 验证误差**虚假地低**。
   这一类最危险：它看起来像「模型很好」，其实评估已经失效。

## 4. 正则化的两种解释，必须都会说

**惩罚视角**：`min R̂_S(w) + λ‖w‖²`，限制有效容量。

**贝叶斯视角**：`w ~ N(0, τ²I)`，MAP 估计

```
argmax_w [ log P(S|w) + log P(w) ] = argmin_w [ Σℓ + (1/2τ²)‖w‖² ]
```

对照可得 `λ = 1/(2τ²)`：**先验越强（τ 越小）→ λ 越大 → 收缩越狠**。
L1 对应拉普拉斯先验，尖峰在 0，所以后验众数落在坐标轴上 → 稀疏。

**为什么正则化能改善泛化**：它让 `f_S` 对 S 的扰动不敏感。
形式上，若算法满足**一致稳定性**（换掉一个样本，输出变化 ≤ β），
则泛化 gap 有界 `O(β·m)`——正则化正是在压 β。这比「防止过拟合」这句口号精确得多。

## 5. 样本复杂度与学习曲线：要多少数据才够

对有限假设空间 `|H| = N`，以概率 `1−δ`：

```
R(f) ≤ R̂_S(f) + √( (log N + log(1/δ)) / (2m) )
```

这个式子给出三个可操作结论：
1. **误差随 1/√m 下降**——数据翻四倍，gap 才减半；
2. **容量（log N）越大，需要的样本越多**——这就是「大模型需要大数据」的形式化版本；
3. 界通常很松（对无限假设空间要用 VC 维/Rademacher），**只能用来比较趋势，不能当预测**。

**学习曲线**（横轴样本量，纵轴误差）是工程上更实用的工具：
- 训练与验证**都高且靠近** → 高偏差，**加数据没用**，要加容量/改特征；
- 训练低、验证高且**间距随数据增大而收窄** → 高方差，**加数据有效**；
- 间距不收敛 → 分布不一致或泄漏，先查数据管道。

## 6. 双下降：经典图像错在哪

把横轴从「模型复杂度」换成「参数量 / 训练轮数」，测试误差的走势是：

```
测试误差
  │╲
  │ ╲                    ← 经典区间：过拟合峰值
  │  ╲      ╱╲
  │   ╲____╱  ╲
  │            ╲___________  ← 过参数化区间：再次下降
  └────────────────────────── 参数量 →
        插值阈值（训练误差≈0）
```

**发生了什么**：在插值阈值附近，模型刚好有足够自由度记住训练集（含噪声），
但还没有多到「存在大量解、SGD 能挑到好的那一个」，因此方差爆炸；
继续增大容量后，零训练误差的解**极多**，SGD 的**隐式偏置**（偏向最小范数/平坦解）
会挑到泛化好的解，误差重新下降。

**它打破了什么**：打破了「复杂度 ↑ ⇒ 方差 ↑」的单调假设，**没有**打破偏差-方差分解本身。
所以正确表述是：「分解仍成立，但在过参数化区间，有效容量不再由参数个数决定」。

**工程含义**：
- 不要用「参数比样本多」判断过拟合，要看**训练/验证间距**；
- 现代模型「先训到插值再早停」是常态，早停点在**第二次下降**的谷底，而不是第一次；
- 这也解释了为什么**大模型 + 早停**能同时低偏差低方差。

## 三视角解析

### 🧑‍💻 程序员视角
- 上手先画**学习曲线**（`sklearn.model_selection.learning_curve`）：它比任何调参都先告诉你
  「该加数据还是该加模型」。数据不够时调参是在拟合验证集。
- 正则化强度不是越大越安全：`λ` 过大 → 高偏差，训练误差先涨、验证误差跟着涨。
  用**对数网格**（1e-4…1e2）扫，看验证曲线的最低点。
- 集成是「降方差的确定性手段」：随机森林几乎不增加偏差；但**Boosting 会增加方差**，
  所以它需要学习率与早停，不能无脑加树。
- 线上「离线好、线上差」的常见原因不是方差，而是**分布漂移**——偏差-方差假设同分布，
  漂移一发生，这套分析全部失效。

### 🎓 博士生视角
- 分解的三项中，`σ²` 与算法无关；偏差由**假设空间是否包含 f*** 决定；方差由**算法对样本扰动的敏感度**决定。经典结论：`E[Err] = σ² + bias² + variance` 是**逐点**成立的，对 x 积分后仍成立。
- 用 **VC 维**刻画容量时，界是分布无关的最坏情形，常数极大；用 **Rademacher 复杂度**可以刻画数据相关容量，解释「同样的参数量，数据分布不同 → 泛化不同」。
- **双下降的三类解释**：① 最小范数插值解的范数随参数量增大而减小（隐式正则）；② 有效自由度由数据协方差的谱决定，而非参数个数；③ 过参数化区域的损失景观更平坦（Hessian 迹更小），对应更好的泛化。三者不互斥。
- **稳定性视角**：SGD 的泛化界可由算法稳定性给出，`β ∝ ηT/m`，因此**学习率与训练步数直接进入泛化界**——这解释了为什么「调学习率能调泛化」。

### 📚 考研者视角
- 这是自命题 AI 专业课的**必考推导**：写出 `Err(x) = σ² + bias² + variance` 的三项来源，
  并说明「哪一项随模型复杂度上升、哪一项下降」。
- 标准表述：偏差度量**学习算法的期望预测与真实结果的偏离程度**（刻画拟合能力），
  方差度量**同样大小的训练集的变动所导致的学习性能的变化**（刻画数据扰动影响），
  噪声表达**当前任务上任何学习算法所能达到的期望泛化误差下界**。
- 常考对比：**Bagging 主要降方差**（并行、平均）、**Boosting 主要降偏差**（串行、拟合残差）。
  答题要给出「为什么」：平均不改变期望，只压方差；前向分步持续减小残差，直接降偏差。
- 易错点：把「偏差-方差窘境」说成「必然的单调权衡」——双下降说明在过参数化区域不成立。
