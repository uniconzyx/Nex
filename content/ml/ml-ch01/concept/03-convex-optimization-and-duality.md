# 优化：凸性、梯度下降与对偶——一切「训练」的数学内核

> 训练模型 = 解一个优化问题。但**能不能解到全局最优**、**要几步**、**对步长多敏感**，
> 全由目标函数的几何性质决定。本章的三个关键词——**凸性、光滑性、强凸性**——
> 就是你判断「这个模型好不好训」的全部依据。

## 1. 凸性：为什么它值钱

**凸集**：`∀x,y∈C, ∀t∈[0,1]: tx + (1−t)y ∈ C`（集合内任意两点的连线仍在集合内）。
**凸函数**：定义域是凸集，且

```
f(tx + (1−t)y) ≤ t f(x) + (1−t) f(y)
```

即「函数图像在任意割线下方」。三条等价判据必须会：

| 判据 | 形式 | 用途 |
|---|---|---|
| 一阶条件 | `f(y) ≥ f(x) + ∇f(x)ᵀ(y−x)` | 说明**梯度给出全局下界**（局部信息定全局） |
| 二阶条件 | `∇²f(x) ⪰ 0`（半正定） | 实际验算：Hessian 特征值非负 |
| 保凸运算 | 非负加权和、仿射复合、逐点最大、部分最小化 | 快速判断「这个目标是不是凸的」 |

**为什么凸性值钱**：凸问题的**任何局部极小都是全局极小**。所以「训练不收敛」在凸问题里
只可能是优化器/步长/数值问题，而不是「陷在局部最优」——这句判断能省掉大量排查时间。

**强凸**：存在 `μ>0` 使 `f(y) ≥ f(x) + ∇f(x)ᵀ(y−x) + (μ/2)‖y−x‖²`。
它保证**解唯一**且**二次增长的下界**，是线性收敛率的前提。
**L-光滑**：`‖∇f(x) − ∇f(y)‖ ≤ L‖x−y‖`，等价于 Hessian 的最大特征值 ≤ L。
`κ = L/μ` 是**条件数**——它决定了梯度下降有多难。

```
        凸 + 光滑                     强凸 + 光滑
   f                          f
   │      ╱‾‾‾╲               │        ╱‾╲
   │    ╱       ╲             │      ╱    ╲
   │  ╱           ╲           │    ╱        ╲
   └──────────────►           └──────────────►
   O(1/k) 次优间隙             (1−μ/L)^k 线性收敛
```

## 2. 梯度下降：收敛率是可以推出来的

更新式 `x_{k+1} = x_k − η∇f(x_k)`。在 L-光滑下取 `η = 1/L`：

```
f(x_{k+1}) ≤ f(x_k) − (1/2L)‖∇f(x_k)‖²
```

累加 k 步并利用凸性，得到经典结论：

```
f(x_k) − f* ≤ L‖x_0 − x*‖² / (2k)     →  O(1/k)
```

若进一步强凸（常数 μ），则

```
‖x_k − x*‖² ≤ (1 − μ/L)^k ‖x_0 − x*‖²   →  迭代数 O(κ log(1/ε))
```

**三个直接可用的推论**：
1. **步长上限是 1/L**。超过它，上面的下降引理不再成立，可能发散。
2. **条件数 κ 决定难度**：κ=1（各向同性）一步到位；κ=10⁶ 时梯度下降在「狭长山谷」里反复横跳。
   **特征标准化正是为了降 κ**——这是预处理最重要的理论理由。
3. **岭回归加 λI 也降 κ**：`κ = (σ_max²+λ)/(σ_min²+λ)`，所以正则化同时改善**泛化**与**可优化性**。

**动量（Momentum）**：`v ← βv − η∇f`，`x ← x + v`。它把「沿同一方向的分量」累加、
把「来回震荡的分量」抵消，等价于把条件数从 κ 改善到 √κ 量级。
**Nesterov** 先在动量方向探一步再取梯度，收敛率同为 O(1/k²) 但常数更优。

## 3. 随机梯度（SGD）：用方差换速度

全量梯度每步要扫 m 个样本，代价 O(md)。SGD 用**小批量**估计：

```
g_B = (1/|B|) Σ_{i∈B} ∇ℓ_i(x),   E[g_B] = ∇f(x),   Var(g_B) ∝ σ²/|B|
```

- **无偏但高方差** → 步长必须随训练衰减（`η_t ∝ 1/√t` 或余弦退火），否则在最优点附近震荡；
- **线性加速**：batch 从 1 增到 B，方差降 B 倍，但**边际收益递减**——超过临界 batch 后
  再增大只增加算力不改善收敛（这是「大批量训练需要调学习率 warmup」的根源）；
- **噪声有正则效应**：小批量噪声帮助逃离尖锐极小值，常带来更好的泛化（这是「大批量泛化差」的常见解释，仍有争议）；
- **收敛率**：凸 + 光滑下，`E[f(x_k)] − f* = O(1/√k)`；强凸下 `O(1/k)`（比全量梯度慢一档）。

## 4. 牛顿法：用二阶信息换迭代数

```
x_{k+1} = x_k − [∇²f(x_k)]⁻¹ ∇f(x_k)
```

在极小值附近**二次收敛**（误差平方级下降），迭代数几乎与 κ 无关。但代价是：
- 构造 + 求逆 Hessian 是 `O(d³)`，高维不可行；
- 需要 Hessian 正定，非凸区域要加阻尼（`H + λI`，Levenberg-Marquardt）；
- **拟牛顿（BFGS/L-BFGS）**用梯度差近似 Hessian 逆，`O(d²)` 内存（L-BFGS 降到 O(md)），
  是逻辑回归、CRF 的经典求解器。

**逻辑回归的 IRLS** 就是牛顿法的一个特例：把加权最小二乘作为每步的子问题。
这解释了为什么 `sklearn` 的 `lbfgs` 求解器在小数据上迭代几十次就收敛。

## 5. 约束优化与对偶：SVM 的地基

原问题：

```
min_x f(x)
s.t.  g_i(x) ≤ 0,  i=1..m
      h_j(x) = 0,  j=1..p
```

**拉格朗日函数**：`L(x, α, β) = f(x) + Σα_i g_i(x) + Σβ_j h_j(x)`，`α ≥ 0`。

**对偶函数**：`g(α,β) = inf_x L(x,α,β)`。它**恒为凹函数**（逐点下确界保凹），
且对任意 `α≥0` 有 `g(α,β) ≤ f(x)`（弱对偶）。

**强对偶**成立的条件（Slater 条件）：凸问题 + 存在严格可行点。
此时 `d* = p*`，且最优解满足 **KKT 条件**：

```
① 平稳性：∇f(x*) + Σα_i∇g_i(x*) + Σβ_j∇h_j(x*) = 0
② 原始可行：g_i(x*) ≤ 0, h_j(x*) = 0
③ 对偶可行：α_i ≥ 0
④ 互补松弛：α_i g_i(x*) = 0        ← 这一条最有用
```

**互补松弛的含意**：若约束**不起作用**（`g_i(x*) < 0`），则 `α_i = 0`；
只有**紧约束**（`g_i(x*)=0`）才有 `α_i > 0`。这正是 SVM 里「只有支持向量有非零 α、
决策边界只由支持向量决定」的来历——**稀疏性不是巧合，是 KKT 的必然结果**。

**为什么 SVM 要转对偶**：转对偶后问题只依赖**样本内积** `⟨x_i,x_j⟩`，
于是可以把内积替换成核函数 `K(x_i,x_j)`，**无需显式构造高维映射**。
这就是「核技巧」的代数基础。

## 6. 一张图收束：模型 → 优化问题 → 解法

```
模型            目标函数几何性质              解法                 保证
────────────────────────────────────────────────────────────────────────
线性回归        凸、光滑、强凸(λ>0)          正规方程/L-BFGS/SGD   全局最优
岭回归          同上，κ 更小                 闭式解              全局最优
Lasso           凸、非光滑(L1)               坐标下降/近端梯度     全局最优
逻辑回归        凸、光滑（非强凸，需正则）    L-BFGS/牛顿(IRLS)    全局最优
SVM(对偶)       凸二次规划(QP)               SMO/内点法           全局最优
神经网络        非凸、非光滑(ReLU)           SGD/Adam             局部最优
```

## 三视角解析

### 🧑‍💻 程序员视角
- 训练不收敛时按顺序查：**特征是否标准化**（κ）、**学习率是否超过 1/L**、
  **loss 是否出现 nan**（数值溢出，先做 log-sum-exp / 减最大值）、**标签是否错位**。
  90% 的「调不动」是这四项之一。
- `sklearn` 的 `solver` 不是随便选的：小数据 `lbfgs`（二阶、快），大数据 `saga`（支持 L1、
  随机平均梯度），稀疏高维 `liblinear`。选错会慢一个数量级。
- 别在凸模型上浪费时间调初始化——凸问题的解与初始化无关（数值病态除外）。
- 早停本质是「用训练步数当正则」：它在验证 loss 开始上升时停，等于限制了参数的最短描述长度。

### 🎓 博士生视角
- 收敛率的三档：**L-光滑凸** `O(1/k)`；**μ-强凸** `O((1−μ/L)^k)`；**加速（Nesterov）** 可达
  `O(1/k²)`，且这是**一阶方法的理论下界**（Nemirovski & Yudin）。所以「加动量」不是玄学，
  是在逼近这个下界。
- 对偶间隙 `p* − g(α,β)` 提供了**可计算的停止准则**——原始-对偶内点法正是靠它判断收敛，
  这比「梯度范数小于阈值」更可靠。
- KKT 的四条是**必要条件**；凸 + Slater 时它也是**充分条件**。非凸问题里 KKT 点只是候选，
  可能是鞍点（二阶条件 `∇²L ⪰ 0` 才能排除）。
- **隐式正则视角**：SGD 的解偏向「低范数/平坦」区域，这不是目标函数写的，而是**算法带来的**。
  这个观察是理解双下降与泛化的关键线索。

### 📚 考研者视角
- 408 里与本章直接对应的是**算法复杂度分析**：梯度下降 `O(1/k)` 的推导方式，
  与「循环不变式 + 求和」的分析范式一致；`κ` 与「最好/最坏情况比值」是同一个思维。
- 数学一/数学二必考的**拉格朗日乘数法**与**KKT** 就在本章：条件极值、不等式约束、
  互补松弛。考研答题要求写清「构造 L → 求偏导 → 联立 → 讨论乘子是否为零」。
- 常见口径错误：把「强对偶一定成立」当成普遍结论——它需要**凸性 + 约束品性（Slater）**。
  非凸问题存在**对偶间隙**，这是 SVM 之外很多问题只能用近似解的原因。
