# 学习范式：从「拟合训练集」到「在未见数据上不犯错」

> 机器学习的一切讨论都建立在一个前提上：**训练集只是从数据分布里抽出的样本，
> 我们要的是在这个分布上表现好，而不是在这批样本上表现好。**
> 这句话听起来像废话，但它直接决定了后面所有概念的位置——损失、正则、验证、
> 泛化界，全是为了把「样本上的表现」和「分布上的表现」之间的缝补上。

## 1. 形式化：一个学习问题由五件东西组成

```text
        未知分布 D                    假设空间 H
   (x, y) ~ D  ──────────────►   f ∈ H : X → Y
        │                              │
        │  抽样                          │  学习算法 A
        ▼                              ▼
   训练集 S = {(xᵢ,yᵢ)}ᵐᵢ₌₁  ──►  f_S = A(S)
                                       │
                                       ▼
                        风险 R(f) = E_{(x,y)~D}[ ℓ(y, f(x)) ]
                        经验风险 R̂_S(f) = (1/m) Σ ℓ(yᵢ, f(xᵢ))
```

| 要素 | 含义 | 典型选择 |
|---|---|---|
| 输入空间 X | 特征怎么表示 | 原始特征、embedding、图像张量 |
| 输出空间 Y | 预测什么 | 连续值、类别、排序、结构化输出 |
| 假设空间 H | 允许哪些函数 | 线性函数、深度为 d 的树、核方法再生核空间 |
| 损失 ℓ | 错多少 | 平方、交叉熵、合页、排序损失 |
| 算法 A | 怎么在 H 里挑 | ERM、正则化 ERM、贝叶斯后验、SGD |

**关键点**：`H` 的复杂度（容量）决定了「能不能拟合」，`A` 的选择决定了「拟合到哪一个」。
后面讲的正则化、早停、集成，本质上都是**在 A 这一层做约束**，而不是改 H。

## 2. 经验风险最小化（ERM）为什么不够

ERM 的做法是 `f_S = argmin_{f∈H} R̂_S(f)`。它在训练集上最优，但有两个致命问题：

1. **过拟合**：当 H 足够大（比如「记住每个样本的查表函数」），存在 f 使 `R̂_S(f)=0`，
   但它在分布外的表现是随机猜测。
2. **ERM 的不一致性**：即使 H 固定，ERM 的泛化误差上界里有一项
   `√(复杂度(H)/m)`。样本量 m 不够时，这一项会把上界撑到 1 以上——界失效，不代表一定过拟合，
   但代表**没有任何保证**。

工程上的解法是**正则化 ERM**：

```
f_S = argmin_{f∈H} [ R̂_S(f) + λ·Ω(f) ]
```

`Ω` 惩罚复杂度（‖w‖²、树的叶子数、网络参数量），`λ` 是「拟合 vs 简单」的旋钮。
从贝叶斯视角看，这就是**最大后验（MAP）**：`Ω` 对应参数的负对数先验。

> 一句话：**ERM 只回答「训练集上谁最好」，正则化 ERM 回答「训练集上够好且不太离谱的谁最好」。**

## 3. 四种学习范式：区别在「监督信号从哪来」

| 范式 | 监督信号 | 典型任务 | 代表 |
|---|---|---|---|
| 监督学习 | 每个样本带标签 y | 分类、回归、排序 | 逻辑回归、GBDT、SVM |
| 无监督学习 | 没有 y，只有结构 | 聚类、降维、密度估计 | K-means、PCA、GMM |
| 自监督学习 | 从数据本身造标签 | 预训练表示 | 掩码语言模型、对比学习、Next-token |
| 强化学习 | 延迟的标量奖励 | 序列决策 | Q-learning、Policy Gradient |

**自监督不是「无监督」的同义词**：它仍然有监督信号（预测被遮住的词、判断两张图是否同源），
只是标签由数据自动生成。这个区分很重要——大模型的预训练就是自监督，
它的成功来源于「造出了极大量、极便宜的标签」，而不是「不需要标签」。

**强化学习与前两者的本质差异**：数据分布**依赖策略**（你的动作改变了下一步看到的状态），
因此 i.i.d. 假设失效，探索与利用产生张力。经典 ML 的交叉验证、ERM 分析**不能直接搬过去**。

## 4. 生成式 vs 判别式：建模什么，决定你能干什么

- **判别式**：直接学 `P(y|x)` 或决策函数 `f(x)`。逻辑回归、SVM、树、绝大多数分类网络。
- **生成式**：学 `P(x,y) = P(x|y)P(y)`，再用贝叶斯公式推 `P(y|x)`。朴素贝叶斯、GMM、HMM。

| 维度 | 生成式 | 判别式 |
|---|---|---|
| 假设强度 | 强（如条件独立） | 弱 |
| 小样本 | 常更好（收敛快） | 易过拟合 |
| 大样本 | 有渐近偏差 | 通常更准 |
| 能采样/补缺失 | 能 | 不能 |
| 半监督 | 可用无标注数据估 P(x) | 不自然 |

**面试常问「哪个更好」，正确答案是「取决于样本量与假设是否正确」**，并给出 Ng & Jordan (2002)
的结论：朴素贝叶斯收敛率 O(log m)，逻辑回归 O(m)，所以小样本时前者领先，样本增大后后者反超。

## 5. 归纳偏置：没有它，学习不可能

归纳偏置是「模型在未见数据上做假设的方式」。它不是缺陷，而是**泛化的必要条件**：

- 线性模型：输出对特征是线性的（轴外的点按线性外推）；
- 决策树：决策边界**轴对齐**的分段常数；
- CNN：局部性 + 平移等变；
- GBDT：多个弱可加修正项叠加；
- kNN：相近的 x 有相近的 y（局部光滑）。

「没有免费午餐」定理（Wolpert, 1996）说：在**所有可能目标函数上均匀分布**时，
任何算法的期望误差相同——**因为没有哪种偏置在所有问题上都对**。
所以模型选型不是找「最强模型」，而是找**偏置与数据生成机制匹配**的模型：

```
表格数据（异质、轴对齐、含缺失/异常） → 树的偏置更匹配 → GBDT 常胜
图像（局部相关、平移不变）           → 卷积偏置更匹配 → CNN
长文本（长程依赖、位置任意）         → 注意力的偏置更匹配 → Transformer
```

## 6. 把「学习」看成压缩：一个更有用的直觉

一个模型能泛化，意味着它**用比数据更短的描述抓住了规律**。
「记住 10000 个样本」需要 10000 条记录，没有压缩；「用 3 个参数的直线解释 10000 个点」
是极高压缩——只有真正存在线性规律时才能做到，所以它能外推。

这个视角能解释三件事：
1. 为什么**正则化有效**：它直接惩罚描述长度；
2. 为什么**数据增强有效**：它把「哪些变换不改变语义」这条先验写进数据，等价于缩小假设空间；
3. 为什么**过度参数化仍能泛化**（双下降）：SGD 的隐式偏置偏向「平坦/最小范数」解，
   这本身是一种压缩，尽管参数个数很多。

## 三视角解析

### 🧑‍💻 程序员视角
- 落地时先问三个问题：**标签怎么来的、正负样本比例多少、预测时刻哪些特征真的可得**。
  这三问答不清，后面选什么模型都是白费。
- 基线顺序：`多数类/均值` → `逻辑回归（带标准化）` → `GBDT` → 再考虑复杂模型。
  跳过前两步的人，通常无法判断「复杂模型没涨点」是模型问题还是特征问题。
- 「生成式 vs 判别式」在工程里的真实分野是**能不能采样**：要做数据增广、异常检测、
  缺失值补全，才需要生成式；只是分类，判别式更省事。
- 不要用训练集上的 loss 判断收敛——它对泛化几乎无信息；看**验证曲线间距**。

### 🎓 博士生视角
- 学习理论的三条主线：**一致性**（ERM 是否收敛到最优）、**收敛率**（要多快）、
  **泛化界**（VC 维/Rademacher 复杂度/稳定性）。VC 界是分布无关的最坏界，实际严重偏松；
  基于算法稳定性的界（Bousquet & Elisseeff）更贴近 SGD。
- 双下降（Belkin et al., 2019）打破的是「容量-方差单调」这一**隐含假设**：
  在插值阈值附近测试误差出现峰值，继续增大容量后误差再次下降。
  机制解释包括**隐式正则**（最小范数解）、**有效维度**（数据流形维数）、
  **平坦极小值**（Hessian 谱）三条线，目前没有统一理论。
- 生成式与判别式的收敛率差异来自**估计目标不同**：`P(x,y)` 的估计误差要经过贝叶斯公式放大，
  而 `P(y|x)` 直接对准决策边界，因此后者渐近更优但样本效率更低。

### 📚 考研者视角
- **408 不考机器学习**，但「算法设计题」常要求**证明贪心/DP 的最优性**，
  这与「ERM 在假设空间内最优」是同一种思维方式：**先明确解空间，再证明你的选择在其中最优**。
- 若报考人工智能方向（自命题 841/859 等），本章对应考点：
  **监督/无监督/强化学习的区别**、**生成式与判别式模型举例**、**过拟合与正则化**、
  **偏差-方差权衡**。标准表述要能写出分解式并说明每一项的含义。
- 易错口径：**「没有免费午餐」≠「所有算法效果一样」**。答题时要补一句
  「该定理假设目标函数在全体上均匀分布，真实问题存在结构，故归纳偏置与问题匹配才产生优势」。
