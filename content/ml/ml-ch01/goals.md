# ml-ch01 · 学习范式与数学基础：从「拟合」到「泛化」

> 先修：data-ch01（NumPy 与向量化）、高等数学（梯度/海森矩阵）、线性代数（特征值/SVD）。
> 后续：ml-ch02（线性模型）、ml-ch04（SVM 的对偶推导）、ai-ch01（深度学习从这里接棒）。
> 面试权重：★★★★★（算法岗一面必问偏差-方差与过拟合；「为什么正则化有用」是区分度题）

## 本章目标

学完你应该能：

1. **把学习问题形式化**：写清「分布 → 样本 → 假设空间 → 学习算法 → 风险」这条链，
   并说明经验风险最小化（ERM）为什么不足，正则化 ERM 补上了什么。
2. **默写偏差-方差分解并解释每一项**：包括三个交叉项为什么消失、分解依赖哪些假设、
   为什么它只对平方损失成立。
3. **拿到一组「训练高/验证高」的曲线就能判断该加数据还是加容量**，
   而不是凭感觉调参；能说清过拟合的五种成因（容量/样本/优化/选择/泄漏）。
4. **判断一个目标函数好不好训**：用一阶/二阶条件验凸性，用 `κ = L/μ` 解释为什么标准化有效，
   用 `O(1/k)` 与 `(1−μ/L)^k` 说出收敛速度的量级。
5. **写出 KKT 四条件并解释互补松弛**：为 ml-ch04 的 SVM 稀疏性打地基——
   能说清「为什么只有支持向量有非零 α」。
6. **解释双下降**：说清它打破的是「容量-方差单调」而非偏差-方差分解本身。

## 关键认知（本章最值钱的三句）

- **训练误差不是目标，它只是分布风险的一个有偏样本估计**。所有泛化手段
  （正则、早停、集成、数据增强）都在做同一件事：**降低模型对训练集抽样的敏感度**。
- **偏差-方差是恒等式，但它有前提**（平方损失、同分布、固定 x 求期望）。
  把它当万能解释去套分类/漂移/双下降，就会得出错误结论。
- **凸性决定的不是「能不能学会」，而是「能不能保证解到全局最优、几步到」**。
  神经网络放弃的是这个保证，换来的是表达能力——这是有意识的交易，不是缺陷。

## 与「深度学习」的分界（避免与 ai 学科混淆）

本章讨论的是**经典机器学习的理论地基**：假设空间、泛化、凸优化。
`ai-ch01` 从**张量、计算图、反向传播**讲起——那是「用多层网络自动学习表示」的另一条路线。

两者的关系是**包含而非并列**：深度学习是机器学习的一个子领域。
分界点在于**表示从哪来**：

| | 经典机器学习（本学科） | 深度学习（ai 学科） |
|---|---|---|
| 特征 | 人工设计（特征工程是核心工作） | 从数据中自动学习表示 |
| 模型 | 凸/近凸、可解释、样本效率高 | 非凸、参数海量、需要大数据 |
| 优化 | 凸优化，有全局最优保证 | SGD/Adam，只有局部最优保证 |
| 典型场景 | 表格数据、中小样本、强解释需求 | 图像/语音/文本、海量数据 |

本学科第 8 章末尾会显式给出「什么时候该上深度学习」的工程判据。
