# 诊断先于调参：偏差-方差、学习曲线与误差分析

> ml-ch01 给出了偏差-方差的**恒等式**；本章讲它的**工程用法**：
> 拿到一个「训练/验证」表现不好的模型，先诊断它是偏差问题还是方差问题，
> 再决定动作。跳过诊断直接调参，是在拟合验证集。
> 诊断工具只有两样：**学习曲线**（误差随样本量怎么变）与
> **误差分析**（错误在样本里怎么分布）。

## 1. 诊断表：从两条曲线读出「该加数据还是该加容量」

**中立陈述**：训练误差与验证误差的**绝对水平**刻画偏差，
两者的**间距**（generalization gap）刻画方差。四个象限对应四种处置：

```text
验证误差 │
        │  ① 都高、靠近            ② 训练低、验证高
        │     → 高偏差                → 高方差
        │     加容量/加特征            加数据/加正则/早停
        │
        │  ③ 都低、靠近            ④ 都高、远离
        │     → 可接受                 → 数据/标注/管道问题
        └──────────────────────────── 训练误差 →
```

| 现象 | 偏差 | 方差 | 典型原因 | 有效动作 | 无效动作 |
|---|---|---|---|---|---|
| 训练高、验证高、gap 小 | 高 | 低 | 容量不足、特征不够、正则太强 | 加容量/加特征/减正则 | **加数据**（两条线都不动） |
| 训练低、验证高、gap 大 | 低 | 高 | 容量过剩、样本少、标签噪声 | 加数据/加正则/早停/集成 | 加特征（gap 更大） |
| 训练低、验证低、gap 小 | 中 | 中 | — | 检查是否接近天花板 | 继续微调 |
| 训练高、验证也高、gap 大 | 高 | 高 | 优化失败/数据错位/标注噪声 | 先查管道与标签 | 任何调参 |

**为什么「加数据」对高偏差无效**：把恒等式 `Err = σ² + bias² + variance` 按
样本量 `m` 展开，典型标度是 `bias² = O(1)`、`variance = O(1/m)`（容量固定时）——
加数据只压 `1/m` 那一项。高偏差时主导项是常数，加多少数据都不动。
这就是学习曲线第一行「两条线都平」的数学原因。

## 2. 学习曲线：让诊断可复现

**中立陈述**：学习曲线是「误差 vs 训练样本量」的曲线，每条曲线按多个训练集大小
重复抽样取平均。它的读法是看**两条线各自的位置**与**间距随样本量的变化趋势**：

```
MSE │
    │ 训练误差 ═══════════════════   （容量固定时缓慢下降后趋平）
    │        ╲
    │         ╲___  验证误差（随 n 增加而下降，向训练误差靠近）
    │              ╲________
    │
    │  ←── gap 随 n 收窄 = 高方差，加数据有效 ──→
    └──────────────────────────────────── 训练样本量 n →
```

```python
# 读图判据（对应 ml-ch04 示例 ex05 的判定逻辑）
if train_err ≈ val_err and both high:  诊断 = "高偏差"；加数据无效
if gap 随 n 增大而明显收窄:             诊断 = "高方差"；加数据有效
if gap 不随 n 收窄:                     诊断 = "分布不一致或泄漏"；先查管道
```

- **高偏差档**（如 1 次多项式拟合 `sin`）：训练/验证都停在噪声水平附近，
  样本量翻十倍曲线平移不到 1 毫米——此时应该换模型/加特征，而不是采购数据。
- **高方差档**（如 9 次多项式）：小样本时 gap 巨大，n 增大后 gap 收窄、
  验证误差持续下降——数据是瓶颈，加数据（或加正则、早停）收益最大。
- **曲线不收敛型**：gap 不随 n 收窄、两线永远远离，通常是**分布不一致**
  （训练/验证不同源）或**泄漏**（离线虚高）——这在调参层面无解，只能查数据管道。

### 学习曲线必须先固定评估口径

**与交叉验证的关系**：学习曲线的每个点本身就是一次「留出/交叉」评估；
所以它必须固定验证集（或固定外层折），只变训练集大小，否则测的是两个变量的叠加。

## 3. 误差分析：错误不是均匀分布的

**中立陈述**：整体错误率 `(1/n)Σ 1[ŷ≠y]` 是**未加权的平均**，
它会把「一个切片错误率 60%、占样本 5%」和「整体 10%」混为一谈。
误差分析的做法是：按业务维度切片，同时报告每个切片的**错误率**与**错误占比**，
用两者的乘积排优先级。

```
总错误 = Σ_切片 (切片样本占比 × 切片错误率)
         └── 两个因子都要大才是优先级高的切片 ──┘
```

| 切片 | 样本占比 | 错误率 | 错误占比 | 诊断 |
|---|---|---|---|---|
| A 区 | 40% | 10% | 22% | 正常水平 |
| B 区 | 35% | 12% | 23% | 正常水平 |
| C 区 | 25% | **38%** | **55%** | **高错误率 × 大占比 → 优先排查** |

（数据形态对应 ml-ch04 示例 ex06：整体 25% 的错误率看不出问题，
拆开后 C 区错误率是 A/B 的两倍且贡献过半错误。）

**操作规程**（Chip Huyen《Designing Machine Learning Systems》第 8 章的误差分析流程）：
1. 先按**业务维度**切（地区/设备/新老用户/渠道/时间），不要按模型内部量切；
2. 同时看错误率与错误占比——只修错误率高的会去啃只有 5 条样本的噪声切片，
   只修错误占比高的会放过「错误率 80% 但样本少」的长尾；
3. 对高优先级切片**看具体失败案例**（打印错误样本、人工归因），
   归类到「数据问题 / 标注问题 / 特征缺失 / 模型容量 / 问题定义」之一；
4. 每轮只改一类问题，重训后对比**切片级**指标——整体指标可能不动，
   但目标切片应该动。

### 误差分析要排在调参之前

**与调参的优先级**：误差分析在调参**之前**。经验上，
「高优先级切片贡献 >30% 错误」时，数据与标注问题的期望收益
远大于超参搜索（调参通常只值 1~3 个点，切片修复常值 10 个点以上）——
这是经验判断，取决于任务，但方向几乎总是如此。

## 4. 天花板：什么时候不该再调模型

**中立陈述**：当验证误差逼近**不可约误差**（贝叶斯误差）时，任何模型手段的
边际收益趋近于零。贝叶斯误差不可直接计算，工程上用两个代理：
**人类在该任务上的表现**，或**同一输入重复标签的经验方差**。

```
验证误差 − 天花板 ≈ 0   →  停止调模型，转向：数据质量 / 特征 / 问题重定义
验证误差 − 天花板 ≫ 0   →  继续按诊断表行动（偏差 or 方差）
```

### 两个可用的天花板代理

- 代理 1：人类专家准确率 95% → 模型 92% 时差距只有 3 个点，
  值得检查的是「错误是否与人类不同质」而不是继续调；
- 代理 2：同一 `x` 重复标注一致率 90% → 任何超过 90% 的离线指标都值得怀疑
  （很可能泄漏，见下一节 ex07）。
- **注意天花板会漂移**：上线后数据分布变了，天花板本身也变，
  要用滚动窗口持续估计（见 ml-ch08 的 MLOps 部分与 ai 学科的监控部分）。

## 三视角解析

### 🧑‍💻 程序员视角
- 落地顺序：**先画学习曲线，再谈调参**。`sklearn` 的 `learning_curve` 一条命令
  出两条线；看「gap 收不收敛」比看任何单点分数都更能回答「该买数据还是该换模型」。
- 误差分析要**可复现**：把切片定义写进配置（不是 notebook 里手改 mask），
  每轮训练自动输出同一张切片表，否则「我们修了 C 区」无法验证。
- 常见陷阱：切片表按 `device ∈ {mobile, desktop}` 切完发现 mobile 差 3 倍，
  往下钻发现是「mobile 且新用户」——**交互切片**才是根因，单维度切片只是入口。
- 「离线好、线上差」先查三件事：**训练/线上特征是否同源**（训练服务偏差）、
  **时间切分是否正确**（随机切造成虚高）、**切片是否掉点**（漂移）。
  这三件查完再怀疑模型，顺序反了会浪费整周。

### 🎓 博士生视角
- 学习曲线与泛化界的对应：固定容量下 `variance = O(1/m)` 正是
  `√(复杂度/m)` 项在均方误差上的体现；容量随 m 增长（结构风险最小化）时，
  曲线形态改变——这是「自适应容量」方法的理论动机。
- 误差分析的统计学形式是**方差分解**：把总误差按切片 `S` 分解为
  `Σ_S P(S)·E[ℓ|S]`，切片间差异即「模型在不同子分布上的风险差异」。
  差异显著 → 子种群风险不公平（subpopulation risk），这也是公平性文献
  （如 group DRO）要优化的对象。
- 天花板的形式化：`R* = E[Var(y|x)]`，任何 `R(f) ≥ R*`。
  当 `R̂_val − R*` 小于估计噪声（样本量决定的 `O(1/√n)`）时，
  「继续优化」在统计上不可分辨——这就是该停手的判据。
- 切片诊断与因果：切片掉点可能来自**选择效应**（新用户本来就更难），
  不一定全是模型缺陷。把「切片错误率」与「切片先验难度」分开，
  才能避免把数据生成机制的问题算到模型头上。

### 📚 考研者视角
- 高频考点：**「模型在训练集上表现好、测试集上差，说明什么？怎么解决？」**
  标准答案三段式：现象 = 过拟合（高方差）；原因 = 模型复杂/数据不足/噪声；
  措施 = 增加数据、正则化、简化模型、早停、集成——**必须同时给出
  「训练误差低、验证误差高」这一判断依据**。
- **学习曲线**是简答题常客：会画、会标注横纵轴、会说
  「两曲线接近且误差都高 → 欠拟合；训练低验证高且间隔大 → 过拟合」。
- 性能度量部分（周志华《机器学习》第 2 章）要能默写：
  查准率/查全率/F1 的定义与公式，以及「P-R 曲线」「ROC/AUC」的绘制方式。
- 易混口径：**偏差-方差分解是期望意义上的恒等式，单次实验测不出三项**；
  答题时说「用实验估计偏差和方差」必须补上「对训练集分布求期望」
  （如重复抽样/bootstrap）这一前提，否则是概念错误。
