# ml-ch04 · 应用机器学习：评估、偏差方差与误差分析

> 先修：ml-ch01（学习范式、偏差-方差、凸优化）、ml-ch02（线性模型与正则化口径）。
> 后续：ml-ch05（决策树与集成）、ml-ch08 末尾的「什么时候该上深度学习」工程判据。
> 面试权重：★★★★★（「训练/验证/测试怎么划」「ROC 和 PR 该看哪个」是算法岗一面高频题；
> 「五类数据泄漏」是区分「跑过 demo」与「上过线」的试金石）

## 本章目标

学完你应该能：

1. **按数据的产生方式选切分策略**：样本独立 → 分层 K 折；同一实体多样本（患者/用户/设备）→
   分组 K 折；带时间顺序 → 前向验证/滚动窗口；调参与评估分离 → 嵌套 CV。
   能说清每种切分「防的是什么错」，以及选错的代价是什么。
2. **识别五类数据泄漏**（预处理、目标、分组、时间穿越、评估重复），并给出对应防线：
   一切 `fit` 进 Pipeline、折内重新拟合、测试集只在最终评估用一次。
3. **用偏差-方差语言做诊断**：看训练/验证曲线与两者的间距，判断「加数据、加容量、
   加正则」哪个真正有效；用学习曲线验证判断，而不是凭感觉调参。
4. **按业务代价选指标与阈值**：不平衡场景用 PR/F1 而非 accuracy/ROC-AUC；
   能解释 AUC 的概率含义（随机抽一对正负例，正例得分更高的概率）；
   知道模型概率不可信时该做 Platt/Isotonic 校准。
5. **跑通完整 ML 工作流**：定义指标 → 切分 → 基线 → 误差分析（切片）→ 迭代 → 上线前检查。
   能把「模型没涨点」定位到数据问题（切片/泄漏/漂移），而不是继续在模型里打转。

## 关键认知（本章最值钱的三句）

- **验证集是「模型选择的测量仪器」，测试集是「最终验收的裁判」**——仪器被反复使用会磨损
  （选择性偏差），裁判被反复围观会失去公正（测试集变验证集）。本章所有切分规则，
  保护的正是这两个角色的分工。
- **「离线分数高」不等于「模型好」**。切分方式错了（分组泄漏、时间穿越），分数衡量的可能是
  记忆力而不是泛化力。看到任何指标先问一句「这个分数可能被什么污染」，再问它是多少。
- **误差分析先于调参**。整体指标是平均值，会掩盖切片差异；按业务维度切片、
  同时看「错误率」与「错误占比」，才能把算力花在真正贵的错误上——
  常见情况是：一个占样本 5% 的切片贡献了 40% 的错误。

## 与「深度学习」的分界（避免与 ai 学科混淆）

本章的**全部方法不依赖模型形式**：切分、指标、泄漏识别、误差分析，对线性模型、
树模型与神经网络一视同仁——这是「应用机器学习」作为方法论文科的价值。

`ai` 学科从**张量、反向传播、多层非线性复合**讲起。本章唯一涉及网络的例子
（迁移实验）只把小型网络当作「预训练权重」的载体，重点在**按目标数据量选训练自由度**
的决策框架；反向传播与网络结构设计是 `ai` 学科的内容，本章不展开。
反过来，本章的切分与评估方法论对深度学习**完全适用**——大模型上线前同样要过
「分组/时间泄漏检查 + 切片误差分析 + 阈值按业务定」这一关。
