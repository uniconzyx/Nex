# ml-ch02 易错点：线性模型的六个认知陷阱

1. **手写 `(XᵀX)⁻¹` 直接求回归系数**
   - 现象：觉得正规方程就是「矩阵求逆」，一行 `np.linalg.inv(X.T@X)@X.T@y` 写完就上线，结果系数数值离谱或在病态数据上报奇异。
   - 根因：`κ(XᵀX) = κ(X)²`，条件数被平方放大；一旦特征尺度不一或共线性，`XᵀX` 接近奇异，求逆的相对误差按 `κ²` 膨胀。
   - 正确做法：用 `np.linalg.lstsq(X, y)`（内部 SVD，数值稳定），或显式 QR/SVD。要做谱滤波/岭回归就用加 `λI` 后的系统，不要对裸 `XᵀX` 求逆。

2. **以为「共线性只影响预测、不用管」**
   - 现象：模型预测分数还行，但业务方要「每个特征的归因」，系数大小符号乱跳，换一批训练样本系数就翻号。
   - 根因：共线性使 `(XᵀX)⁻¹` 在小奇异值方向上被 `1/σ_min` 放大，系数方差爆炸；单个系数的 t 检验失效。
   - 正确做法：上线归因前先算 **VIF**（`1/(1−R²ⱼ)`），`>10` 即严重共线性；要么删/合并特征、做 PCA，要么上岭回归压方差。若目标纯预测、不解释，可保留但必须说清「系数不可解释为因果」。

3. **把 Lasso 当「万能特征选择器」而不看特征相关性**
   - 现象：高度相关的特征组里，Lasso 只随机保留一个、其余压零；换几次随机种子或重抽样，被选中的那一个变来变去，结果不稳定。
   - 根因：Lasso 的变量选择一致性依赖「不可表示性条件」，相关特征违反它时就随机挑；菱形约束域在相关方向上没有「整组一起为零」的偏好。
   - 正确做法：相关特征组用**弹性网**（`l1_ratio<1`），它倾向于整组一起选入或剔除；或先做相关性聚类再选代表特征。

4. **逻辑回归无脑用 MSE 当损失**
   - 现象：分类任务直接最小化 `(y − p)²`，训练慢、概率校准差，饱和样本梯度几乎为零。
   - 根因：MSE = 高斯 MLE，但 `y∈{0,1}` 不是高斯；且梯度含 `p(1−p)` 因子，在 `p→0/1` 时 →0，**梯度消失**。
   - 正确做法：用**交叉熵**（伯努利 MLE），梯度是 `Σ(p−y)x` 无饱和因子；这是统计前提（伯努利）决定的，不是口味。

5. **不平衡数据直接信任默认阈值 0.5**
   - 现象：1% 正例的欺诈检测，模型 accuracy 99%、但一个欺诈都没召回；PR-AUC 极低却没人看。
   - 根因：默认 0.5 假设两类对称、近似均衡；不平衡时正例的似然被稀释，阈值应下移。
   - 正确做法：用 `predict_proba` + **PR 曲线**选阈值（看 F1/P-R 权衡）；或用 `class_weight='balanced'`（等价于对少数类加权/重复样本）。ROC-AUC 在不平衡下会虚高，别只看它。

6. **可分数据上跑无正则逻辑回归，怀疑「初始化没调好」**
   - 现象：迭代次数打满、`‖w‖` 每轮增长、loss 缓慢下降但不停，第一反应是换初始化。
   - 根因：线性可分时存在方向使所有间隔为正，把 `w` 放大 k 倍 loss 严格下降趋 0 但取不到 0——**最优解在无穷远**，凸问题没有坏的局部最优，是问题本身无有限解。
   - 正确做法：加 **L2 正则**（默认 sklearn `C=1.0`，C 是 λ 的倒数）让目标强凸、解唯一；或早停限制 ‖w‖；先排查是否特征泄漏导致「假可分」。
