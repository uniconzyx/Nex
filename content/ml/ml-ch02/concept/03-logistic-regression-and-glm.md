# 逻辑回归与广义线性模型：把「分类」做成「回归」

> 回归做完了，但标签是 0/1 时直接套最小二乘会出问题：预测值可能跑出 [0,1]，
> 残差也不再高斯。逻辑回归的解法是用一个「链接函数」把线性预测子挤进概率，
> 再用交叉熵（伯努利 MLE）当损失。它和线性回归共享同一套优化语言（梯度、Hessian、牛顿法），
> 最后被 GLM 统一成「线性预测子 + 指数族分布 + 链接函数」一个框架。

## 1. 从 odds 到 logit：为什么是 sigmoid

对二分类，记 `p = P(y=1|x)`。直接用 `p = wᵀx` 会越界，所以先取**几率 odds**：

```
odds = p / (1 − p)        ∈ (0, ∞)
logit(p) = log(p/(1−p))   ∈ (−∞, ∞)
```

令 `logit(p) = wᵀx`（线性预测子作用在 logit 上），反解：

```
p = 1 / (1 + exp(−wᵀx)) = σ(wᵀx)        ← sigmoid
```

```
σ(z) = 1/(1+e⁻ᶻ)
 1 ───────────────╲___
    ╲               ╲___
     ╲                   ╲___
 0 ─────────────────────────────── z = wᵀx
      （把任意线性得分单调映射到 (0,1)，且 z=0 处 p=0.5）
```

**为什么要绕一圈到 logit**：odds 非负、logit 无界，恰好能被线性函数自由拟合；
而 p 本身被夹在 [0,1]，线性拟合会逼出「>1 或 <0 的概率」这种无意义值。

## 2. 交叉熵 = 极大似然：为什么不用 MSE

样本独立、标签伯努利 `yᵢ ∈ {0,1}`，似然：

```
P(y|X,w) = Πᵢ pᵢ^{yᵢ} (1−pᵢ)^{1−yᵢ},   pᵢ = σ(wᵀxᵢ)
```

负对数似然（即**交叉熵 / logistic loss**）：

```
ℓ(w) = −Σᵢ [ yᵢ log pᵢ + (1−yᵢ) log(1−pᵢ) ]
```

**这就是逻辑回归的损失**——不是 MSE，而是伯努利 MLE。这一点必须讲清：

| 损失 | 来源 | 在可分数据上 |
|---|---|---|
| 交叉熵 | 伯努利 MLE（正确统计前提） | 无有限解，但加 L2 后强凸可解 |
| MSE | 高斯 MLE（错误前提） | 梯度消失、训练慢、概率校准差 |

为什么不用 MSE：MSE 假设 `y` 是 `σ(wᵀx)` 加高斯噪声，但 `y∈{0,1}` 明显不是高斯；
更严重的是，在 `pᵢ→0/1` 处 MSE 的梯度 `−(yᵢ−pᵢ)·pᵢ(1−pᵢ)·xᵢ` 含 `pᵢ(1−pᵢ)→0`，**梯度消失**，
训练极慢。交叉熵的梯度是 `Σ(yᵢ−pᵢ)xᵢ`（无 `p(1−p)` 因子），信号饱和时梯度不消失。

## 3. 梯度与 Hessian：凸性从哪来

记 `pᵢ = σ(zᵢ)`，`zᵢ = wᵀxᵢ`。梯度：

```
∇ℓ = Σᵢ (pᵢ − yᵢ) xᵢ = Xᵀ(p − y)
```

Hessian：

```
∇²ℓ = Xᵀ diag(pᵢ(1−pᵢ)) X
```

对角元 `pᵢ(1−pᵢ) ∈ (0, 0.25]` **恒非负**，故 Hessian **半正定** → 目标**凸** → 任何局部极小即全局极小。
若 `X` 列满秩且 `pᵢ` 不退化（数据不可分），对角元严格正 → **严格凸 → 唯一解**。
**可分数据**时 `pᵢ→0/1`，对角元 → 0，Hessian 退化、`κ→∞`、参数爆炸——这就是「可分 + 无正则不收敛」的机制（详见 interview）。

## 4. 牛顿法 / IRLS：每步是加权最小二乘

牛顿更新 `w ← w − (∇²ℓ)⁻¹ ∇ℓ`。代入上面的梯度/Hessian，令 `W = diag(pᵢ(1−pᵢ))`：

```
w ← w + (XᵀWX)⁻¹ Xᵀ(y − p)
   = (XᵀWX)⁻¹ XᵀW ( Xw + W⁻¹(y − p) )     ← 令 z = Xw + W⁻¹(y−p) 为「工作响应」
   = (XᵀWX)⁻¹ XᵀW z
```

这正是**加权最小二乘**：`min_w (z − Xw)ᵀ W (z − Xw)`。
每步用当前 `p` 重算权重 `W` 与工作响应 `z`，再解一个岭式正规方程——这就是 **IRLS（迭代重加权最小二乘）**。
它让逻辑回归在小数据上迭代几十次就收敛（`sklearn` 的 `lbfgs` 本质如此，且强凸时二次收敛）。

## 5. Softmax 多分类：数值稳定靠 log-sum-exp

`K` 类时把 sigmoid 推广：对每个类 k 设分数 `z_k = w_kᵀx`，

```
P(y=k|x) = e^{z_k} / Σ_j e^{z_j} = softmax(z)_k
```

**数值陷阱**：`e^{z_k}` 会溢出。用「减最大值」技巧：

```
log Σ_j e^{z_j} = a + log Σ_j e^{z_j − a},   a = max_j z_j
```

这样指数项最大为 1，绝不溢出。交叉熵梯度为 `Σ_k (p_k − 𝟙{y=k}) w_k`——与二分类同构。

## 6. 类别不平衡与阈值：默认 0.5 往往错

逻辑回归输出**概率**，决策阈值默认 0.5 只在「两类代价对称、近似均衡」时合理。
不平衡时（如 1% 正例）：

- **阈值上移**：若漏报代价高，把阈值降到 0.1~0.3 提高召回；
- **类别权重**：`class_weight` 等价于对少数类样本加大 `W` 权重，等价于**过采样/重复少数类样本**；
- **看 PR 曲线而不是 ROC**：不平衡下 ROC-AUC 虚高，PR-AUC / F1 更能反映真实表现。

```
正例比例 1% 时：
  ROC-AUC 0.95 可能只意味着「把正例都判负的代价是误报多」——看着好，召回可能 0；
  PR 曲线直接暴露「查准率随召回崩塌」，判断更诚实。
```

## 7. GLM 统一视角：线性预测子 + 指数族 + 链接函数

逻辑回归不是特例，而是**广义线性模型**的一个成员。GLM 三要素：

```
① 随机分量：y | x ~ 指数族分布  { 高斯(回归), 伯努利(逻辑), 泊松(计数), 伽马(正连续) }
② 系统分量：η = wᵀx  （线性预测子）
③ 链接函数：g(μ) = η，μ = E[y|x]，g 是 μ 的单调可逆函数
```

```
分布         μ = E[y]        链接 g(μ)            对应模型
─────────────────────────────────────────────────────────────
高斯        μ               g = μ（恒等）         线性回归
伯努利      p               g = logit(p)          逻辑回归
泊松        λ               g = log(λ)            Poisson 回归
伽马        1/λ             g = 1/μ              逆高斯回归
```

**统一意义**：所有 GLM 都用**自然参数 = 线性预测子**，损失 = 该分布的负对数似然，
梯度/Hessian 形式一致 → 同一套 IRLS 求解器通吃。这正是「为什么分类和回归共享优化语言」。

## 三视角解析

### 🧑‍💻 程序员视角
- 永远用 `predict_proba` 而不是 `predict` 做业务决策——概率才有阈值可调的空间。先画 PR 曲线再定阈值，别直接信任默认 0.5。
- 不平衡数据第一步不是换模型，是 **`class_weight='balanced'` 或调阈值**。它等价于给少数类加权，工程上就是「重复少数类样本」的数值实现。
- 数值稳定三件套：`log-sum-exp` 减最大值、sigmoid 用 `np.expit`（内置稳定版）、避免手写 `1/(1+exp(-z))` 在 |z| 大时溢出。
- 求解器选择：`lbfgs`（默认、小数据快）、`saga`（支持 L1、大数据）、`liblinear`（二分类超大特征）。别用无正则的纯梯度下降硬跑可分数据——会参数爆炸。
- **注意 `sklearn` 的 `LogisticRegression` 默认带 L2**（`penalty='l2', C=1.0`）：想要「无正则」必须显式设 `penalty=None`，否则你会误以为逻辑回归天然有有限解。

### 🎓 博士生视角
- 交叉熵梯度的简洁性来自指数族的自然参数：`∇_w ℓ = Xᵀ(μ − y)`，对任何 GLM 都成立（μ 是该分布均值）。逻辑回归只是伯努利特例。
- 凸性的精确条件：Hessian `Xᵀ W X`，`W` 半正定保证凸；`X` 列满秩且 `W` 非奇异（不可分）保证严格凸。可分使 `W` 出现零对角元 → 退化、无有限解——这正是牛顿法在可分数据上步长发散的数学原因。
- IRLS 与加权最小二乘的等价是 GLM 的核心算法：每步重算 `W`（来自当前均值 μ）和 `z`（工作响应 `η + (y−μ)/(dμ/dη)`），迭代直到收敛。它本质是牛顿法在 GLM 上的特例，且在 μ 的典则链接下具有二次收敛。
- 校准：逻辑回归输出**已是似然概率**（在模型正确时校准），但树模型输出概率常需 Platt/Isotonic 校准。这也是「线性模型概率更可信」的原因之一。

### 📚 考研者视角
- 高频推导：**写出逻辑回归损失并求梯度**。先给 `p=σ(wᵀx)`、负对数似然 `−Σ[y log p+(1−y)log(1−p)]`，再用 `σ' = σ(1−σ)` 推出 `∇=Σ(p−y)x`。这步几乎必考。
- **为什么不用 MSE**：标准答案要点出「伯努利标签非高斯」「MSE 在饱和区梯度消失」「交叉熵 = 伯努利 MLE 有统计正确性」。能对比两者梯度公式即可拿分。
- 易混：**逻辑回归是「回归」还是「分类」？** 它是分类模型，但训练目标是「最大化条件似然（回归概率）」——名字里的 regression 指的是对 logit 做线性回归，不是输出连续值。
- GLM 框架是加分题：能说出「三要素（指数族+线性预测子+链接函数）」并举例「恒等链接→线性回归、logit 链接→逻辑回归」，说明你理解了分类与回归的统一。
