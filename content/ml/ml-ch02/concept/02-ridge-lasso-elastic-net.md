# 岭回归、Lasso 与弹性网：用正则化驯服线性模型

> 上一讲说清了最小二乘的几何与统计前提。这一讲解决它的两个弱点：
> **数值病态（共线性）** 和 **高维稀疏（d 比 m 还大）**。
> 工具就是正则化——但 L2（岭）和 L1（Lasso）的数学性质截然不同：
> 一个收缩系数、一个直接把系数压成零。理解它们的差别，是理解「模型选择」的起点。

## 1. 岭回归：闭式解与「谱滤波」视角

岭回归目标（带 L2 惩罚）：

```text
min_w ‖y − Xw‖² + λ‖w‖²
```

正规方程变成 `(XᵀX + λI)w = Xᵀy`，**永远可逆**（λ>0 时 `XᵀX + λI` 正定），闭式解：

```
w*(λ) = (XᵀX + λI)⁻¹ Xᵀy
```

用 SVD 展开 `X = UΣVᵀ`，令 `Σ = diag(σᵢ)`：

```
w*(λ) = V diag( σᵢ / (σᵢ² + λ) ) Uᵀy
```

**这就是「谱滤波」视角的全部**：岭回归沿每个主方向把系数乘以收缩因子

```
gᵢ(λ) = σᵢ / (σᵢ² + λ) · σᵢ = σᵢ² / (σᵢ² + λ)
```

```
收缩因子 gᵢ(λ) = σᵢ² / (σᵢ² + λ)
 1 ────────────────────╲
     ╲                  ╲
      ╲                  ╲___  小 σᵢ 方向（共线性/噪声方向）收缩最强
       ╲                      ╲ 大 σᵢ 方向几乎不收缩（gᵢ → 1）
        ─────────────────────────────── σᵢ/√λ →
```

- 大奇异值方向：`σᵢ² ≫ λ`，`gᵢ ≈ 1`，**几乎不收缩**（信号方向保留）；
- 小奇异值方向：`σᵢ² ≪ λ`，`gᵢ ≈ σᵢ²/λ`，**收缩到接近零**（噪声/共线性方向被滤掉）。

这正是上一讲「共线性让 `1/σ_min` 放大」的对症药：**在小方向补 λ，把被放大的项压回来**。
同时 `κ(XᵀX + λI) = (σ_max²+λ)/(σ_min²+λ) < κ(XᵀX)`，所以岭回归**同时改善泛化与可优化性**。

## 2. Lasso 的 L1 稀疏几何与软阈值

Lasso 把惩罚换成 L1（本节采用 `½‖y−Xw‖² + λ‖w‖₁` 的写法，与示例代码一致）：

```
min_w  ½‖y − Xw‖² + λ‖w‖₁
```

关键区别在**几何**。L2 球是圆的，L1 球是菱形，`‖w‖₁ ≤ t` 的解集是一个**旋转 45° 的菱形**，
它的顶点（尖角）正好落在坐标轴上：

```
w₂         L1 菱形（Lasso）         L2 圆（岭）
 │   ◣      ◢                      ╱‾‾╲
 │ ◣          ◢                   ╱      ╲    ← 圆与等高线
 │◣    ●       ◢                  ╱    ●     ╲     相切多在中部
 ●└───────────▶ w₁               ╱             ╲
（最优解落在尖角=某轴 → 该维系数=0）  （圆与等高线相切→各维都非零）
```

### 为什么 L1 会产生稀疏解

等高线（残差平方和的椭圆）碰到菱形尖角的概率远大于碰到圆边界的某点——
于是 L1 让**大量系数精确为零** → 稀疏、内建特征选择。

**软阈值（soft-thresholding）** 是 Lasso 的坐标下降核心算子。对正交化后的单变量问题，解为：

```
wⱼ = S_λ(β̂ⱼ) = sign(β̂ⱼ) · max(|β̂ⱼ| − λ/2, 0)
```

### 软阈值：L1 的逐坐标实现

即「把无惩罚估计往零推 λ/2，推过零就取零」。这就是 L1 把系数压成零的逐坐标实现。

## 3. 坐标下降推导（为什么是软阈值）

Lasso 不可导，但**关于单个 wⱼ 是分段二次的**。固定其余坐标，仅看 wⱼ 的目标：

```
Q(wⱼ) = ½‖r − Xⱼwⱼ‖² + λ|wⱼ| + const
       = ½·‖Xⱼ‖²·(wⱼ − β̂ⱼ)² + λ|wⱼ| + const
```

其中 `β̂ⱼ = (Xⱼᵀr)/(XⱼᵀXⱼ)`，`r = y − Σ_{k≠ⱼ} Xₖwₖ` 是不含第 j 维的残差。
对上式分段求导令为 0，即得软阈值解 `wⱼ = S(β̂ⱼ, λ/‖Xⱼ‖²)`。
**算法**：轮流对每个 j 更新 `wⱼ ← S(Xⱼᵀr, λ)/‖Xⱼ‖²`，`r` 同步更新。
收敛性由目标函数的凸性 + 坐标 Lipschitz 保证（Tseng, 2001）。

## 4. 弹性网：在高度相关特征上救 Lasso

### Lasso 的选择不稳定性

Lasso 有一个著名缺陷：**当特征高度相关时，它随机挑一个、把其余压零**（选择不稳定，
且丢掉互补信息）。弹性网同时用 L1 和 L2：

```
min_w ‖y − Xw‖² + α·ρ‖w‖₁ + α·(1−ρ)/2 ‖w‖²
```

`ρ ∈ [0,1]` 是 L1 占比。`ρ→1` 退化为 Lasso，`ρ→0` 退化为岭回归。
弹性网在相关特征组上**倾向于把整组一起选入或一起剔除**，解决了 Lasso 的「随机选一个」。
这也是 sklearn `ElasticNet` 的思路。

## 5. L1/L2 的贝叶斯先验：拉普拉斯 vs 高斯

MAP 估计 `argmax_w [log P(y|w) + log P(w)]`。高斯噪声 MLE 给 `Σℓ_res`，加上先验：

```
w ~ N(0, τ²I)   ⟹  log P(w) = −‖w‖²/(2τ²) + C   →  L2（岭），λ = 1/(2τ²)
w ~ Laplace(0,b) ⟹  log P(w) = −(1/b)Σ|wⱼ| + C   →  L1（Lasso）
```

```
先验密度
高斯：    ┌──┐     平滑、在 0 处有限 → 不鼓励但允许非零，系数收缩
         │  │
        ─┴──┴─ 0

拉普拉斯： ╱╲         尖端在 0 → 后验众数更易落在 0 → 稀疏
         ╱  ╲
        ╱    ╲ 0
```

**这是「为什么 Lasso 稀疏」的概率论解释**：拉普拉斯先验在 0 处有尖峰，
把质量集中在「很多维度恰好为 0」上，MAP 众数自然落在坐标轴上。
（详见 interview 追问：几何 + 贝叶斯两种解释都要会。）

## 三视角解析

### 🧑‍💻 程序员视角
- 选型口诀：**要稀疏/特征选择 → Lasso 或弹性网；只要稳定降方差、特征都重要 → 岭回归**。
  预测场景默认从岭回归或弹性网起步，Lasso 只在「真的想减特征数」时用。
- sklearn 里 `alpha` 就是 λ。注意 `Ridge(alpha=λ)` 的惩罚是 `λ‖w‖²`，而 `ElasticNet` 的 `alpha` 同时控制 L1+L2 总量，`l1_ratio` 控制比例。调参先扫 `alpha` 的对数网格。
- **弹性网救相关特征**：如果你的特征有「高度相关的冗余组」（如 one-hot 的派生、共线指标），纯 Lasso 会随机保留组内一个，结果对数据扰动极不稳定；换成 `l1_ratio=0.5` 左右会稳很多。
- 数值上，坐标下降实现 Lasso 极快；但 sklearn 默认 `saga`/`liblinear` 在大 n 小 d 上也很好。不要自己手搓 SVD 求岭回归，用 `Ridge` 即可。

### 🎓 博士生视角
- 谱滤波视角统一了岭回归与岭稀疏 PCA、Tikhonov 正则化。收缩因子 `σᵢ²/(σᵢ²+λ)` 等价于对 `1/σᵢ` 做「噪声放大抑制」，是处理病态逆问题（反卷积、断层扫描）的通用范式。
- Lasso 的「不可表示性条件」（irrepresentable condition）给出**变量选择一致性**的充要条件：被选中变量的特征不能和被剔除变量的特征过度相关。这从理论上解释了「为什么相关特征上 Lasso 不稳定」——相关越强，越违反该条件。
- 弹性网的「组效应」由 Zou & Hastie (2005) 给出：当 `|XⱼᵀXₖ|` 接近 1 时，两系数差值有界 `|ŵⱼ − ŵₖ| ≤ λ(1−ρ)/(1+ρ)`，即强制它们一起动。这正是 `l1_ratio<1` 的价值。
- 贝叶斯层级：Lasso 的完全贝叶斯（非 MAP）对应 **贝叶斯 Lasso**（Park & Casella, 2008），用指数尺度混合把拉普拉斯先验写成高斯的无限混合，可做完整的后验推断而非点估计。

### 📚 考研者视角
- 自命题 AI 常考：**推导岭回归闭式解**。令 `∂/∂w [‖y−Xw‖²+λ‖w‖²] = −2Xᵀ(y−Xw)+2λw = 0`，得 `(XᵀX+λI)w = Xᵀy`。要会写这步。
- **L1 vs L2 的几何区别**是标配题：画 L1 菱形 vs L2 圆，说明尖角落在坐标轴上 → 稀疏。答题要结合「等高线与约束域相切」的图。
- 易错口径：**「L1 一定比 L2 好」错**。L1 在小样本、强噪声、相关特征下选择不稳定；L2 更稳定且解析可解。选型看目标（是否要稀疏）和数据（是否相关）。
- 贝叶斯解释是加分项：能补一句「L2=高斯先验、L1=拉普拉斯先验、λ 与先验方差的关系 λ=1/(2τ²)」就能把「为什么正则化有用」讲透。
