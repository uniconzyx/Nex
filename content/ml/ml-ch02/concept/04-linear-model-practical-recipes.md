# 线性模型实战手记：凯喵在面试里被连问七层的十二个现场

> 这一章讲最小二乘与极大似然、Ridge/Lasso/ElasticNet、逻辑回归与 GLM。公式都能背，但面试官一深问就露怯：为什么用平方损失、正则项为什么能防过拟合、L1 为什么产生稀疏、逻辑回归的损失为什么不是平方、偏差为什么是「先验」。这篇手记用十二个现场把这些「为什么」钉死。

## 开场：线性模型是「所有模型的母语」

很多人觉得线性模型太简单、不值得深学。但凯喵的经验是：**面试官判断一个候选人懂不懂机器学习，最常用的一把尺子就是线性模型能讲多深**。

因为它把几乎所有核心概念都收在一个可解析求解的框架里：损失函数、极大似然、正则化、偏差-方差、凸优化、闭式解与迭代解、泛化界。能在它身上把「为什么」讲透的人，学任何复杂模型都会更快；只背结论的人，换个模型就露馅。

下面十二个现场，前六个是最小二乘与似然，中间三个是正则化，后三个是逻辑回归与 GLM。

### 现场一：为什么用平方损失，而不是绝对值损失

面试第一问。三个层次回答，深度递增：

**层次一（几何）**：平方损失对应「垂直距离的平方和最小」，闭式解漂亮。

**层次二（概率）**：假设 `y = wᵀx + ε`，`ε ~ N(0, σ²)`，则 `p(y|x,w) = N(wᵀx, σ²)`。对数似然：

```python
import numpy as np

def neg_log_likelihood(w, X, y, sigma=1.0):
    """高斯噪声假设下的负对数似然 = 常数 + 平方损失 / (2σ²)"""
    resid = y - X @ w
    return 0.5 * np.sum(resid ** 2) / sigma ** 2 + len(y) * np.log(sigma * np.sqrt(2 * np.pi))

# 结论：最小化平方损失 <=> 在「高斯噪声」假设下最大化似然
```

**层次三（统计）**：若噪声是拉普拉斯分布（`p(ε) ∝ exp(-|ε|/b)`），负对数似然就是**绝对值损失**，对应中位数回归——对离群点更稳健。

所以「为什么用平方损失」的完整答案是：**因为隐含假设了高斯噪声**。换噪声假设就换损失，这是 GLM 的统一视角。

### 现场二：闭式解 `w = (XᵀX)⁻¹Xᵀy` 什么时候不能用

公式好写，但三个条件不满足就崩：

```python
import numpy as np

def ols_closed_form(X, y):
    XtX = X.T @ X
    # 问题一：完全共线性 -> XtX 奇异，不可逆
    if np.linalg.matrix_rank(XtX) < XtX.shape[0]:
        raise ValueError("XtX 奇异：存在完全共线或 n < d")
    # 问题二：病态 -> 数值不稳定，条件数大时结果不可信
    cond = np.linalg.cond(XtX)
    if cond > 1e10:
        print(f"警告：条件数 {cond:.2e} 过大，建议改用 SVD 或加正则")
    # 数值上更稳的做法是解线性方程组或用 SVD，而不是显式求逆
    return np.linalg.solve(XtX, X.T @ y)

# 更稳的等价实现（不求逆、不平方条件数）
def ols_lstsq(X, y):
    return np.linalg.lstsq(X, y, rcond=None)[0]
```

三个坑：**完全共线**（两列线性相关，`XtX` 奇异）、**n < d**（样本少于特征，无唯一解）、**病态**（条件数大，微小扰动导致解剧烈变化）。

实践约定：**永远不要显式 `inv(XtX)`**，用 `solve` 或 `lstsq`（内部 SVD）。这一条在面试里答出来就是加分项，因为它体现了数值意识。

### 现场三：完全共线时为什么有无穷多解

`y = w₁x₁ + w₂x₂`，若 `x₂ = 2x₁`，那么 `(w₁, w₂) = (1, 0)` 与 `(0, 0.5)` 给出完全相同的预测。所有满足 `w₁ + 2w₂ = c` 的解都等价。

几何上：`XtX` 的秩 ≤ 1，它的零空间非空，任何零空间向量加到解上都不改变损失。

这正是**正则化存在的第一个理由**：Ridge 加上 `λ‖w‖²` 后，问题变成严格凸，解唯一：

```python
def ridge_closed_form(X, y, lam):
    d = X.shape[1]
    return np.linalg.solve(X.T @ X + lam * np.eye(d), X.T @ y)
# lam > 0 时 XtX + lam*I 一定可逆（特征值全部 > 0）
```

面试延伸：Ridge 在共线时的行为是「把权重平摊给相关特征」——因为平摊能让 `‖w‖²` 最小。

### 现场四：Ridge 为什么能防过拟合，三种等价视角

**视角一（约束优化）**：Ridge 等价于「在 `‖w‖² ≤ t` 的球内最小化残差平方和」。球的约束把解限制在小范数区域，模型复杂度被限制。

**视角二（贝叶斯）**：`w` 上加高斯先验 `w ~ N(0, τ²I)`，最大后验（MAP）就是 Ridge。正则项系数 `λ = σ²/τ²`——**先验越强（τ 小），λ 越大**。

**视角三（谱/特征值）**：对 `XtX` 做特征分解，Ridge 把每个方向的解缩放 `λᵢ/(λᵢ+λ)` 倍。小特征值方向（对应数据方差小的方向）被压得最狠——正是这些方向容易过拟合噪声。

```python
import numpy as np

def ridge_shrinkage_demo():
    lam_vals = np.array([0.01, 0.1, 1.0, 10.0])
    eig = np.array([100.0, 10.0, 1.0, 0.1])     # 假设的 XtX 特征值
    for lam in lam_vals:
        shrink = eig / (eig + lam)
        print(f"λ={lam:5.2f} 缩放因子={np.round(shrink, 3)}")
    # 特征值 0.1 的方向在 λ=10 时被压到 0.0099，几乎完全丢弃
```

这个视角最能解释「为什么 Ridge 有效」：它做了一个**软性的降维**，把信息量少（方差小）的方向几乎抹掉，而保留信息量大的方向。

### 现场五：Lasso 为什么产生稀疏解，而 Ridge 不

最经典的图形解释：

```text
Ridge 的约束区域是圆（‖w‖₂ ≤ t）
Lasso 的约束区域是菱形（‖w‖₁ ≤ t）

损失函数的等高线是椭圆。椭圆与圆相切，切点通常不在坐标轴上 → 分量都非零
椭圆与菱形相切，切点极大概率落在菱形的「顶点」上 → 某个分量为 0
```

严格说明：L1 范数在坐标轴方向不可微（有尖点），最优解容易落在尖点上。而 L2 处处可微，梯度不会把解推向坐标轴。

```python
import numpy as np

def soft_threshold(z, lam):
    """Lasso 的坐标下降核心算子：把 |z| 小于 lam 的分量直接压成 0"""
    return np.sign(z) * max(0.0, abs(z) - lam)

for z in [0.3, 1.0, 5.0]:
    print(f"z={z}  λ=1 -> {soft_threshold(z, 1.0)}")
# z=0.3 -> 0.0（被压成零，产生稀疏）
# z=1.0 -> 0.0
# z=5.0 -> 4.0（整体平移，不只是缩放）
```

这个「软阈值」算子就是 Lasso 稀疏性的机制来源：**小于阈值的直接归零，大于阈值的整体平移**。对比 Ridge 是「等比缩放」，永远不会精确到 0。

### 现场六：ElasticNet 存在的理由——Lasso 的两个毛病

Lasso 有两个明确缺陷：

```text
缺陷一：p > n 时最多选出 n 个变量
  Lasso 的解的稀疏度受样本量限制，高维小样本时选不全

缺陷二：相关特征组里随机挑一个
  两个高度相关的特征，Lasso 会随机保留一个、把另一个压成 0
  → 结果不稳定，换个随机种子就换了特征
```

ElasticNet 混合两者：

```python
def elasticnet_objective(w, X, y, lam, l1_ratio):
    resid = y - X @ w
    l1 = l1_ratio * np.sum(np.abs(w))
    l2 = (1 - l1_ratio) * 0.5 * np.sum(w ** 2)
    return 0.5 * np.sum(resid ** 2) + lam * (l1 + l2)

# l1_ratio=1 -> Lasso；l1_ratio=0 -> Ridge
# 实践常用 l1_ratio=0.5，既稀疏又稳定
```

它的效果是「**相关特征组会一起被选入或一起被剔除**」（grouping effect），比 Lasso 在相关特征上稳定得多。

### 现场七：正则项要不要包含截距项

**不要**。截距 `b` 表示「特征全为 0 时的基准预测」，惩罚它等于强行把预测拉向 0，引入偏见（尤其在 `y` 的均值远离 0 时）。

标准做法是**先中心化**，再对非截距项加正则：

```python
def center_and_fit(X, y, lam):
    x_mean = X.mean(axis=0)
    y_mean = y.mean()
    Xc, yc = X - x_mean, y - y_mean      # 中心化后截距为 0
    w = np.linalg.solve(Xc.T @ Xc + lam * np.eye(X.shape[1]), Xc.T @ yc)
    b = y_mean - x_mean @ w              # 反解回原尺度的截距
    return w, b
```

顺带一个重要配套：**正则化前必须标准化特征**。因为 L1/L2 惩罚对所有系数一视同仁，而不同量纲的系数尺度差很多——「房价（百万）」的系数会比「房间数（个）」小几个数量级，不标准化的话惩罚会不成比例地压死小量纲特征。

### 现场八：逻辑回归的损失为什么不是平方损失

如果对 sigmoid 输出直接用平方损失，会得到非凸的目标函数（因为 sigmoid 非线性 + 平方），梯度下降容易陷入局部极小，且梯度在预测错得离谱时会**消失**（sigmoid 饱和，梯度趋 0）。

正确做法是用**交叉熵**（等价于伯努利分布的负对数似然）：

```python
import numpy as np

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

def logloss(w, X, y):
    """y ∈ {0,1}，返回平均交叉熵"""
    p = sigmoid(X @ w)
    eps = 1e-12
    return -np.mean(y * np.log(p + eps) + (1 - y) * np.log(1 - p + eps))

def grad_logloss(w, X, y):
    """梯度形式极简：Xᵀ(p - y)/n，正是「残差乘特征」"""
    p = sigmoid(X @ w)
    return X.T @ (p - y) / len(y)
```

两个关键性质：**交叉熵是凸的**（保证全局最优）、**梯度是 `Xᵀ(p−y)`**（预测越错梯度越大，不会饱和消失）。对比平方损失 + sigmoid 的梯度含 `p(1−p)` 因子，预测错得越离谱梯度反而越小——这是「学不动」的根源。

### 现场九：逻辑回归的「回归」二字从哪来

名字里带「回归」，因为它的本质是**对对数几率做线性回归**：

```text
log(p / (1-p)) = wᵀx + b

左边叫 logit（对数几率），右边是线性函数。
所以逻辑回归 = 「用线性模型拟合 logit」。
```

推导：从 `p = σ(z)` 出发，`z = log(p/(1−p))`。`p ∈ (0,1)` 映射到 `z ∈ (−∞, +∞)`，正好与线性函数的值域匹配。

这个视角的价值是可以推广到 GLM：**广义线性模型 = 「选择指数族分布 + 链接函数，对线性预测子建模」**：

```text
分布            链接函数            模型
高斯            恒等 g(μ)=μ         线性回归
伯努利          logit g(μ)=log(μ/(1-μ))   逻辑回归
泊松            log g(μ)=log(μ)     泊松回归（计数）
伽马            log 或 倒数         生存/时长模型
```

所以「为什么 GLM 用特定链接函数」的答案是：**链接函数把均值 μ 的定义域映射到实数域，同时让充分统计量（线性预测子）自然出现**——这是指数族分布的性质，不是随便选的。

### 现场十：逻辑回归的「准确率 95%」可能是假象

类别不平衡时准确率毫无意义：正例 3%、全预测负例就有 97% 准确率。

必须看的分层指标：

```python
def binary_report(y_true, y_pred, y_prob):
    tp = np.sum((y_pred == 1) & (y_true == 1))
    fp = np.sum((y_pred == 1) & (y_true == 0))
    fn = np.sum((y_pred == 0) & (y_true == 1))
    precision = tp / max(1, tp + fp)
    recall = tp / max(1, tp + fn)
    f1 = 2 * precision * recall / max(1e-12, precision + recall)
    # AUC 衡量「排序能力」，与阈值无关，是更稳的主指标
    return {"precision": precision, "recall": recall, "f1": f1}
```

凯喵的判断顺序：**先看 AUC（排序能力），再看 PR 曲线（不平衡时的真相），最后才看某个阈值下的 P/R**。准确率只在类别平衡时才有参考价值。

另外要区分两个「不平衡处理」：
- **改数据**：过采样/欠采样/SMOTE —— 改变分布，可能引入偏差。
- **改权重**：`class_weight='balanced'` —— 只改损失权重，不改变数据分布，通常更安全。

### 现场十一：L2 正则化让逻辑回归的损失「严格凸」，但不影响排序

一个细节题：给逻辑回归加 L2 正则，会改变 AUC 吗？

答案：**会改变，但通常很小**。L2 把系数整体收缩，预测概率的尺度变了，但**排序（谁大谁小）往往几乎不变**——因为收缩是单调的。所以 AUC 变化小，而「校准度」（预测概率是否等于真实频率）会变化。

这解释了为什么「加正则后准确率降了但 AUC 没降」是常见现象：模型排序能力还在，只是概率被压平了，阈值需要重调。

实践建议：**加了正则之后必须重新调阈值**，否则会误判为「模型变差」。

### 现场十二：把「线性模型」理解成「只能拟合直线」

最常见的概念误解。线性模型的「线性」指的是**对参数线性**，不是对特征线性：

```python
# 这些全都是线性模型（对 w 线性），只是特征做了变换
# 多项式回归
phi = lambda x: np.column_stack([x, x**2, x**3])
# 交互项
phi2 = lambda x1, x2: np.column_stack([x1, x2, x1*x2])
# 样条基
phi3 = lambda x: np.column_stack([x, np.maximum(0, x - k) for k in [1, 2, 3]])
```

只要模型形如 `y = wᵀφ(x) + b`，它就是线性模型——闭式解、凸性、正则化的所有结论都适用。这就是「特征工程」在线性模型上如此重要的原因：**你是在用非线性变换扩充假设空间，而求解仍保持线性**。

反过来，`y = w₁·sin(w₂·x)` 对 `w₂` 非线性，就不是线性模型了，闭式解失效。

## 三视角解析
### 🧑‍💻 程序员视角
平方损失对应「高斯噪声假设下的极大似然」，绝对值损失对应「拉普拉斯噪声」——选哪个取决于你对残差分布的假设，不是「哪个更好算」。闭式解 `w = (XᵀX)⁻¹Xᵀy` 在 `XᵀX` 奇异时不可用（完全共线），工程上解 `(XᵀX + λI)w = Xᵀy` 或直接用 SVD/QR 分解，避免显式求逆的数值不稳定。Ridge 防过拟合有三种视角：约束优化（L2 球）、贝叶斯（高斯先验）、数值（改善条件数），面试能说出三种就够深。

### 🎓 博士生视角
线性模型是「偏差-方差权衡」最清晰的例子：OLS 是无偏但方差大，Ridge 引入偏差换取方差下降，`λ` 控制权衡点。从谱分解看，Ridge 对 `XᵀX` 的小特征值方向收缩更强，等价于「抑制数据方差小的方向」——这正是它稳定估计的原因。Lasso 的 L1 正则产生稀疏解，几何解释是「菱形约束的顶点在坐标轴上」，贝叶斯解释是拉普拉斯先验。

### 📚 考研者视角
算法岗面试高频：
1. **损失函数**：平方损失、绝对值损失、Huber 损失的鲁棒性对比。
2. **正则化**：L1 稀疏、L2 平滑、弹性网的组合；为什么 L1 能产生稀疏解。
3. **闭式解与数值稳定**：`XᵀX` 奇异的原因与对策（伪逆、QR、SVD）。
4. **线性回归的假设**：线性、独立、同方差、无多重共线性，违反后的影响。

## 收尾：凯喵的线性模型七问

面试被深挖时，这七问能撑住大部分：

**损失为什么是平方**——高斯噪声下的极大似然；换拉普拉斯噪声就是绝对值损失。

**闭式解的坑**——共线奇异、n<d 无唯一解、病态不稳；永远别显式求逆，用 SVD。

**Ridge 为什么有效**——约束球 / 高斯先验 MAP / 特征值软收缩，三个视角等价。

**Lasso 为什么稀疏**——L1 约束域是菱形，切点落在顶点；软阈值算子直接归零。

**逻辑回归为什么用交叉熵**——平方损失 + sigmoid 非凸且梯度饱和；交叉熵凸且梯度是 `Xᵀ(p−y)`。

**GLM 的链接函数怎么选**——由指数族分布决定，把均值定义域映射到实数域。

**线性模型能拟合曲线吗**——能，「线性」指对参数线性，特征可以任意非线性变换。

最后说一句观念上的话。线性模型看起来是入门内容，但它是机器学习里少有的**可以完全讲清楚**的模型：从假设（噪声分布）到目标（似然）到解（闭式/迭代）到泛化（正则/先验）到评估（AUC/校准），每一环都有严格推导，没有黑箱。

凯喵见过的最有效的学习方式，是拿一张纸把这条链从头推一遍：写出高斯假设 → 推出平方损失 → 求导得正规方程 → 分析 `XtX` 的性质 → 加 L2 得到 Ridge → 用贝叶斯解释 λ → 换伯努利分布得到逻辑回归。这一遍推导大约两小时，但做完之后，你对「模型是什么」的理解会超过读十本书——因为你不是在记结论，而是在看结论怎么被逼出来。
