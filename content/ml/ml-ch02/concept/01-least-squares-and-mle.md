# 最小二乘与极大似然：线性模型的地基

> 线性回归看起来是「机器学习的 Hello World」，但它的几何与统计解释，
> 决定了后面岭回归、Lasso、逻辑回归甚至 PCA 怎么理解。
> 这一章先把「最小二乘 = 正交投影」「条件数平方放大」「MLE 在高斯噪声下等价」这三件事钉死，
> 再解释为什么多重共线性会让系数爆炸——这是所有线性模型共用的语言。

## 1. 几何本质：最小二乘是「把 y 投影到列空间」

设 `X ∈ ℝ^{m×d}`（每行一个样本，每列一个特征），`y ∈ ℝ^m`，`w ∈ ℝ^d`。
最小二乘目标

```text
min_w ‖y − Xw‖²
```

`Xw` 是 `X` 的**列空间 `C(X)`** 中的一个向量。改 `w` 等于在 `C(X)` 里移动。
要使 `‖y − Xw‖` 最小，就是找 `C(X)` 中离 `y` 最近的点——也就是 **`y` 在 `C(X)` 上的正交投影**。

```
        y
        │\
        │ \  残差 r = y − Xw*
        │  \  （垂直于 C(X)）
        │   \
        ──────●──────────  C(X)（X 的列张成的平面）
             Xw*  （投影）
```

由正交性，最优残差 `r* = y − Xw*` 必须**正交于列空间**，即正交于 `X` 的每一列：

```
Xᵀ(y − Xw*) = 0   ⟹   XᵀX w* = Xᵀy
```

这就是**正规方程（normal equation）**。`Xw*` 是投影，残差与所有特征列正交——
直观地说：「已经没有任何线性组合能再减少残差了」。

**三个推论必须记住**：
1. 解存在性不要求 `X` 满秩：`XᵀXw = Xᵀy` 总有解（即使 `XᵀX` 奇异），最小范数解由伪逆给出；
2. 若 `y ⟂ C(X)`（即特征与标签零相关），投影为 0，`w* = 0`；
3. `R²` 的几何意义是「投影平方长度 / y 的平方长度」：**中心化后**（带截距）就是解释掉的 y 在特征方向上的比例；

## 2. 正规方程与数值稳定性：条件数被平方放大

### 闭式解的痛点：XᵀX 的条件数

闭式解 `w* = (XᵀX)⁻¹ Xᵀy`。问题在于 `XᵀX` 的**条件数**：

```
κ(XᵀX) = κ(X)²
```

`κ(X) = σ_max / σ_min`（最大/最小奇异值之比）。做最小二乘时，数据矩阵的几何条件数被**平方**，
于是数值敏感度急剧恶化——这是「为什么不要直接用 `XᵀX` 求逆，而要用 QR 或 SVD 分解」的根本原因。

```
求解方式         数值代价           条件数表现
─────────────────────────────────────────────────────
(XᵀX)⁻¹Xᵀy       O(d³)，但 κ→κ²     √κ 附近的相对误差被放大到 κ² 量级
QR 分解           O(m d²)           只用 κ(X)，误差 ~ κ
SVD / 伪逆        O(m d²)           可显式丢弃 σ≈0 的方向（截断）
```

**工程取舍**：`m ≫ d` 且条件数不大时，正规方程最快；条件数大（特征尺度不一、共线性）
时优先 QR；需要做「谱滤波」（下一讲岭回归）或丢弃小奇异值方向时，SVD 最干净。

## 3. 高斯噪声下的极大似然：为什么「平方损失」不是拍脑袋

假设真值是线性函数加**零均值高斯噪声**：

```
y = Xw + ε,   ε ~ N(0, σ²I)
```

则 `y | X ~ N(Xw, σ²I)`，对数似然为

```
log P(y|X,w) = −(m/2)log(2πσ²) − (1/2σ²) ‖y − Xw‖²
```

**对 w 最大化**等价于最小化 `‖y − Xw‖²`——**最小二乘就是高斯噪声下的 MLE**。
这件事非常重要：它告诉我们平方损失的统计前提是高斯同方差噪声；当噪声重尾（离群多）或异方差时，
平方损失会过度受离群点牵引，此时应换稳健损失（Huber）或加权最小二乘。

> 一句话：**最小二乘 = 几何投影（纯粹代数）；高斯 MLE = 同一件事的统计学解释**。
> 两者等价，但「MLE 视角」让我们能推广到非高斯（逻辑回归的伯努利 MLE 就是交叉熵）。

## 4. 多重共线性：为什么系数会失控

当两个特征高度相关（如 `x₂ ≈ 3x₁ + c`），`X` 的列几乎线性依赖，`σ_min → 0`，`κ → ∞`：

```
w* = (XᵀX)⁻¹Xᵀy   在 σ_min 方向上被 1/σ_min² 放大
```

于是：
- **系数方差爆炸**：`Var(ŵ) = σ²(XᵀX)⁻¹`，`(XᵀX)⁻¹` 的对角元随 κ² 增大；
- **系数符号/大小不稳定**：训练集换几个样本，`ŵ` 剧烈摆动甚至符号翻转；
- **单个特征的 t 检验失效**，但整体预测可能还行（共线性压的是「解释性」不是「预测」）。

### 诊断与处置（按优先级）

```
现象                 诊断                        正确做法
─────────────────────────────────────────────────────────────
系数巨大/符号反常     VIF = 1/(1−R²ⱼ) > 10     删特征 / 合并 / 主成分 / 加岭正则
κ(XᵀX) 极大          条件数 > 1000             标准化 + QR/SVD，而不是对 XᵀX 求逆
权重随样本抖动        bootstrap 重抽 σ(ŵ) 大   报告置信区间，或用岭回归压方差
```

**关键认知**：共线性伤害的是「系数估计」，不是「预测」。如果目标是预测，可解释性让步给正则；
如果目标是解释，必须先把共线性处理掉，否则系数没有因果含义。

## 三视角解析

### 🧑‍💻 程序员视角
- 别手写 `(X.T @ X)` 再 `np.linalg.inv`——这是新人最常犯的数值错误。直接 `np.linalg.lstsq(X, y)`（内部做 SVD，数值稳定），或 `scipy.linalg.lstsq`。要的就是那个「不用自己求逆」的稳定性。
- 上线前看 `np.linalg.cond(X)`：条件数上万就该警惕系数抖动。特征尺度不一（如「收入」和「年龄」）要先标准化，`κ` 瞬间降几个数量级，梯度下降和正规方程都变稳。
- 业务要「哪个特征重要」时，共线性会让答案不可信。先算 VIF，再决定是删特征还是老老实实说「这两个特征说不清谁贡献大」。
- 离群点会把回归线拽偏：平方损失对大残差惩罚二次。先画残差图，有尾巴就换 Huber 或 robust 回归。

### 🎓 博士生视角
- 投影视角的推广：最小二乘解是 `C(X)` 上的投影算子 `P = X(XᵀX)⁺Xᵀ`。残差空间的正交补正是 `C(X)`，所以 `r* ⟂ C(X)` 等价于 `r* ∈ N(Xᵀ)`。这与 Gram-Schmidt（QR）是同构表述。
- 条件数平方放大的严格论证：`κ(AᵀA) = κ(A)²`（对 SVD，`AᵀA` 的奇异值是 `A` 的平方）。因此相对误差从 `O(κ(X))` 退化到 `O(κ(X)²)`。这就是为什么数值线性代数教科书一律反对显式构造 `XᵀX`。
- MLE 的不变性：若噪声非高斯，`argmax_w log P(y|X,w)` 一般**不再**是最小二乘。伯努利噪声 → 逻辑回归（交叉熵）；泊松噪声 → 带 log 链接的 GLM。平方损失是「高斯」的专属。
- 共线性的统计本质：`(XᵀX)⁻¹` 的存在性不依赖满秩（用 Moore-Penrose 伪逆），但**方差无界**依赖满秩。伪逆给出的是最小范数解，它在小奇异值方向上的大分量只是「数学上最近」，没有统计意义。

### 📚 考研者视角
- 自命题 AI 专业课（如 841/859）常考：**推导正规方程**。标准步骤是令 `∂‖y−Xw‖²/∂w = 0`，得 `−2Xᵀ(y−Xw)=0`，即 `XᵀXw = Xᵀy`。这一步要会默写。
- **R² 与 adjusted R²**：`R² = 1 − RSS/TSS`。考研常问「加入无关特征 R² 一定升」为什么——因为列空间只增不减，投影不会变远。adjusted R² 用自由度惩罚，才是比较模型的口径。
- 易混概念：**最小二乘解 ≠ 唯一解**。不要求 `X` 满秩；满秩时唯一，不满秩时解空间是一个仿射子空间，最小范数解由伪逆给出。
- 高斯-马尔可夫定理是高频考点：在所有**线性无偏**估计里，最小二乘估计方差最小（BLUE）。注意前提是「线性无偏」——岭回归是有偏的，所以不在这个比较框架内，但它通常 MSE 更小。
