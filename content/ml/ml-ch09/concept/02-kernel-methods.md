# ml-ch09 · 核心概念（二）：核方法与核函数

> 视角覆盖：程序员（工程决策）/ 博士生（第一性原理）/ 考研者（笔面口径）。三者互补、不重复。

```text
核技巧：不显式映射到高维，也能算「映射后的内积」
    K(x, z) = φ(x)·φ(z)
    SVM 的对偶形式只需 K，不需要 φ 本身
    -> 代价从 O(高维) 降为「求一次核函数」

常用核：
    线性核      K = x·z                高维稀疏文本
    多项式核    (γ x·z + r)^d           特征交互
    高斯核/RBF  exp(-γ‖x-z‖²)          无穷维映射，最常用
    sigmoid     近似两层神经网络

    γ 的意义：越大 -> 决策边界越弯曲 -> 越容易过拟合

成本：核矩阵是 n×n
    n = 10^4 -> 10^8 个元素（GB 级）不可承受
    -> 大样本用线性核，或用 Nystroem / RBFSampler 做近似特征映射
```

## 1. 核技巧：不搬家也能算「搬家后的内积」

线性不可分时最直觉的做法是**升维**：把 $x$ 映射到高维 $\phi(x)$，在高维空间里线性可分。但直接构造 $\phi$ 会遇到两个问题：维度可能爆炸（多项式核的维度是组合数），甚至无限维（RBF）。

核技巧绕开了它：注意到 SVM 的对偶与决策函数里，**数据只以内积 $\langle x_i,x_j\rangle$ 的形式出现**。于是定义

$$K(x,z)=\langle\phi(x),\phi(z)\rangle$$

只要能把内积算出来，就**不需要显式构造 $\phi$**。这就是核技巧（kernel trick）的全部内容——它不是一个算法，而是一个「换掉内积」的接口约定。

举个能算清的例子。取 $\phi(x)=(x_1^2,\sqrt2x_1x_2,x_2^2)$（2 维升到 3 维），则

$$K(x,z)=\langle\phi(x),\phi(z)\rangle=(x^\top z)^2$$

而右式用原始 2 维坐标只需 2 次乘法就能算（`ex05` 会数值验证两者相等）。维度从 3 涨到组合数时，右边仍只是一次内积加平方——**代价与 $\phi$ 的维度无关**。

对 RBF 核更极端：

$$K(x,z)=\exp\big(-\gamma\|x-z\|^2\big)$$

它对应**无限维**的特征映射（可展开成泰勒级数，每一项都是一个多项式特征）。也就是说，用 RBF 相当于在一个无限维空间里做线性 SVM，而计算量只是两个向量求差、求范数、取 exp。

### 🧑‍💻 程序员视角

- 三个默认选择：**线性核**（高维稀疏，如文本 TF-IDF）、**RBF**（低维稠密，默认首选）、**多项式核**（阶数低、特征交互明显，如 $d=2$）。没有理由时先用 RBF。
- RBF 的 $\gamma$ 是「单个样本的影响半径」：$\gamma$ 大 → 每点影响范围小 → 边界扭曲、过拟合；$\gamma$ 小 → 边界接近线性、欠拟合。sklearn 的默认 `gamma='scale'` 是 $1/(d\cdot\mathrm{Var}(X))$，比自己拍一个数靠谱。
- **核矩阵内存是硬约束**：$n=50000$ 的 float64 核矩阵要 20GB。所以 `SVC` 在 $n>2$ 万时基本不可用，必须换线性模型或 Nyström 近似/随机特征近似。
- 自定义核：`SVC(kernel=callable)` 传 `K(X,Y)->(n,m)` 函数即可，但 sklearn 要求它返回**预计算的 Gram 矩阵**时用 `kernel='precomputed'` 更高效；序列/图数据的核（字符串核、图核）就走这条路。

### 🎓 博士生视角

- **合法核的判据（Mercer 定理）**：对称函数 $K$ 是合法核，当且仅当对任意有限样本集，Gram 矩阵 $K_{ij}=K(x_i,x_j)$ 都**半正定**。这是「存在某个 $\phi$ 使 $K=\langle\phi,\phi\rangle$」的充要条件（在紧集上连续情形）。
- 半正定的实操检验：算 Gram 矩阵的特征值，最小值 $\ge-\epsilon$ 即合法（数值误差允许轻微负值）。`ex04` 就做这件事——线性/多项式/RBF 都半正定，而「$K(x,z)=-\|x-z\|$」这类明显不合格。
- 核与正则化的关系（核机器视角）：在 RKHS（再生核希尔伯特空间）中，SVM 的解落在由核张成的有限维子空间里（表示定理），$\|w\|_{\mathcal H}$ 是 RKHS 范数，正是「函数平滑度」的度量。**选核 = 选先验 = 选平滑度假设**，不是选一个相似度公式。
- RBF 的 $\gamma$ 在 RKHS 视角下的作用是控制核的**特征值衰减速度**：$\gamma$ 越大，Gram 矩阵越快趋近单位阵（近似插值），有效自由度越高——这就是它过拟合的机制，而不是「半径小了」这么直观的说法。
- 与深度学习的关系：无限宽网络的 NTK（神经正切核）极限下，网络训练等价于核方法。这条结论既解释了「核方法为什么至今仍是强基线」，也说明了「深度网络相对核方法的优势来自特征学习（学 $\phi$）而非核本身」。

### 📚 考研者视角

- **必背**：核技巧的定义（用 $K$ 替代内积，不显式构造 $\phi$）；Mercer 条件（Gram 矩阵半正定）；常用核：线性 $x^\top z$、多项式 $(x^\top z+c)^d$、高斯/RBF $\exp(-\gamma\|x-z\|^2)$、sigmoid。
- **常考计算**：给 2 维点与 $\gamma=0.5$，算 RBF 核值；给多项式核 $(x^\top z+1)^2$，写出对应的显式特征映射（$\phi(x)=(x_1^2,\sqrt2x_1x_2,x_2^2,\sqrt2x_1,\sqrt2x_2,1)$）。
- **高频问法**：① 为什么核技巧能「隐式升维」；② RBF 核为什么对应无限维；③ 核函数必须满足什么条件。
- **易混**：核函数 ≠ 相似度函数（相似度不保证半正定，如「负距离」不是合法核）；核技巧 ≠ 降维（它升维，不是降维，降维是 PCA 那条线）。

## 2. 核的选择：先验、平滑度与「维度诅咒」的交换

选核本质上是选**先验假设**：

| 核 | 假设 | 适用 | 风险 |
|---|---|---|---|
| 线性 | 决策边界是超平面 | 高维稀疏（文本）、$n$ 很大 | 欠拟合非线性 |
| 多项式 $(x^\top z+c)^d$ | 特征间有 $d$ 阶交互 | 低维、交互明确（物理/化学） | 数值不稳（大值取 $d$ 次幂溢出） |
| RBF | 函数**局部平滑**、任意连续函数都能逼近 | 通用默认 | 维度高时核矩阵趋近单位阵（所有点都"不相似"） |
| Sigmoid | 类似两层网络 | 少见 | 不总满足 Mercer 条件 |

**高维下的 RBF 会失效**，这一点必须有量化认识：若数据在 $d$ 维超立方体上均匀分布，两点距离的分布集中在 $\sqrt{2d\sigma^2}$ 附近，相对波动 $\sim1/\sqrt{d}$。$d=1000$ 时所有点对的距离几乎相同，RBF 核值几乎一样 → 核矩阵近似全 1 矩阵 → 模型退化为常数。这是「核方法在高维失效」的严格版本（不是玄学）。

这也解释了为什么文本用线性核：文本维度十万级，RBF 直接退化，而线性核在稀疏高维上反而表现好。

### 🧑‍💻 程序员视角

- 高维（$d>10^3$）优先线性核，别试 RBF；低维（$d<50$）且 $n<10^4$ 优先 RBF。这条判据能省掉大量无用的网格搜索。
- 多项式核的数值问题：$d\ge3$ 且特征值大时会溢出，用 `coef0` 调偏移或先标准化，或者干脆换 RBF。
- 文本场景的经典组合：TF-IDF + 线性 SVM，$O(n\cdot\mathrm{nnz})$ 训练，比核 SVM 快几个数量级且精度相当。
- 需要解释性时用线性核：权重可读（每个特征的贡献），核 SVM 的决策边界无法解释——这在风控/医疗场景往往是硬约束。

### 🎓 博士生视角

- 「所有点对距离趋同」的严格表述是**距离集中现象**（distance concentration）：$\frac{\mathrm{std}(D)}{\mathbb{E}[D]}\to0$ 当 $d\to\infty$。它对所有基于距离的方法（KNN、K-means、RBF 核）同样成立，是维数灾难的共同根源。
- 核的选择等价于在 RKHS 里选一个**范数**，从而定义「什么样的函数是简单的」。线性核的 RKHS 是有限维欧氏空间，RBF 的 RKHS 是解析函数空间（更平滑）——所以 RBF 更偏好平滑解，噪声大时反而稳健，信号锐利时反而失真。
- 多核学习（MKL）把核本身当参数学，形式上是在做「先验的自动选择」。这与深度学习的「特征学习」是同一目标的两条路：MKL 学核的凸组合（受限），网络学任意非线性映射（更自由）。
- 随机特征（Random Fourier Features）把 RBF 核近似成有限维显式映射 $z(x)=[\cos(\omega_i^\top x),\sin(\omega_i^\top x)]$，$\omega_i\sim\mathcal{N}(0,2\gamma I)$。这让核方法可以走 SGD、扩展到百万样本——是「核方法与深度学习和解」的工程路径。

### 📚 考研者视角

- **必背**：四种核的形式与适用场景；「高维用线性、低维用 RBF」的口径；RBF 的 $\gamma$ 与过拟合的关系。
- **常考问法**：① 为什么文本分类常用线性核；② 高斯核的带宽 $\sigma$（或 $\gamma$）如何影响模型复杂度；③ 多项式核的阶数 $d$ 越大意味着什么（更高阶交互、更易过拟合）。
- **易混**：$\gamma$ 与 $\sigma$ 是倒数关系（$K=\exp(-\|x-z\|^2/(2\sigma^2))$ 对应 $\gamma=1/(2\sigma^2)$），不同教材写法不同，答题时写清定义式。

## 3. 求解与工程：SMO、多分类与大规模

**SMO（序列最小最优化）** 是 SVM 的标准求解器。核心观察：对偶问题有一个等式约束 $\sum_i\alpha_iy_i=0$，所以**不能只更新一个变量**（会破坏约束）。SMO 每次挑两个变量 $(\alpha_i,\alpha_j)$，固定其余，此时约束退化为一条直线，问题有**解析解**：

$$\alpha_j^{\text{new}}=\alpha_j+\frac{y_j(E_i-E_j)}{\eta},\qquad \eta=K_{ii}+K_{jj}-2K_{ij}$$

其中 $E_k=f(x_k)-y_k$ 是预测误差。更新后要裁剪到 $[L,H]$（由 $y_i,y_j$ 的符号与 $C$ 决定），再回代求 $\alpha_i$。每步 $O(n)$（更新核矩阵的一行），整体近似 $O(n^2)$。

每步只动两个变量，看起来极慢，但**大多数 $\alpha$ 会迅速停在 0 或 $C$（边界）**，真正需要反复调整的只有少数——这就是稀疏性的计算红利。

**多分类**：SVM 原生二分类，两种扩展：

| 策略 | 做法 | 复杂度 | 特点 |
|---|---|---|---|
| OvR（一对多） | $k$ 个分类器，每个「本类 vs 其余」 | $k$ | 快，但类别不平衡（1 vs $k-1$） |
| OvO（一对一） | $\binom{k}{2}$ 个分类器，两两投票 | $k(k-1)/2$ | 慢，但每个子问题平衡、精度常更好 |

sklearn 的 `SVC` 默认 **OvO**，`LinearSVC` 默认 **OvR**——这是一个常被忽略的默认值差异，会导致两者在小类别数下表现不同。

**大规模**：$n$ 大时三条路——① 线性 SVM（LIBLINEAR，坐标下降，$O(n d)$ 每轮）；② 核近似（Nyström / 随机特征，把 $O(n^2)$ 降到 $O(nm)$）；③ 换模型（GBDT 在表格数据上通常更强且更快）。

### 🧑‍💻 程序员视角

- 参数优先级：标准化 > $C$ > $\gamma$ > 核选择。前两个调好了，换核的收益通常小于 3 个点；标准化没做，调什么都没用。
- 训练时间预估：`SVC` 在 $n=10^4$ 上通常几十秒到几分钟；$n=10^5$ 基本不可用。做 POC 时先 `train_test_split` 抽样看趋势，别在全量上等。
- `decision_function_shape='ovr'` 只改输出形状（把 OvO 的投票转成 ovr 分数），**不改内部训练方式**——这一点常被误读。
- 上线前必查：`n_support_` 总数（决定推理成本）、`support_vectors_` 的内存（$n_{sv}\times d$ 浮点）、是否用了 `probability=True`（推理变慢）。

### 🎓 博士生视角

- SMO 的收敛性来自「每步在可行域内做精确的二维最小化」，目标单调下降且下界存在，因此收敛到全局最优（对偶是凹 QP）。工作集选择（启发式挑最大违反 KKT 的一对）只影响速度，不影响最优性。
- $\eta=K_{ii}+K_{jj}-2K_{ij}$ 是「两样本在 RKHS 中的距离平方」，必须 $\ge0$（核半正定的推论）。$\eta=0$ 表示两点在特征空间重合，此时更新无意义，需要换一对——实现里必须处理这个退化。
- 多分类的 OvO 与 OvR 可以统一成**纠错输出码**（ECOC）：用码本矩阵把 $k$ 类映射到多个二分类问题，OvO/OvR 都是特定码本。这个视角解释了「为什么 OvO 常更准」（码本列间距离更大，纠错能力更强）。
- 大规模核方法的核心矛盾是「$O(n^2)$ 的核矩阵」。Nyström 用 $m$ 个诱导点近似 $K\approx K_{nm}K_{mm}^{-1}K_{mn}$，误差界依赖诱导点对数据分布的覆盖——这与后来深度学习里的「稀疏注意力/诱导点」是同一思想。

### 📚 考研者视角

- **必背**：SMO 更新两个变量的原因（等式约束）；OvO 与 OvR 的分类器个数；大规模场景的替代方案。
- **常考问法**：① 为什么 SMO 一次更新两个 $\alpha$；② $k$ 分类问题 OvO 需要多少个分类器（$k(k-1)/2$）；③ SVM 训练慢怎么办。
- **易混**：SMO ≠ 坐标下降（SMO 是两坐标的解析块更新，坐标下降是单坐标）；OvO 的投票 ≠ 概率（票数相同需要额外规则）。

## 可运行代码：核技巧 = 不显式升维也算出高维内积

「核函数等于高维内积」这句话可以用多项式核直接验证——两边数值完全相等：

```python
import numpy as np

rng = np.random.default_rng(0)
X = rng.normal(size=(5, 2))

def poly(A, B, d=2):
    return (A @ B.T + 1) ** d          # K(x, y) = (x·y + 1)^d

def feat(X):                            # 显式映射：1, x1, x2, x1², x2², √2·x1x2
    x1, x2 = X[:, 0], X[:, 1]
    return np.column_stack([np.ones(len(X)), x1, x2, x1 ** 2, x2 ** 2,
                            np.sqrt(2) * x1 * x2])

Z = feat(X)
print("poly 核 == 显式特征内积:", np.allclose(poly(X, X), Z @ Z.T))   # True
print("特征维度:", Z.shape[1])                                         # 6，而原维度是 2

def rbf(A, B, gamma=1.0):
    d2 = ((A[:, None, :] - B[None, :, :]) ** 2).sum(-1)
    return np.exp(-gamma * d2)          # 隐式映射到无限维，K 仍然只是 n×n 矩阵

K = rbf(X, X)
print("RBF 对称:", np.allclose(K, K.T))
print("对角为 1:", np.allclose(np.diag(K), 1.0))
print("半正定:", np.linalg.eigvalsh(K).min() >= -1e-12)
```

第一行 `True` 就是核技巧的全部内容：**同一个数字，可以用「先升维再内积」算，也可以用
「在原空间算核」算**。RBF 对应的特征空间是无限维的，连 `feat()` 都写不出来，但 `K` 依然只是
一个 `n×n` 矩阵——这就是它能把非线性问题交给线性算法的原因。

顺带解释三条常用判据：对称性来自内积的交换律，对角为 1 来自 `exp(0)=1`，
半正定则是「它必须是某个特征空间的内积」的充要条件（Mercer 定理）——**任给一个函数当核是错的，
它得先过 PSD 这一关**。
