# ml-ch09 · 核心概念（三）：SVM 的工程位置与选型边界

> 视角覆盖：程序员（工程决策）/ 博士生（第一性原理）/ 考研者（笔面口径）。三者互补、不重复。

## 1. 在模型光谱里定位 SVM

把常见分类器按「决策边界的形状 / 依赖的假设 / 数据规模」摆开：

| 模型 | 边界 | 关键假设 | $n$ 大时 | 可解释性 | 概率输出 |
|---|---|---|---|---|---|
| 逻辑回归 | 线性（可加核） | 对数几率线性 | 很好 | 强（系数） | 原生 |
| 线性 SVM | 线性 | 间隔最大 | 很好 | 强（系数） | 需校准 |
| 核 SVM | 非线性（核决定） | 局部平滑 | 差（$O(n^2)$） | 弱 | 需校准 |
| 决策树/GBDT | 轴对齐分段 | 特征阈值组合 | 好 | 中（特征重要性/SHAP） | 好（校准后） |
| 神经网络 | 任意 | 平滑 + 分层特征 | 好（需 GPU） | 弱 | 原生 |

三条实用结论：

1. **表格数据、$n$ 中等（千到十万）、$d$ 小** → GBDT 通常赢 SVM，且更快、更好调。这是过去十年的经验共识（多个 benchmark 复现）。
2. **$d$ 很大、稀疏（文本）** → 线性 SVM 与逻辑回归打平，但线性 SVM 对间隔更敏感、常略优；且不需要概率时更省。
3. **$n$ 很小（几十到几百）、$d$ 中等、边界非线性** → 核 SVM 仍是最强基线之一，因为它对过拟合的抵抗力来自「间隔 + 凸优化」，而不是靠正则化调参。

一个常被忽略的事实：**SVM 在小样本高维上表现好，不是因为它"聪明"，而是因为它的假设最少**（只假设局部平滑），VC 维由间隔控制而非维度。相对地，神经网络在小样本上要靠强先验（架构/预训练）才能不崩。

### 🧑‍💻 程序员视角

- 建模顺序建议：**先线性基线（LR/线性 SVM）→ 再 GBDT → 再核方法/深度模型**。跳过基线直接上核 SVM，往往在 $n$ 上万时被训练时间劝退。
- 需要「哪个特征起作用」时，别用核 SVM——用线性 SVM 的系数或 GBDT + SHAP。核 SVM 只能给出「哪些样本是支持向量」，解释粒度停在样本级。
- 小样本（$n<500$）时核 SVM + 嵌套交叉验证是很稳的方案，尤其在不允许用预训练模型的内网场景（医疗/工业检测的小数据集）。
- 不要在生产做「在线学习」用 SVM：新样本必须重训，模型更新成本高。GBDT 可以增量、LR 可以 SGD 增量。

### 🎓 博士生视角

- SVM 的泛化保证来自**间隔界**：对间隔 $\gamma$ 的分类器，其 VC 维上界约为 $O(R^2/\gamma^2)$（$R$ 为数据半径），与维度无关。这是「高维小样本可用」的理论解释，也是它与「维度灾难」不冲突的原因——它绕开了维度，用的是间隔。
- 与逻辑回归的差别在**损失尾部**：hinge 在 $y f(x)>1$ 后梯度为 0，因此对「已经很对的样本」不再调整，模型只关注边界附近；log-loss 永远在推远所有样本，因此对异常点更敏感（会被远处错分点持续拉拽）。
- 这个差别带来可观测的鲁棒性差异：**SVM 对标签噪声相对稳健**（噪声点若被 $C$ 截断，影响有限），逻辑回归会被持续拉偏。这也是「$C$ 相当于对每个样本的损失设上限」的解释——hinge + 上界 $\alpha\le C$ 等价于**截断损失**。
- 从统计效率看，log-loss 是 proper scoring rule（能给出校准概率），hinge 不是——所以「SVM 概率不准」不是实现问题，而是损失本身不含概率语义。

### 📚 考研者视角

- **必背对比**：SVM vs 逻辑回归（损失、稀疏性、概率、鲁棒性）；SVM vs 决策树（边界形状、可解释性、缺失值处理）。
- **常考问法**：① 为什么 SVM 适合小样本高维；② SVM 为什么对噪声稳健（hinge 截断）；③ 什么场景不该用 SVM。
- **易混**：SVM 不是「只能二分类」（有 OvO/OvR）；「最大间隔」不等于「最大准确率」（间隔是正则，不是目标）。

## 2. 不平衡、代价敏感与概率校准

**不平衡**：标准 SVM 对所有样本用同一个 $C$，少数类因数量少而在总损失里被淹没。两种修法：

- **类权重**：给少数类更大的 $C_i$（sklearn 的 `class_weight='balanced'` 按 $n/(k\cdot n_c)$ 设置），等价于「少数类的违规更贵」。
- **改变阈值/重采样**：SMOTE 过采样、欠采样，或直接调决策阈值（用 `decision_function` 排序后选阈值）。

**概率校准**：SVM 输出的是到超平面的**距离**（`decision_function`），不是概率。要概率有三条路：

1. **Platt scaling**：在 SVM 分数上拟合一个 logistic（$P(y=1|f)=1/(1+\exp(Af+B))$），用交叉验证避免过拟合。sklearn 的 `probability=True` 就是它。
2. **等渗回归（isotonic）**：非参数单调映射，样本多时比 Platt 更灵活，样本少时易过拟合。
3. **换模型**：直接要概率就用逻辑回归/GBDT，别硬掰。

注意：**距离不是概率，也不能直接当置信度**。SVM 的分数尺度依赖 $\|w\|$ 与 $C$，不同数据集之间不可比；把 `decision_function` 的输出当「置信度百分比」是常见错误。

### 🧑‍💻 程序员视角

- 不平衡场景的标准流程：先看 **PR 曲线**（不是 ROC），再定阈值；`class_weight` 与阈值调整二选一（同时做会双重补偿、过度偏向少数类）。
- 校准后再上线：如果业务要用「概率」做定价/风控，必须做校准并画**可靠性曲线**（reliability diagram）；未校准的 Platt 输出在小样本上会严重失真。
- 早停/特征选择上，SVM 的 `coef_` 只在**线性核**下存在；用 RBF 时看 `dual_coef_` 与支持向量，不要试图读「特征重要性」——那是错的。

### 🎓 博士生视角

- Platt scaling 的正当性是「把 SVM 分数视为一个单调的充分统计量」，再用一个参数化链接函数映射到概率。它假设分数与对数几率线性，样本少时偏差大；等渗回归放宽了这个假设但需要更多数据（$O(n)$ 的分箱）。
- 「距离不可比」的严格原因：$\|w\|$ 由 $C$ 与数据尺度共同决定，同一决策边界可以对应任意尺度的分数。要让分数可比，必须显式归一化（如除以 $\|w\|$ 得几何距离），但那仍然不是概率。
- 类别加权的贝叶斯解释：给少数类更大的 $C$ 等价于改变**先验**（把先验从经验频率改成均匀），因此它改变的是决策阈值而非条件分布——这也是为什么加权后校准会变差。
- 不平衡下的评估理论：ROC 对类别比例不敏感（TPR/FPR 都不含 $n_-$），PR 曲线敏感。因此「不平衡看 PR」不是习惯，而是由指标定义决定的。

### 📚 考研者视角

- **必背**：类别加权的两种实现（$C_i$ / 重采样）；Platt scaling 的作用；为什么不平衡看 PR 而非 ROC。
- **常考问法**：① SVM 如何输出概率（Platt/等渗）；② 不平衡时怎么改 SVM；③ 为什么 `decision_function` 不能当概率。
- **易混**：`predict_proba` ≠ `decision_function`（前者校准过、后者是距离）；过采样 ≠ 加权（前者改数据分布、后者改损失）。

## 3. 什么时候不该用 SVM

明确列出「SVM 不适用」的场景，比背优点更有价值：

| 场景 | 原因 | 替代 |
|---|---|---|
| $n>10^5$ | 核矩阵 $O(n^2)$ 内存、SMO $O(n^2)$ 时间 | 线性模型 / GBDT / 神经网络 |
| 需要概率且要准 | hinge 非 proper scoring rule | 逻辑回归 / GBDT |
| 需要特征重要性 | 核 SVM 无系数 | 线性 SVM / GBDT + SHAP |
| 在线/增量学习 | 无原生增量更新 | SGDClassifier / 在线 GBDT |
| 高维稀疏 + 非线性 | RBF 在高维退化（距离集中） | 线性核 + 特征交叉 / 深度模型 |
| 多分类 + 大 $k$ | OvO 需 $k(k-1)/2$ 个模型 | 朴素贝叶斯 / 线性 softmax |

反过来，SVM 仍是这些场景的首选：**小样本、中等维度、边界非线性、要求凸优化可复现（不吃随机种子）、需要理论保证**。

### 🧑‍💻 程序员的判断流程图

1. $n$ 是否 > 5 万？是 → 放弃核 SVM。
2. 是否需要概率/特征重要性？是 → 逻辑回归或 GBDT。
3. 是否小样本（$n<2000$）且非线性？是 → 核 SVM（RBF），配嵌套 CV。
4. 以上都不是 → 先跑线性 SVM 与 GBDT 两个基线，谁好用谁。

### 🎓 博士生视角

- SVM 的「不吃随机种子」是常被低估的优点：凸 QP 有唯一全局最优，同样的数据必得同样的模型。这对监管/复现要求高的场景（医疗、金融模型备案）是实质优势，而深度模型与 GBDT 都受初始化/采样顺序影响。
- 核方法的现代复兴形态是**核近似 + SGD**（随机特征）与 **NTK 视角**：前者解决规模，后者解决理论。理解 SVM 的对偶与表示定理，是读懂这两条线的门槛。
- 「深度模型打败核方法」的准确表述是：在**大数据 + 有结构先验（局部性/平移等变）**的场景，学到的特征优于手工核；在**小数据**上，核方法仍是更稳的先验。

### 📚 考研者视角

- **必背**：SVM 的四个典型不适用场景；凸优化的可复现优势。
- **常考问法**：① 大数据下 SVM 为什么不行；② 什么情况下 SVM 优于神经网络（小样本、理论保证）；③ SVM 的训练复杂度。
- **易混**：训练复杂度 $O(n^2 d)$ 与预测复杂度 $O(n_{sv}d)$ 要分开说（预测只依赖支持向量数）。

## 三视角小结

| 主题 | 程序员要会 | 博士生要会 | 考研/笔面要会 |
|---|---|---|---|
| 定位 | 建模顺序（线性→GBDT→核） | 间隔泛化界、hinge vs log-loss 尾部 | 与 LR/树的对比表 |
| 不平衡 | PR 曲线 + 类权重 + 阈值 | 类权重=改先验、PR/ROC 的敏感性 | 加权与重采样、Platt |
| 概率 | `probability=True` 的代价 | proper scoring rule | Platt/等渗、距离≠概率 |
| 边界 | 四步判断流程 | 凸优化的可复现价值、NTK | 不适用场景与复杂度 |
