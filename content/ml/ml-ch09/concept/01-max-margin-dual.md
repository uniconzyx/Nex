## 1. 最大间隔：把「分类正确」加码成「分类得有余量」

逻辑回归只要求 $y_i(w^\top x_i+b)>0$（分对就行），于是**离超平面很近的正确分类**也拿满分。SVM 的要求更强：不只是分对，还要**留出最大余量**。

先约定几何口径。超平面 $w^\top x+b=0$ 到点 $x$ 的**函数间隔**是 $|w^\top x+b|$，**几何间隔**是

$$\gamma=\frac{|w^\top x+b|}{\|w\|}$$

函数间隔会随 $w$ 缩放而变（$w,b$ 同乘 2，函数间隔翻倍但超平面没变），所以只有几何间隔才有几何意义。**SVM 的第一步规范化**就是利用这个自由度：令最近点的函数间隔恰为 1，即 $y_i(w^\top x_i+b)\ge1$，此时间隔宽度为

$$\text{margin}=\frac{2}{\|w\|}$$

于是「最大化间隔」等价于「最小化 $\|w\|^2$」：

$$\min_{w,b}\ \tfrac12\|w\|^2\quad\text{s.t.}\quad y_i(w^\top x_i+b)\ge1,\ i=1..n$$

这就是**硬间隔 SVM** 的原始问题：一个凸二次规划（QP），目标凸、约束线性，因此有唯一全局最优（$w$ 唯一，$b$ 在退化情形可能不唯一）。

**软间隔**处理「线性不可分」：给每个样本一个松弛变量 $\xi_i\ge0$，允许它违规一点点，但违规要付代价：

$$\min_{w,b,\xi}\ \tfrac12\|w\|^2+C\sum_i\xi_i\quad\text{s.t.}\quad y_i(w^\top x_i+b)\ge1-\xi_i,\ \xi_i\ge0$$

$C$ 是「间隔宽度」与「违规总量」的交换率：$C\to\infty$ 退化为硬间隔；$C$ 小则容忍更多违规（更宽间隔、更偏置）。**$C$ 不是正则化系数而是容错的价格**，这是最容易被误解的一点。

把约束代入消去 $\xi_i$，软间隔可写成更常用的**合页损失（hinge）**形式：

$$\min_{w,b}\ \sum_i\max\big(0,\,1-y_i(w^\top x_i+b)\big)+\frac{1}{2C}\|w\|^2$$

这条式子说明了 SVM 与逻辑回归的真实关系：**两者只差损失函数**（hinge vs log-loss），都是「损失 + L2」；hinge 在间隔外**恰好为 0**，这是 SVM 稀疏性（只有支持向量起作用）的根源，而 log-loss 永远不为 0，所以逻辑回归所有样本都参与。

### 🧑‍💻 程序员视角

- **样本量选择题**：$n$ 在万级以内、特征维度中等 → 核 SVM（`SVC`）；$n$ 十万以上 → 线性 SVM（`LinearSVC`/LIBLINEAR）或直接上 GBDT/线性模型，核 SVM 的 $O(n^2)\sim O(n^3)$ 会拖死。
- **必须标准化**：SVM 基于距离/内积，特征量纲差一个数量级就会主导核矩阵。`StandardScaler` 是管线里的硬要求（树模型不需要，这点常被拿来对比）。
- **`C` 与 `gamma` 的调参区间**：$C$ 在 $10^{-3}\sim10^{3}$ 做 log 网格；RBF 的 $\gamma$ 同理。二者一起网格搜索（`GridSearchCV`），因为它们的交互很强（大 $C$ + 大 $\gamma$ = 过拟合）。
- **`probability=True` 有代价**：SVM 原生不输出概率，sklearn 用 Platt scaling（内部 5 折 CV 拟合 sigmoid），训练时间显著增加且概率未校准。需要概率就换逻辑回归或做后校准。
- `class_weight='balanced'` 在不平衡数据上很有效（等价于给少数类更大的 $C$），但会推高少数类的支持向量数量、拖慢推理。

### 🎓 博士生视角

- 为什么「最小化 $\|w\|$」等价于「最大化间隔」：间隔是 $\|w\|$ 的反比，且规范化 $y_i(w^\top x_i+b)\ge1$ 用掉了 $w$ 的尺度自由度。若不做规范化，最小化 $\|w\|$ 会退化成「把 $w$ 压到 0」的平凡解——**约束是尺度规范的载体**，这一步不能省。
- 硬间隔解的存在性要求数据线性可分；软间隔的 QP 在任意数据上都有解，因为 $\xi$ 给了可行性。这是「SVM 总能用」的严格理由。
- hinge 损失是 **0-1 损失的最紧凸上界**（在间隔尺度上），这是它作为代理损失的正当性来源；log-loss 也是凸上界但更平滑、尾部不截断。
- 从统计学习理论看，SVM 的泛化界由**间隔**而非维度控制：间隔越大，VC 维上界越小。这解释了「SVM 能在高维小样本上工作」——它不是靠维度惩罚，而是靠间隔。
- 一个反直觉的结论：硬间隔 SVM 的对偶解中，**只有支持向量对应的 $\alpha_i>0$**，其余全为 0；因此模型只依赖少数样本。这不是实现优化，而是 KKT 互补松弛的**结构性结果**。

### 📚 考研者视角

- **必背**：几何间隔与函数间隔的定义与关系；硬间隔原始问题；软间隔的两种等价形式（$\xi$ 形式与 hinge 形式）。
- **常考计算**：给 $w=(3,4)$、$b=-1$ 与点 $x=(1,1)$，求几何间隔（$\frac{|3+4-1|}{5}=1.2$）；给支持向量求间隔宽度 $2/\|w\|$。
- **高频问法**：① 为什么 SVM 要最大化间隔（结构风险最小化/泛化界）；② $C$ 的作用（容错价格，$C$ 大→过拟合）；③ SVM 与逻辑回归的区别（损失函数、稀疏性、概率输出）。
- **易混**：函数间隔 vs 几何间隔（前者可缩放，后者不）；「最大化间隔」≠「最小化分类错误」（后者是 0-1 损失，不可导）。

## 2. 拉格朗日对偶：把「约束」变成「内积」

原始问题是带不等式约束的凸 QP。用拉格朗日乘子 $\alpha_i\ge0$、$\mu_i\ge0$：

$$L(w,b,\xi,\alpha,\mu)=\tfrac12\|w\|^2+C\sum_i\xi_i-\sum_i\alpha_i\big[y_i(w^\top x_i+b)-1+\xi_i\big]-\sum_i\mu_i\xi_i$$

对 $w,b,\xi$ 求偏导置零，得到三条**关键关系**：

$$\frac{\partial L}{\partial w}=0\ \Rightarrow\ w=\sum_i\alpha_iy_ix_i,\qquad \frac{\partial L}{\partial b}=0\ \Rightarrow\ \sum_i\alpha_iy_i=0,\qquad \frac{\partial L}{\partial \xi_i}=0\ \Rightarrow\ \alpha_i+\mu_i=C$$

代回 $L$ 得到**对偶问题**：

$$\max_\alpha\ \sum_i\alpha_i-\tfrac12\sum_{i,j}\alpha_i\alpha_jy_iy_j\,x_i^\top x_j\quad\text{s.t.}\quad 0\le\alpha_i\le C,\ \sum_i\alpha_iy_i=0$$

这里有三个「决定性」的观察：

1. **$w$ 只是样本的线性组合**（$w=\sum\alpha_iy_ix_i$），且只有 $\alpha_i>0$ 的样本参与——这些就是**支持向量**。
2. **对偶问题只出现内积 $x_i^\top x_j$**，从不出现单独的 $x_i$。这一步是核技巧的全部前提：把内积换成核函数 $K(x_i,x_j)$，对偶形式一字不改。
3. **决策函数也只用内积**：$f(x)=\mathrm{sign}\big(\sum_i\alpha_iy_i\langle x_i,x\rangle+b\big)$。所以预测成本正比于支持向量数，而不是维度。

**KKT 条件**把原始解与对偶解锁在一起，其中对 SVM 最有解释力的是**互补松弛**：

$$\alpha_i\big[y_i(w^\top x_i+b)-1+\xi_i\big]=0$$

它直接给出「支持向量」的分类：

| 位置 | $\alpha_i$ | 含义 |
|---|---|---|
| $y_if(x_i)>1$ | $\alpha_i=0$ | 间隔外的普通点，**对模型无影响** |
| $y_if(x_i)=1$ | $0<\alpha_i<C$ | 恰在边界上的**自由支持向量**，决定 $b$ |
| $y_if(x_i)<1$ | $\alpha_i=C$ | 间隔内/被错分的**有界支持向量** |

$b$ 的求法就来自第二行：取任一 $0<\alpha_i<C$ 的样本，$b=y_i-\sum_j\alpha_jy_j\langle x_j,x_i\rangle$。实践中为了数值稳定，会对所有自由支持向量求出的 $b$ 取平均。

### 🧑‍💻 程序员视角

- 看到「支持向量数 ≈ 训练样本数」就是**过拟合信号**（$C$ 太大、$\gamma$ 太大或数据不可分）；正常情况下支持向量占比 10%-40%，占比越低泛化通常越好、推理越快。
- `SVC.support_vectors_` 与 `n_support_` 可以直接验证上面那张表：`dual_coef_` 的绝对值等于 $C$ 的样本就是「有界支持向量」。
- 训练慢的两个原因：核矩阵 $O(n^2)$ 内存、SMO 迭代 $O(n^2 d)$。$n>2\times10^4$ 时优先换 `LinearSVC`（LIBLINEAR 的坐标下降，线性时间近似）。
- 增量/在线场景别用 SVM：它没有原生的在线更新（新增样本要重解 QP）。这是 GBDT/线性模型在生产里更常见的原因之一。

### 🎓 博士生视角

- 强对偶成立要求 Slater 条件（存在严格可行点）；软间隔 SVM 因 $\xi$ 可放大，总存在严格可行点，故强对偶恒成立——这是「对偶解 = 原始解」的严格保证，也是能安全用 SMO 解对偶的前提。
- 对偶问题的 Hessian 是 $\tilde K_{ij}=y_iy_jK_{ij}$，它是半正定的（$K$ 半正定 + 秩 1 符号变换不改变特征值符号）。因此对偶是**凹**最大化问题，任意局部最优即全局最优。
- 支持向量的稀疏性来自 hinge 的**分段线性**：间隔外的样本梯度恰为 0，因此它们在解里「不活跃」。换成 log-loss（处处非零梯度）就失去稀疏性——这是「损失形状决定解的结构」的干净案例。
- 对偶变量 $\alpha_i$ 可以解释为「该样本对约束的**影子价格**」：$\alpha_i$ 越大，说明放松该样本的间隔约束能带来多少目标改进。$C$ 是价格上限，超过就被截断。
- 一个常见误解需要澄清：**SVM 不是「只依赖支持向量所以训练不需要全量数据」**——找支持向量的过程必须看全部样本，稀疏性省的是**存储与推理**，不是训练。

### 📚 考研者视角

- **必背推导链**：原始问题 → 拉格朗日 → 对 $w,b,\xi$ 求导 → 代回得对偶 → KKT 三条（$\alpha_i\ge0$、互补松弛、$\sum\alpha_iy_i=0$）。
- **常考问法**：① 写出软间隔 SVM 的对偶问题并说明 $0\le\alpha_i\le C$ 从哪来（$\alpha_i+\mu_i=C$ 且 $\mu_i\ge0$）；② 解释支持向量的三种情形；③ 为什么 $w$ 可以写成样本的线性组合。
- **易混**：$\alpha_i=0$ 的样本不是支持向量；「支持向量」≠「误分类样本」（有界支持向量包含间隔内的正确分类点）。
- **口径提醒**：对偶问题是**最大化**（因为原始是最小化、约束是 $g\le0$）；写成最小化时要取负号，考试里写反方向是常见扣分点。

## 3. 为什么「对偶」值得单独学

对偶不只是求解技巧，它带来三个不可替代的东西：

1. **核化能力**：原始问题里 $w$ 是显式向量，无法在无限维空间表示；对偶里只有内积，可以换成核。
2. **稀疏性**：对偶解中大量 $\alpha_i=0$，模型只依赖少数样本。
3. **可解释性**：$\alpha_i$ 是影子价格，$C$ 是价格上限，$b$ 由自由支持向量决定。

代价是对偶变量有 $n$ 个（原始只有 $d+1$ 个），因此**$n\gg d$ 时原始问题更省**（线性 SVM 走原始形式），**$n$ 小 $d$ 大时对偶更省**（核 SVM 走对偶）。这个取舍是「线性 SVM vs 核 SVM」两条工程路线的分水岭。

### 🧑‍💻 程序员视角

- 记住这条工程判据：**$n$ 大 $d$ 小 → 原始（LinearSVC）；$n$ 小 $d$ 大 → 对偶（SVC + 核）**。选错方向的代价是内存爆炸（核矩阵 $n^2$）或训练极慢。
- 文本分类（$d$ 十万级、$n$ 万级）的经典组合就是线性 SVM（原始形式），它能和 logistic 打平但更快，且对高维稀疏特征天然友好。

### 🎓 博士生视角

- 原始与对偶的复杂度取舍可以从变量数与约束数直接读出：原始 $d+1+n$ 个变量、$2n$ 个约束；对偶 $n$ 个变量、$2n$ 个约束（含界）。SMO 只处理对偶的等式约束（两变量成对更新），因此每步 $O(n)$。
- 对偶的核化把「特征映射 $\phi$ 的显式构造」替换为「核函数求值」，把复杂度从 $O(d_\phi)$ 降到 $O(n^2)$ 次核调用。当 $d_\phi=\infty$（RBF）时，这是唯一可行的路径。
- 从表示定理（representer theorem）看，任何带 L2 正则的 ERM 解都可写成 $w=\sum\alpha_i\phi(x_i)$ —— SVM 只是这个定理的一个实例。这条视角把核方法与后来的核岭回归、高斯过程统一起来。

### 📚 考研者视角

- **必背**：原始与对偶的适用场景（$n$ vs $d$）；表示定理的结论形式。
- **常考问法**：① 为什么核 SVM 用对偶形式；② 对偶问题的变量个数是多少（$n$）；③ SMO 为什么一次更新两个变量（等式约束）。
- **易混**：对偶问题 ≠ 拉格朗日函数（前者是后者的 min-max 结果）；「强对偶成立」不是所有问题都成立（凸 + Slater 条件）。

### 函数间隔、几何间隔与间隔宽度

```python
import numpy as np
w = np.array([3.0, 4.0]); b = -1.0
pts = np.array([[1.0, 1.0], [0.0, 0.0], [2.0, 0.0]])
norm_w = np.linalg.norm(w)
print(f"||w|| = {norm_w:.4f}")
for x in pts:
    f = w @ x + b                       # 函数间隔（带符号）
    print(f"x={x}: w·x+b = {f:+.2f}, 函数间隔|.| = {abs(f):.2f}, 几何间隔 = {abs(f)/norm_w:.4f}")
print()
print(f"若把 w,b 同乘 2：w={2*w}, b={2*b}")
w2, b2 = 2 * w, 2 * b
f2 = w2 @ pts[0] + b2
print(f"  函数间隔 {f2:+.2f}（翻倍），几何间隔 {abs(f2)/np.linalg.norm(w2):.4f}（不变）")
print()
# 规范化后（支持向量上 y(w·x+b)=1）的间隔宽度
print(f"规范化到 y_i(w·x_i+b)>=1 时，间隔宽度 = 2/||w|| = {2/norm_w:.4f}")
print("结论：函数间隔可被尺度任意缩放，只有几何间隔有几何意义；")
print("      因此 SVM 先用 y_i(w·x_i+b)>=1 固定尺度，再把『最大化 2/||w||』换成『最小化 ||w||^2』")
```

实际输出：

```text
||w|| = 5.0000
x=[1. 1.]: w·x+b = +6.00, 函数间隔|.| = 6.00, 几何间隔 = 1.2000
x=[0. 0.]: w·x+b = -1.00, 函数间隔|.| = 1.00, 几何间隔 = 0.2000
x=[2. 0.]: w·x+b = +5.00, 函数间隔|.| = 5.00, 几何间隔 = 1.0000

若把 w,b 同乘 2：w=[6. 8.], b=-2.0
  函数间隔 +12.00（翻倍），几何间隔 1.2000（不变）

规范化到 y_i(w·x_i+b)>=1 时，间隔宽度 = 2/||w|| = 0.4000
结论：函数间隔可被尺度任意缩放，只有几何间隔有几何意义；
      因此 SVM 先用 y_i(w·x_i+b)>=1 固定尺度，再把『最大化 2/||w||』换成『最小化 ||w||^2』
```

### 一维硬间隔 SVM 的解析解

```python
import numpy as np
x = np.array([-1.0, 1.0])
y = np.array([-1.0, 1.0])
# 对称 ⇒ b=0；支持向量满足 w*x_i = y_i ⇒ w=1
w, b = 1.0, 0.0
print(f"数据: x={x}, y={y}")
print(f"解析解: w={w}, b={b}")
for xi, yi in zip(x, y):
    print(f"  y={yi:+.0f}: y(w·x+b) = {yi*(w*xi+b):+.2f}  (应为 1 -> 是支持向量)")
print(f"间隔宽度 = 2/|w| = {2/abs(w):.4f}")
print()
print("对偶验证：α 由 KKT 决定，两点的 α 都应为 1/2（对称），且 Σα_i y_i = 0：")
alpha = np.array([0.5, 0.5])
print(f"  Σα_i y_i = {(alpha*y).sum():+.6f}")
print(f"  w = Σα_i y_i x_i = {(alpha*y*x).sum():+.4f}  (与解析解一致)")
print("结论：1D 两个对称点 ⇒ w=1, b=0, margin=2；α 的对称性来自数据的对称性")
```

实际输出：

```text
数据: x=[-1.  1.], y=[-1.  1.]
解析解: w=1.0, b=0.0
  y=-1: y(w·x+b) = +1.00  (应为 1 -> 是支持向量)
  y=+1: y(w·x+b) = +1.00  (应为 1 -> 是支持向量)
间隔宽度 = 2/|w| = 2.0000

对偶验证：α 由 KKT 决定，两点的 α 都应为 1/2（对称），且 Σα_i y_i = 0：
  Σα_i y_i = +0.000000
  w = Σα_i y_i x_i = +1.0000  (与解析解一致)
结论：1D 两个对称点 ⇒ w=1, b=0, margin=2；α 的对称性来自数据的对称性
```

## 三视角小结

| 主题 | 程序员要会 | 博士生要会 | 考研/笔面要会 |
|---|---|---|---|
| 间隔 | 标准化必做、$C$ 的区间 | 间隔上界泛化、hinge 是 0-1 最紧凸上界 | 几何/函数间隔、$2/\|w\|$ |
| 对偶 | 原始 vs 对偶的选型判据 | Slater 条件、Hessian 半正定 | 对偶推导链、$0\le\alpha\le C$ |
| KKT | 支持向量占比诊断 | 影子价格、稀疏性的损失来源 | 三类支持向量、$b$ 的求法 |
| 取舍 | $n$ 大→线性、$n$ 小→核 | 表示定理、复杂度对比 | 变量数 $n$ vs $d+1$ |
