# ml-ch09 · 支持向量机与核方法

> 先修：ml-ch02（逻辑回归、正则化）、ml-ch01（凸优化与对偶）。
> 衔接：ml-ch05（树与集成的对比选型）、ml-ch04（$C$ 与 $\gamma$ 的交叉验证选法）。
> 面试权重：★★★★★（「间隔/对偶/核技巧」是算法岗区分度题；推导写不出来基本止步二面）
> 本机无 scikit-learn/cvxopt，全部示例用 **NumPy 从零实现并真实运行**（见 examples/），
> 其中 `ex07` 是一个完整的简化 SMO，可直接复现软间隔解。

## 本章目标

学完你应该能：

1. **说清函数间隔与几何间隔的区别**，并解释为什么「最大化间隔」等价于「最小化 $\|w\|^2$」（尺度规范化那一步不能省）。
2. **写出软间隔 SVM 的原始问题与对偶问题**，并完整推导 $w=\sum\alpha_iy_ix_i$、$\sum\alpha_iy_i=0$、$0\le\alpha_i\le C$ 这三条从哪来。
3. **用 KKT 互补松弛判断三类支持向量**，并说明 $b$ 为什么由「自由支持向量」决定、稀疏性从哪来。
4. **解释核技巧为什么成立**：对偶只含内积 → 换成 $K$ → 不构造 $\phi$；并能手算多项式核的显式特征映射、说明 RBF 为什么对应无限维。
5. **判断核的合法性（Mercer/Gram 半正定）**，并解释高维下 RBF 为什么退化（距离集中）。
6. **写出 SMO 的一步更新公式**，说清为什么必须同时更新两个变量（等式约束）。
7. **给出 SVM 的选型边界**：什么场景该用（小样本、凸优化可复现），什么场景不该用（$n>10^5$、要概率、要特征重要性）。

## 关键认知（本章最值钱的三句）

- **对偶只出现内积**，所以核技巧不是「新算法」，只是「把内积换掉」这一行接口改动；RBF 之所以能工作，是因为没人要求你把 $\phi$ 写出来。
- **稀疏性来自 KKT 互补松弛，不是来自优化技巧**：间隔外的样本 $\alpha_i=0$，对模型毫无影响；换成 log-loss 就立刻失去这个性质。
- **$C$ 是违规的单价，不是正则化系数**：$C$ 大 = 不允许犯错 → 支持向量多、间隔窄、易过拟合；$C$ 小 = 允许犯错 → 更宽间隔、更稳健。
## 与相邻章节的边界

本章只讲**最大间隔分类器**这一条线：几何间隔 → 软间隔原始问题 → 对偶 → 核技巧 → SMO。
不重讲的东西，各自归口如下：

- **与 ml-ch02（线性/逻辑回归）**：两者都是线性分类器，差别在两处——损失（hinge vs log-loss）
  与输出（间隔 vs 概率）。要概率就回 ch02 的逻辑回归或对 SVM 做 Platt 校准；
  要稀疏支持向量与间隔解释就留在这里。
- **与 ml-ch04（评估与误差分析）**：$C$、$\gamma$ 怎么选属于 ch04 的交叉验证与误差分析流程，
  本章只回答「这两个超参各自把偏差/方差推向哪边」。
- **与 ml-ch05（树与集成）**：选型边界本章第 3 篇给判据——
  小样本高维稠密（$n<10^5$、$d$ 大、特征同量纲）优先 SVM；混合类型特征、要大样本吞吐、
  要特征重要性优先 GBDT。
- **与 ai 学科**：核方法是**固定核 + 凸优化**，深度学习是**学表示**。
  两者不是替代关系，在无限宽单隐层的高斯过程极限下有已知对应（Neal 1996），
  本章只在「核 = 隐式特征内积」这个接口处点到，不展开。
