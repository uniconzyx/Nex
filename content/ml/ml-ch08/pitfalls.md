# ml-ch08 易错点：强化学习的六个高频陷阱

1. **Q 表一律初始化为 0，还奇怪「有些动作永远学不到」**
   - 现象：训练几千轮后，总有一批 `(s, a)` 的 Q 值纹丝不动，对应动作再也没被选过；
     或者一开始所有 Q 都是 0，随机游走式探索把高价值区域也游荡过去了，回报曲线趴在地上。
   - 根因：初值在 RL 里不是「中性设定」，而是**先验**。全 0 初值意味着
     「没试过的动作价值为 0」——如果奖励全为负（如每步 −1 的迷宫），0 反而是乐观上界，
     每个未访问动作都显得比已知的更好，行为不可控；如果奖励有正有负，0 又可能是悲观下界，
     未访问动作永远竞争不过偶然被试过的动作，形成**自我强化的锁死**。
   - 正确做法：按任务符号选初值——全负奖励用**乐观初值**（如 `+r_max/(1−γ)` 或一个
     明显偏大的正数），逼智能体系统性地试遍每个动作；奖励符号不定时用随机小值 +
     访问计数（或 UCB 式加分）。表格型 Q-learning 的「初值即探索策略」，与深度网络的
     「参数初始化只影响优化」是两回事，不能套用 ML 的直觉。

2. **周期任务里把 γ 设成 1，然后困惑于「价值怎么不收敛」
   - 现象：一个会循环的状态（如迷宫里的环、金融里的持仓调整），设 γ=1 后 Q 值每轮上涨，
     几个 epoch 后溢出成 `inf`，曲线整体翘头。
   - 根因：γ=1 时回报是**无穷级数**。若存在一条每步都拿正奖励的环，绕环一圈价值 +r，
     无限绕下去 `G = ∞`，价值函数根本没有有限值，Bellman 方程的解不存在。
     γ<1 时 `Σγ^k` 收敛，绕环价值被压成 `γ^L/(1−γ^L)` 的有限量；γ=1 时分母为 0，直接爆炸。
   - 正确做法：周期/持续型任务γ 必须 <1（0.9~0.99 按视野取）；γ=1 只允许
     **必然有限步终止**的任务。若物理上需要「看得极远」，用平均奖励准则
     （average-reward）或相对价值迭代，而不是把 γ 推到 1。另外记住
     `|G| ≤ r_max/(1−γ)`：γ=0.99 时价值尺度是 γ=0.9 的 10 倍，估计误差同步放大。

3. **把 RL 当监督学习做：随机打乱 mini-batch、盼着 loss 单调下降
   - 现象：DQN 训练时把整个 buffer 当训练集，每个 epoch 全量前向一遍；或者
     看到 loss 不降就加学习率、换初始化，把深度学习的调试手册整套搬过来，
     越调越糟；又或者抱怨「梯度明明下降了，怎么策略还是随机乱走」。
   - 根因：监督学习的数据 i.i.d. 且与模型无关；RL 的样本是**当前策略自己走出来的**
     (s, a, r, s') 序列——时间上强相关、分布随策略移动、目标值（target）本身
     也是当前网络的估计（自举）。「固定数据集 + 独立同分布 + 固定标签」三条假设
     一条都不成立，SGD 的收敛分析整体失效。loss 曲线不单调是常态：它同时混了
     「策略在变、目标在动、分布在漂移」三个变源。
   - 正确做法：按 RL 的规律看指标——看**评估回报**（关掉探索、多 episode 平均），
     不是训练 loss；样本保持在线时序采样（回放 buffer 里可以做随机 mini-batch，
     但别把「按 epoch 遍历整个 buffer」当成训练方式）；策略分布变了是特性不是 bug。
     调参顺序：先确认回报曲线整体上扬，再谈 loss 细节。

4. **DQN 忘记（或写错）目标网络，然后花两周调学习率
   - 现象：按「标准配方」搭好 DQN，训练曲线剧烈震荡或缓慢发散，
     Q 值整体越训越大（max 过估计的典型症状），换优化器、调 batch size、加归一化
     都不见好。
   - 根因：target 里用了**正在训练的那份参数**：`r + γ max Q_θ(s', a')`。
     每个梯度步都让 θ 变化，回归目标随之移动——模型在追一个自己制造的移动靶，
     自举回路正反馈，Q 值螺旋上升。这与 bootstrapping 的初衷（用旧估计稳定新估计）相反。
   - 正确做法：维护一份冻结的目标参数 `θ⁻`，target 全部用 `θ⁻` 计算并 `detach`，
     每 C 步（或每个训练步软更新 `θ⁻ ← τθ⁻ + (1−τ)θ`）同步一次。
     自查方法：打印 target 网络参数的 `version`，确认它在同步周期内**完全不变**。
     仍震荡再依次查：奖励是否裁剪、max 是否换成 Double DQN 的「选评分离」。

5. **用训练曲线报「策略水平」，而且只跑一个种子
   - 现象：论文/报告里贴一张回报曲线，取最后 100 个 episode 的均值当最终性能；
     换个 seed 重跑，曲线形状和终值都大变，之前「算法 A 优于 B」的结论翻转。
   - 根因：两件事叠加。其一，训练时的 ε 通常还没衰到终值，曲线尾部仍含探索噪声，
     「训练回报」≠「策略回报」；其二，RL 对随机种子极度敏感——初值、探索轨迹、
     环境随机性层层放大，单次运行的终值方差常常和算法间差距同量级
     （Henderson et al., 2018 的系统性结论）。单 seed + 训练曲线 = 没有信息量的报告。
   - 正确做法：评估与训练分离——训练结束后关掉 ε，用纯贪心策略单独跑 N 个
     episode 取均值 ± 标准差；至少 5 个种子，报区间而不报单值；比较算法时
     报均值差与置信区间。自己写实验报告先立这个规矩，复现别人结果时也先查这条。

6. **终止态忘了乘 `(1−done)`，上一回合的价值漏进下一回合
   - 现象：回合制环境（CartPole、GridWorld 到终点）训练时，终止边界附近的
     Q 值异常偏高；智能体学会「主动撞终止」——在 done=True 前一步刷一笔大奖励，
     然后被结算。
   - 根因：target 写成了 `r + γ·max Q(s', a')`，而 `s'` 是终止态时
     **不存在后续回报**，`G` 到 `r` 就结束了。终止态的 Q 值按定义应为 0
     （或只等于离开奖励），不乘 `(1−done)` 会把「下一回合开局状态的当前估计」
     折现回来，凭空注入一笔虚假价值；早期开局估计偏高时，这个虚假值还会被自举放大。
   - 正确做法：target 一律写成 `r + γ·(1−done)·max_{a'} Q(s', a')`，
     buffer 里必须存 `done` 位；TD/MC 同理（`G ← r + γ·(1−done)·G`）。
     数值自查：训练稳定后打印终止态的 Q 表行，应≈0（或≈离开奖励），
     持续偏大就是这个 bug。
