# ml-ch08 · 强化学习：马尔可夫决策过程与 Q-learning

> 先修：ml-ch02（最小二乘与梯度下降的直觉）、概率论（条件期望、马尔可夫链）。
> 后续：ai-ch04（RLHF/DPO——策略梯度从这里走进大模型对齐；本章只铺垫到表格型 Q-learning 与 DQN 最小直觉）。
> 面试权重：★★★★☆（算法岗/数据岗常考「Bellman 方程推导」「on/off-policy 区别」「DQN 为什么用经验回放与目标网络」；纯工程岗多为概念题）

## 本章目标

学完你应该能：

1. **把一个决策问题写成 MDP 五元组** `(S, A, P, R, γ)`：说清马尔可夫性质在要求什么、
   γ 为什么必须小于 1（或终止态兜底）、以及「策略 π」如何把序贯问题变成每一步的条件分布。
2. **默写回报与价值函数的定义并互相推导**：`G_t = r_{t+1} + γG_{t+1}`、`V^π`、`Q^π`，
   并能从 `V^π` 的定义推出 `Q^π` 与策略评估的迭代式——即 Bellman 期望方程。
3. **写出 Bellman 最优方程并解释它为什么不是一个线性方程组**：说清
   `V* = max_a (R + γΣP·V*)` 里的 `max` 带来了什么，以及 Bellman 最优性算子
   `T` 为什么是 γ-压缩的（`‖Tf − Tg‖∞ ≤ γ‖f − g‖∞`）、 Banach 不动点定理如何保证价值迭代收敛到唯一 `V*`。
4. **从零实现价值迭代/策略迭代与 Q-learning/SARSA**：说清三者的 target 差异
   （`max` vs 采样 vs `π(a'|s')`）、ε-greedy 在探索-利用张力中的位置，
   并能在 GridWorld / CliffWalking 上跑出收敛曲线，指出「on-policy 学到的是π下的最优，off-policy 直接逼近 Q*」。
5. **解释 DQN 的两个补丁各自修了什么 bug**：经验回放打破样本时间相关性（i.i.d. 化）、
   目标网络固定回归目标（否则模型在追逐自己产生的移动靶）；并能说明为什么「RL 论文难复现」
   （种子方差大、评估协议不统一）不是态度问题而是方法问题。

## 关键认知（本章最值钱的三句）

- **强化学习不是监督学习加了个奖励**。监督学习的数据分布由环境给定、与模型无关；
  强化学习的数据分布**由策略自己产生**——动作改变了下一步看到的状态，
  所以 i.i.d. 假设失效，交叉验证、ERM 分析都不能直接搬。
- **Bellman 方程是「自洽」而不是「定义」**。`V^π` 有一个明确的期望定义，
  Bellman 方程说的是「满足这个方程的函数恰好就是 V^π」；最优性算子把「求解」
  变成「迭代到一个不动点」，收敛性由 γ-压缩性保证——这是 RL 里少数有严格理论的部分。
- **Q-learning 的收敛保证是有前提的**：表格表示 + 每个状态-动作对被无限次访问 +
  学习率衰减。换成函数逼近（致命三要素：逼近 + 自举 + 离策略同时出现），
  收敛性证明就失效了——DQN 是工程上work、理论上开口的补丁集合，不是定理。
## 与「深度学习」的分界（避免与 ai 学科混淆）

本章只讲**表格型强化学习**与 DQN 的**最小直觉**：价值迭代、Q-learning、SARSA
都在有限状态-动作空间上用「查表 + 迭代」求解，不需要神经网络；
DQN 部分只解释「用网络代替 Q 表时出现的两个问题及两个补丁」的机制，
不涉及网络结构设计、技巧与调参。

反向传播、卷积/循环结构、策略梯度（REINFORCE、Actor-Critic）、PPO/TRPO 等
「深度强化学习」内容归 ai 学科（如 ai-ch04 的 RLHF/DPO）。

两者的关系同样是**包含而非并列**，分界点在**函数逼近器从哪来**：

| | 表格型 RL（本章） | 深度强化学习（ai 学科） |
|---|---|---|
| 价值表示 | 一张表 `Q(s,a)`，查表即用 | 网络 `Q_θ(s,a)`，前向即用 |
| 泛化 | 无——未见过的 `(s,a)` 只能给初值 | 有——相近状态共享价值估计 |
| 收敛理论 | 表格 Q-learning 有（需无限访问） | 多数算法只有经验证据 |
| 样本效率 | 极低（无泛化，每个格子都要踩） | 低但靠泛化与回放缓解 |
| 典型算法 | 价值迭代、策略迭代、Q-learning、SARSA | DQN 及以后、策略梯度、PPO |

一句话：**本章负责「把 Bellman 方程和 Q-learning 的机理讲透」，
「把神经网装进去还能不能训」是 ai 学科的问题。**
