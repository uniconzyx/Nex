# 时序差分与 Q-learning：没有模型时怎么学，以及装上神经网络后出了什么问题

> 上一节的动态规划有个隐藏前提：**模型已知**。真实任务里 `P` 和 `R` 往往未知，
> 智能体只能靠「走一步、看一眼奖励」的样本学习。时序差分（TD）把 DP 的自举思想
> 搬到采样设置下；Q-learning/SARSA 是它的两个动作-价值版本，分野只有一个问题：
> **target 里的下一个动作，按谁的政策来选。**

## 1. 预测问题的一根光谱：MC 与 TD(0)

策略评估在「无模型」下只有采样可用。两个极端：

| | 蒙特卡洛（MC） | 时序差分 TD(0) |
|---|---|---|
| target | 完整回报 `G_t = Σ γ^k r_{t+k+1}` | 一步 `r_{t+1} + γV(s_{t+1})` |
| 自举 | 无（要等回合结束） | **有**（用当前 V 估计未来） |
| 更新 | `V(s_t) ← V(s_t) + α(G_t − V(s_t))` | `V(s_t) ← V(s_t) + α(r_{t+1} + γV(s_{t+1}) − V(s_t))` |
| 回合制 | 必须 | 逐步在线，**终止态也适用** |
| 偏差/方差 | 无偏、方差大 | 有偏（初值不准）、方差小 |

TD 误差 `δ_t = r_{t+1} + γV(s_{t+1}) − V(s_t)` 是整个 TD 家族的心跳：
它是「**预期 minus 现实**」——上一时刻的预测与这一时刻的现实之间的落差。
可以证明 MC 的更新是 TD 误差的累积和（`G_t − V(s_t) = Σ γ^k δ_{t+k}`）：
**TD 是在线的、边发生边学；MC 是离线的、攒完一集再结账。**

从 DP 的视角看 TD：DP 用 `Σ_{s'} P(s'|s,a)V(s')` 做期望备份，TD 用**一次采样**
`V(s_{t+1})` 替代那个期望——**采样替换掉了求和**，所以 TD 是「带噪声的 DP」。
这解释了它为什么既自举（像 DP）又能在环境里在线跑（像 MC）。

## 2. Q-learning 与 SARSA：差一个 max 的分野

把 TD 搬到 Q 表上，更新规则是同一族：

```text
Q(s,a) ← Q(s,a) + α · [ target − Q(s,a) ]

SARSA（on-policy）:   target = r + γ·Q(s', a')     其中 a' ~ π(·|s')   （实际走的动作）
Q-learning（off-policy）: target = r + γ·max_{a'} Q(s', a')           （假设里的最优动作）
```

名字就是更新五元组 `(s, a, r, s', a')` 的谐音。差别一眼可见：

| | SARSA | Q-learning |
|---|---|---|
| target 的 `a'` | **采样**得到（ε-greedy 实际走的那步） | **max** 得到（表中最大项） |
| 学到的 | `Q^π`——当前 ε-greedy 策略下的价值 | `Q*`——最优策略的价值，与行为策略无关 |
| 行为策略 | 与目标策略**同一个**（on-policy） | 行为策略 ε-greedy，目标策略贪心（off-policy） |
| 悬崖行走 | 贴着崖边走（怕自己探索时掉下去） | 贴边但接受「沿最优线擦过」（ optimistically 利用已知） |
| 收敛条件 | 表格 + GLIE 访问 | 表格 + 每对 `(s,a)` 无限次访问 + 学习率衰减 |

**on/off-policy 的本质**：`target` 里「谁替未来的自己拍板」。SARSA 的行为与目标
是同一个策略——它回答的问题是「按我现在这套（含探索噪声）的行为方式走，值多少」；
Q-learning 的 target 假设「从 s' 起永远选表中最大值」——它直接逼近 `Q*`，
行为策略只负责喂数据，不污染目标。这个分野在函数逼近下会被放大（见第 4 节）。

一个具体差别（CliffWalking）：ε 不变时，SARSA 的安全路线偏保守（目标里含了自己
将来可能踩空的动作价值），Q-learning 的最优路线紧贴悬崖（target 只看最好动作）。
**SARSA 学的是「我实际会怎么走」的价值，Q-learning 学的是「最好能怎么走」的价值。**

## 3. ε-greedy：探索与利用的最小可行解

```
a = argmax_a Q(s,a)          以 1−ε   （利用：吃当前认知的红利）
a = 随机动作                  以 ε     （探索：花成本换未知信息）
```

- ε 太大 → 行为接近随机，`Q*` 估计方差大；ε 太小 → 过早锁死在次优动作
  （一条没走过的近路永远不会被发现）。
- 常用调度：ε 从 1.0 线性衰减到 0.05~0.1，或按访问计数衰减 `ε_s = N_0/(N_0 + N(s))`。
- 理论与工程的分界：收敛证明要求 **GLIE**（贪心极限无限访问）；
  固定 ε=0.1 的 Q-learning 在表格下通常 work 但没有严格保证。

## 4. 装上神经网络：致命三要素与 DQN 的两个补丁

表格 Q-learning 的收敛证明依赖「值存进一格、不影响别的格」。把 `Q(s,a)` 换成
`Q_θ(s,a)` 后，一次参数更新改变**所有**状态-动作对的估计——泛化能力来了，
稳定性没了。Sutton 把函数逼近 + 自举 + 离策略三者的组合称为**致命三要素**
（deadly triad）：三者同时出现时，线性 TD 都可能发散（Baird 反例）。

DQN（Mnih et al., 2015/2015 Nature）的两个补丁，各自精确地修一个 bug：

| 补丁 | 修的 bug | 机制 |
|---|---|---|
| **经验回放** | 样本强时间相关 → 一步梯度估计有偏/震荡 | 存 `(s,a,r,s',done)` 进大 buffer，训练时**随机采样 mini-batch**，把轨迹切成近 i.i.d. 样本；同时每个样本被重复利用，样本效率提高 |
| **目标网络** | target 里的 `max Q(s',a')` 用的是**正在被更新的参数** → 回归目标每步都在动，模型追逐自己的移动靶 | 冻结一份 `θ⁻` 的副本，target 用 `θ⁻` 算，每 C 步同步一次 `θ⁻ ← θ`，回归目标短期固定 |

DQN 的损失就是普通的均方误差（这也是它「最小实现」即可理解的原因）：

```
L(θ) = E_{(s,a,r,s',done) ~ D} [ ( r + γ(1−done)·max_{a'} Q_{θ⁻}(s',a') − Q_θ(s,a) )² ]
```

注意 target 里没有梯度（常数）：目标网络 + detach 保证这是「回归一个固定标签」，
和训练一个普通的分类/回归网络流程同构——**DQN 的全部机灵都在数据侧与标签侧，
不在网络结构。**

补丁之外，工程上常见的还有：奖励裁剪（Atari 把 ±1）、帧堆叠补部分可观察、
Double DQN（解耦「选动作」与「估价值」，压 max 算子过估计偏差）、
优先经验回放（按 TD 误差采样）。它们都在同一个方向上打补丁：**三要素拆不掉，就逐个削弱。**

## 5. 为什么 RL 论文难复现：这是方法问题，不是态度问题

Henderson et al. (2018) 的系统性研究给出三条结论，面试与工程都值得引述：

1. **种子方差极大**：同一个算法在不同随机种子下的最终性能曲线常常**天差地别**——
   RL 是序贯 + 探索 + 自举的复合过程，初值、探索轨迹、环境随机性层层放大；
   单次运行的「最终性能」几乎不可信。
2. **评估协议不统一**：报告「训练曲线最后 100  episode 均值」与「训练结束后
   关掉探索、单独跑 N 集贪心评估」是两回事——后者才是「策略的真实水平」，
   前者混着还在衰减的 ε 与偶然的高分手气。
3. **对照实现细节不可见**：奖励整形、网络初始化、回放 buffer 大小、目标网络同步周期……
   每个都影响结论，但论文里往往只写一句「按标准配置」。

**正确的复现姿势**（也是写自己实验报告的标准）：多种子（≥5，报均值与标准差/
置信区间）、训练与评估分离、报学习曲线而不只是终值、固定并公开所有随机源。
这也解释了为什么 RL 论文里「单 seed 击败基线」的说法越来越不被接受。

## 三视角解析

### 🧑‍💻 程序员视角
- 表格 Q-learning 的完整实现只要四样东西：`Q` 表、`choose_action`（ε-greedy）、
  `learn`（一行 target 更新）、训练循环。先跑通 100 行的表格版，再碰 DQN——
  跳步的人分不清「RL 的 bug」和「框架的 bug」。
- 调试 Q-learning 先看三个数：**回报曲线是否整体上扬**、**Q 表非零占比**
  （长期 <50% 说明探索不足或 γ 太小奖励太稀）、**ε 是否真的在衰减**
  （最常见的 bug：衰减写在循环外，ε 永远是 1.0）。
- DQN 最小实现清单：buffer（`deque(maxlen)`）、行为网络 + 目标网络两份参数、
  每步 soft update 或每 C 步 hard copy、`detach` 掉 target、`done` 位参与 target。
  缺任何一个都会出现「曲线看着在学但就是不收敛」的鬼故事。
- 评估与训练分离是底线：训练时 ε=0.1，评估时 ε=0（纯贪心），分开两个循环。
  用训练曲线报「策略水平」是 RL 报告里最常见的虚高。

### 🎓 博士生视角
- on/off-policy 的形式化：行为策略 β 产数据，目标策略 π 被估计。
  off-policy 修正靠**重要性采样比** `π(a|s)/β(a|s)`；Q-learning 用 max 巧妙地
  绕开了显式 IS（这也是它对采样分布要求宽松的原因），但代价是 max 偏差。
- 线性函数逼近下 TD(0) 的收敛由 ODE 方法刻画（`E[Δθ]` 的流）；自举 + 离策略 +
  逼近三者齐备时该 ODE 的投影算子不再压缩——Baird 反例是线性情形发散的实证。
- Double Q-learning（van Hasselt 2010）把「选」与「评」分给两张表，
  证明 max 过估计随 |A| 增长；Double DQN 把「评」交给目标网络，是同一思想的最小改动。
- 分布视角（Bellemare et al. 2017，C51/QR-DQN）：价值不是标量而是回报分布 `Z(s,a)`，
  Bellman 方程升级为分布的闭合运算——这是「自举+逼近」框架下仍在推进的方向，
  说明经典标量 Bellman 只是这个谱系的一阶近似。

### 📚 考研者视角
- 高频考点与标准口径：**写出 TD(0) 与 Q-learning 的更新式**、**比较 MC/TD/DP**
  （自举与否、是否需要模型、在线性）、**SARSA 与 Q-learning 的 target 差异及
  各自名称含义**、**ε-greedy 的作用**、**DQN 两个补丁修什么问题**。
- 「Q-learning 是 off-policy」的完整论证：target 用 `max_{a'}Q(s',a')`，
  不依赖产生数据的行为策略，因此估计的是 `Q*` 本身；而 SARSA 的 target 用
  实际动作 `a' ~ π`，估计的是 `Q^π`。答题时把这个对应关系写出来，再各举一个行为差异。
- 易错口径：**TD 误差里的 `V(s_{t+1})` 不是回报、不是标签，而是当前估计**——
  说「TD target 就是真实回报」是概念错误；MC 的 target 才是完整回报。
- 收敛条件别漏：表格 Q-learning 的经典结论要求**每个 `(s,a)` 被无限次访问**，
  答题时写成「在适当的学习率衰减与访问条件下以概率 1 收敛到 Q*」。
