# 马尔可夫决策过程：把「序贯决策」写成数学

> 强化学习的一切讨论都从一句话开始：**智能体在一个状态序列里不断选动作，
> 每个动作换来一个奖励，同时把环境推向下一个状态；目标是让长期累积奖励最大。**
> 把这句话严格化，就得到马尔可夫决策过程（MDP）——它是本章后续所有方程的公理化地基。

## 1. MDP 五元组：一个决策问题由五样东西定义

一个（有限的）马尔可夫决策过程是五元组 `M = (S, A, P, R, γ)`：

| 组成 | 含义 | 形式 |
|---|---|---|
| `S` | 状态空间 | 有限集 `{s₁, …, s_n}`（本章只做表格型） |
| `A` | 动作空间 | 有限集 `{a₁, …, a_m}` |
| `P` | 转移核 | `P(s'|s,a)`，满足 `Σ_{s'} P(s'|s,a) = 1` |
| `R` | 奖励函数 | `R(s,a)` 或 `R(s,a,s')`，标量 |
| `γ` | 折扣因子 | `γ ∈ [0,1)`，本章默认 `γ = 0.9~0.99` |

**马尔可夫性质**：`P(s_{t+1} | s_t, a_t, s_{t-1}, a_{t-1}, …) = P(s_{t+1} | s_t, a_t)`。
即「给定现在，未来与过去独立」。这条性质不是世界的属性，而是**我们对状态表示的要求**——
如果未来还依赖过去某个被丢掉的信息，说明状态特征没抽全（经典例子：只看棋子位置的围棋
其实不是马尔可夫的，还要知道「打劫」历史）。

一个最小例子（GridWorld，`γ = 0.9`）：

```
   ┌───┬───┬───┬───┐
   │ S │   │   │ +1│      规则（每步）：
   ├───┼───┼───┼───┤      · 智能体在格子里，每步选 上/下/左/右
   │   │ × │   │ −1│      · 有 0.8 概率按所选方向移动，0.1/0.1 滑向垂直两侧
   ├───┼───┼───┼───┤      · 撞墙不动；走到 +1 或 −1 得奖励并终止
   │   │   │   │   │      · 普通格每步奖励 r = −0.01（催它别磨蹭）
   └───┴───┴───┴───┘
```

注意转移核里的 **0.8/0.1/0.1**：动作不保证成功，这是真实世界（打滑、延迟、噪声）的
数学化身，也是「策略要用期望而不是确定链来评估」的原因。

## 2. 回报 G_t：把「长期累积奖励」定义清楚

从时刻 t 起，智能体希望最大化的是**回报**：

```
G_t = r_{t+1} + γ·r_{t+2} + γ²·r_{t+3} + … = Σ_{k=0}^{∞} γ^k · r_{t+k+1}
```

它有一个**递推形式**，后面所有 Bellman 方程都从这一行出发：

```
G_t = r_{t+1} + γ·G_{t+1}
```

**为什么有折扣 γ？** 三个理由，重要性递增：

1. **数学上**：γ < 1 保证无限步任务的回报级数收敛（奖励有界时 `|G_t| ≤ r_max/(1−γ)`），
   价值函数是有限数，方程才有解；
2. **经济学上**：即时收益优于延迟收益（利息、风险、死亡）；
3. **工程上**：γ 是「视野」旋钮——γ=0 只吃眼前奖励（贪心短视），γ→1 看得远但对估计误差极其敏感
   （价值量级 `r/(1−γ)` 爆炸，见 pitfalls.md 第 2 条）。

无折扣（γ=1）只对**必然终止**的有限步任务合法：此时 `G_t` 是有限项和，天然收敛。

## 3. 策略 π 与两个价值函数：V^π 与 Q^π

**策略** `π(a|s)` 是「在每个状态下选动作的条件分布」。随机策略不是妥协，
而是探索的载体（见 concept/03 的 ε-greedy）与部分可观察/博弈场景的必需。

给定 π，定义两个价值函数（都是**期望**，不是单次轨迹的回报）：

```
V^π(s) = E_π[ G_t | s_t = s ]                  # 从 s 出发、按 π 走的期望回报
Q^π(s,a) = E_π[ G_t | s_t = s, a_t = a ]       # 从 s 出发、先强制走 a、之后按 π 的期望回报
```

两者的关系一步可见（把第一项奖励与转移显式写开）：

```
Q^π(s,a) = R(s,a) + γ·Σ_{s'} P(s'|s,a)·V^π(s')
V^π(s)   = Σ_a π(a|s)·Q^π(s,a)
```

| | V^π | Q^π |
|---|---|---|
| 输入 | 状态 | 状态 + 动作 |
| 回答 | 「在这个状态按 π 走，未来值多少」 | 「在这个状态先做这个动作，未来值多少」 |
| 能否直接导出策略 | 不能（还要知道每步哪个动作好） | **能**：`π*(s) = argmax_a Q*(s,a)` |

最后一行是 Q 函数在工程上好用的根本原因：**模型无关（model-free）时，
环境模型 P、R 未知，V 无法直接用于选动作（选动作需要知道「动作把我送到哪」），
而 Q 已经把「动作 → 未来」打包好了**。

## 4. 与监督学习的根本分界：数据分布依赖策略

机器学习其他章节的数据是「环境给一批 `(x, y)`，与模型无关」；强化学习的「数据」是
**策略自己走出来的轨迹** `(s, a, r, s')`：

```
监督学习：  样本 (x, y) ~ D        D 固定，与模型 f 无关  →  随机梯度是 D 上的无偏样本
强化学习：  样本 (s,a,r,s') ~ D_π  D_π 由 π 产生，π 每步在变  →  分布本身是移动的
```

三个直接后果（这是本章最难、也最值钱的认识）：

1. **i.i.d. 假设失效**：同一条轨迹里相邻样本强相关（状态连续演化），
   「随机打乱 mini-batch」在 RL 里不是自然操作——DQN 的经验回放正是在修补这一点（concept/03）；
2. **没有「正确答案」**：监督学习有标签 `y` 告诉你对错，RL 只有延迟的标量奖励，
   早期动作的好坏要等一串结果出来才能反推——这就是**时序差分信用分配**问题；
3. **探索与利用的张力**：监督学习不需要「试探」，RL 不试就永远不知道没走过的动作好不好——
   ε-greedy、置信上界、内在奖励全是这个张力的不同解法。

## 三视角解析

### 🧑‍💻 程序员视角
- 写 RL 代码先画「交互循环」，而不是先写网络。一个能跑的骨架永远长这样：
  `s = env.reset()` → `for t in range(T): a = policy(s); s, r, done = env.step(a)` →
  把 `(s, a, r, s', done)` 存进 buffer。Gymnasium 的 `reset/step` 接口就是这个循环的标准化。
- 折扣因子在代码里不是一个玄学参数：γ=0.9 的智能体「视野」约 10 步（`1/(1−γ)`），
  γ=0.99 约 100 步。任务里奖励延迟超过视野，它就当奖励不存在——调不通先查 γ。
- 终止位 `done` 要单独存、单独用：`G = r + γ·(1−done)·G_next`。
  忘了乘 `(1−done)`，终止态会把下一回合的开局价值错误地折现回来。
- 表格型 RL 的 `Q` 就是一个二维数组 `Q[|S|, |A|]`，用 `defaultdict` 或 `np.zeros((nS, nA))`；
  越界/未访问项给 0 还是给乐观初值，是策略问题不是语法问题（见 pitfalls.md 第 1 条）。

### 🎓 博士生视角
- 严格说 MDP 允许无限 S/A、连续转移核，本章限定有限是**为了查表算法有定义**；
  函数逼近是把这个假设换掉的代价——致命三要素（逼近 + 自举 + 离策略）在有限表格下
  不同时成立，所以表格 Q-learning 有收敛证明而 DQN 没有一般性证明。
- 马尔可夫性质与「状态充分统计量」的关系：若真实过程不是马尔可夫的，
  可以取增广状态 `s̃_t = (s_t, 全部历史)` 恢复马尔可夫性——代价是状态空间指数爆炸，
  这正是循环神经网络/部分可观察 MDP（POMDP）要处理的问题。
- 期望回报最大化的策略不一定存在（无限视野、一般策略类下），
  有限 MDP 中**确定性平稳策略**内取到最优——这是「策略迭代为什么不亏」的理论依据；
  平均奖励准则（average-reward MDP）是另一条不依赖折扣的路线。
- 形式化上「策略 → 价值 → 改进」构成一个偏序提升框架，
  可以证明 `Q^π(s, π'(s)) ≥ V^π(s)` 时 π' 不劣于 π，且改进严格直到 `π*`（策略改进定理）。

### 📚 考研者视角
- 若报考人工智能方向（自命题常考 RL 基础），本章对应的高频考点与标准口径：
  **MDP 五元组各是什么**、**回报与价值函数的定义式**（`G_t = Σγ^k r`、`V^π(s) = E_π[G_t|s_t=s]`）、
  **折扣因子的作用**（保证级数收敛/权衡远近）、**V 与 Q 的互换公式**。
  定义题要能一字不差写出期望形式，并说明 `E` 的下标是「对谁求期望」。
- 「马尔可夫性」的答题模板：先写条件等式 `P(s_{t+1}|s_t,a_t,历史) = P(s_{t+1}|s_t,a_t)`，
  再补一句「含义：未来只依赖当前状态与动作，与历史无关」。
- 易错口径：**γ 趋近 1 不等于「模型更好」**。要答出「γ→1 时价值尺度按 1/(1−γ) 放大，
  估计误差同步放大，且周期任务可能价值无穷」。
- 与概率论考点衔接：回报是随机变量，价值是它的期望； Bellman 方程的推导本质是
  **全期望公式 `E[X] = E[E[X|Y]]`** 的两次使用——这个视角能对付「证明 Bellman 期望方程」类题目。
