# Bellman 方程与动态规划：从「自洽条件」到「可收敛的迭代」

> 价值函数有明确的期望定义，但定义里藏着无限级数，没法直接算。
> Bellman 方程把这个定义改写成一个**自洽条件**——「V 在某个状态的值 = 立即奖励 + 折扣后的后继价值的期望」。
> 于是求解从「求和」变成「迭代」；而迭代能收敛，靠的是最优性算子的一个代数性质：γ-压缩。

## 1. Bellman 期望方程：两次使用全期望公式

对任意策略 π，回报递推 `G_t = r_{t+1} + γG_{t+1}` 两边取条件期望：

```
V^π(s) = E_π[ r_{t+1} + γ·G_{t+1} | s_t = s ]
       = E_π[ r_{t+1} | s_t = s ] + γ·E_π[ G_{t+1} | s_t = s ]
```

第一项就是对动作与转移求期望；第二项对 `s_{t+1}` 再用一次全期望公式
`E[G_{t+1}] = Σ_{s'} P(s_{t+1}=s')·E[G_{t+1}|s_{t+1}=s']`，而 `E[G_{t+1}|s_{t+1}=s'] = V^π(s')`。得到：

```
V^π(s) = Σ_a π(a|s) [ R(s,a) + γ·Σ_{s'} P(s'|s,a)·V^π(s') ]        （Bellman 期望方程）
```

换成算子语言：`V^π = T_π(V^π)`，其中 `(T_π f)(s) = Σ_a π(a|s)[R(s,a) + γΣ_{s'}P(s'|s,a)f(s')]`。
注意这个算子是**线性的**：`T_π` 是「折扣转移矩阵 + 奖励向量」，即
`V^π = (I − γP^π)^{-1} r^π`——理论上解线性方程组可得解析解，但 `|S|` 一大就不可行。

Q 版本的期望方程（自洽性同样成立，concept/01 已给互换式）：

```
Q^π(s,a) = R(s,a) + γ·Σ_{s'} P(s'|s,a)·Σ_{a'} π(a'|s')·Q^π(s',a')
```

**自洽 ≠ 定义**。方程 `V = T_π V` 的解是唯一的，而那个唯一解恰好是 `V^π`——
方程是性质的载体，不是新定义。考试里「证明某函数是 V^π」的标准打法就是：
验证它满足 Bellman 期望方程，再用唯一性。

## 2. Bellman 最优方程：一个 max 让问题质变

最优价值函数 `V*(s) = max_π V^π(s)`。把「先选最优动作、之后也按最优走」写出来：

```
V*(s) = max_a [ R(s,a) + γ·Σ_{s'} P(s'|s,a)·V*(s') ]              （Bellman 最优方程）
Q*(s,a) = R(s,a) + γ·Σ_{s'} P(s'|s,a)·max_{a'} Q*(s',a')
```

与期望方程的差别只有一处——`Σ_a π(a|s)` 换成 `max_a`——但后果是本质的：

| | Bellman 期望方程 | Bellman 最优方程 |
|---|---|---|
| 算子 | 线性（对给定 π） | **非线性**（max 不可交换、不可微） |
| 解 | 唯一（π 固定时） | 唯一（V* 唯一；最优策略可多个） |
| 求解 | 线性代数 | **只能迭代**（无闭式） |
| 行为 | 评估一个已知策略 | 直接找最优 |

已知 π 用期望方程（策略评估）；找最优策略用最优方程（价值迭代/策略迭代）。
两者共享同一个迭代引擎，区别只在 target 里「按 π 加权」还是「取 max」。

## 3. 动态规划三件套：评估、改进、迭代

DP 的前提是**已知模型**（P 与 R 已知）——名字里的「规划」就是这个意思：
不与环境交互，纯在脑内（内存里）推演。

### 3.1 策略评估（Policy Evaluation）

反复施加 `T_π` 直到不动点。伪码：

```
V ← 任意初值（如全 0）
repeat:
    Δ ← 0
    for each s in S:
        v ← V[s]
        V[s] ← Σ_a π(a|s) [ R(s,a) + γ·Σ_{s'} P(s'|s,a)·V(s') ]
        Δ ← max(Δ, |v − V[s]|)
until Δ < θ
```

这就是「备份」（backup）：每个状态的值来自它的后继状态的当前估计——形象地说，
值像水一样从终止态沿着状态图倒灌回来。误差按 γ 每步衰减，所以迭代收敛速度
由 γ 决定（γ=0.9 时每次 sweep 把误差压掉一个数量级）。

### 3.2 策略改进（Policy Improvement）

对当前 V^π 做**贪心改进**：`π'(s) = argmax_a Q^π(s,a)`。
策略改进定理保证 `π'` 不会比 π 差：

```
若对所有 s 有 Q^π(s, π'(s)) = max_a Q^π(s,a) ≥ V^π(s)，则 V^{π'} ≥ V^π（逐点）
```

证明思路：贪心动作的价值 ≥ 沿用 π 的价值，而「后继仍按 π」不变，逐项比较即得。
**这条定理是整个策略迭代合法性的来源**：它保证改进方向单调向上。

### 3.3 策略迭代 vs 价值迭代

| | 策略迭代 | 价值迭代 |
|---|---|---|
| 每轮结构 | 完整评估 V^π → 改进 π | 一步备份（不评估完就贪心） |
| 迭代式 | 外层策略更替 + 内层 V 收敛 | `V_{k+1}(s) ← max_a[R(s,a) + γΣP V_k]` |
| 轮数 | 通常很少（策略单调改善） | 可能多，但每轮便宜 |
| 何时用 | 中小规模、要显式策略 | 大规模、只要 V* |

价值迭代是「截断了策略迭代的内循环」：内层只做一次备份就急着贪心。
它为什么还对？因为它的算子就是 Bellman 最优性算子 `T`，同样收敛（见下节）。

## 4. 压缩映射：为什么迭代一定能收敛

Bellman 最优性算子 `T` 定义在价值函数空间上（装备无穷范数 `‖f‖∞ = max_s |f(s)|`）：

```
(Tf)(s) = max_a [ R(s,a) + γ·Σ_{s'} P(s'|s,a)·f(s') ]
```

**命题（γ-压缩）**：对任意价值函数 f、g，

```
‖Tf − Tg‖∞ ≤ γ·‖f − g‖∞
```

**证明**（关键是不等式 `|max_a u(a) − max_a v(a)| ≤ max_a |u(a) − v(a)|`）：

固定任意 s，设 `a*` 是 `Tf` 一侧取到 max 的动作。则

```
(Tf)(s) − (Tg)(s) = [R(s,a*) + γΣP f] − max_a[R(s,a) + γΣP g]
                 ≤ [R(s,a*) + γΣP f] − [R(s,a*) + γΣP g]        （max 换成 a* 处的项只会变小）
                 = γ·Σ_{s'} P(s'|s,a*)·(f − g)(s')
                 ≤ γ·‖f − g‖∞
```

交换 f、g 地位得反向不等式，故 `|(Tf)(s) − (Tg)(s)| ≤ γ‖f − g‖∞`，再对 s 取 max 即得。∎

**Banach 不动点定理**说：完备度量空间上的压缩映射有唯一不动点，且从任意初值
出发的迭代 `V_{k+1} = T(V_k)` 都收敛到它，误差按 `‖V_k − V*‖∞ ≤ γ^k ‖V_0 − V*‖∞` 线性收缩。

两件事拼起来，就是价值迭代的完整合法性：

```
Bellman 最优方程的解   =  T 的不动点（自洽性：V* 满足方程）
迭代 V_{k+1} = T V_k  →  V*（Banach：压缩保证收敛到唯一不动点）
```

附带一个工程含义：γ=0.99 时每轮误差只乘 0.99，收敛需要几百轮；
γ=0.5 时几轮就到位——**γ 不只决定视野，还决定 DP 迭代的收敛速度**。

## 5. 一个端到端的最小数值例子

3 状态链（`s1 → s2 → s3`，s3 有奖励 1 后终止，每步动作唯一），γ=0.9，V 初值 0：

```
k=0: V = [0, 0, 0]
k=1: V = [0, 0, 1]                     # s3 自拍：V(s3)=r=1
k=2: V = [0, 0.9, 1]                   # s2 = 0 + 0.9·V(s3)
k=3: V = [0.81, 0.9, 1]                # s1 = 0 + 0.9·V(s2)
k=∞: V = [0.9², 0.9, 1] = [0.81, 0.9, 1]   # 已收敛
```

两轮之后值与解析解 `V(s1)=γ², V(s2)=γ, V(s3)=1` 完全一致——因为链上无环，
误差一轮传完。**有环/多路径时，误差在环里按 γ 绕圈衰减，轮数由环长与 γ 共同决定。**

## 三视角解析

### 🧑‍💻 程序员视角
- 价值迭代的代码只有十几行，核心是「对每个 s 把所有动作试一遍取 max」：
  `V[s] = max(R[s,a] + γ * P[s,a] @ V for a in actions)`。
  模型 `P` 用 `P[s, a]` 存成 `nS × nA × nS` 的张量，`P[s,a] @ V` 就是期望。
- 收敛判据用无穷范数 `Δ = max|V_new − V_old| < θ`，与理论证明同口径；
  θ 取 1e-6 量级即可，别用「迭代轮数固定 1000」这种与问题规模脱钩的判据。
- 策略迭代在中小 GridWorld 上通常 5~20 轮收敛，每轮评估反而可能上千次 sweep——
  两阶段都实现、按规模切换，是 RL 作业的常见形态。
- 备份方向别搞反：DP 是「后继的值往当前状态写」；写成「当前值推后继」就变成了
  前向模拟，收敛性完全不同。

### 🎓 博士生视角
- 压缩性证明里 `γ` 只用了「奖励有界」这一件事；若把 `max` 换成 softmax  Boltzmann 算子
  （`(T_τ f)(s) = τ log Σ_a exp([R+γΣPf]/τ)`），算子仍压缩，但不动点变成最大熵价值——
  这是 soft Q-learning / SQL 的路线，用软化换探索与多模态。
- 策略改进定理的严格陈述需要策略空间上定义偏序 `π₁ ≤ π₂ ⟺ V^{π₁} ≤ V^{π₂}`；
  有限 MDP 下每次改进至少把一个状态的贪心动作换掉，而状态-动作对有限，故有限步终止。
- 值迭代的收敛率 `O(γ^k)` 在 γ→1 时退化，这是「短视折扣换收敛速度」的经典交易；
  相对价值迭代（relative value iteration）与 Gauss–Seidel 型扫描（用新值更新旧值）在
  平均奖励准则下给出加速，工程实现常直接受益。
- Bellman 方程与「最优控制/哈密顿-雅可比-贝尔曼方程」同源：连续状态极限下
  `V* = max_a [R + γ∫P V*]` 就是 HJB 的特例——DP 的价值迭代与最优控制的
  Pontryagin 极大值原理是一条河的两段。

### 📚 考研者视角
- 高频考点与标准口径：**默写 Bellman 期望方程与最优方程**（差一个 `Σπ` vs `max`）、
  **证明 Bellman 最优性算子是压缩映射**（就是上面那条 `max` 不等式）、
  **说明 Banach 定理给出什么保证**（唯一不动点 + 任意初值收敛 + 误差按 γ^k 收缩）。
- 「证明 V* 满足 Bellman 最优方程」的模板：先设 `V*` 为最优值，写出
  `V*(s) = max_a E[r + γV*(s')]`；反方向用「若 f 满足方程，则 f = Tf = T^k f → V*」
  （Banach 极限唯一）证唯一性。
- 策略改进定理的表述要能写出不等式链：`V^{π'}(s) ≥ Q^π(s, π'(s)) = max_a Q^π(s,a) ≥ V^π(s)`，
  并指出「≥ 中至少一个 s 取严格 > 才叫严格改进，有限状态空间保证有限步到最优」。
- 易错口径：**策略迭代的「内层评估」必须收敛到 V^π 才能改进**；只跑几步就贪心，
  那是价值迭代，两者的轮数/收敛论证不能混写。
