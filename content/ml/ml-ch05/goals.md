# ml-ch05 · 决策树与集成学习：从信息增益到 XGBoost

> 先修：ml-ch02（线性模型的最大似然视角——树与它共享「先用模型定义损失、再谈优化」的思路）。
> 后续：ml-ch06（无监督学习）、ml-ch07（推荐系统）；GBDT 是后续所有表格数据任务的默认基线。
> 面试权重：★★★★★（算法岗必考：信息增益手算、Bagging/Boosting 的区别、XGBoost 分裂增益推导，几乎场场有人问）

## 本章目标

学完你应该能：

1. **在给定数据上手算三种分裂准则**：写出信息增益、增益率、基尼指数的公式，
   解释信息增益为什么偏爱取值多的特征（IV 惩罚从哪来），并用同一份数据排出三者的特征次序。
2. **说清 CART 两件事**：回归树叶值为什么是子树均值（对 SSE 求驻点）、
   连续特征为什么用「排序后相邻取值中点」做候选阈值。
3. **区分预剪枝与后剪枝并说出各自代价**：CCP 的 α 路径是什么、
   为什么后剪枝通常更稳但更贵。
4. **推导 Bagging 的方差缩减公式** `ρσ² + (1−ρ)σ²/B`，
   解释随机森林的特征子采样降的是「树间相关性 ρ」而不是单树偏差，
   并说明 OOB 为什么是 36.8% 的免费验证集。
5. **写出 GBDT 的加法模型与负梯度拟合**：说明平方损失下负梯度就是残差、
   logistic 损失下为什么是 `p−y`，以及学习率与树数为什么必须联动。
6. **复现 XGBoost 的分裂增益公式**：给出二阶泰勒展开、叶权 `w* = −G/(H+λ)`、
   增益 `½[G_L²/(H_L+λ) + G_R²/(H_R+λ) − G²/(H+λ)] − γ`，
   并指认 `λ`、`γ`、`min_child_weight` 各自在公式里的位置。
7. **说清 LightGBM 三板斧各自解决的瓶颈**：直方图分箱（候选切分从 n−1 压到 bin−1）、
   leaf-wise（同预算更低训练损失但有深度失衡风险）、GOSS（保留大梯度、加权小梯度）。

## 关键认知（本章最值钱的三句）

- **树是「轴对齐的分段常数逼近器」**：它的偏差来自分段常数本身，方差来自对训练样本的敏感。
  剪枝、Bagging、Boosting、正则项，全部是在这对矛盾上做不同方向的交易——没有谁是免费午餐。
- **集成的收益是「平均掉独立噪声」，不是「模型变强」**：Bagging 压方差不降偏差，
  所以对高方差模型（深树）有用；Boosting 逐轮拟合残差降偏差，所以对高偏差模型（浅树）有用。
  把 Boosting 用在低偏差模型上、把 Bagging 用在高偏差模型上，都是拿错工具。
- **XGBoost 的每一项超参都能在分裂增益公式里指认位置**：`λ` 进分母收缩叶值、
  `γ` 是分裂门槛、`min_child_weight` 卡子结点 H。会推公式的人调参是扫公式，
  不会推的人调参是玄学——本章 examples 就是让你把公式手算一遍。
## 与「深度学习」的分界（避免与 ai 学科混淆）

本章讨论的是**轴对齐分段常数函数与它们的加法/平均组合**：决策树、随机森林、GBDT、XGBoost、LightGBM。
`ai` 学科从**可微参数化的多层网络**讲起——那是「学连续表示」的另一条路线。

两者的关系是**并列的两种归纳偏置**，不是深浅之分：

| | 树与集成（本学科） | 深度网络（ai 学科） |
|---|---|---|
| 函数形式 | 分段常数（轴对齐划分） | 连续可微复合函数 |
| 特征尺度 | 不需要标准化（按阈值比较） | 必须标准化（按加权和） |
| 缺失/异常值 | 树天然可处理（缺一路走另一路） | 需要显式填充/归一化 |
| 数据偏好 | 表格数据常胜 | 图像/语音/文本常胜 |
| 优化 | 贪心分裂/加法拟合，无梯度 | 反向传播 + SGD |

工程判据一句话：**异质表格数据（数值+类别+缺失混杂）先用 GBDT 打基线**，
它通常比同数据量的神经网络更准、更快、更可解释；只有当数据是无结构信号（像素/波形/词序列）时，
换路线到 ai 学科才划得来。
