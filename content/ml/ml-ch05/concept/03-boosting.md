# Boosting 与 GBDT：加法模型、负梯度与分裂增益

> Bagging 问「怎么把噪声平均掉」，Boosting 问「怎么把一堆弱模型加成一把强的」。
> 答案是**加法模型** `F_M = F_{M−1} + ν·h_m`：每一轮不重新学，而是在当前模型的错误方向上修一小步。
> 这条主线串起三件事：拟合什么（负梯度）、一步多大（学习率），以及 XGBoost 把这套流程
> 用二阶信息武装之后，每个超参待在分裂增益公式的哪个位置。
> 本章的全部公式都只涉及树与加法组合——**不经过反向传播，也不碰神经网络**，
> 那是 ai 学科的另一条路线。

## 1. 加法模型与负梯度：每一轮拟合什么

**中立陈述**。Boosting 家族共享同一个函数形式——**加法模型**：

```
F_M(x) = F₀(x) + Σ_{m=1}^{M} ν·h_m(x)          # F₀ 通常是常数（训练标签均值）
```

训练用**前向分步**：每轮固定住上一轮的 `F_{m−1}`，只学第 m 个基学习器：

```
h_m = argmin_h Σ_i L(y_i, F_{m−1}(x_i) + h(x_i))
```

对光滑损失 L，在 `F` 处一阶展开，最优局部方向就是**负梯度**（Friedman, 2001）：

```
r_i = − ∂L(y_i, F) / ∂F |_{F = F_{m−1}(x_i)}

平方损失:   L = ½(y−F)²   →  r_i = y_i − F_{m−1}(x_i)        # 就是残差
logistic:   L = −[y·log p + (1−y)·log(1−p)],  p = σ(F)
            →  r_i = p_i − y_i                              # 形式相同，含义不同
```

「GBDT 拟合残差」只在平方损失下成立；换损失就换拟合目标——这正是 GBDT 能做分类的原因。

```
Bagging:   ┌─ 树₁ ─┐  ┌─ 树₂ ─┐  ┌─ 树₃ ─┐     并行：各学各的，最后平均
Boosting:  F₀ ─+h₁→ F₁ ─+h₂→ F₂ ─+h₃→ F₃      串行：每轮修上一轮的错
```

**学习率 ν（shrinkage）是步长**：ν 小则每步只走一小段、需要更多轮；ν 与树数必须**反向联动**，
因为「步长总和」守恒。ex08 用 30~100 个树桩（depth=1）拟合 `sin(2πx)`：

| 学习率 ν | 10 轮 MSE | 30 轮 MSE | 100 轮 MSE | 测试 MSE |
|---|---|---|---|---|
| 0.05 | 0.2448 | 0.1190 | 0.0643 | 0.0410 |
| 0.10 | 0.1516 | 0.0860 | 0.0408 | 0.0189 |
| 0.30 | 0.0827 | 0.0417 | 0.0283 | **0.0131** |
| 1.00 | **0.0493** | **0.0351** | **0.0223** | 0.0173 |

ν=1.0 训练 MSE 最低但测试 MSE 反高于 ν=0.3——**shrinkage 用训练拟合速度换平滑度**，
是 Boosting 里最便宜的正则。基学习器用浅树（树桩 / depth 3）也是同一逻辑：
Boosting 逐轮降偏差，基学习器要高偏差低方差；这与 Bagging 用深树正好互补。

## 2. XGBoost：二阶泰勒展开与分裂增益

**中立陈述**。XGBoost（Chen & Guestlin, KDD 2016）把第 m 轮的目标写成**显式正则的优化问题**
（对损失做二阶泰勒展开，常数项与分裂无关，略去）：

```
Obj = Σ_{i=1}^{n} [ g_i·f(x_i) + ½·h_i·f(x_i)² ] + ½·λ·Σ_j w_j² + γ·T

g_i = ∂ℓ/∂F |_{F_{m−1}(x_i)},   h_i = ∂²ℓ/∂F² |_{...}
      logistic: g_i = p_i − y_i,  h_i = p_i(1−p_i)     # h 只取决于当前预测，与标签无关
      平方损失: g_i = y_i − F,     h_i ≡ 1
```

对叶子 j 聚合梯度统计量 `G_j = Σ_{i∈R_j} g_i`、`H_j = Σ_{i∈R_j} h_i`，叶权有**闭式解**：

```
w_j* = −G_j / (H_j + λ)            叶子 j 对目标的最优贡献 = −G_j² / (2·(H_j + λ))
```

于是任意候选切分的增益（分裂后两叶贡献 − 父叶贡献，再减 γ 的「过路费」）：

```
Gain = ½·[ G_L²/(H_L+λ) + G_R²/(H_R+λ) − G²/(H+λ) ] − γ
       └── 分裂后 ──┘    └── 不分裂时父结点的贡献 ──┘
```

这个式子最重要的工程含义：**分裂搜索只需要每个结点的 (G, H) 聚合量**，
不需要逐样本遍历损失——分块、并行、抽样、分箱全部建立在这上面。

ex09 手算实测（8 个样本，上一轮打分 F=−0.85 → p=0.2994，logistic 损失）：
根结点 `G=−1.6045, H=1.6782`；λ=1 时枚举 7 个候选切分，最优为 `x≤0.350`，Gain=1.2957。
同一最优切分上扫 λ：

| λ | w*_L | w*_R | Gain |
|---|---|---|---|
| 0.0 | −1.4274 | 2.3862 | **2.8602** |
| 1.0 | −0.5513 | 1.2216 | 1.2957 |
| 20.0 | −0.0435 | 0.1189 | **0.1090** |

**三个正则项在公式里的位置，必须指认清楚**：

| 超参 | 公式位置 | 作用机制 |
|---|---|---|
| λ（reg_lambda） | `w*` 与 Gain 的分母 `H+λ` | 收缩叶值；H 小（样本少 / 曲率小）的叶子被压得越狠；λ→∞ 增益→0，树退化为不分裂 |
| γ（min_split_loss） | Gain 末尾的减项 | 「新增一个叶子必须赚回的最小增益」；只在分裂决策处做阈值，不改变已选定的叶值 |
| min_child_weight | 子结点约束 `H_L ≥ cw, H_R ≥ cw` | 卡住 hessian 之和太小的子结点（≈预测不确定性），**不是样本数**——ex09 中 H_L=0.629，mcw=1.0 即被拒绝 |

γ 从 0 到 0.20 时 ex09 的最优切分仍满足 `Gain−γ > 0`——门槛的存在意义是挡住一堆「赚不到钱」的分裂，
而不是改变已经赚钱的那个分裂的选择。与经典 GBDT 相比，XGBoost 的增量是
**二阶近似（叶权闭式）+ 显式正则（λ/γ）+ 系统工程（分块、稀疏感知、并行）**三件事，
算法层面仍是前向分步的加法模型。

## 3. LightGBM：三板斧——直方图、leaf-wise、GOSS

**中立陈述**。LightGBM（Ke et al., NeurIPS 2017）的三项改进都在回答同一个问题：
当 n 和 d 都很大时，每一步分裂的账单怎么付。三板斧的共同哲学是**用可控精度换规模**。

**直方图分箱**：把连续特征装进 bin 个桶（默认上限 255），先在桶上累加
(count, Σg, Σh)，再只枚举桶边界做候选——候选切分从 `n−1` 压到 `bin−1`：

```
精确扫描：  每结点每特征遍历 n−1 个相邻中点        O(n)
直方图：    先聚合到 bin 个桶，再遍历 bin−1 个边界   O(n) 一次 + O(bin) 每结点
桶减法：    右兄弟直方图 = 父结点直方图 − 左孩子直方图   # 省掉一次 O(n) 扫描
```

ex10 实测（n=3000，32 个等比分位桶）：精确扫描 2999 个候选 vs 直方图 31 个候选；
最优阈值差 0.0148（不超过一个桶宽 0.0305），SSE 下降相对误差 **0.60%**；
桶减法与直接计算的直方图差为 0（机器精度）。误差被桶宽封顶，这是分箱近似的代价。

**leaf-wise 生长**：level-wise 逐层对称地长；leaf-wise 每轮只分裂**全局增益最大的叶子**。
同样分裂预算下训练损失更低，但深度分布失衡：

| 方式（预算 127） | 叶子数 | 最大深度 | 训练 MSE | 测试 MSE |
|---|---|---|---|---|
| level-wise | 128 | 9 | 0.0698 | **0.1220** |
| leaf-wise | 128 | 14 | **0.0648** | 0.1263 |

ex10 的深度分布给出原因：leaf-wise 有 21 个叶子长在深度 10、还有深度 13/14 的长链，
每片只由很少样本支撑；level-wise 的 128 片有 122 片集中在深度 6–9。
**深链是方差放大器**——所以 LightGBM 必须同时限制 `num_leaves` 与 `min_data_in_leaf`，
只限 `max_depth` 挡不住这种不均匀的深。

**GOSS（基于单边的梯度采样）**：保留全部大梯度样本（top a%），
对小梯度样本抽 b%，并按 `(1−a)/b` 加权补偿：

```
加权总质量 = a·k + b·k·(1−a)/b = k        # 恒等式：抽样不改变梯度的总质量
```

ex10（a=0.2, b=0.1, k=2000）：只用 600 个样本重排分裂增益，加权总数恰为 2000；
20 次重复抽样选出的切分全部落在全量最优 t* 的 ±0.06 内（19/20 在 ±0.05 内），
增益排名 Spearman 相关 0.98~0.996。不补偿的对照组里，小梯度池只剩 b=10% 的质量，
增益被系统性低估、分裂选择漂移。GOSS 是 Boosting 特有的抽样——按「当前还没拟合好的程度」
而非均匀抽样，因为加法模型里大梯度样本正是下一棵树最该看的地方。

**EFB（互斥特征捆绑）**：把几乎不同时非零的特征（如 one-hot 的伴生列）捆成一列，
降维不丢信息——是 GOSS 之外针对高维稀疏特征的配套优化，一句话点到为止。

## 三视角解析

### 🧑‍💻 程序员视角
- 调参先对公式再动手：`eta` 是步长、`num_round` 是轮数（两者联动，见 pitfalls 第 4 条）；
  `max_depth` / `num_leaves` 是树容量 T；`min_child_weight` 卡子结点 H；
  `reg_lambda` / `reg_alpha` 是叶权正则；`gamma` 是分裂门槛；
  `subsample` / `colsample_bytree` 是每轮的抽样。**每个旋钮都能在分裂增益公式里指认位置**，
  指认不了的参数说明你还没理解它在优化什么。
- 常见 bug 清单：① 早停只配了 `eval_set` 没管最优轮次语义，拿最后一棵树去 serving；
  ② 直方图分箱的 bin 边界必须固化进模型 artifact，线上重新分箱 = 静默错位，
  上线后要监控「落在训练范围外的比例」；③ 类别不平衡先调 `scale_pos_weight` 或重采样，
  再重扫 `min_child_weight`——样本权重直接进 G/H，约束的实际含义随权重漂移；
  ④ 初始预测（XGBoost 的 `base_score` / `intercept_`）是真的在学，它决定初始 p、
  进而决定初始 h = p(1−p)，λ 的相对收缩强度跟着变。
- XGBoost vs 原生 GBDT 的工程增量记住三样：二阶泰勒（叶权闭式）、显式正则、系统优化。
  面试问「GBDT 和 XGBoost 差在哪」，答这三层比报菜名参数强。
- 大数据默认路线：行数多上直方图 + GOSS（LightGBM），列稀疏互斥上 EFB，
  类别特征多上 CatBoost 的有序目标统计；三者都是同一族算法的工程变体，公式没变。

### 🎓 博士生视角
- 第一性原理：前向分步就是**函数空间的梯度下降**——假设空间是树构成的加法群，
  每轮沿负梯度方向取一步，学习率是步长。Bagging 是「并行平均」（集成内部独立），
  Boosting 是「串行修正」（集成内部相依），这一字之差决定了全部偏差-方差画像：
  Boosting 逐轮压低训练偏差，方差却随轮数上升，所以早停是它的必需品。
- 二阶项的来源与用途：logistic 的 Hessian `p(1−p) ∈ (0, 1/4]`，平方损失 `h ≡ 1`。
  二阶项让叶权有闭式解 `−G/(H+λ)`，更关键的是让分裂目标只依赖 (G, H) 聚合量——
  这是 XGBoost 能分块、并行、抽样的根本原因，二阶展开「省掉」的正是逐样本的损失评估。
- AdaBoost 可以理解为**指数损失的加法模型**（Freund & Schapire, 1997；ESL §10.4）：
  指数损失对错分样本惩罚极重，所以它把容量全花在难例上——对标签噪声敏感；
  logistic 损失的尾部轻得多，鲁棒性更好。这是「损失函数选择」而非「算法选择」的差异。
- 非凸损失下二阶展开只是局部 Newton 近似，分裂搜索仍是贪心的——XGBoost 不保证全局最优，
  它保证的是每一步的局部最优有闭式解、且带正则。
- 直方图近似的误差结构：分位数分箱让阈值误差 ≤ 桶宽，增益误差取决于桶内梯度分布
  的集中度（ex10 实测 0.60%）；分箱数是偏差—方差权衡的又一个旋钮。
- 历史线：AdaBoost（Freund & Schapire, 1997）→ 加法逻辑回归（Friedman, Hastie & Tibshirani, 2000）→
  梯度提升机 / MART（Friedman, 2001）→ XGBoost（2014 系统，2016 论文）→ LightGBM（2017）→
  CatBoost（2017，有序目标统计）。一条「从加权投票到二阶正则化到系统优化」的演化线，
  每一步都在给同一个加法模型换更便宜的步子。

### 📚 考研者视角
- **加法模型 + 负梯度是标准表述**（李航《统计学习方法》8.4 提升树；ESL 第 10 章）：
  能写出 `F_M(x) = Σ ν·h_m(x)` 前向分步形式，并推导平方损失下负梯度 = 残差、
  logistic 损失下 = `p − y`。第二个口径是高频区分点。
- **XGBoost 目标函数与分裂增益公式要能默写**：`Obj = Σ[g_i f + ½h_i f²] + ½λΣw_j² + γT`；
  叶权 `w* = −G/(H+λ)`；增益 `½[G_L²/(H_L+λ) + G_R²/(H_R+λ) − G²/(H+λ)] − γ`。
  然后指认 λ（分母、收缩叶值）、γ（门槛、不碰叶值）、min_child_weight（子结点 H 下限）的位置。
- **AdaBoost 与 GBDT 的关系**：AdaBoost 是指数损失的加法模型；GBDT 把损失推广到任意可微损失。
  标准答案一句话：「前者是后者的特例，损失函数从指数损失推广到一般可微损失」。
- **Bagging vs Boosting 对比**（样本权重、并行/串行、降方差/降偏差、基学习器强弱）
  与 02 文件同一口径；补一句 GBDT 的方差随轮数上升、需早停。
- **LightGBM 三板斧名词解释**：直方图分箱（候选切分 n−1 → bin−1）、
  leaf-wise（每次分裂增益最大的叶子，同预算训练损失更低但有深度失衡风险）、
  GOSS（保留大梯度 + 加权抽小梯度）。
- 易混口径：① 「拟合残差」只在平方损失下成立，一般说法是**拟合负梯度**；
  ② 学习率 ν 与树数必须反向联动（步长总和守恒），这是调参题的标准采分点；
  ③ logistic 损失下 `h_i = p_i(1−p_i)`、平方损失下 `h_i ≡ 1`，别混。
- 参考书对应：《统计学习方法》李航 第 8 章（提升方法）；《机器学习》周志华 第 8 章（集成学习）；
  ESL（Hastie et al.）第 10 章（Boosting and Additive Trees）；
  XGBoost 原始论文：Chen & Guestlin, KDD 2016；LightGBM：Ke et al., NeurIPS 2017。
