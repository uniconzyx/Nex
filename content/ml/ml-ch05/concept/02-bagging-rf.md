# Bagging 与随机森林：平均掉独立噪声，压不掉相关噪声

> Bagging 的全部收益与全部局限，都写在一个恒等式里：
> `Var(平均) = ρσ² + (1−ρ)σ²/B`。它同时说明两件事——
> **为什么平均能降方差**（独立部分按 1/B 衰减），以及**为什么平均有天花板**
> （相关部分 ρσ² 一个都消不掉）。
> 随机森林的全部设计，就是在 Bagging 之上多走一步：**主动把树间相关系数 ρ 打下来**。
> 本章钉死三个数字：0.632 从哪来、方差公式怎么推、mtry 到底在降什么。

## 1. Bootstrap 与 OOB：36.8% 是哪来的，验证集为什么免费

**中立陈述**。Bootstrap（Efron, 1979）从 n 个样本**有放回**地抽 n 个：每轮每个样本被抽中的概率 1/n，
于是某个样本一次都没被抽中的概率是 `(1−1/n)^n`：

```text
P(样本 i 不在袋中)   = (1 − 1/n)^n  → e^{−1} ≈ 0.368
P(样本 i 至少中一次) = 1 − (1 − 1/n)^n → 1 − e^{−1} ≈ 0.632
```

OOB（out-of-bag，袋外样本）：对每个样本 i，只让「训练时没见过 i」的那些树来预测它。
不切分任何验证集，就得到每个样本的「干净」预测——这是 Bagging 顺带送的交叉验证。

```
n=5, B=3 的 bootstrap（数字 = 原样本编号）
原样本      1   2   3   4   5
Bag 1      3   3   1   5   1        ← 2、4 没中：对 2、4 而言这棵树是 OOB
Bag 2      5   2   2   2   1        ← 3、4 没中
Bag 3      1   1   4   4   5        ← 2、3 没中
每棵袋内约 36.8% 的位置是重复样本；每个样本平均被 0.368·B 棵树排除在外
```

ex05 实测（n=200，B=300，回归树 depth=4）：平均唯一入样比例 **0.6331**，
理论 `1−(1−1/200)^200 = 0.6330`——n=200 时极限值已经收敛得很好。
OOB MSE = 0.3739，独立测试 MSE = 0.3687（相对偏差 1.41%）；同一实验里单棵树测试 MSE 0.5606，
集成后降到 0.3687，**下降 34.2%**——Bagging 确实在压方差。

| 性质 | OOB 估计 | 独立测试集 |
|---|---|---|
| 是否要额外切分数据 | 否，训练顺带得到 | 是 |
| 每个样本由多少棵树预测 | 约 0.368·B 棵（袋外树） | 全部 B 棵 |
| 用途 | 调参、早停、看收敛 | 最终报告指标 |
| 风险 | 做过超参搜索后不再无偏；树间强相关时会低估集成方差 | 无（只要真的隔离） |

两个容易记错的细节：① 0.368 是**渐近值**，n=10 时 `(0.9)^10 = 0.3487`，与极限差 5%，
小样本别硬套；② OOB 是验证估计而不是测试估计——拿它做过选择就会乐观，
最终报数必须留一层从头到尾没参与任何决策的数据（本章 pitfalls 有完整讨论）。

## 2. 方差缩减：推导、极限与数值验证

**中立陈述**。设 B 个预测器 `f₁…f_B` 各自方差 `σ²`、两两相关系数 `ρ`（均匀相关），取简单平均：

```
f̄ = (1/B)·Σ_b f_b

Var(f̄) = (1/B²)·[ B·σ² + B(B−1)·ρσ² ]        # B 个方差项 + B(B−1) 个协方差项
        = σ²/B + (1 − 1/B)·ρσ²
        = ρσ² + (1−ρ)·σ²/B

B → ∞:  Var(f̄) → ρσ²                          # 独立部分被平均掉，相关部分一个都消不掉
```

这个推导只需要二阶矩存在——**不要求基学习器是树、不要求无偏**，是纯粹的方差账。
两个直接推论：

1. **平均不改期望**（`E[f̄] = E[f]`）：Bagging 只压方差、不降偏差。
   所以它对高方差基学习器（不剪枝的深树）有效，对低方差基学习器（线性模型、浅 kNN）几乎无收益；
2. **收益上限由 ρ 决定**：ρ 来自「同一份训练集 + 同一个贪心算法」的共享结构，
   不是树数能解决的问题。

ex06 用受控噪声结构（`f_i = √ρ·Z + √(1−ρ)·ε_i`，σ²=1）验证：

| ρ | B=1 | B=10 | B=100 | 理论 (B=100) |
|---|---|---|---|---|
| 0.0 | 0.9845 | 0.0999 | 0.0100 | 0.0100 |
| 0.3 | 0.9908 | 0.3674 | 0.3056 | 0.3070 |
| 0.6 | 0.9911 | 0.6419 | 0.6006 | 0.6040 |
| 0.9 | 1.0078 | 0.9084 | 0.8878 | 0.9010 |

ρ=0.9 时 100 棵树只把方差从 1 压到 0.89~0.90——**「多训几棵树」救不了强相关**；
ρ=0 时 B=100 方差 0.0100，与理论严丝合缝。这就是随机森林要动 ρ 的动机。

## 3. 特征抽样与去相关：随机森林比 Bagging 多了什么

**中立陈述**。随机森林（Breiman, 2001）= Bootstrap + **每次分裂只在 mtry 个随机特征里选最优**
（随机子空间思想来自 Ho, 1995）。动机：同一份数据、同一个贪心准则下，强特征几乎在每棵树里
都先被选中，树与树于是强相关；特征抽样强制「这一刀换个特征子集来问」，把 ρ 打下来。

但降 ρ 有代价：**单树能看到的特征变少，偏差上升**。随机森林要赢，必须同时满足
「树间有差异」和「每棵树足够好」——公式 `ρσ² + (1−ρ)σ²/B` 只保证「降 ρ 有用」，
不保证「降 mtry 一定降测试误差」。

ex06 在「5 个特征测同一个潜在因子 + 另 5 个测另一个」的冗余数据上的实测
（n=300，d=10，B=60，depth=5）：

| mtry | 树间平均相关 ρ | 单树 MSE | 集成 MSE |
|---|---|---|---|
| 2 | 0.7466 | 2.3290 | 0.9268 |
| 5 | 0.7681 | 2.2256 | 0.9271 |
| 10 | 0.7757 | **2.1937** | **0.8669** |

mtry 从 10 降到 2，ρ 只从 0.776 动到 0.747——换一组特征仍在测同一个因子；
集成 MSE 反而从 0.867 涨到 0.927。ρ 的小幅下降抵不过单树偏差的上升。
**mtry 是 U 形旋钮，不存在普适最优，用 OOB 或验证集扫，不要照搬 √d。**

**RF 与 Bagging 的系统性差别**：

| 维度 | Bagging | 随机森林 |
|---|---|---|
| 随机性来源 | 仅 bootstrap 样本 | bootstrap + 每结点 mtry 个特征子集 |
| 树间相关 ρ | 高（强特征主导每棵树） | 更低（分裂被强制换特征） |
| 基学习器 | 任意，通常是不剪枝的深树 | 通常也是深树且**不剪枝**（Breiman 原论文的建议） |
| mtry 默认 | — | 分类 √d、回归 d/3（Breiman 的经验默认，**不是定理**；sklearn 回归器默认取全部特征） |
| OOB | 有 | 有（RF 论文即用 OOB 估泛化误差） |
| 变量重要性 | 无内建 | 不纯度重要性（有偏，见下）/ 置换重要性 |

一个必须知道的附带事实：**不纯度重要性对取值多 / 基数高 / 连续的特征有系统性虚高**
（Strobl et al., 2007）——分裂机会多、偷看标签的机会就多；纯噪声特征也能排进前列。
机制层面的解释与工程处置见本章 pitfalls 第 6 条。

## 三视角解析

### 🧑‍💻 程序员视角
- OOB 是调参神器也是审计雷区：`oob_score=True` 白送一个验证误差，但**别把它当最终指标报数**——
  用它选过 mtry/树数之后，它已经不再是独立的泛化估计。
- bootstrap 样本里有约 36.8% 的重复行。任何假设「样本独立同分布、每行等权」的下游代码
  （手写树的 min_samples_leaf 计数、样本权重）在袋内数据上都是错的；要么按 idx 计数，
  要么显式维护重复权重。
- 随机森林的随机性按**列索引**抽样：改特征顺序 = 换一棵树，模型文件与特征管道必须锁死。
  上线事故的高发形态是「特征工程脚本加了一列，森林全变」。
- mtry 用 OOB 扫 U 形曲线（对数网格，如 1/4·√d ~ d），别信默认值；树数加到 OOB 曲线平了就停，
  再加只是买延迟。
- 并行度：树间独立，`n_jobs=-1` 近似线性加速；但内存 = B × 单树体积，
  预测延迟 = B × 树深，树数不是免费的。

### 🎓 博士生视角
- 方差公式是**均匀相关假设下的平均场近似**：真实树间的相关矩阵并不均匀（强特征驱动的分裂
  让相关性集中在相似区域），公式的价值在于给出 ρ 与 B 两个杠杆的量化分工。
- 独立情形 `Var(f̄) = σ²/B` 就是平均的经典结论；ρσ² 项来自**共享的训练集抽样**。
  所以降低 ρ 的两条路——随机化算法（特征子采样）与随机化数据（bootstrap）——
  攻击的是两个不同来源，RF 是同时用。
- Bagging 的有效性与基学习器的**稳定性**成反比（Breiman, 1996）：对不稳定算法
  （树、子集选择）收益巨大，对稳定算法（线性回归、kNN 大 k）收益趋零。
  这是「Bagging 不是万能药」的理论根据。
- OOB 与 Efron 的 .632 bootstrap（1983）同源：都基于袋外表现构造误差估计；
  .632 族估计在过拟合区间需要 + 修正，说明「袋外 ≈ 测试」本身是有条件的近似。
- 不纯度重要性的偏差根源是**用同一份数据同时做分裂选择与重要性评估**：
  候选切点数不均 + 选择效应，让高基数特征系统性占优（Strobl et al., 2007）；
  条件推断森林通过置换检验重新校准 p 值，是理论上的修正方向。
- 与 jackknife 的关系：bootstrap 用「有放回重抽」绕开影响函数的估计，
  代价是袋内数据的相依性——OOB 正是绕开这层相依性的干净用法。

### 📚 考研者视角
- **必考推导**：`Var(f̄) = ρσ² + (1−ρ)σ²/B`。标准步骤是展开 `(1/B²)` 里的
  B 个方差项与 B(B−1) 个协方差项，再合并；要能说出 `B→∞` 时余下 ρσ² 及其含义。
- **Bagging vs Boosting 对比表**（标准答案口径，背下来）：样本权重（bootstrap 重抽 /
  逐轮调错分权重）、训练方式（并行 / 串行）、主要作用（降方差 / 降偏差）、
  基学习器（强而方差大 / 弱而偏差大）。
- **两个数字要会算**：bootstrap 唯一入样比例 63.2%（`1−(1−1/n)^n → 1−e^{−1}`）、
  袋外比例 36.8%（`e^{−1}`）。
- **OOB 定义**：袋外样本；用仅由未包含它的树组成的集成来预测它，用于泛化误差估计。
- **随机森林的标准表述**：以决策树为基学习器、bootstrap 聚合 + 随机特征子空间
  （Ho 1995 / Breiman 2001），通过「平均降方差 + 特征子采样降 ρ」提升泛化。
- 易混口径：σ² 是**单棵树在不同 bootstrap 样本上的预测方差**，不是标签噪声方差；
  ρ 是**两棵树预测的两两相关**，不是特征相关。
- 参考书对应：《机器学习》周志华 第 8 章（集成学习：Bagging 与随机森林）；
  ESL（Hastie et al.）第 8 章（Bagging）与第 9 章（树）。
