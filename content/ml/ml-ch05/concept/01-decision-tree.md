# 决策树：不纯度口径、切分点搜索与剪枝

> 决策树是「轴对齐的分段常数逼近器」：它把特征空间切成一堆格子，每个格子吐一个常数。
> 这个身份决定了它的全部性格——**偏差来自分段常数本身，方差来自对训练样本切在哪一刀的敏感**。
> 本章回答三个问题：这一刀凭什么这么切（不纯度口径）、去哪找候选切口（连续特征）、
> 什么时候停手（剪枝）；回归树则演示同一套骨架换一个损失函数怎么平移。

## 1. 不纯度与分裂准则：ID3、C4.5、CART 的三种口径

**中立陈述**。结点不纯度度量「这堆样本有多杂」。设结点 D 上第 k 类样本占比 p_k：

```
H(D)     = −Σ_k p_k·log₂ p_k                # 熵（单位 bit）
Gini(D)  = 1 − Σ_k p_k²                      # 基尼指数
```

一次候选分裂 A 把 D 切成 V 份 D^v，用「杂度下降了多少」评分：

```
Gain(D, A)     = H(D) − Σ_v (|D^v|/|D|)·H(D^v)       # 信息增益（ID3 口径）
IV(A)          = −Σ_v (|D^v|/|D|)·log₂(|D^v|/|D|)     # 属性固有值（取值分布的熵）
GainRatio(D,A) = Gain(D, A) / IV(A)                   # 增益率（C4.5 口径）
ΔGini(D, A)    = Gini(D) − Σ_v (|D^v|/|D|)·Gini(D^v)  # 基尼下降（CART 口径）
```

**信息增益偏好多取值特征，且这不是实现 bug 而是度量选择**。Gain 只奖「纯度提升」、
不罚「切得碎」：取值数越多，条件熵越容易趋小；极端情形是 ID 列——每个分支只剩一个样本，
`H(D|A)=0`，Gain 顶到理论上限 `H(D)`。Quinlan 在 C4.5 里用 IV 给「切得碎」征税：
IV 本身就是分支占比分布的熵，取值越多 IV 越大，增益率因此自动回落。

ex01 在 14 样本天气数据（9 正 / 5 负，`H(D)=0.9403`、`Gini(D)=0.4592`）上的实测：

| 特征 | 取值数 | H(D\|A) | Gain | IV | GainRatio | Gini(D\|A) |
|---|---|---|---|---|---|---|
| outlook | 3 | 0.6935 | **0.2467** | 1.5774 | **0.1564** | 0.3429 |
| humidity | 2 | 0.7885 | 0.1518 | 1.0000 | 0.1518 | 0.3673 |
| wind | 2 | 0.8922 | 0.0481 | 0.9852 | 0.0488 | 0.4286 |
| temp | 3 | 0.9111 | 0.0292 | 1.5567 | 0.0188 | 0.4405 |

读法：outlook 的 Gain 领先 humidity 1.63 倍，增益率口径只剩 1.03 倍——IV 惩罚把差距压了回来。
注意 temp 的 IV 同样高达 1.5567、Gain 却只有 0.0292：**「IV 大」本身不制造 Gain，
制造 Gain 的是「取值多到真把样本切碎了」**。ID 列属于后者，前者只是分母大。

**熵与基尼不是单调等价的**。两者都是凹的纯度函数，但端点曲率不同：

```
p→0 时： dH/dp = log₂((1−p)/p) → −∞        # 熵在「接近纯」的区域极陡
          dGini/dp = 2−4p → 2              # 基尼端点斜率有限
p=1/2 附近： H(p) ≈ 0.279 + (2/ln2)·Gini(p)  # 只差一个仿射变换，两准则几乎一致
```

后果（ex02 反例，父结点 50 正 / 50 负）：候选 A 把 10% 切出一块绝对纯的结点，
候选 B 把 20% 切到 p=0.15——**熵选 A**（ΔH=0.1080 > 0.0958），**基尼选 B**（ΔGini=0.0612 > 0.0556）。
同一份数据、同一个「提升纯度」的目标，两种口径可以长出不同的树；小样本、类别不平衡时差异被放大。
工程含义：别把 `gini` 与 `entropy` 的差异当数值噪声。

**三种口径的出身与边界**：

| 算法 | 分裂准则 | 特征处理 | 软肋 |
|---|---|---|---|
| ID3（Quinlan, 1986） | 信息增益 | 仅离散 | 系统性偏向多取值特征 |
| C4.5（Quinlan, 1993） | 增益率 | 离散 + 连续（排序二分） | IV 很小时比值虚高；实用做法是「先取 Gain 高于平均的候选，再比 GainRatio」 |
| CART（Breiman et al., 1984） | 基尼指数 | 离散 + 连续，统一分类回归 | 连续特征要扫描排序，计算量略高 |

**独热编码与信息增益的隐藏坑**：one-hot 把一个 K 取值类别列拆成 K 个 0/1 列，每列 IV=0、
单列 Gain 都不大，但 K 次二元分裂叠加后等效于一次多路分裂——偏好没有消失，
只是从「Gain 虚高」变形为「叶子数虚高、更难正则」。类别特征的现代做法是让框架原生支持
（XGBoost/LightGBM 的 categorical feature）或有序目标编码，而不是 one-hot 之后喂树。

## 2. 连续特征的切分点：为什么是「相邻取值的中点」

**中立陈述**。CART 把连续特征离散化：按取值排序后，只在**相邻两个不同取值的中点**取候选阈值
`thr = 0.5·(x₍ᵢ₎ + x₍ᵢ₊₁₎)`。理由是：任何划分目标（SSE、Gini、Gain）作为阈值的函数是**阶梯函数**，
阈值在相邻两点之间移动完全不改变左右集合，所以最优阈值总可以推到某个相邻区间里，取中点是数值习惯：

```
排序后的特征取值：  x₁ ≤ x₂ ≤ x₃ ≤ x₄ ≤ x₅ ≤ x₆
                   ●───●───●───●───●───●
                       ↑   ↑   ↑   ↑   ↑
候选阈值          ½(x₁+x₂) ……… ½(x₅+x₆)
                  左={x₁}       左={x₁..x₅}, 右={x₆}
（thr 落在 (x₂, x₃) 内任何位置，划分结果完全相同）
```

单特征的候选切分扫描（排序 + 前缀和，O(n log n)）：

```python
order = np.argsort(x); xs, ys = x[order], y[order]
c1, c2 = np.cumsum(ys), np.cumsum(ys**2)      # 前缀和：Σy、Σy²
best = SSE(ys)                                 # 不分裂的基线
for i in range(min_leaf, n - min_leaf):
    if xs[i] == xs[i-1]:
        continue                               # 相同取值之间没有候选点
    thr = 0.5 * (xs[i-1] + xs[i])
    sse_L = c2[i-1] - c1[i-1]**2 / i           # 左：Σy² − (Σy)²/n 的 O(1) 写法
    sse_R = (c2[-1]-c2[i-1]) - (c1[-1]-c1[i-1])**2 / (n-i)
    if sse_L + sse_R < best:
        best = sse_L + sse_R
```

三个必须记住的数字性质：
1. 候选切分数 = **不同取值数 − 1**（不是 n−1；重复取值被跳过）；
2. 边界归属惯例是 `x ≤ thr` 归左——训练与 serving 必须用同一个 `≤`；
3. 每结点每特征 O(n log n)（排序主导），d 个特征就是 O(d·n log n)——这是后面
   LightGBM 把候选压到「桶数 − 1」的直接动机（见 `03-boosting.md`）。

## 3. 预剪枝与后剪枝：两种不同的搜索空间

**中立陈述**。**预剪枝**在生长过程中提前停止：`max_depth`、`min_samples_leaf`、
「分裂增益低于阈值就停」。**后剪枝**先长成满树，再自底向上合并子树；
经典做法是 CCP（代价复杂度剪枝，Breiman et al., 1984）：

```
min_{T ⊆ T₀}  [ SSE(T) + α·|leaves(T)| ]        # α 给「每多一个叶子」定价
α: 0 → ∞  给出嵌套的子树序列 T(α₁) ⊃ T(α₂) ⊃ …   # 剪枝路径
剪枝判据：子树带来的 SSE 下降 < α×(叶子数−1) 就剪掉
```

ex04 在同一份训练集（n=150，噪声 σ=0.35）上的对照：

| 模型 | 叶子数 | train MSE | val MSE | test MSE |
|---|---|---|---|---|
| 完全不剪枝 | 28 | **0.0478** | 0.1927 | **0.1511** |
| 预剪枝 d=8, leaf≥8 | 13 | 0.0742 | 0.1549 | **0.1247** |
| 后剪枝 CCP α=0.3961 | 7 | 0.0813 | 0.1646 | 0.1391 |

三点读法：
- 全树训练误差最低、测试误差最高——**它把噪声也切成了叶子**；
- 预剪枝的致命弱点是**贪心早停**：当前分裂增益小，不代表子结点之后没有价值；
  后剪枝先长满再整棵子树地比较，没有这个视野问题，代价是先付满训练成本；
- 本实验里预剪枝测试误差更低，是因为它的网格搜索动了 25 个候选、CCP 只沿 17 个点走——
  **差别在搜索粒度，不在「谁更先进」**；样本更多、叶值估计更稳时，后剪枝的优势才显现。

## 4. 回归树：平方误差准则与叶值

**中立陈述**。CART 回归树与分类树共享同一副骨架，只把「不纯度」换成平方误差：
叶值取子树均值，分裂最小化两枝 SSE 之和。叶值为什么是均值，一步求驻点：

```
叶结点最优常数： c* = argmin_c Σ_{i∈leaf} (y_i − c)²
∂/∂c = −2·Σ(y_i − c) = 0   ⟹   c* = (1/n)·Σ y_i = mean(y)
分裂准则：      min_{j,s} [ SSE(D_L) + SSE(D_R) ]
                ⟺ 最大化方差下降（SSE = 组内方差 × 组内样本数）
```

ex03 在一维正弦加噪数据上的验证：max_depth=3 时训练 MSE 0.0512
（常数基线 0.5286，降了 90%），7 个叶子；「每个叶子的预测值与该叶样本均值的最大偏差」= 4.85e-11——
**叶值=均值是恒等式，不是近似**。

两个工程后果：
- **MSE 对异常值敏感**：一个 10 倍异常点把整格叶值拽向自己；要稳健就换 MAE，
  此时叶值变成中位数（对 c 求导得 |y−c| 的符号和为零）；
- 回归树同样需要剪枝——它的过拟合形态是「叶子越来越薄、方差越估越小」。

## 三视角解析

### 🧑‍💻 程序员视角
- 上线前先打印每个特征的**取值数与 IV**：树对 ID 列、时间戳、UUID 没有天生免疫力，
  信息增益会「精准地」过拟合它们。这一步比任何调参都便宜，也是本章 examples 第一个教的事。
- 手写熵/NLL 时 `p[p>0]` 掩码必须加，否则空分支出 `0·log0 = NaN`；
  条件熵要**按分支样本数加权**（`|D^v|/|D|·H(D^v)`），不是简单平均——这是手写实现第一大口径错，
  错了数字会「看起来都挺对」。
- sklearn 口径备忘：`criterion` 只是不纯度选择，`'gini'`（默认）与 `'entropy'`（`'log_loss'`）
  不影响建树逻辑；后剪枝走 `ccp_alpha`，`cost_complexity_pruning_path()` 直接给出
  (alpha, impurities) 序列，画一条验证曲线就能定位 α。
- 缺失值是树的高发事故区：sklearn 的树不接 NaN（要预填），且预测时遇到训练中没出现的类别取值会报错。
  先定缺失策略（单独一类 / 按比例分流）再上线，别等线上来了新 NA。
- 回归树拿均值当叶值，等于把异常值的影响平方后放大；重尾业务指标先做对数或分位变换，
  或者直接换 MAE 口径的树。

### 🎓 博士生视角
- 第一性原理：信息增益就是互信息 `I(D; A)`，ID3 是在做互信息的贪心最大化。它偏好多值特征
  不是 bug，而是「度量未给切分代价定价」；IV 惩罚相当于除以一个随分支数增长的量，
  把「每 bit 纯度提升的代价」重新校准。
- 熵与基尼的局部关系：`p=1/2` 附近 `H(p) ≈ 0.279 + (2/ln2)·Gini(p)`，仿射等价，
  所以平衡结点上两种准则几乎一致；分歧全部集中在端点邻域——ex02 的反例正是构造端点场景。
- 复杂度账：精确贪心每结点 O(d·n log n)（排序主导），整棵树 O(d·n log²n) 量级；
  这是直方图分箱「每特征 O(n) → O(bin)」的动机，也是 XGBoost/LightGBM 系统工程投入的起点。
- 树的不稳定性是经典结论（Hastie et al., ESL 2nd ed., §9.2）：数据的微小扰动会长出结构
  完全不同的树。高方差是树的天性，这正是 Bagging 的直接动机——单棵树是「高方差、低偏差」的
  典型基学习器。
- 剪枝的统计学地位：CCP 是在嵌套子树序列上做模型选择，α 路径给出整条「复杂度—误差」折衷；
  后剪枝本质上是用验证信息替换训练集自评，视野完整但成本后置；预剪枝把两者压成一次贪心。
- 历史线：ID3（1986）→ C4.5（1993，增益率 + 连续特征 + 剪枝）→ CART（1984，基尼 +
  分类回归统一）→ MARS（Friedman, 1991）→ 提升方法（Friedman, 2001）。「一个叶一个常数」
  的骨架三十年没变，变的是切分准则与组合方式。

### 📚 考研者视角
- **手算信息增益是自命题 AI 专业课的高频题**（给 14 条天气数据算 Gain / GainRatio / Gini）。
  标准口径：对数取底 2；条件熵按样本数加权；IV 用同一组分支比例算 `−Σ p·log₂ p`。
  能完整默写这三个公式就拿到大半分数。
- **增益率的标准表述**要写全三句：动机（信息增益对取值数目多的特征有系统性偏好）、
  公式（`GainRatio = Gain/IV`）、软肋（IV 很小时比值虚高，C4.5 先取 Gain 高于平均的候选再比 GainRatio）。
- **ID3 / C4.5 / CART 对比表**要能默写：算法、分裂准则、是否支持连续特征、剪枝策略。
- **两个必会推导**：① 回归树叶值=子树均值（对 SSE 求驻点）；② 连续特征候选阈值=排序后相邻取值中点。
- **剪枝对比**：预剪枝（判断结点是否继续分裂，基于增益阈值/深度/叶样本数）与后剪枝
  （ CCP，在完整树上自底向上剪）。标准答案要指出后剪枝通常泛化更好但训练成本更高。
- 易混口径：熵的对数底只差常数因子（bit vs nat），不影响 argmax，但**手算题默认 log₂**；
  基尼不需要对数所以更快；分类误差率不可微，不直接用作分裂准则。
- 参考书对应：《统计学习方法》李航 第 5 章、《机器学习》周志华 第 4 章。
