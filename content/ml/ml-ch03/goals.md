## 本章目标

学完你应该能：

1. **手算一次前向传播**：给定 `X、W、b`，写出每层的 `Z = XW + b`、`A = g(Z)`，
   说清每个张量的形状，并解释「多层线性仍是线性」的证明。
2. **按任务选激活与损失**：隐藏层 ReLU、二分类 sigmoid + BCE、多分类 softmax + CE、回归 linear + MSE，
   并能说出错配后会出现什么可观测现象。
3. **手推两层 MLP 的反向传播**：写出 `dZ₂=(p−y)/m`、`dW₂=A₁ᵀdZ₂`、`dZ₁=dA₁⊙g′(Z₁)`、`dW₁=XᵀdZ₁`，
   并用中心差分做数值梯度校验（相对误差 < 1e−6）。
4. **写出数值稳定的 softmax 与交叉熵**：解释为什么要先减最大值，证明梯度是 `p−y`。
5. **诊断一个训练过程**：从训练/验证曲线判断高偏差还是高方差，能选对 L2、Dropout、早停、
   学习率与 batch size 的处理顺序；在不平衡数据上用 P/R/F1 与阈值而不是 accuracy。

## 关键认知（本章最值钱的三句）

- **没有非线性，深度为 0**。仿射变换的复合仍是仿射变换；堆 100 层线性层，假设空间和 1 层线性回归完全相同。
  非线性不是「让模型更强」的装饰，而是从线性假设空间跨到非凸富表达空间的唯一开关。
- **反向传播没有新数学，只有链式法则 + 复用前向缓存**。真正容易错的是形状、`/m` 的口径、
  激活导数与数值稳定性；所以手写网络的验收标准不是「loss 降了」，而是「数值梯度校验通过」。
- **训练误差不是目标，验证间隙才是诊断信号**。高偏差该加容量/特征，高方差才该加数据/正则；
  不分清这两者就调参，等于在错误的方向上反复试错。
## 与 ai 学科的分界（本章只到最小 MLP）

本章讲的是**一个两层全连接网络**：前向、反向、softmax、Adam、诊断。目标是「能解释 + 能手写」，
不追求在真实任务上刷分。

以下内容**不在本章**，属于 `ai` 学科：

| 主题 | 归属 | 原因 |
|---|---|---|
| CNN / RNN / Transformer / LLM | `ai` 学科 | 结构先验与序列建模，超出「最小 MLP」 |
| 梯度消失/爆炸的完整机制 | `ai` 学科 | 需要雅可比谱、初始化理论、归一化与残差连接 |
| 分布式训练、混合精度、算子融合 | `ai` 学科 | 系统工程，不影响本章的概念闭环 |
| 反向传播的自动微分实现细节 | `ai` 学科 | 本章只手写两层，框架的 VJP/图优化不展开 |

一句话：**本章负责让你「看懂并写出」一个小网络；`ai` 学科负责让你「训练大网络」**。

### 判据：什么时候该上深度学习

这是全学科最后要能脱口而出的一张表。判据按**数据形态**分，不按「哪个更新」分：

| 数据形态 | 默认首选 | 什么时候才换 DL |
|---|---|---|
| 表格（结构化、列语义明确） | GBDT（XGBoost/LightGBM） | 样本 > $10^5$ 且有强交互特征、或要与文本/图像联合建模 |
| 图像 / 音频 / 视频 | CNN 或预训练骨干 | 基本必上；小样本走微调而不是从零训 |
| 文本 | 预训练模型微调 / LLM | 基本必上；< 1 千条样本先试 TF-IDF + 线性 |
| 序列决策 | 先建 MDP，再谈 RL | 状态空间连续且高维时才上深度 RL（ml-ch08） |

三条硬约束（任一不满足就先别上 DL）：

1. **样本量**：参数量与样本量差三个数量级以上时，DL 的方差项会吃掉全部收益。
   表格任务上这个结论有系统证据（Grinsztajn et al., 2022, NeurIPS：树模型在中等规模表格数据上仍普遍优于 DL）。
2. **可解释性**：要给出「为什么拒贷/为什么报警」的可审计理由时，线性模型 + 特征工程比注意力热图更站得住。
3. **维护成本**：DL 带来 GPU、版本漂移、推理延迟三项固定开销；如果业务提升不到 1 个点，这笔账算不过来。
