# 前向传播：神经元、层与激活函数
> 神经网络训练由三步循环构成：前向（输入经层层加权求和+激活得到预测）、反向（链式法则从损失算每层权重梯度）、更新（优化器沿负梯度调权）。梯度消失/爆炸、学习率大小是训练稳定性的关键旋钮。

```text
前向 (forward):
   z = W·x + b ;  a = σ(z)        逐层传播
   ŷ = softmax(z_last)            多分类输出概率

损失 L = CrossEntropy(ŷ, y_true)

反向 (backward) — 链式法则:
   ∂L/∂W = ∂L/∂a · ∂a/∂z · ∂z/∂W
   从输出层往回，把梯度「分摊」给每层权重

更新 (SGD / Adam):
   W ← W − η · ∂L/∂W             η=学习率

  多分类: 输出层 softmax + 交叉熵；二分类: sigmoid + BCE
  梯度消失: 深层 + sigmoid → 梯度趋零 → 用 ReLU/BatchNorm
  学习率太大震荡、太小慢 → 用自适应(Adam)或 warmup+衰减
```


> 神经网络听起来神秘，但「前向传播」只有两步：**先做一次仿射变换，再过一次逐元素非线性**。
> 把这两步重复 L 次，就是深度网络的全部推理过程。
> 这一讲把形状、公式、激活函数的选择钉死——它们是后面手写反向传播的前提。

## 1. 一个神经元：加权和 + 偏置 + 激活

一个神经元接收 d 维输入 `x = [x₁,…,x_d]`，先算加权和，再过激活函数：

```
z = wᵀx + b = Σⱼ wⱼxⱼ + b
a = g(z)
```

- `w ∈ ℝ^d` 是权重，衡量每个输入的重要性和方向；
- `b ∈ ℝ` 是偏置，决定「神经元有多容易被激活」——它把激活阈值从 0 移开；
- `g(·)` 是激活函数，给输出加非线性。

**没有偏置会怎样**：所有决策边界被迫过原点。对中心不在原点的数据，
网络要多花一层去平移，或者根本学不好。这就是「偏置不是可选项」的原因。

**没有激活会怎样**：神经元退化成线性回归。下一节会证明，堆多少层都一样。

## 2. 一层：矩阵形式与维度约定

把 m 个样本叠成 `X ∈ ℝ^{m×d_in}`，一层有 `d_out` 个神经元，权重按行堆成
`W ∈ ℝ^{d_out×d_in}`，偏置 `b ∈ ℝ^{d_out}`：

```
Z = X Wᵀ + b          # (m,d_in) @ (d_in,d_out) + (d_out,) -> (m,d_out)
A = g(Z)              # 逐元素，形状不变
```

用 `W` 而不是 `Wᵀ` 的写法更常见于教科书：

```
Z = X W + b,   W ∈ ℝ^{d_in×d_out}
```

两种写法等价，只是参数的存储方向不同。**工程上最重要的是始终只用一个约定**。
NumPy 里 `X @ W` 要求 `W` 是 `(d_in,d_out)`，而 PyTorch 的 `nn.Linear(d_in,d_out)`
内部存的权重是 `(d_out,d_in)`、做的是 `X @ W.T`——混用就会得到形状对但语义错的静默 bug。

```
        x₁ ──w₁₁──┐
        x₂ ──w₂₁──┼──► z₁ ──g──► a₁ ──┐
        x₃ ──w₃₁──┘                    │
                                        ├──► 下一层
        x₁ ──w₁₂──┐                    │
        x₂ ──w₂₂──┼──► z₂ ──g──► a₂ ──┘
        x₃ ──w₃₂──┘
        （每个输出神经元都看到全部输入；层与层之间是全连接）
```

**维度检查口诀**：`(m, d_in) @ (d_in, d_out) = (m, d_out)`。
中间维度必须相同，输出维度等于这一层神经元个数。批量大小 m 不参与任何参数形状，
所以同一个模型可以处理 1 条或 1024 条样本。

## 3. 为什么必须有非线性：多层线性仍是线性

设两层都不带激活：

```
第一层：h = W₁x + b₁
第二层：y = W₂h + b₂ = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)
```

令 `W = W₂W₁`、`b = W₂b₁ + b₂`，则 `y = Wx + b`——**还是一个线性函数**。
推广到 L 层、任意宽度，结论不变：仿射变换的复合仍是仿射变换。

这意味着：

1. 没有非线性，100 层 MLP 的表达能力和 1 层线性回归完全一样；
2. 参数变多只是换了一种分解方式，不增加假设空间的表达能力；
3. 反向传播能训练它，但训练出来的仍是一个线性模型。

**非线性的作用**是把输入空间「折弯」，让最后一层线性分类器可以在折弯后的空间里切分。
XOR 是最小例子：四个点无法用一条直线分开，但用两个 ReLU 神经元把象限映射到
新的二维坐标后，一个线性边界就够了（见 `examples/ex03`、`ex04`）。

```
原始空间（线性不可分）        隐层空间（线性可分）
  x₂                            h₂
  │  0   1                      │  0   1
  │  1   0                      │  0   1
  └──────── x₁                  └──────── h₁
  一条直线切不开                隐层把两类搬到对角，直线可切
```

**注意**：非线性不是「越强越好」。ReLU 折得足够多，容量过大就会过拟合；
激活函数的选择要和网络宽度、正则化一起看。

## 4. 激活函数怎么选

| 激活 | 表达式 | 导数 | 值域 | 典型位置 | 主要问题 |
|---|---|---|---|---|---|
| sigmoid | `1/(1+e⁻ᶻ)` | `σ(1−σ)` | (0,1) | 二分类输出层 | 两端饱和，导数趋于 0 |
| tanh | `(eᶻ−e⁻ᶻ)/(eᶻ+e⁻ᶻ)` | `1−tanh²` | (−1,1) | 浅层隐藏层 | 同样饱和，但零中心 |
| ReLU | `max(0,z)` | `1[z>0]` | [0,∞) | 隐藏层默认 | 负区间梯度为 0（dead ReLU） |
| Leaky ReLU | `max(αz,z)`，α≈0.01 | `1` 或 `α` | (−∞,∞) | 担心死亡时 | 多一个超参 |
| linear | `z` | `1` | ℝ | 回归输出层 | 没有非线性 |

**选择规则（工程默认）**：

- 隐藏层：先用 **ReLU**。它计算便宜、正区间不饱和、梯度稳定；出现大量死亡神经元再换 Leaky ReLU / GELU。
- 二分类输出：**sigmoid**，配合二元交叉熵；输出可解释为概率。
- 多分类输出：**softmax**，配合分类交叉熵；各类概率和为 1。
- 回归输出：**linear**（恒等），不要再套 sigmoid——否则输出被限制在 (0,1)，房价永远预测不到 300 万。
- 多标签分类：每个标签独立做 **sigmoid**，不要用 softmax（softmax 强制互斥）。

**为什么 sigmoid/tanh 在深层里不好用**：导数最大只有 0.25（sigmoid）和 1（tanh），
且 |z| 稍大就迅速趋 0。多层连乘会让梯度指数衰减——这就是「梯度消失」。
本章只强调工程结论：**隐藏层默认 ReLU，别用 sigmoid 堆深**；
完整的机制与残差连接、归一化等对策属于 `ai` 学科，本章不展开。

## 5. 输出层、损失与任务三者必须匹配

| 任务 | 输出层 | 损失 | 标签形状 |
|---|---|---|---|
| 回归 | linear（1 个输出） | MSE / MAE / Huber | `(m,1)` 连续值 |
| 二分类 | sigmoid（1 个输出） | 二元交叉熵 | `(m,1)`，0/1 |
| 多分类（互斥） | softmax（C 个输出） | 分类交叉熵 | `(m,)` 或 one-hot `(m,C)` |
| 多标签 | 每个标签 sigmoid | 每个标签二元交叉熵求和 | `(m,C)`，每维 0/1 |

**错配的代价**：回归套 sigmoid → 输出被截断，模型永远欠拟合；
多分类用 MSE → 梯度含 `p(1−p)` 因子，饱和区学不动；
二分类用 softmax（2 个输出）→ 数学上可行但多一组冗余参数，且标签要转 one-hot。
这三件事在代码里都不会报错，只会让指标莫名其妙地差。

## 三视角解析

### 🧑‍💻 程序员视角
- 先写形状断言：`assert X.shape[1] == W.shape[0]`，再做矩阵乘。神经网络 80% 的 bug 是形状/转置，不是数学。
- 偏置不要漏。`Z = X @ W` 能跑，但模型表达能力少一截，且损失下降会更慢——这种「能跑但不对」的 bug 最难查。
- 批量维永远在最前面。不要把 `(d,)` 和 `(1,d)` 混用；NumPy 的广播会把错误藏起来，直到某天 m=1 才爆炸。
- 推理时不需要缓存；训练时才需要保存 `Z`、`A` 供反向使用。把两者混在一个函数里，容易在部署时白占显存。
- 激活函数用 `np.maximum(z, 0)` 而不是 `z * (z > 0)`：后者在 `z=0` 处会产生 `0 * False = 0`，数值上没错，但会多一次临时数组。

### 🎓 博士生视角
- 万能逼近定理（Cybenko 1989；Hornik et al. 1991）说：单隐层、足够宽的 sigmoid/ReLU 网络可以以任意精度逼近紧集上的连续函数。它保证「存在」，不保证「SGD 能找到」，也不给宽度下界。
- 深度带来的不是简单的参数效率，而是**分层复合**的归纳偏置：深层网络可以指数级更高效地表示某些分段线性函数（Telgarsky 2016 的锯齿函数构造）。这是「深」而非「宽」的理论动机之一。
- 仿射复合的证明说明：非线性是假设空间从「线性」跨到「非凸、富表达」的唯一开关。优化难度也随之从凸优化变成非凸优化——这是一次有意识的交换。
- 激活函数的饱和性质决定了雅可比矩阵的谱。sigmoid 的导数上界 0.25，L 层连乘的上界是 `0.25^L`；ReLU 在激活区导数恒为 1，才让深网络的梯度不至于必然消失。完整的谱分析与初始化方案（Xavier/He）在 `ai` 学科展开。
- softmax 是指数族分布的规范参数化：它把 logits 映射到单纯形，交叉熵对应多项式分布的极大似然。这个视角在 `ml-ch02` 的 GLM 里已经出现过。

### 📚 考研者视角
- 标准定义要会默写：神经元输出 `a = g(Σ wᵢxᵢ + b)`；一层的前向 `A = g(XW + b)`。
- 高频计算题：给 `m` 个样本、`d_in` 维输入、`d_out` 个神经元，问参数个数和输出形状。
  参数 = `d_in × d_out + d_out`（权重+偏置），输出 = `(m, d_out)`。
- 常考判断：「多层线性网络等价于单层线性网络」——对，因为仿射复合仍是仿射；「增加层数一定增强表达能力」——错，没有非线性时不成立。
- 易混：sigmoid 值域 (0,1)、tanh 值域 (−1,1)、ReLU 值域 [0,∞)；sigmoid 导数 `σ(1−σ)`、tanh 导数 `1−tanh²`、ReLU 导数在 0 处通常约定为 0。
- 输出层与任务匹配是简答题常客：回归用恒等、二分类用 sigmoid、多分类用 softmax，损失分别对应 MSE、二元交叉熵、分类交叉熵。
