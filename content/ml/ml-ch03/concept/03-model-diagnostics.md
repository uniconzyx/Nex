# 模型诊断：从训练/验证曲线到正则化与迁移

> 训练一个 MLP 只需几十行，难的是回答「它现在到底是欠拟合、过拟合，还是数据有问题」。
> 这一讲给出一套工程诊断顺序：**先看训练/验证误差，再看间隙，再看切片，再动正则与学习率**。
> 偏差-方差的完整理论推导在 `ai-ch01`，本章只保留能直接指导调参的诊断口径。

## 1. 训练/验证误差怎么读：四象限

拿到一条训练曲线和一条验证曲线，先看两个量：**验证误差的绝对水平**、**训练-验证间隙**。

| 训练误差 | 验证误差 | 间隙 | 诊断 | 优先动作 |
|---|---|---|---|---|
| 高 | 高 | 小 | 欠拟合（高偏差） | 加特征/加宽加深/降正则/训练更久 |
| 低 | 高 | 大 | 过拟合（高方差） | 加数据/加正则/早停/降容量 |
| 低 | 低 | 小 | 拟合良好 | 看切片、看校准、看上线分布 |
| 高 | 更高 | 大 | 优化失败或数据问题 | 查标签/学习率/梯度/泄漏 |

**关键口径**：

- 「高」是相对**贝叶斯误差**（该任务理论上能做到的最低误差）而言，不是相对 0。
  人类标注一致率 85% 的任务，验证 88% 已经接近上限，不该继续压训练误差。
- 间隙要用**同一指标**、**同一预处理**计算。训练时开数据增强、验证不开，间隙会被夸大。
- 验证误差先降后升的拐点，就是早停点；但拐点之后继续训练，训练误差仍会降——这是过拟合的典型形状。

```text
误差
 │
 │ 验证 ──╮
 │        ╰──╮
 │           ╰──────╮         ← 过拟合：验证回升
 │ 训练 ─────────────╲────    ← 训练继续降
 └──────────────────────── 轮数
        ↑
      早停点（验证最低）
```

## 2. 偏差与方差：工程上怎么估

平方损失下，对固定输入 x 的期望误差可以分解为：

```
E[(y − f̂(x))²] = σ² + (E[f̂(x)] − f(x))² + E[(f̂(x) − E[f̂(x)])²]
                 = 噪声 + 偏差² + 方差
```

- **偏差**：模型平均预测与真实函数的距离——容量不足、特征不足、正则过强；
- **方差**：模型预测随训练集抽样的波动——容量过大、样本太少、对噪声敏感；
- **σ²**：数据本身的噪声，任何模型都消不掉，是误差下界。

**工程上不直接算这三项**（真实 f 未知），而是用学习曲线间接判断：

| 学习曲线形状 | 诊断 | 加数据有效吗 |
|---|---|---|
| 训练/验证都高、间隙小、随样本量持平 | 高偏差 | 基本无效，先加特征/容量 |
| 训练低、验证高、间隙随样本量收窄 | 高方差 | 有效，但收益递减 |
| 训练低、验证也低 | 良好 | 不需要 |

**注意**：偏差-方差分解的严格前提是平方损失、同分布、固定 x 求期望。
把它直接套到 0-1 损失、AUC、或分布漂移的场景，只能作定性参考，不能当恒等式用。

## 3. 正则化：三种最常用的容量刹车

### 3.1 L2 权重衰减

```
L_reg = L + (λ/2)·Σ_l ‖W_l‖²
∂L_reg/∂W_l = ∂L/∂W_l + λW_l
```

- 效果：把权重往 0 拉，限制模型对单个特征的依赖，降低方差；
- 贝叶斯解释：高斯先验下的 MAP；
- 只惩罚权重，**通常不惩罚偏置**（偏置不影响函数复杂度）；
- λ 过大 → 欠拟合；λ 是需要在验证集上选的超参，不是固定常数。

### 3.2 Dropout

训练时每个神经元以概率 p 被临时丢弃，保留下来的输出除以 `1−p`（inverted dropout），
保证训练与推理的期望一致：

```
train:  mask ~ Bernoulli(1−p);  a = a ⊙ mask / (1−p)
eval:   a = a                  # 不丢弃、不缩放
```

- 直觉：每次训练一个「子网络」，推理时近似对指数多个子网络做集成；
- p 常取 0.2~0.5；p 太大导致欠拟合，p=0 等于没开；
- **训练/推理必须切换模式**，这是最常见的上线事故之一；
- Dropout 与 BatchNorm 同用时行为会互相干扰，现代网络更常用其他正则（数据增强、weight decay）。

### 3.3 早停

监控验证误差，在它连续若干轮不下降时停止训练，并回滚到验证最优的 checkpoint。

- 它等价于一种「训练步数上的正则」：限制了参数离开初始点的距离；
- 对二次目标，早停与 L2 有近似等价关系（步数与 λ 的对应）；
- 早停的验证集必须**独立于测试集**，否则等于用测试集调参。

## 4. 学习率与 batch size：一对耦合的超参

### 4.1 学习率的两侧失败

| 现象 | 学习率 | 处理 |
|---|---|---|
| loss 下降极慢、几百步几乎不动 | 太小 | 乘以 3~10 再试 |
| loss 震荡、偶尔跳高 | 偏大 | 降一半，或加 warmup |
| loss 变 nan / 参数爆炸 | 太大 | 降 10 倍，加梯度裁剪 |
| 前期降得快、后期在最优附近抖 | 偏大（末期） | 学习率衰减/余弦退火 |

**诊断手法**：固定其他条件，扫 `1e−4, 1e−3, 1e−2, 1e−1`，画最终验证误差的 U 形。
不要凭感觉一次调一个数量级以内的小步。

### 4.2 batch size 不是「越大越好」

- 大 batch → 梯度噪声小、训练稳定、吞吐高，但**单位样本的信息量变少**，同样 epoch 下更新次数少；
- 小 batch → 梯度噪声大，噪声本身有正则效果，常泛化略好，但训练慢且不稳；
- 经验规则：batch 翻倍，学习率大致翻倍（linear scaling rule），并配合 warmup；
- batch 太小（如 1~4）时，BatchNorm 统计量极不稳定；本章的 NumPy 示例用全批量，避免这个问题。

## 5. 类别不平衡：别用 accuracy 做决策

设正例率 1%，一个「全判负」的模型 accuracy = 99%，但召回为 0。
**accuracy 在不平衡任务上几乎不携带信息**。改用：

```
Precision = TP/(TP+FP)      # 判为正的里有多少是真的
Recall    = TP/(TP+FN)      # 真的正例里抓到了多少
F1        = 2PR/(P+R)       # 二者的调和平均
```

- **PR 曲线**：横轴 recall、纵轴 precision，基线是正例率；不平衡时比 ROC 更诚实；
- **ROC 曲线**：横轴 FPR、纵轴 TPR；负例极多时 FPR 分母大，曲线容易显得漂亮；
- **阈值**：不是模型参数，是业务成本参数。漏判代价高 → 降阈值提召回；误判代价高 → 升阈值提精确率；
- **class weight / 重采样**：改变训练分布，等价于在损失里给少数类更大权重；
  注意重采样必须在**训练折内**做，否则会造成泄漏（见 `ml-ch04`）。

## 6. 迁移学习：什么时候真的有用

迁移的前提是**源任务与目标任务共享可复用的底层结构**：

| 条件 | 建议 |
|---|---|
| 目标数据很少（几十~几百）、源任务相似 | 冻结底层，只训练最后一层（线性探针） |
| 目标数据中等、源任务相似 | 解冻部分层，小学习率微调 |
| 目标数据充足 | 从零训练或全量微调 |
| 源任务与目标任务语义差异大 | 不迁移，或只迁移通用底层（负迁移风险） |

**负迁移**：源任务学到的特征对目标不仅无用，还引入错误的归纳偏置，导致比从零训练更差。
判断方法只有一个：**在目标验证集上对比「迁移 vs 从零」**，不要凭「预训练一定更好」的直觉。

**工程细节**：冻结层的 BatchNorm 统计量也要冻结（否则前向仍会更新 running stats）；
微调时用比从头训练小 10~100 倍的学习率，避免把预训练权重冲掉。

## 7. 本章的边界

本章只到「能解释 + 能手写一个最小 MLP」：

- **不展开** CNN、RNN、Transformer、LLM 的结构与训练技巧；
- **不展开** 梯度消失/爆炸的完整机制、初始化理论、归一化层、残差连接；
- **不展开** 分布式训练、混合精度、算子融合等系统工程。

这些内容的完整推导在 `ai-ch01` 及后续 `ai` 章节。本章的目标是：
给你一个能跑、能校验、能诊断的最小闭环，遇到更复杂的模型时知道该看哪几个量。

## 三视角解析

### 🧑‍💻 程序员视角
- 诊断顺序不要乱：先确认「单批能过拟合」（排除实现 bug），再看训练/验证间隙（排除容量问题），最后才调正则和学习率。跳过第一步，你会把代码 bug 当成过拟合调半天。
- 每次实验只改一个变量，并记录：学习率、batch、正则、种子、数据版本。没有实验记录的调参是玄学。
- 验证集要固定。重新切分一次验证集，指标波动可能比模型改进还大；小数据用重复交叉验证。
- 不要用测试集选阈值/选模型。测试集只用一次，否则它就不再是测试集。
- 上线前把「训练/推理模式」写成显式开关，并加一个单元测试：同一输入在 eval 模式下两次前向必须完全一致。

### 🎓 博士生视角
- 偏差-方差分解是平方损失下的恒等式，前提是同分布、固定 x、对训练集求期望。分类任务常用 0-1 损失，分解不再成立；可用交叉熵的 Bregman 散度分解做类比，但项的含义会变。
- 学习曲线的渐近行为由假设空间的复杂度与样本量共同决定：高偏差时增加数据只能逼近一个非零下界；高方差时验证误差以 `O(1/√m)` 左右的速度靠近训练误差。
- 早停与 L2 的等价性在二次目标、梯度流极限下有精确对应（Yao et al. 2007）；对一般非凸网络只是定性类比。
- Dropout 的集成解释（Srivastava et al. 2014）是「指数多个子网络的几何平均」，但权重共享使它们并不独立，理论上的方差缩减小于独立集成。
- 迁移学习的负迁移与「任务相似度」没有统一定义；工程上只能以目标验证集为准。领域自适应理论用分布差异（MMD、对抗距离）给出上界，但常数项很松。

### 📚 考研者视角
- 高频简答：过拟合的表现、原因、解决办法。标准答法要分「数据（增多/增强/降噪）、模型（降容量/正则/早停）、优化（调 lr/加约束）、评估（交叉验证/查泄漏）」四层，不要只答「加正则」。
- 偏差-方差分解要会写：`E[(y−f̂)²] = σ² + bias² + variance`，并说明三项含义；常考「为什么它只对平方损失成立」。
- 学习率的影响是选择题常客：过大会震荡/发散，过小会收敛慢/陷入平台；batch 过大等价于降低梯度噪声、减少更新次数。
- 不平衡指标：accuracy 的陷阱、P/R/F1 的定义与计算、ROC-AUC 与 PR-AUC 的区别。计算题要会从混淆矩阵手算。
- 易错：「验证误差最低的点就是最终模型」——还要回滚 checkpoint；「Dropout 在推理时也要随机丢弃」——错，推理时关闭。
