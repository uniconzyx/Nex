# 反向传播与训练：链式法则、softmax 与 Adam

> 前向传播把输入变成预测，反向传播把「预测错多少」变回「每个参数该往哪改」。
> 它没有新数学，只有链式法则；难的是**把每一层的局部导数写对、把形状对齐、把数值算稳**。
> 这一讲给出可直接手推的两层公式、数值校验方法，以及训练循环里最常见的几个坑。

## 1. 计算图：前向缓存是反向的原材料

把两层网络画成计算图（每个节点是一个张量运算）：

```
X ──► Z₁=XW₁+b₁ ──► A₁=g₁(Z₁) ──► Z₂=A₁W₂+b₂ ──► P=σ(Z₂) ──► L=BCE(P,Y)
       │                  │                  │
     cache Z₁          cache A₁          cache P
```

反向传播需要前向的中间结果：`dW₂ = A₁ᵀ dZ₂` 用到 `A₁`，`dZ₁ = dA₁ ⊙ g₁'(Z₁)` 用到 `Z₁`。
所以训练时要**缓存每一层的输入与激活**，推理时不需要。
这也是为什么训练显存远大于推理：batch 越大、层越深，缓存越多。

**计算图的意义**：它把「求整个网络的梯度」拆成「每个节点只负责自己的局部导数」。
框架（PyTorch/TensorFlow）做的就是在前向时记录图，反向时按拓扑逆序调用每个节点的 `backward`。

## 2. 链式法则逐层求导：两层网络的手推

约定：`X ∈ ℝ^{m×d}`，`W₁ ∈ ℝ^{d×h}`，`W₂ ∈ ℝ^{h×1}`，`y ∈ ℝ^{m×1}`，
隐藏层 `g₁ = tanh`，输出层 `σ`，损失为**按样本平均**的二元交叉熵：

```
L = −(1/m) Σᵢ [ yᵢ log pᵢ + (1−yᵢ) log(1−pᵢ) ]
```

### 2.1 输出层

先对 logit 求导。sigmoid 与 BCE 组合有一个著名的化简：

```
∂L/∂z₂ = (p − y)/m          # (m,1)
```

推导：`∂L/∂p = −(y/p − (1−y)/(1−p))/m`，`∂p/∂z₂ = p(1−p)`，相乘后
`p(1−p)·[−(y/p − (1−y)/(1−p))]/m = (p−y)/m`。
**这就是「分类用交叉熵」的工程回报：梯度里没有 `p(1−p)` 饱和因子。**

```
dW₂ = A₁ᵀ dZ₂               # (m,h)ᵀ @ (m,1) -> (h,1)
db₂ = sum(dZ₂, axis=0)      # (1,)
```

### 2.2 隐藏层

把误差传回隐藏层，先经过 `W₂`，再乘激活函数的局部导数：

```
dA₁ = dZ₂ W₂ᵀ               # (m,1) @ (1,h) -> (m,h)
dZ₁ = dA₁ ⊙ g₁'(Z₁)         # 逐元素，形状不变
dW₁ = Xᵀ dZ₁                # (m,d)ᵀ @ (m,h) -> (d,h)
db₁ = sum(dZ₁, axis=0)      # (h,)
```

### 2.3 通用形式（第 l 层）

对任意层，记 `A₀ = X`，`Z_l = A_{l−1}W_l + b_l`，`A_l = g_l(Z_l)`：

```
dZ_l = dA_l ⊙ g_l'(Z_l)
dW_l = A_{l−1}ᵀ dZ_l
db_l = sum(dZ_l, axis=0)
dA_{l−1} = dZ_l W_lᵀ
```

反向从 `l = L` 开始，按 `L, L−1, …, 1` 逆序执行。**每一层只需要四个式子**，
这就是「反向传播 = 链式法则 + 动态规划」的全部。

### 2.4 梯度累加：batch 是求和，不是平均

损失对 m 个样本求和时，`dW = Σᵢ xᵢ δᵢ`；矩阵形式 `Xᵀ dZ` 自动完成求和。
如果用「平均损失」，则 `dZ` 里要除以 m。**这两种口径不能混**：

- 用 sum 损失但按 mean 算梯度 → 梯度小了 m 倍，学习率实际被缩小；
- 用 mean 损失但按 sum 算梯度 → 梯度大 m 倍，容易发散。

微批（gradient accumulation）时，先把每个 micro-batch 的梯度**累加**，再统一 `optimizer.step()`；
等价于大 batch，但显存只占一个小 batch。

## 3. 数值梯度校验：手写网络的唯一保险

解析梯度写得对不对，不靠盯代码，靠中心差分：

```
∂L/∂θ ≈ [L(θ+ε) − L(θ−ε)] / (2ε)
```

实现要点：

1. 用 `float64`，`ε ≈ 1e−5 ~ 1e−7`；太小会被舍入误差吞掉，太大会被截断误差主导；
2. 用**相对误差** `|g_num − g_ana| / max(1, |g_num| + |g_ana|)`，阈值 `1e−6` 量级；
3. 只抽查少量参数（每个参数矩阵取几个下标），因为数值校验是 `O(参数量)` 次前向；
4. 避开不可导点：ReLU 在 0 附近左右导数不同，别在 `z≈0` 处校验；
5. 校验前关掉 Dropout、固定随机种子，否则前向本身不可复现。

```python
# 中心差分：对参数 P 的第 idx 个元素
old = P.flat[idx]
P.flat[idx] = old + eps; lp = loss(params)
P.flat[idx] = old - eps; lm = loss(params)
P.flat[idx] = old
num = (lp - lm) / (2 * eps)
rel = abs(num - ana) / max(1e-12, abs(num) + abs(ana))
```

**经验**：如果相对误差在 `1e−10` 量级，基本可以确信公式正确；
如果是 `1e−3`，通常漏了 `/m`、转置错了，或某个激活导数用错；
如果误差随 ε 变小反而变大，是浮点舍入，不是公式错。

## 4. softmax 多分类与交叉熵

### 4.1 定义与数值稳定

C 类分类，logits `z ∈ ℝ^C`：

```
p_k = exp(z_k) / Σⱼ exp(zⱼ)
```

直接算 `exp(z)` 在 `z > 709`（float64）时溢出为 `inf`，`inf/inf = nan`。
标准实现先减最大值：

```
m = max(z)
p_k = exp(z_k − m) / Σⱼ exp(zⱼ − m)
```

因为分子分母同乘 `e^{−m}`，结果不变；减完后最大的指数是 0，其余 ≤0，不会溢出。
交叉熵也可写成稳定的 log-sum-exp：

```
CE = −log p_y = log Σⱼ exp(zⱼ) − z_y
   = m + log Σⱼ exp(zⱼ − m) − z_y
```

### 4.2 梯度：又是 p − y

对单个样本，`∂CE/∂z_k = p_k − 1[k=y]`。写成矩阵：

```
dZ = (P − Y)/m        # P 是 softmax 输出，Y 是 one-hot
```

这与二分类的 `(p−y)/m` 完全同形——不是巧合：二分类是 C=2 的 softmax 特例
（两类 softmax 的差就是 sigmoid）。**记住这一条，多分类反向就不会写错。**

**工程提醒**：框架里的 `CrossEntropyLoss` 通常接收 **logits** 而不是概率，
内部做 log-softmax；如果你先手动 softmax 再传进去，等于做了两次，梯度会被压扁。

## 5. Adam 的直觉：给每个坐标一个自己的学习率

### 5.1 从 SGD 到 Adam

```
SGD:      θ ← θ − η·g
Momentum: m ← β₁m + (1−β₁)g;              θ ← θ − η·m
RMSProp:  v ← β₂v + (1−β₂)g²;             θ ← θ − η·g/(√v+ε)
Adam:     m ← β₁m + (1−β₁)g
          v ← β₂v + (1−β₂)g²
          m̂ = m/(1−β₁ᵗ),  v̂ = v/(1−β₂ᵗ)     # 偏差修正
          θ ← θ − η·m̂/(√v̂+ε)
```

- `m` 是一阶矩（梯度的滑动平均）——提供动量，抑制震荡；
- `v` 是二阶矩（梯度平方的滑动平均）——提供每个坐标的尺度；
- `m̂/√v̂` 近似「信噪比」：梯度方向稳定（|m| 大、v 小）就走大步，方向乱（v 大）就走小步；
- **偏差修正**：`m`、`v` 初始化为 0，前几步会偏向 0；除以 `1−βᵗ` 把初期的偏差补回来，
  否则第一步的更新会异常小。

默认超参 `β₁=0.9, β₂=0.999, ε=1e−8` 在大多数任务上够用，`η` 仍需按任务调（常用 `1e−3`）。

### 5.2 Adam 不是万能的

- 在高度非平稳目标上，`v` 的历史会拖慢后期的精细收敛；有时 SGD + 动量最终泛化略好；
- `L2` 正则加在 Adam 的梯度里会被 `√v` 缩放，导致大权重方向的实际惩罚变弱；
  **AdamW** 把 weight decay 从梯度里解耦出来，直接乘在参数上，这是现在的默认做法；
- Adam 的自适应步长对 batch size 敏感：batch 太小，`v` 噪声大；batch 太大，单位计算的学习信号变少。

## 6. 训练循环的常见 bug

| 现象 | 根因 | 正确做法 |
|---|---|---|
| loss 震荡上升、参数爆炸 | 学习率过大 / 没做梯度裁剪 | 降 lr；先跑几个 step 打印梯度范数 |
| loss 几乎不降 | 忘记减均值、学习率过小、标签/输出错配 | 检查 reduction、lr、输出层与损失 |
| 第二次迭代 loss 突然变好又变差 | 梯度没清零，累加了上一批 | 每个 step 先 `zero_grad()` |
| 训练 loss 正常、验证一塌糊涂 | 训练时开了 Dropout/BatchNorm，验证没切 eval | 显式 `model.eval()` / 关闭随机性 |
| 出现 `nan` | softmax/exp 溢出、log(0)、除零 | 减最大值、clip 概率、加 eps |
| 验证指标比训练还好 | 验证时仍有随机增强 / 数据泄漏 | 关增强、查预处理与切分 |
| 小 batch 训练极不稳定 | 梯度方差大、BatchNorm 统计量噪声 | 增大 batch 或换 LayerNorm/GroupNorm |

**一条硬规则**：每个训练脚本先做三件事——**单批过拟合**（用 1 个 batch 训练到 loss≈0）、
**梯度校验**（手写层）、**打印梯度范数**。这三步能排掉绝大多数「模型不学」的问题。

## 三视角解析

### 🧑‍💻 程序员视角
- 反向传播的代码顺序与推导顺序相反：先算输出层 `dZ`，再逐层往前。写的时候把每层的 `cache` 当成函数返回值，别用全局变量。
- 所有除法都想清楚分母是谁：`/m` 是样本数，`/batch` 是批大小，`/√v` 是逐坐标。混一个就是「训练能跑但效果差一半」。
- 数值校验只在 debug 模式跑；生产训练不要开，成本是前向的参数量倍。
- 混合精度训练时，softmax/CE 要在 float32 里算；`exp` 在 float16 下很容易溢出。
- 上线前把 `model.eval()`、`torch.no_grad()`（或 NumPy 的只前向路径）写成固定模板，别靠记忆。

### 🎓 博士生视角
- 反向传播是**反向模式自动微分**（reverse-mode AD）在计算图上的特例。它的计算复杂度与前向同阶（常数约为 2~3 倍），与参数量的关系是「一次反向得到全部梯度」，这正是它比数值微分高效的根本原因。
- 雅可比-向量积（VJP）视角：每层反传实际是在算 `vᵀJ`，其中 `J` 是该层输出的雅可比。框架的 `backward` 接口本质是 VJP，而不是显式构造雅可比。
- `dZ = (P−Y)/m` 来自指数族 + 交叉熵的规范链接（canonical link）；对一般 GLM，梯度都是 `Xᵀ(μ−y)` 的形式。这个统一性在 `ml-ch02` 已出现。
- Adam 的收敛分析依赖「有界梯度 + 递减步长」等假设（Kingma & Ba 2015）；在非凸深度网络上只有局部收敛保证。AdamW 的解耦权重衰减（Loshchilov & Hutter 2019）修正了 Adam 中 L2 与自适应学习率耦合的问题。
- 梯度消失/爆炸的完整机制（雅可比谱、初始化方差、残差连接、归一化）属于 `ai` 学科；本章只需知道「连乘 + 饱和导数」是根因。

### 📚 考研者视角
- 必考推导：给定两层网络与平方损失/交叉熵，写出 `∂L/∂W₁`、`∂L/∂W₂`。标准步骤是「先算输出层误差，再乘权重转置，再乘激活导数」。
- 记清形状：`dW_l` 的形状永远与 `W_l` 相同；`db_l` 的形状等于该层神经元数；`dZ_l` 与 `Z_l` 同形。
- 高频判断：「反向传播需要重新做一次前向」——错，它复用前向缓存；「梯度校验比解析梯度快」——错，数值梯度是 O(参数量) 次前向。
- softmax 的性质常考：输出和为 1、平移不变、`∂p_k/∂z_j = p_k(δ_kj − p_j)`；交叉熵对 logit 的梯度是 `p − y`。
- Adam 的偏差修正公式要会写：`m̂ = m/(1−β₁ᵗ)`、`v̂ = v/(1−β₂ᵗ)`；解释「为什么需要」——零初始化导致前几步矩估计偏小。
- 易错：`sigmoid` 的导数是 `σ(1−σ)`，不是 `σ`；`tanh` 的导数是 `1−tanh²`，不是 `1−tanh`。
