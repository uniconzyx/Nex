# ml-ch06 易错点：无监督与降维的六个认知陷阱

1. **K-means 前没标准化，量纲大的特征垄断距离**
   - 现象：用「身高(cm) + 体重(kg) + 收入(元)」直接聚类，簇几乎完全由收入决定，身高体重形同虚设。
   - 根因：K-means 用欧氏距离，平方后大尺度特征贡献主导畸变 J，主方向被它独占。
   - 正确做法：聚类/PCA 前**先标准化**（或单位统一）；只有特征本就同量纲、尺度即语义时才不标准化。

2. **把 K-means 当「通用聚类」，硬切月牙/环/非凸簇**
   - 现象：同心环数据上 K-means 按半径/位置横切，把每个环切成两半，簇毫无意义。
   - 根因：K-means 隐含「球状、等方差、同密度」假设，欧氏距离划出的只能是凸区域。
   - 正确做法：非凸/任意形状用 **DBSCAN 或谱聚类**；别指望调 K 调出月牙——换方法而不是调参数。

3. **用肘部法的「拐点」硬选 K，忽略轮廓系数**
   - 现象：J-K 曲线是平滑弯弧，没有清晰拐点，硬选一个 K 后簇质量很差。
   - 根因：肘部法的拐点常常主观、不明显；J 随 K 单调递增，没有数学上的唯一拐点。
   - 正确做法：用**轮廓系数**（平均 s 最高）或 gap statistic 客观选 K，肘部法只作辅助直觉。

4. **DBSCAN 的 ε 与 minPts 乱拍，全变噪声或全连一团**
   - 现象：ε 太小 → 几乎每个点都是噪声；ε 太大 → 所有点连成一个大簇，K 失去意义。
   - 根因：DBSCAN 对 ε 极敏感，且 ε 与 minPts 耦合（minPts 小则 ε 要小）。
   - 正确做法：minPts 取 ≈2d，再用**k-距离图**（第 k 近邻距离排序后的拐点）定 ε；先定 minPts 再定 ε。

5. **PCA 直接对协方差矩阵做特征分解，数值不稳**
   - 现象：高维/病态数据上 `eig(XᵀX)` 给出的主方向严重偏移，甚至报错。
   - 根因：`κ(XᵀX) = κ(X)²`，条件数被平方，浮点误差被放大。
   - 正确做法：对去中心化数据做 **SVD**（`np.linalg.svd`），主方向取右奇异向量，方差解释用 `s²`，数值稳且一步到位。

6. **在 t-SNE 图上量距离、数异常、比簇大小**
   - 现象：根据 t-SNE 布局中两团离得远，就下结论「这两类差异更大」，或据簇面积判断密度。
   - 根因：t-SNE/UMAP 只承诺**局部邻域关系**，全局距离、簇间远近、密度都是渲染结果，不对应真实度量。
   - 正确做法：t-SNE 只做**探索性可视化**；要定量距离/密度，回到 PCA 或原始空间；换困惑度看局部结构是否稳定。
