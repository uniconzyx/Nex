# K-means：畸变函数、Lloyd 迭代与簇数选择

> K-means 是无监督里第一个「看起来会了、上手就翻车」的算法：三步就能写完，
> 但目标函数为什么单调下降、为什么必然局部最优、K 到底怎么选，每一步都有坑。
> 这一章把「畸变 J 的定义 → 两步各自最优 → 单调收敛但不全局 → k-means++ 的概率保证
> → 肘部/轮廓/间隙三种选 K 口径」钉死，再划定它的失效边界。

## 1. 目标函数：畸变 J 与「硬分配」假设

给 N 个点 `x_n ∈ ℝ^d` 和 K 个中心 `μ_k`，K-means 最小化**簇内平方和**（distortion）：

```
J({r_nk}, {μ_k}) = Σ_{n=1}^{N} Σ_{k=1}^{K} r_nk ‖x_n − μ_k‖²

约束：r_nk ∈ {0, 1}，Σ_k r_nk = 1   （每个点硬分配给唯一一个簇）
```

把约束代进去，J 有一个更赤裸的写法：

```
J = Σ_n min_k ‖x_n − μ_k‖²
```

**三个必须点明的性质**：

1. **J 同时依赖「分配」和「中心」两族变量**，且是整数约束的 r——直接对 r 求导没意义，只能交替优化；
2. J 的度量是**欧氏距离平方**，于是它隐含假设「簇是球状、等方差、同密度」——非球形数据上 J 的最小值与人的直觉无关（见第 6 节）；
3. J 随 K 单调不增（K 个子问题的最优值 ≤ 合并后的最优值），所以「J 越小越好」不能直接用来选 K。

## 2. Lloyd 迭代：两步各自最优

Lloyd 算法（Lloyd 1982；MacQueen 1967 的 k-means 同名工作更早）交替做两件事：

```
分配步（固定 {μ}，优化 {r}）：   r_nk = 1  ⟺  k = argmin_j ‖x_n − μ_j‖²
更新步（固定 {r}，优化 {μ}）：   ∂J/∂μ_k = −2 Σ_n r_nk (x_n − μ_k) = 0
                                 ⟹  μ_k = (Σ_n r_nk x_n) / (Σ_n r_nk)   （簇内均值）
```

- **分配步**是 J 对 r 的**精确最小化**：固定中心后每个点独立决策，选最近的中心一定不增 J；
- **更新步**是 J 对 μ 的**精确最小化**：对每个簇的 μ_k 解一个凸二次函数，驻点就是簇内均值；
- 两步合起来是**分块坐标下降（block coordinate descent）**：目标函数单调不增。

每轮成本 `O(N·K·d)`——N 个点各算 K 个距离，与迭代轮数（通常个位数）相乘，
比一次 PCA 还便宜。这也是 K-means 能上大规模的原因（mini-batch 变体进一步降成本）。

## 3. 单调收敛 ≠ 全局最优

```
J 随轮次
 │╲
 │ ╲___
 │     ╲____
 │          ╲________      ← 单调不增，有限步到驻点
 │                    ――――
 └──────────────────────→ Lloyd 轮次
```

**单调性的证明一句话就能说清**：分配步和更新步各自都是「固定另一族变量后的精确最小化」，
所以每一轮 `J(t+1) ≤ J(t)`；而 N 个点的 K-划分只有有限种，J 不可能无限严格下降 → 有限步终止。

**但收敛到的只是 J 的驻点（局部最优），且「差」的程度可能非常大**。本仓示例 ex01 的实测：
同一份 300 点数据跑 30 次随机初始化，最终 J 落在两个平台上——最好 241.2、最差 837.2，
相差约 3.5 倍。换句话说：**「Lloyd 收敛了」这句话不包含任何「结果好」的信息**，
它只说明「不可能再靠换分配/挪中心下降了」。

工程上因此有三条固定动作：

1. **多随机重启**（n_init，sklearn 默认 10）取最小 J——便宜且有效；
2. **k-means++ 初始化**（下一节）从源头降低抽到坏起点的概率；
3. 对「簇明显不球」的数据，换方法（DBSCAN/谱聚类）而不是加重启。

## 4. k-means++：把「运气」变成概率保证

纯随机初始化的问题是：两个中心可能落进同一个真簇，某个真簇被跳过——之后 Lloyd 无论怎么迭代都救不回来
（它只能收敛到局部最优）。k-means++（Arthur & Vassilvitskii, SODA 2007）的改法是**平方距离采样**：

```
1. 第一个中心均匀随机；
2. 之后每轮，对每个点算 D(x)² = min_{已选中心 c} ‖x − c‖²，
   按概率  D(x)² / Σ_x' D(x')²  抽下一个中心。
```

**为什么平方**：线性距离下，靠近已有中心的点仍有可观概率被重复抽中；平方后近处被强烈压制，
但又不是零概率——「偶尔探到远处」的能力保留了下来。这就是它的理论保证：
期望畸变 `E[J] = O(log k) · J*`（J* 为全局最优），与 K 成对数而非线性。

本仓示例 ex02 在「一个大簇 + 四个小簇」的不等规模数据上实测 60 次重启：
随机初始化 36/60 到达最优平台，k-means++ 54/60——**收益主要在均值与到达率**，
而在「最差情况」下两者可能打平（小簇场景下随机也不是全无机会）。所以工程口径是：
k-means++ 显著降低试错成本，但不做「一次成功」的保证；正式生产仍然配合 n_init。

## 5. 簇数选择：肘部、轮廓、间隙统计

J 随 K 单调不增，所以「最小 J」永远选 K=N（每点一族），选 K 必须引入**额外准则**。三种主流口径：

**（a）肘部法则**：看 J(K) 曲线边际下降 `Δ(K) = J(K−1) − J(K)` 的骤减点。
直觉是「真簇数之内 J 掉得快，超过之后只是把一个真簇切成两半，J 掉得平」。
但**肘常常是平滑弧没有拐点**（ex03 的实测曲线上 K=4 只是「最弯」而非「折断」），
自动判定阈值（如 Δ(K+1)/Δ(K) < 0.5）属于经验判断，只能作辅助直觉。

**（b）轮廓系数**（Rousseeuw 1987）：对每个点 i，

```
a(i) = i 到同簇其他点的平均距离；   b(i) = i 到「最近的外簇」所有点的平均距离
s(i) = ( b(i) − a(i) ) / max( a(i), b(i) )      ∈ [−1, 1]
```

`s(i) ≈ 1` 表示分得干净，`≈ 0` 表示骑在两个簇边界上，`< 0` 表示大概率分错了簇。
对全部点取平均得平均轮廓 `s̄(K)`，**取使 s̄(K) 最大的 K**。它比肘部客观（有定义、可算、可比较），
但计算 `O(N²)`，且对「簇非球」的数据会系统性低估好结果——轮廓系数的几何假设同样是球状。

**（c）间隙统计**（Tibshirani, Walther & Hastie, JRSS-B 2001）：把数据的 `log J(K)` 与
B 组「覆盖数据包围盒的均匀参考样本」的 `log J(K)` 期望对比：

```
Gap(K) = E_B[ log W*_K ] − log W_K        （W_K = J(K)，W*_K = 参考数据的 J）
选最小 K 使  Gap(K) ≥ Gap(K+1) − s_{K+1}  （s_{K+1} 为参考分布的标准误）
```

它把「J 降了多少」放到「随机数据也该降多少」的参照系里，是三者中最统计学的，
代价是要生成 B 组参考样本；且**高维下包围盒体积爆炸、均匀采样极度稀疏**（经验判断：d 明显大于 10 后基本不实用）。

```
方法         计算成本      客观性      主要软肋
──────────────────────────────────────────────────────────────
肘部法       O(NKd)/轮      主观       拐点常常不存在，只能辅助
轮廓系数     O(N²)          高         O(N²) 贵；同样假设球状簇
间隙统计     O(B·NKd)       高         参考分布生成贵；高维失效
```

ex03 的实测（四团不等大小/方差的 K=1..8 扫描）：肘部与轮廓系数都指向 K=4
（平均轮廓 0.717，且 K>4 后轮廓明显走低）——两个独立口径互相印证时，选 K 的结论才敢下。

## 6. 失效边界：球状、等方差、同密度

K-means 的失效不是 bug，是 J 的定义把「簇」写死了。本仓示例逐个实测了三条边界：

| 数据形态 | K-means 行为 | 本质原因 |
|---|---|---|
| 同心环 | 按半径横切，每环切两半，错分率 0.479 | 欧氏 Voronoi 划分只能是凸区域 |
| 少量远端异常点（1.5%） | J ×3.1、质心拖偏 0.14、撬动 14% 总平方和 | 平方损失对远离的点惩罚二次 |
| 高维（d≥100） | 距离集中，同簇最近邻率→0.5，判断边际坍缩 | 所有点对之间的欧氏距离趋同（Beyer et al. 1999） |

这三条对应三种正确处置：**非凸换密度/谱方法，异常点先清洗或用稳健（k-medoids）替代，
高维先降维或换对集中不敏感的度量**。共同的一句话：**J 的下降不等于业务上的「簇分对了」**。

## 三视角解析

### 🧑‍💻 程序员视角

- 上线前先标准化：量纲不一致时，大尺度特征直接垄断 J（pitfalls 第 1 条）。`StandardScaler` 之后再看簇，否则你以为在聚类，其实在按收入排序。
- `n_init` 别省：随机重启是最便宜的保险，配合 k-means++ 使用。生产上 `KMeans(n_clusters=k, n_init=10)` 是底线配置；sklearn 1.4+ 默认就是 `n_init='auto'`（k-means++ 下一次）。
- 空簇是真的会发生的 bug：某个中心一轮里抢不到任何点，`μ_k` 更新出现 0/0。多数实现的做法是把空簇重新放到「离现有中心最远的点」上；手写实现必须处理，否则 `nan` 会静默污染后续所有轮次。
- K 的选择别拍脑袋：肘部 + 轮廓两个口径跑一遍，互相印证再定；只在验证指标（如下游任务的稳定性）上认输。ex03 的字符条形图打印本身就该进 CI——选 K 的结论要可复现。
- 线上事故高发区：**用训练时的 K 去推线上分布漂移后的数据**。新数据的尺度、密度变了，J 的口径失效，要周期性重估中心甚至重选 K。

### 🎓 博士生视角

- Lloyd 迭代的严格身份是**分块坐标下降**：分配步是 J 对组合变量 r 的精确最小（等价于对固定 μ 的 Voronoi 划分），更新步是 J 对 μ 的精确最小（凸二次函数取驻点）。坐标下降的一般收敛定理（每块精确最小 + 目标连续）直接给出单调不增；终止性靠**划分空间有限**。
- **k-means++ 的 O(log k) 是期望意义下的近似比**：证明用「某个簇在 D² 采样下被跳过的概率」的势函数分析，与度量空间维度无关。后续工作（如 k-means#）把它推向「免参数、无需指定 K」的方向。
- **k-means 是球状等方差 GMM 的硬分配极限**：`Σ_k = σ²I`、`σ → 0` 时 responsibility 退化为 one-hot，EM 的 M 步退回 Lloyd 更新。这把第 03 篇的 EM 与本篇统一起来：K-means 不是独立发明，是 GMM 的一个退化切片。
- **NP-hard 性**：即使在平面（d=2），最小化 J 也是 NP-hard（Dasgupta 的近似综述）； Lloyd 只是多项式时间的局部搜索。因此「全局最优」在生产里从来不是选项，改进初始化/重启才是。
- **间隙统计的理论基础**是置换检验式的「对标零分布」：参考分布选均匀（而非高斯）是为了「无任何簇结构」的最强零假设；选 K 的 `1-标准误` 规则是「在 Gap 掉得明显超过参考噪声之前停下来」。

### 📚 考研者视角

- 自命题 AI 专业课高频：**写出 J 的两种等价形式**（指示变量形式与 `Σ_n min_k ‖x_n − μ_k‖²`），并说明为什么对 r 不能直接求导（整数约束）。
- **单调收敛的标准证明**：分配步固定 μ、J 不增（每点取最近中心）；更新步固定 r、J 不增（对 μ_k 求导得簇内均值）；两步交替 → J 单调不增；划分有限 → 有限步终止。四句话，缺一不可。
- **收敛到局部最优的标准论证**：J 是划分的非凸函数，不同初始化收敛到不同驻点；举「两个中心落进同一真簇」的例子说明为什么 Lloyd 救不回来。
- **k-means++ 的考点**：D² 采样公式 + `E[J] = O(log k) J*` 的期望近似比 + 与纯随机的对比（纯随机无任何保证）。
- **肘部 vs 轮廓的口径**：肘部看 J 的边际下降（主观、无定义），轮廓 `s(i) = (b−a)/max(a,b)`（客观、取值 [−1,1]）；答题要会写 a(i)、b(i) 的定义和「平均轮廓最大选 K」的流程。
- 易混：**K-means 收敛 ⟂ 结果正确**；**J 最小 ⟂ K 最优**；**Lloyd 的「轮数」由数据决定，不是超参数**。
