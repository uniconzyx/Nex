# 密度估计与异常检测：从高斯 ε 到 DBSCAN 的密度视角

> 异常检测是「用正常数据训练一个『什么叫正常』的模型，然后把不像正常的东西标出来」。
> 这条路线的地基是**密度估计**：把 p(x) 估出来，低于阈值 ε 的就是异常。
> 这一章把「一元/多元高斯密度估计 → 阈值 ε 怎么选、用什么指标选 → 协方差结构
> 决定谁能抓住『联合异常』→ DBSCAN 用同一套密度思想做聚类」串成一条线。

## 1. 高斯密度估计与阈值 ε

对正常样本 `x_1…x_N`，假设它们来自一个多元高斯：

```text
p(x; μ, Σ) = (2π)^{−d/2} |Σ|^{−1/2} exp( −½ (x − μ)ᵀ Σ⁻¹ (x − μ) )
```

参数用 MLE（闭式，不需要迭代）：

```
μ̂ = (1/N) Σ_n x_n
Σ̂ = (1/N) Σ_n (x_n − μ̂)(x_n − μ̂)ᵀ        （注意除以 N，不是 N−1）
```

### 检测规则只有一句话

检测规则就一句话：**算 `p(x)`，小于阈值 ε 判异常**。ε 是唯一的超参数，
它不来自任何公式，来自**验证集上的指标最大化**——这是它与监督学习最像也最容易被误用的地方。

**为什么用对数**：高维下 `p(x)` 是 d 个小于 1 的数连乘，直接算会下溢到 0；
工程上一律算 `log p(x)`（例 ex05 直接打印 log10 p(x) 的字符直方图），阈值同步取对数。
顺便说：多元高斯的对数形式把指数项变成马氏距离，这正是第 3 节的入口。

## 2. ε 怎么选：F1 口径与 skew 警告

### 异常检测评估的三个坑

**（a）准确率在极度不平衡下是废指标**。异常率 1% 时，「全部判正常」准确率 99%。
PR 曲线、F1 才是主指标；`F1 = 2PR/(P+R)`，P = 精确率（判异常的里多少是真异常），
R = 召回率（真异常里抓住了多少）。

**（b）ε 与 P/R 的权衡是单调的**：ε 调高 → 判异常的标准放宽 → P 降 R 升；ε 调低 → P 升 R 降。
不存在「两个都最大」的点，只能按业务代价选工作点（漏检贵就保 R，误报贵就保 P）。

**（c）验证集必须独立**。μ̂/Σ̂ 用训练集估、ε 在验证集上扫网格选 F1 最大、最后在测试集报告——
三份数据三个用途。**拿训练集既估参数又选 ε 是经典的过拟合 ε**：F1 会虚高，
因为 ε 已经被同一份数据「看」着调过了。

ex05 的实测流程（正常 N(3.0, 0.9)、异常 N(3.0, 0.9) 右偏重叠区注入，制造真实的模糊边界）：
在 13 个对数网格点上扫 ε，验证集 F1 峰值 0.889 出现在 `ε ≈ 4.6e-3`，测试集 F1 = 0.769。
注意**从验证到测试 F1 掉了 0.12**——这就是 ε 过拟合验证集 + 两类分布本身重叠的正常代价，
不是 bug。选 ε 的口径因此是「验证集上最优 + 测试集上如实报告」，不是「两条都好看」。

## 3. 多元高斯的协方差结构：谁定义了「异常」

一元高斯把「远离均值」当作异常，多元高斯把这个概念升级成**马氏距离**：

```
d_M²(x) = (x − μ)ᵀ Σ⁻¹ (x − μ)
```

### 几何解释：白化空间里的欧氏距离

它的几何解释是**白化空间里的欧氏距离**：先把数据的椭球轮廓「捏成圆球」再量长度。
Σ 的结构直接决定「什么叫异常」：

| Σ 的形式 | 假设 | 行为 |
|---|---|---|
| `σ²I` 球形 | 各向同性 | 马氏距离退化为欧氏距离/σ，「远离均值」即异常 |
| 对角 Σ | 特征独立 | 每个特征单独看 z 分数；**漏掉沿相关方向的联合偏移** |
| 完整 Σ | 特征可相关 | 短轴方向的小偏移 = 大马氏距离；能抓住联合异常 |

ex06 在强相关各向异性数据（Σ = [[2.5,1.5],[1.5,1.0]]，长轴/短轴 ≈ 2.2 倍）上实测：
注入两族异常——家族 A 沿短轴偏 3~5 个短轴标准差（欧氏距离只有 ~2，埋在正常范围里），
家族 B 沿长轴偏 6σ（显眼）。三种检测器在 97.5% 分位阈值下：

```
检测器          家族 A(10)   家族 B(10)   机理
────────────────────────────────────────────────────────
欧氏距离          0/10         10/10       只量长度，不量方向
马氏(对角 Σ)      0/10         10/10       独立假设下，短轴偏移被长轴方差「掩护」
马氏(完整 Σ)     10/10         10/10      白化后沿短轴偏 3~5σ 一目了然
```

**「边际正常、联合异常」**是这一节最值得记住的现象：家族 A 的单个点，两个特征的
边际 z 分数都不到 1σ，单独看人畜无害，联合密度却已掉到尾部——这正是对角 Σ 与
完整 Σ 的分水岭，也是「先画特征相关图，再选协方差结构」这条工程守则的由来。

**完整 Σ 的代价**：`d(d+1)/2` 个参数。d=100 时就要 5050 个参数，N 不够时 Σ̂ 本身不可靠；
且存在鸡生蛋问题——**异常点会把 Σ̂ 带偏**（一个极端点就能扭歪主轴），然后用被污染的 Σ
去检测污染它的那个点。工程处置：shrinkage（`Σ̂(1−λ) + λ·diag`）、稳健协方差估计
（MCD 一类）、或降维后再估完整 Σ。

## 4. DBSCAN：同一套密度思想，换个用法

K-means 用「到中心的距离」定义簇，DBSCAN（Ester et al., KDD 1996）用**局部密度**定义簇。
三个角色：

```
核心点：|N_ε(x)| ≥ minPts        （邻域内够热闹）
边界点：|N_ε(x)| < minPts，但在某个核心点的 ε-邻域内
噪声点：其余（不贴任何核心点）
```

密度直达 → 密度可达 → 密度相连，取密度可达的「最大可连集团」为一个簇。
于是 K-means 的三个硬假设全部消失：**不预设 K**（簇数由密度结构决定）、
**能找非凸簇**（月牙、环都行）、**显式输出噪声**（噪声点不强行分配）。

**ε 与 minPts 是一对耦合参数**，不能各自拍：

- `minPts` 相对不敏感，经验起点是 `≈ 2d`（Schubert et al. 2017 的分析支持这一量级）；
- `ε` 极敏感，标准做法是 **k-距离图**（k = minPts）：算每个点到第 k 近邻的距离，
  排序后画曲线，取**拐点**处的距离作为 ε。这是经验判断，但比肉眼试 ε 可复现得多。

ex07 的实测扫描（三团不同密度 + 8 个远散布离群点）把 ε 的相变行为画了出来：

```
ε = 0.10 → 0 个簇（全噪声）        ε = 0.9  → 3 个簇，准确率 1.000
ε = 0.15 → 3 个小核                ε = 1.5  → 3 个簇
ε = 0.40 → 12 个碎片（一簇被切碎）  ε = 2.2  → 3 个簇
ε = 0.60 → 3 个簇（质量已恢复）      ε ≥ 3.0  → 2 个簇（过并）
```

### DBSCAN 的 ε 平台区

只有在平台区 `ε ∈ [0.9, 2.2]`，簇的准确率与离群召回才同时到 1.00；
ε 稍小就碎，稍大就并。**「DBSCAN 无参数」是错觉，它只是把 K 换成了 (ε, minPts) 这一对更耦合的参数。**

**DBSCAN 的已知软肋**（诚实标注）：单一全局 ε 假设数据密度均匀——一簇密一簇稀时它救不了
（HDBSCAN 的层级变密度是后续改进方向）；高维下同样面临距离集中，ε 邻域的意义退化。

## 三视角解析

### 🧑‍💻 程序员视角

- 密度估计的数值第一守则：**全程算 log p，别算 p**。高维下 p(x) 轻松下溢到 0，比较全变 0；`np.logaddexp` / log-sum-exp 是必需品。ex05 的 ε 网格就用对数刻度。
- 异常检测上线前先看**先验**：如果异常率是 1e-4，验证集里要保证有足够多的正例才能估 F1——不然 P/R 的置信区间宽到没法用。这时宁可做「排序 + 人审 top-K」而不是硬阈值。
- 别用欧氏距离直接做异常分：先画特征相关热力图，强相关就上完整协方差。ex06 里对角 Σ 把整个家族 A 漏光——这种漏检在监控系统里表现为「告警静默失效」，比误报危险得多。
- DBSCAN 调参顺序固定：**先定 minPts ≈ 2d，再画 k-距离图定 ε**，反过来调（先 ε 后 minPts）会陷入「两个参数互相追」的循环。ε 扫描的相变表（ex07）本身就是回归测试——数据管道变了要重跑。
- 协方差会被异常污染这件事，实践顺序是：**先稳健估计 Σ̂，再算马氏距离，再定 ε**。三步顺序反了，污染会静默进入阈值。

### 🎓 博士生视角

- 高斯 MLE 与马氏距离的桥梁：`log p(x) = const + d_M²(x)`（差一个 −½ 和 log|Σ| 项），所以「密度阈值」与「马氏距离阈值」在同一个 Σ 下**完全等价**；ε 的选择 = 分位数选择。正态下 `d_M² ~ χ²_d`，阈值可用分位数解析给出——这是「密度阈值」的频率学派解释。
- 对角 Σ 漏检联合异常的统计本质：在相关系数 ρ 下，沿短轴方向单位位移的密度衰减是沿长轴的 `(1+ρ)/(1−ρ)` 倍；ρ→1 时这个比值爆炸。所以「边际独立」不是工程近似，是**结构性的检错能力丧失**。
- DBSCAN 的形式化：核心点是「局部密度超过水平集」的点，DBSCAN 找的是密度函数的**上水平集连通分支**（cluster tree 视角，HDBSCAN 的理论基础）。ε = 密度阈值，minPts = 抑制孤立噪声的平滑参数。
- 协方差估计的维数灾难：`Σ̂` 有 `d(d+1)/2` 个参数，当 `N` 不同量级大于 `d²` 时 MLE 才稳；Ledoit-Wolf  shrinkage 的最优强度有解析形式（按 Frobenius 准则最小化 MSE），这不是启发式。
- ε/F1 选择与 ROC-PR 的关系：skew 数据上 PR 曲线比 ROC 敏感得多，因为 FP 率被巨大规模的负例稀释。选 ε 用验证集 PR 口径，是「估计分布 shift 下的风险」的代理。

### 📚 考研者视角

- 高频推导：**写出多元高斯的 MLE**（μ̂ 为样本均值，Σ̂ 为样本二阶中心矩除以 N），并说明对数似然为何要对数化（防下溢 + 指数项变马氏距离）。
- 标准定义题：**马氏距离** `d_M² = (x−μ)ᵀΣ⁻¹(x−μ)`，它与白化的关系（`d_M = ‖Σ^{−1/2}(x−μ)‖`），以及三种 Σ 结构（球形/对角/完整）各自的行为差异。
- ε 的选择口径：**验证集上扫 ε 网格、以 F1 最大为准则**；P/R 随 ε 的单调权衡（ε↑ → R↑ P↓）；skew 数据下准确率失效的原因（负例占 99% 时全判负即 99%）。
- DBSCAN 三件套的定义必须逐字：**核心点**（ε-邻域内点数 ≥ minPts）、**边界点**（邻域不够但在核心点邻域内）、**噪声点**（其余）；以及密度可达的传递闭包定义。
- 易混：**协方差除以 N 还是 N−1**（MLE 是 N，无偏估计是 N−1，题目说「极大似然」就除以 N）；**对角 Σ ≠ 特征独立假设可忽略**——它恰恰是联合异常漏检的根源；**DBSCAN 无参数是错觉**（ε/minPts 更耦合）。
