# GMM 与 EM：软分配、下界构造与「K-means 的极限」

> K-means 把每个点硬塞给一个簇，GMM 说：凭什么？重叠区的点本来就说不清属于谁。
> 给它一个**软分配**（responsibility），目标函数从畸变 J 换成对数似然，
> 优化算法就是 EM。课程里的直觉是「GMM 是 K-means 的软升级」，
> 这一章要回答三个更深的问题：软在哪一步、EM 为什么单调收敛、两者到底差多少。

## 1. 隐变量与 responsibility：把「软」写进模型

高斯混合模型假设每个点由一个隐变量 `z_n ∈ {1,…,K}` 选择成分后生成：

```
p(x) = Σ_k π_k N(x | μ_k, Σ_k)        混合先验：π_k ≥ 0, Σ_k π_k = 1
```

引入隐变量 `z_n`（one-hot 向量）后，**完整数据** `(x, z)` 的联合与后验都好写：

```
p(z_n = k) = π_k
p(x_n | z_n = k) = N(x_n | μ_k, Σ_k)
p(z_n = k | x_n) = γ_nk = π_k N(x_n | μ_k, Σ_k) / Σ_j π_j N(x_n | μ_j, Σ_j)
```

`γ_nk` 就是 **responsibility**：第 k 个成分对「解释第 n 个点」负多大责任。
γ 是全 0/1 向量时退化为 K-means 的硬分配；γ 可以是 0.5/0.5 时，模型承认「这个点骑在边界上」。
ex08 实测：重叠区的点 γ 真的落在 0.5 附近（按 γ≈0.5/0.25/0.75 取样打印软指派表），
78/220 个点在两团重叠数据上拿到 0.05 < γ < 0.95 的「模糊分配」（ex09）——这不是缺陷，是模型在如实报告不确定性。

## 2. E 步与 M 步

EM（Dempster, Laird & Rubin, JRSS-B 1977）交替两步：

```
E 步：固定 θ = (π, μ, Σ)，算 responsibility
       γ_nk ← π_k N(x_n | μ_k, Σ_k) / Σ_j π_j N(x_n | μ_j, Σ_j)

M 步：固定 γ，对 θ 最大化「加权对数似然」Q(θ) = Σ_n Σ_k γ_nk log[ π_k N(x_n|μ_k,Σ_k) ]
       N_k  = Σ_n γ_nk
       π_k  = N_k / N
       μ_k  = (1/N_k) Σ_n γ_nk x_n                        （软加权均值）
       Σ_k  = (1/N_k) Σ_n γ_nk (x_n − μ_k)(x_n − μ_k)ᵀ
```

M 步的每个更新都是**闭式**：把 γ 当权重看，就是加权 MLE——μ_k 是软加权均值，
Σ_k 是软加权二阶矩，π_k 是软计数占比。这解释了为什么 EM 在 GMM 上好用：
没有梯度、没有学习率，每步都是精确最大化。

## 3. 下界构造与单调收敛证明（必须会写）

直接最大化 `log p(X|θ)` 难，因为 `log` 里面有个 `Σ_z`。EM 的全部威力来自**给对数似然造一个下界**：

```
第 1 步（引入任意分布 q(z)）：
  log p(X|θ) = log Σ_Z p(X, Z | θ)
             = log Σ_Z q(Z) · p(X, Z | θ) / q(Z)

第 2 步（Jensen，log 是凹函数）：
  log p(X|θ) ≥ Σ_Z q(Z) log [ p(X, Z | θ) / q(Z) ] ≡ L(q, θ)

第 3 步（拆开恒等式）：
  L(q, θ) = log p(X | θ) − KL( q(Z) ‖ p(Z | X, θ) )
```

于是 `L(q, θ)` 是 `log p(X|θ)` 的下界，差一个 KL 散度。两步各自干一件事：

- **E 步**：固定 θ，取 `q(Z) = p(Z | X, θ)`（后验）→ KL = 0，下界**贴紧**对数似然；
- **M 步**：固定 q，`θ ← argmax_θ L(q, θ)` → 下界**抬升**，抬升后 `log p` 不降。

```
log p(X|θ)
 │          ―――― θ(t)，E 步后下界贴紧此处
 │        ╱‾‾‾‾‾
 │       ╱    ╲
 │      ╱      ╲    ―――― θ(t+1)，M 步后抬升
 │     ╱        ╲╱‾‾‾‾‾
 │    ╱              （下一轮 E 步再贴紧）
 │   ╱
 └──────────────────────────────→ EM 轮次
     E 步贴紧      M 步抬升
```

**单调收敛定理**：每轮 `log p(X|θ^{(t+1)}) ≥ log p(X|θ^{(t)})`；
数值上 ex08 实测：1D 两成分 GMM 的对数似然从 −333.27 单调升到 −286.19（64 轮），
相邻轮最小增量 7.2e-12（浮点精度处仍不减）——单调不降是真的可以逐轮打印验证的。

**两个诚实的限定**：① 单调收敛只保证到**驻点（局部最优）**，EM 对初始化敏感——
ex08 的坏初始化停在 L = −302.35，比好初始化的 −286.19 差一截；
② 收敛速度可能是线性的（取决于观测信息矩阵的谱），坏初始化下慢到工程上不可用。

## 4. GMM 与 K-means：差在哪、极限在哪

两者的关系是「软硬之别 + 目标之别」，三个层次都要能说清：

**（a）硬/软分配**：K-means 的 `r_nk` 是 one-hot；GMM 的 `γ_nk` 是后验概率。
分配一步，GMM 把「归属」从确定事件变成概率——重叠区的点不再被强行切走。

**（b）目标函数**：K-means 最小化畸变 `J = Σ_n Σ_k r_nk‖x_n − μ_k‖²`；
GMM 最大化对数似然 `log p(X|θ)`。前者是几何量（对尺度敏感、随量纲变），
后者是概率量（自动归一化、可与 BIC 对话）。

**（c）σ → 0 极限**：令 `Σ_k = σ²I`（等方差球形）且 `σ → 0`：

```
γ_nk → r_nk（one-hot 硬分配，高斯核变成 δ 函数）
μ_k 更新 → 簇内均值（软权重全变成 0/1）
Σ_k, π_k 更新退化为平凡量
```

**E 步退回 Lloyd 的分配步，M 步退回 Lloyd 的更新步**。ex09 实测：把 GMM 的方差按 τ 缩放压向 0
（τ = 1e-4），硬分配与 K-means 的一致率 0.977、畸变 461 → 400.9（K-means 的 J = 396.67）。
**诚实标注**：残余的 2% 不一致不是数值噪声，是 GMM 在优化似然、K-means 在优化 J，
两个目标的最优点本来就差之毫厘——「GMM 是 K-means 的软版本」是极限意义成立，
不是逐点相等。

```
维度        K-means                    GMM + EM
──────────────────────────────────────────────────────────────
分配        硬（one-hot r）             软（后验 γ）
目标        畸变 J（欧氏口径）           对数似然（概率口径）
簇形状      球状、等方差（Voronoi）     任意 Σ_k：轴长/方向/体积皆可学
重叠区      强行切走                    如实给 0.5/0.5
收敛保证    坐标下降，单调不增           下界交替，对数似然单调不降
```

## 5. BIC 与成分数：怎么知道 K 取对了

GMM 的 K 不能靠「似然最大」选——K 越大似然必然越高（多一个成分总能更好地拟合）。
标准工具是 **BIC**（Schwarz 1978）：

```
BIC(K) = log p(X | θ̂_K) − (p_K / 2) log N
p_K = K − 1 + K·d + K·d(d+1)/2      （完整 Σ 时的参数量；球形/对角 Σ 相应减少）
```

第二项是**复杂度惩罚**：K 翻倍时参数量近似翻倍，`log N` 规模的数据量才能撑住。
选 BIC 最大的 K。**限定**：BIC 是渐近近似，N 小时不稳定（经验判断：小样本上 AIC/交叉验证更稳）；
且它仍然只能在你已经收敛到「好的局部最优」的前提下比较——所以标准流程是
**每个 K 多次随机初始化（或用 K-means 结果初始化）取最高似然，再比 BIC**。

**成分坍缩**是 GMM 特有的失效模式：某个 μ_k 被单个点吸住、Σ_k → 0 时，
似然 `N(x|μ_k, σ²)` 在 σ→0 时趋于无穷——模型「作弊」而不是建模。
工程对策：Σ_k 加方差下界、π_k 设最小权重（低于阈值合并/重启该成分）、
用 K-means 的结果初始化 EM（这也是 sklearn 的默认策略）。

## 三视角解析

### 🧑‍💻 程序员视角

- 初始化决定生死：EM 对初值极敏感（ex08 好坏初始化差 16 个 log 单位）。生产上默认用 K-means 结果初始化 μ/Σ、π 用簇占比——比纯随机稳得多。sklearn 的 `GaussianMixture(init_params='kmeans')` 就是这个套路。
- 数值三件套：`log-sum-exp` 算 γ 的分母（防下溢）、协方差加 `reg_covar`（默认 1e-6，防空簇/奇异）、似然打 log。少任何一件，线上都会偶发 `nan` 或 `inf`，而且只在特定数据分布下暴露，极难复现。
- 成分坍缩的症状是「某簇的权重趋近 0、协方差趋近 0」：监控 `min(π)` 和 `min(det(Σ))` 两个量，比监控似然更早发现问题。坍缩后的模型看似似然很高，实际退化成了「一个高斯 + 噪声」。
- BIC 选 K 的工程口径：每个 K 跑 `n_init` 次取最优，再比 BIC；BIC 曲线通常在真 K 后抬升（惩罚起作用），抬升点就是工作点。ex08/ex09 的似然打印格式（每轮 L 与 ΔL）直接可作为收敛监控。
- 预测时的口径注意：GMM 给 `predict`（硬）和 `predict_proba`（软）两套 API——下游做「边界样本人工复审」时用 `predict_proba` 挑 γ 接近 0.5 的点，比硬分类后瞎猜高效得多。

### 🎓 博士生视角

- 下界构造是 EM 的**唯一本质**：`L(q,θ) = log p(X|θ) − KL(q‖posterior)`，E 步令 KL=0（变分后验精确），M 步在 `q` 固定的前提下最大化 L。任何「EM 变体」（如变分自编码器的重参数化思路）都是把这个 KL 换成可计算的近似——那是 ai 学科的衔接点，本学科只用到精确后验这一档。
- 单调收敛的证明链：E 步 `log p(θ_t) = L(q_t, θ_t)`（贴紧）；M 步 `L(q_t, θ_{t+1}) ≥ L(q_t, θ_t)`（最大化）；下一轮 E 步 `log p(θ_{t+1}) = L(q_{t+1}, θ_{t+1}) ≥ L(q_t, θ_{t+1})`（KL ≥ 0）。三行不等式给出全局单调性，不依赖任何凸性——**EM 不要求问题是凸的**，这是它相对梯度法的独特优势，也是它只能到局部最优的原因。
- 收敛速度由**缺失信息比例**决定：Louis (1982) 的观测信息矩阵 `I_obs = I_com − I_mis`，缺失信息越多线性收敛越慢。坏初始化（中心远离真簇）意味着观测信息严重缺失，表现为似然爬升缓慢——与 ex08 的实测一致。
- GMM ↔ K-means 的严格关系：等方差球形 GMM 在 `σ² → 0` 时，最大化似然等价于最小化畸变（对数似然中的指数项支配），γ → one-hot。两者是**同一族模型的两个极限**，K-means 不是 GMM 的「近似实现」而是它的退化切片。
- BIC 的渐近理论（Schwarz 1978）：`BIC` 是 `log` 边际似然的 Laplace 近似，一致性要求维数固定、N→∞。K 随 N 增长时 BIC 失效，需要 larger-penalty 的准则（如 AIC3、Cp 一族的扩展）——这是模型选择理论本身的活跃区。

### 📚 考研者视角

- 必考推导：**EM 下界构造**。三步（引入 q → Jensen → KL 恒等式）要能默写，并说明「E 步取后验使 KL=0」「M 步使下界抬升」如何拼出单调性。
- 必考推导：**GMM 的 M 步四个闭式更新**（N_k、π_k、μ_k、Σ_k），由 `Q(θ)` 对相应参数求导置零得到；μ_k 是软加权均值这一句要点明。
- 标准表述题：**responsibility 的定义** `γ_nk = π_k N(x_n|μ_k,Σ_k) / Σ_j π_j N(x_n|μ_j,Σ_j)`，以及它作为后验 `p(z_n=k|x_n)` 的身份。
- 关系题：**GMM 与 K-means 的联系与区别**。联系：`Σ_k = σ²I`、`σ→0` 时 E 步退化为最近邻分配、M 步退化为簇内均值；区别：软/硬分配、似然/畸变口径、簇形状自由度。
- 计算题口径：BIC 公式 `log p(X|θ̂) − (p/2) log N` 与 GMM 的参数量 `K−1 + Kd + Kd(d+1)/2`（完整 Σ）；选 BIC 最大的 K。
- 易混：**EM 收敛 ⟂ 全局最优**（只保证驻点）；**似然大 ⟂ K 选对**（K 越大似然必高，必须惩罚）；**E 步的 q 是后验不是先验**；**μ_k 更新是「软加权」不是「硬分桶后求均值」**——γ 的权重缺一格都不对。
