# ml-ch06 · 无监督学习与降维：聚类、谱方法与 PCA

> 先修：ml-ch01（向量空间、特征值直觉）、ml-ch05（高斯混合与 EM——K-means 是它的极限）。
> 后续：ml-ch08（评估与特征工程，聚类结果怎么评）、ai 学科（非线性流形学习用神经网络表达）。
> 面试权重：★★★★☆（K-means/PCA 几乎必问；谱聚类和 t-SNE 的「距离不可解释」是区分度题）

## 本章目标

学完你应该能：

1. **把 K-means 写成「最小化簇内平方和的 Lloyd 迭代」**：说清目标函数、每步为何保证目标不增
   （单调收敛）、K-means++ 为什么比随机初始化好、肘部法与轮廓系数怎么选 k。
2. **指出 K-means 的失效场景**：球状等方差假设、对尺度/离群敏感、不能处理非凸簇，
   并知道 DBSCAN 与谱聚类分别如何补这些洞。
3. **实现 DBSCAN 并讲清三件套**：核心点（邻域内 ≥ minPts）、边界点、噪声点，
   以及 ε 与 minPts 如何共同决定密度阈值；层次聚类的单链接/全链接/平均链接差异。
4. **推导谱聚类的图拉普拉斯与松弛**：未归一化/对称归一化/随机游走三种拉普拉斯，
   RatioCut 与 Ncut 如何被松弛成「取拉普拉斯前 k 小特征向量」，以及为什么它能切非凸簇。
5. **用 SVD 实现 PCA 并解释两个等价视角**：最大方差投影 ≡ 最小重构误差，
   方差解释率怎么算、白化做什么、标准化为什么影响主方向。
6. **分清降维方法的适用边界**：核 PCA 处理非线性、t-SNE/UMAP 保局部邻域但**距离不可解释**，
   能说出「t-SNE 图上点之间的距离没有意义」为什么是真的。

## 关键认知（本章最值钱的三句）

- **「相似」本身就是假设**：聚类/降维没有标签，算法用「距离/相似图」替你定义了「什么叫近」，
  你选的度量（欧氏/余弦/高斯核）直接决定了簇的形状——这不是细节，是模型的归纳偏置。
- **K-means 假设簇是「球状、等方差、同密度」**：一旦真实簇是月牙、环、各向异性，它必翻车；
  此时要么换度量（谱），要么换密度定义（DBSCAN），而不是调 k。
- **t-SNE/UMAP 只承诺「邻域关系」，不承诺「全局距离」**：在它的图上看簇间远近、看异常点是**错觉**；
  真要做定量距离，回到 PCA 或原始空间。

## 与「深度学习」的分界（避免与 ai 学科混淆）

本章是**线性/核/图**驱动的经典降维与聚类。深度学习从**自编码器/表示学习**讲起——AE 用神经网络
把 PCA 推广成非线性，但「最大方差/最小重构」「邻域保持」这些第一性原理属于本章。

工程分界：

| | 经典降维/聚类（本学科） | 深度表示学习（ai 学科） |
|---|---|---|
| 映射 | 线性（PCA）/ 核 / 图拉普拉斯 | 神经网络 encoder |
| 可解释 | 主成分是线性组合，可解释 | 隐空间难解释 |
| 规模 | 稠密 SVD 受 `O(d³)`，需近似 | 可扩展到大图/大图像 |
| 非线性 | 靠核技巧（手动选核） | 自动学（端到端） |

非线性流形（如图像流形）用核 PCA/UMAP 只够「探索性」；要拿它做特征，才上自编码器——那是 ai 学科。
