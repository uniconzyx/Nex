# fund-ch05 · 查找与哈希

> 先修：fund-ch03（树与二叉树，B 树在 ch03 已初步接触，本章补查找口径）。衔接：fund-ch06（排序与复杂度，查找与排序的 ASL/判定树同源）。
> 学科归属：408 数据结构（严蔚敏教材第 8 章「查找」）。面试权重：★★★★☆（哈希表几乎必问，B 树是数据库/OS 文件系统的底层）。

## 本章目标

学完你应该能：

1. **说清「平均查找长度 ASL」这一统一口径**：ASL(成功) 与 ASL(失败) 的加权定义，并能在顺序/折半/分块/哈希四种结构上手算。
2. **手算折半查找的判定树**：给出长度 n，画出判定树、判定其高度 = ⌈log₂(n+1)⌉、写出最坏/平均比较次数，并指出「判定树是平衡二叉树、失败结点 = n+1 个」。
3. **分块查找的折中本质**：块间有序、块内无序，索引表 + 顺序/折半定位块 + 块内顺序查；给出其 ASL 近似公式并解释为何介于顺序与折半之间。
4. **写出 B 树与 B+ 树的阶/高度/关键字数约束**：m 阶 B 树每个非根结点关键字数 ∈ [⌈m/2⌉−1, m−1]，根 ∈ [1, m−1]；能由结点数反推高度上界；能讲清 B+ 树「数据只在叶子、叶子链表串联」与 B 树「数据分布各层」的根本差异。
5. **构造哈希表并统计探测次数**：除留余数法取模，冲突处理对线性探测/二次探测/双重散列/拉链法分别写出地址递推式、装填因子 α 的影响、以及查找成功/失败的 ASL。
6. **工程选型**：在「哈希 vs B 树 vs 跳表 vs 有序数组」之间按读多写少/范围查询/磁盘 IO 维度做取舍。

## 复杂度目标（面试要能脱口而出）

| 查找方式 | 最坏 | 平均（成功） | 失败 | 备注 |
|---|---|---|---|---|
| 顺序查找 | O(n) | (n+1)/2 | n+1 | 对有序无序均适用 |
| 折半查找 | O(log n) | ≈ log₂(n+1)−1 | ⌈log₂(n+1)⌉ | 要求**有序** |
| 分块查找 | O(√n) | (s+b)/2+1 | 块间+块内 | s 块数、b 块长 |
| 哈希（理想） | O(n) | O(1+α) | O(1+α) | 依赖散列质量 |
| B 树查找 | O(log_t n) | O(log n) | O(log n) | t 为最小度，磁盘友好 |
