# 学习目标 · 计算机组成原理：数据表示与运算

> 408 考研「计算机组成原理」第二章核心。本章解决一个问题：**机器里只有 0 和 1，凭什么能表示负数、小数、和"精度"？**

## 一、知识目标

学完本章，你应当能够：

1. **说清四种机器数**：原码、反码、补码、移码的定义、相互关系、各自能表示的数值范围，
   以及为什么**只有补码被现代计算机采用**（加减法统一、无 ±0 二义性）。
2. **独立完成补码加减运算**并判断溢出：单符号位（进位异或）与双符号位（变形补码）两种判据都要会。
3. **拆解 IEEE 754 单/双精度**：符号位、阶码（**偏置**而非补码）、尾数（**隐含最高位 1**），
   会手算「十进制 ↔ 位模式」的双向转换，会判断规格化数/非规格化数/Inf/NaN。
4. **说清浮点运算五步**：对阶 → 尾数加减 → 规格化 → 舍入 → 溢出判断；并能指出**对阶丢低位**是误差主源。
5. **掌握常见陷阱**：`0.1 + 0.2 != 0.3` 的位级原因、整数溢出（UB 与模回绕的区别）、
   隐式类型转换与整数提升、大端/小端的判定方法、舍入模式（就近偶数）与截断的区别。

## 二、能力目标

- 能对给定的 C 代码**预测**其位级行为（而不是靠"跑一下看看"）；
- 能在工程中**主动选择**类型：什么时候用 `int64_t`、什么时候用定点数、什么时候必须用 `double`；
- 能读懂「浮点累加误差」「金额用 double 出错」这类真实事故的根因并给出修法。
