# fund-ch07 · 数据表示与运算实战：凯喵的位运算现场

> §1–§4 讲表示法，这一节用可算的片段把「为什么会错」钉死。计组选择题爱考边界，下面每条都是真题级陷阱。

### 原码补码反码：为什么计算机用补码

原码有 ±0、加减要分符号；反码有循环进位麻烦；**补码**让减法变加法（加负数），符号位自然参与运算，且只有一套 0。现代机器清一色补码，不是历史偶然。

### 补码加法的统一之美

`A - B` 直接算成 `A + (~B + 1)`。凯喵验证：8 位下 `5 - 3` = `00000101 + 11111101` = `0000010`（进位溢出丢弃），结果是 2，正确。一套加法器搞定加减。

```python
def sub8(a, b):
    return (a + ((~b & 0xFF) + 1)) & 0xFF   # 补码减法：加负数
print(sub8(5, 3), sub8(0, 1))              # 2, 255(即 -1)
```

### 溢出如何判定（符号位 + 进位）

同号相加、结果符号却变了，就是溢出。硬件用「最高位进位 ⊕ 符号位进位」判定。凯喵提醒：进位和溢出不是一回事——无符号看进位，有符号看溢出。

### IEEE754 为什么 0.1 + 0.2 ≠ 0.3

0.1 在二进制里是无限循环小数，IEEE754 单/双精度只能近似存储，两次近似相加的误差累加，结果变成 `0.30000000000000004`。这是表示误差，不是 bug。

```python
print(0.1 + 0.2)          # 0.30000000000000004
print(abs(0.1+0.2-0.3) < 1e-9)   # True，用容差比较
```

### 规格化与隐藏位

IEEE754 尾数隐含一个前导 1（规格化数），省一位精度；非规格化数（指数全 0）没有隐藏位，用来表示极接近 0 的数，避免突然下溢到 0。

### 位运算的奇技：交换/判奇偶/取模

异或 `a ^= b; b ^= a; a ^= b` 可不用临时变量交换；`x & 1` 判奇偶；`x & (n-1)` 当 n 是 2 的幂时等价于 `x % n`。凯喵在底层优化里常用 `x & -x` 取最低置位。

```c
int lowbit(int x){ return x & -x; }   // 提取最低位的 1
```

### 算术移位 vs 逻辑移位

**有符号数右移**是算术移位（补符号位），保持符号；**无符号右移**是逻辑移位（补 0）。左移两者一致。凯喵提醒：`-1 >> 1` 在 C 里多数实现仍是 -1（算术右移），别想当然。

### 浮点比较必须用容差

永远别写 `if (a == b)` 比较两个浮点。用 `abs(a-b) < eps`。凯喵见过用 `==` 判相等导致循环不终止的死循环。

### 大数吃小数：累加求和的坑

`1e7 + 1.0` 在单精度里仍是 `1e7`——大数尾数位宽有限，小数被舍入掉。大量累加要改用 `double`、Kahan 补偿求和，或按绝对值从小到大排序后相加。

### 字长边界：溢出前的预警

8 位有符号范围 `[-128,127]`，`127 + 1` 会绕成 `-128`（补码回卷）。写循环、做计数、解析协议长度字段时，先把边界算清楚，别让输入把你推过边界。

### 补码范围速算

n 位有符号补码范围一眼算：`[-2^(n-1), 2^(n-1)-1]`。8 位就是 `[-128, 127]`，16 位是 `[-32768, 32767]`。

```python
print(-(2**7), 2**7 - 1)    # -128 127
print(-(2**15), 2**15 - 1)  # -32768 32767
```

### 用位运算判定 2 的幂

`x & (x-1)` 会把最低位的 1 清掉；若结果为 0 且 x>0，说明只有一个 1，即是 2 的幂。

```c
int is_pow2(int x) { return x > 0 && (x & (x - 1)) == 0; }
```

### 浮点相等的容差比较

永远别直接 `==` 比浮点。用相对/绝对容差，封装成函数复用。

```python
def feq(a, b, eps=1e-9):
    return abs(a - b) < eps
```
