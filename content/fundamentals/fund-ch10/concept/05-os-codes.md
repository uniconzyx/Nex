# fund-ch10 · 内存管理、文件与 IO 实战

### 分页地址翻译（逻辑 → 物理）

逻辑地址 = 页号 + 页内偏移；用页表把页号换成页框号，偏移原样拼接。

```python
PAGE = 4096
logical = 0x2A3F
pno, off = logical // PAGE, logical % PAGE
frame = page_table[pno]          # 查页表
physical = frame * PAGE + off
```

### 页表项与多级页表

32 位地址、4KB 页、4 字节 PTE → 单级页表需 `2^20` 项 ≈ 4MB 常驻；二级页表只展开用到的目录项，省内存。

### LRU 页面置换模拟

维护访问栈，命中则提到栈顶，缺页则淘汰栈底。

```python
def lru(pages, cap):
    mem, faults = [], 0
    for p in pages:
        if p in mem:
            mem.remove(p); mem.append(p)
        else:
            if len(mem) == cap: mem.pop(0)
            mem.append(p); faults += 1
    return faults
print(lru([1,2,3,1,4,2,3], 3))   # 5 次缺页
```

### 银行家算法安全检查

对每进程记录 `Max`、`Allocation`，计算 `Need = Max − Allocation`；找 `Need ≤ Available` 的进程放行并回收，能全放行则安全。

### 磁盘调度（SCAN / LOOK）

SCAN 像电梯：磁头沿一个方向扫描，到端点才反向；LOOK 是「无请求即反向」的优化版，少走冤枉路。

### 文件分配（连续 / 链表 / 索引）

连续分配快但易碎片；链式分配无随机访问；索引分配（如 UNIX inode 的 12 直接 + 间接块）兼顾随机访问与灵活性。

### 空闲空间管理（位示图 / 成组链接）

位示图 O(1) 查询但元数据常驻内存；成组链接把空闲块自身当存储，省额外空间但每次分配要读盘。

### IO 控制方式（轮询 / 中断 / DMA）

轮询占 CPU；中断在完成后通知；DMA 让设备直接读写内存、只在起止时打扰 CPU，大幅降开销。

### 缓冲与 spooling

缓冲平滑生产/消费速度差；spooling 把独占设备（打印机）的「作业」排队进磁盘，变独占为共享。

### 虚拟文件系统 VFS 抽象

VFS 用统一 inode/文件操作接口屏蔽底层文件系统差异，上层 open/read 无需关心是 ext4 还是 NTFS。

## 三视角解析
### 🧑‍💻 程序员视角
凯喵线上遇到「内存看着够、进程却被 OOM kill」，查下来是 `RSS` 与 `VSZ` 的区别没搞清：`VSZ` 是虚拟地址空间大小，`RSS` 是实际驻留的物理页。分页地址翻译手算时最容易错的是「页内偏移位数 = log₂(页大小)」，剩下才是页号；多级页表则要按「每级页表项数 = 页大小 / 页表项大小」逐级切分地址。页面置换的 LRU 用栈实现最直观，但真实系统很少用严格 LRU（每次访问都要更新链表太贵），Linux 用「时钟算法（clock）」近似，靠访问位轮转。

### 🎓 博士生视角
虚拟内存的三个目标——隔离、抽象、超额分配——都建立在「页表」这一间接层上。多级页表用「稀疏映射」换取空间：一级页表未使用的项可以直接不分配二级页表，代价是 TLB 缺失时多几次访存。页面置换的最优算法 OPT（替换未来最久不用的页）不可实现，但它给出了性能上界，也用来证明 LRU 的「栈算法」性质：LRU 的命中率随容量单调不减，FIFO 则会出现 Belady 异常（增加页框反而缺页更多）。工作集模型（working set）用最近 Δ 次访问的页集合刻画局部性，是「抖动」治理的理论依据。

### 📚 考研者视角
408 内存与文件管理是计算题密集区：
1. **地址翻译**：给逻辑地址、页大小，求页号与页内偏移；多级页表按「页目录索引 / 页表索引 / 偏移」切分。注意「页表项大小决定一页能放多少项」。
2. **页面置换**：给访问串与页框数，分别用 OPT、FIFO、LRU 算缺页次数。OPT 要往后看最远，LRU 要往前看最近，别搞反。
3. **有效访问时间**：`EAT = 命中率 × (TLB + 访存) + 缺失率 × (TLB + 两级访存 + 缺页处理)`，按题意逐项累加。
4. **磁盘调度**：FCFS、SSTF、SCAN、CSCAN、LOOK 的磁头移动总距离，画数轴逐段加。
5. **文件分配**：连续、链接、索引三种的优缺点；索引分配下「给文件大小求需要几个索引块」。
