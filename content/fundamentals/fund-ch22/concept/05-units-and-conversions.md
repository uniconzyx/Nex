# 单位与换算：这一章最容易丢分的隐形战场

> 物理层的题目，十道里有三道的答案是一个数字。算错不是思路问题，是**单位没换**。
> 本节把本章反复出现的换算收成一张速查表：dB 与倍数、波特率与比特率、带宽与时延、
> 采样频率、以及内存与硬盘两种"千进制"。考前扫一遍，比多刷两道题划算。

### 一、dB 与倍数：只背一条换算就够

dB 是**比值**的对数表达，不是绝对量。功率比：

$$P_{dB} = 10\log_{10}\frac{P_2}{P_1}$$

由此得到三条必背结论：**功率翻倍 = +3dB**，**功率变成 1000 倍 = +30dB**，**30dB 对应信噪比 1000:1**。
题目若给"信噪比 30dB"，代入香农公式前必须先换成 1000，写成 $\log_2(1+1000)=9.97$ bit/符号；
直接把 30 代进去会得到 $\log_2(31)\approx 4.95$，整道题连带"取 min"全错。

幅度比（电压、电流）用的是 $20\log_{10}$，所以**幅度翻倍 = +6dB**。考试不会直接考这个换算，
但会考"同一个 dB 数对应功率还是幅度"，答错方向就整体错一倍。

### 二、波特率、比特率、符号率：三个名字两种含义

一个码元携带 $\log_2 V$ bit，这是**调制**带来的。链路上：

- **波特率（Baud）** = 码元速率 = 每秒传多少个码元；
- **比特率（bps）** = 波特率 × $\log_2 V$。

用 16-QAM（$V=16$，每码元 4 bit）跑 2400 Baud，得到的比特率是 9600 bps —— 这正是
调制解调器标称"最高 9600bps"的由来。写题时务必看清问的是 Baud 还是 bps：
问 Baud 用波特率，问 bps 要乘 $\log_2 V$。这也是曼彻斯特编码带宽利用率只有 50% 的原因：
它 1 bit 占 2 个码元，等于 $\log_2 V = 1$。

### 三、带宽、时延与 BDP：别把"快"和"早到"混为一谈

链路有两个互不相干的量：

- **传输时延** = 数据长度 ÷ 发送速率 → 加带宽能变小；
- **传播时延** = 距离 ÷ 信号速度 → **加带宽完全无效**。

卫星链路单程 36000km，传播时延约 120ms，无论多快都省不掉。工程上更常用 **BDP**
（带宽时延积）来描述"链路上同时能塞多少数据"：

$$BDP = \text{带宽} \times \text{传播时延}$$

例：1Gbps × 100ms = 100Mbit = 12.5MB。TCP 初始窗口小于 BDP，就会在长肥管道上白白等待，
这正是"带宽高不等于下载快"的根源。填空时注意 BDP 用**比特**还是**字节**，差 8 倍。

### 四、采样定理：模拟转数字的门槛

对最高频率为 $f$ 的模拟信号，采样频率至少要 $2f$ 才可能无失真还原（奈奎斯特采样定理），
工程上还要留余量，通常取 44.1kHz 对应 20kHz 的人声频段。这一条常出现在"采样率与量化"
的选择题里，和前面"信噪比决定电平数"是同一类考点：**都是"上限由物理量决定"的题**。

### 五、两种"千进制"：内存与硬盘

内存按 2 的幂算（1KB = 1024B，1MB = 1024KB），硬盘厂商按 10 的幂算（1GB = 1000MB）。
所以标称 500GB 的硬盘，系统里显示约 465GiB，差值就是进制换算造成的，不是被偷了容量。
凡是"文件大小、剩余空间、传输时间"类计算，先确认题目给的是 GiB 还是 GB。

```text
┌──────────────────────────────────────────────┐
│  30 dB  →  功率 ×1000  →  log2(1+1000) ≈ 9.97 bit/符号 │
│  16-QAM →  每码元 4 bit  →  2400 Baud = 9600 bps  │
│  1 Gbps × 100 ms → BDP 100 Mbit = 12.5 MB       │
│  采样 ≥ 2 × 最高频率  →  20 kHz 音频取 44.1 kHz   │
│  500 GB(10³) ≈ 465 GiB(2¹⁰)                    │
└──────────────────────────────────────────────┘
```

```python
# 三个换算写成函数，考试时照着抄思路
import math

def db_to_ratio(db: float) -> float:
    """dB -> 功率倍数（30dB = 1000）"""
    return 10 ** (db / 10)

def shannon_bits_per_symbol(db: float) -> float:
    """香农：信噪比给 dB 时必须先换成倍数"""
    return math.log2(1 + db_to_ratio(db))

def bit_rate(baud: int, levels: int) -> int:
    """比特率 = 波特率 × log2(V)"""
    return baud * math.log2(levels)

def bdp_bytes(bps: int, delay_ms: float) -> float:
    """带宽时延积（字节）"""
    return bps * (delay_ms / 1000) / 8

print(round(shannon_bits_per_symbol(30), 2))   # 9.97
print(bit_rate(2400, 16))                      # 9600
print(round(bdp_bytes(1e9, 100), 1))            # 12500000.0
```

## 三视角解析
### 🧑‍💻 程序员视角
凯喵买了一块「1TB」硬盘，装到系统里只有 931GB，第一反应是被坑了。其实是两种千进制：厂商按 `10^12` 字节标称，操作系统按 `2^40` 显示，`10^12 / 2^40 ≈ 0.909`。网络侧同理：千兆网卡是 1Gbps（bit），实际下载速度上界约 125MB/s，再扣掉 TCP/IP 头与握手开销，跑满 110MB/s 就算合格。**凡是看到 b 与 B、10 的幂与 2 的幂，先停下来换单位再算**——物理层题目里，一半的错误都不是思路错，而是这一步。

### 🎓 博士生视角
dB 的定义依赖被测量的物理量性质：功率/能量类用 `10log₁₀(P₂/P₁)`，幅度/电压类用 `20log₁₀(A₂/A₁)`，因为功率正比于幅度平方。混淆这两者会差一倍（3dB 变 6dB），这是工程实践里最常见的量纲错误。香农容量 `C = B log₂(1 + S/N)` 中的信噪比必须以**线性倍数**代入，若题目给的是 dB，先按 `S/N = 10^(dB/10)` 还原。采样定理 `f_s ≥ 2f_max` 是充分条件而非必要条件——带通信号可以用低于 2f_max 的速率采样（带通采样），只要不产生频谱混叠，这一点在软件无线电里被大量使用。

### 📚 考研者视角
本章的换算题只有六条主线，考前默写一遍即可：
1. **dB 与倍数**：功率翻倍 = +3dB，10 倍 = +10dB，1000 倍 = +30dB。给信噪比 dB 求倍数用 `10^(dB/10)`。
2. **奈氏与香农**：`C = 2W log₂V`（无噪声、V 为码元种类）、`C = W log₂(1+S/N)`（有噪声）。两式常同时出现，问「实际能到多少」取较小值。
3. **波特率与比特率**：`比特率 = 波特率 × log₂V`，V 是调制电平数。
4. **编码效率**：4B/5B 是 80%，8B/10B 是 80%，64B/66B 约 97%。
5. **存储单位**：`1TB = 10^12 B`（厂商标称）vs `1TiB = 2^40 B`（系统显示）。
6. **时延与带宽积**：`传播时延 = 距离 / 光速`（光纤约 `2×10^8 m/s`），`时延带宽积 = 带宽 × 传播时延`，代表「管道里能装多少比特」。
