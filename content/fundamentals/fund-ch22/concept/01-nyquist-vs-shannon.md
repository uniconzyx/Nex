# 信道容量：奈氏与香农，两个上限取较小值

## 1. 背景/动机

"这条线最快能跑多少？"——这是物理层最根本的问题。答案来自两个完全不同的角度：

- **奈奎斯特（Nyquist）**：从**信号能抖多快**出发。带宽 $W$ 决定了每秒最多能传多少个码元（$2W$），电平数 $V$ 决定了每个码元能载几个比特。这是**无噪声**的理想上限。
- **香农（Shannon）**：从**信息能抗多少噪声**出发。噪声会淹没电平，所以即使你无限细分电平，能可靠传输的信息量也有一个天花板。

工程上必须**同时满足两者**，所以极限速率 = $\min(\text{奈氏}, \text{香农})$。这条"取小"是 408 大题的必备步骤。

## 2. 定义/要点

### 两个公式：一个是码元上限，一个是信息上限

$$\text{奈氏（无噪声）}: \quad C = 2W\log_2 V \quad\text{(bps)}$$

$$\text{香农（有噪声）}: \quad C = W\log_2\left(1 + \frac{S}{N}\right) \quad\text{(bps)}$$

| 符号 | 含义 | 常见取值 |
|---|---|---|
| $W$ | 信道带宽（Hz） | 电话线 3kHz、WiFi 20/40/80MHz |
| $V$ | 码元的离散电平数（星座点数） | 2（NRZ）、4（QPSK）、16（16-QAM） |
| $S/N$ | 信噪比（**功率比，无量纲**） | 30dB → 1000 倍 |

### dB 与倍数：考场上最常错的一步

**dB 换算是必考点**：

$$\left(\frac{S}{N}\right)_{\text{倍}} = 10^{\,\text{dB}/10}$$

| dB | 10 | 20 | 30 | 40 |
|---|---|---|---|---|
| 倍数 | 10 | 100 | **1000** | 10000 |

```text
两个上限谁在起约束？（W=3kHz）

  速率
  40k ┤                       ╭──── 奈氏(V=16) = 24k 被封顶
       │                  ╭────╯

       │            ╭────╯

  10/20dB：香农 < 奈氏 → 噪声是瓶颈（提高电平数没用）

```

## 3. 可运行代码（C，含中文注释 + 真实输出）

```c
#include <stdio.h>
#include <math.h>
/* c01：奈氏 vs 香农 —— 两个上限，取较小者
 * 奈氏（无噪声）：C = 2W·log2(V)   —— 受「码元速率」限制
 * 香农（有噪声）：C = W·log2(1+S/N) —— 受「信噪比」限制
 * 实际系统必须同时满足两者，所以极限速率 = min(奈氏, 香农)。
 * 这条「取小」常被忘，408 大题里若只算一个就会丢分。*/
int main(void) {
    double W = 3000.0;
    double dbs[] = {10, 20, 30, 40};
    int    V[]   = {2, 4, 8, 16, 32};

    printf("带宽 W = %.0f Hz，比较不同信噪比下的两个上限\n", W);
    printf("--------------------------------------------------------------------------\n");
    printf("%-10s %-14s %-16s %-16s %s\n", "S/N(dB)", "V=2 奈氏", "V=16 奈氏", "香农", "实际可用");
    for (int i = 0; i < 4; i++) {
        double snr = pow(10.0, dbs[i] / 10.0);
        double shannon = W * log2(1.0 + snr);
        double n2 = 2.0 * W * log2(2.0);
        double n16 = 2.0 * W * log2(16.0);
        double best = (n16 < shannon) ? n16 : shannon;
        printf("%-10.0f %-14.0f %-16.0f %-16.0f %.0f\n", dbs[i], n2, n16, shannon, best);
    }
    printf("--------------------------------------------------------------------------\n");
    printf("读法：\n");
    printf("  1) 信噪比低时（10dB），香农只有约 10kbps，比奈氏（V=16 时 24kbps）更严 ——\n");
    printf("     说明「噪声」才是真瓶颈，光提高电平数没用；\n");
    printf("  2) 信噪比高时（40dB），香农 39.9kbps 超过奈氏上限，此时「码元速率」成了瓶颈；\n");
    printf("  3) 两个上限都不能突破：前者是物理定律，后者是采样定理。\n");
    return 0;
}
```

这张表最值得记住的是**最后两行**：信噪比从 30dB 提到 40dB（10 倍功率），香农上限从 29902 涨到 39864，但"实际可用"**卡在 24000 一动不动**——因为奈氏已经把 3kHz 带宽、16 电平的天花板钉死了。**这就是"取小"的物理含义：木桶的最短板决定容量。**

## 三视角解析

### 🧑‍💻 程序员视角

**真实工作场景**：办公室 WiFi 白天只有 30Mbps，夜里（没人用）能跑 300Mbps，而 AP 的协商速率明明写着 866Mbps。运维第一反应是"AP 性能不行"，换了个更贵的 AP，白天还是 30Mbps。

真因在**信噪比**：白天隔壁有 20 多个 AP 在同频段，$S/N$ 从 40dB 掉到 15dB 左右。按香农，80MHz 带宽下：

- $S/N=40\text{dB}$（10000 倍）→ $C = 80\text{M} \times \log_2(10001) \approx 1.06\text{Gbps}$（理论上限，实际协商 866M）
- $S/N=15\text{dB}$（31.6 倍）→ $C = 80\text{M} \times \log_2(32.6) \approx 402\text{Mbps}$

再叠加**调制降阶**（信噪比差时从 256-QAM 退到 QPSK，每码元比特从 8 降到 2），实际吞吐掉到 30Mbps 完全合理。**换 AP 不解决干扰，换信道/上 5GHz/加 AP 密度才解决。**

这给你一个可操作的判断法则：**如果 Wi-Fi 慢但信号格数满，八成是同频干扰**（信号强 ≠ 信噪比高）。用 `iw dev wlan0 link` 看 `signal` 与 `tx bitrate`，再看 `iw dev wlan0 scan | grep -i ssid` 数一下同频 AP 数量就清楚了。

### 🎓 博士生视角

奈氏与香农分别对应两个信息论/信号处理的基石：

- **奈氏**背后是**采样定理**：带宽 $W$ 的信号，每秒最多能分辨 $2W$ 个独立样本（每个周期正负半周各一个码元）。这是**时域自由度**的上限，与噪声无关。
- **香农**背后是**信道编码定理**：在噪声下，只要速率低于 $W\log_2(1+S/N)$，就**存在**一种编码使误码率任意小。注意它是**存在性**结论，不告诉你码怎么设计——LDPC/Turbo/Polar 码都是在逼近这个界。

两者相乘得到工程上的"频谱效率"概念：

$$\eta = \frac{C}{W} \le \log_2(1 + S/N) \quad \text{(bit/s/Hz)}$$

| 系统 | 频谱效率（bps/Hz） | 手段 |
|---|---|---|
| 2G GSM | ~0.3 | GMSK |
| 4G LTE | ~3 | 64-QAM + MIMO 2×2 |
| 5G NR | ~10-30 | 256-QAM + Massive MIMO + 大带宽 |
| 香农界（30dB） | **9.97** | 单天线理论上限 |

5G 能超过单天线香农界，靠的是**空间维度**（MIMO 把它变成"多根独立的管道"）——这提醒我们：**香农界是"给定带宽与信噪比"下的界，一旦引入空间/极化/码域这些新维度，界本身要重写。** 本章后面的 CDMA 就是"码域维度"的第一次引入。

### 📚 考研者视角

**408 高频考法**：

1. **给带宽、信噪比、电平数，求最大速率**（综合题常客）。标准三步：
   ① 算香农 $C_s = W\log_2(1+S/N)$（先做 dB→倍数换算！）；
   ② 算奈氏 $C_n = 2W\log_2 V$；
   ③ 取 $\min(C_s, C_n)$，并说明**谁在起约束**（这句话经常单独给分）。
2. **只给"信噪比 30dB、带宽 3kHz"求上限**：答案 29.9kbps ≈ 30kbps。记住这个经典结论，选择题常直接考。
3. **"采用 4 电平，带宽 3kHz，无噪声，求速率"**：$2 \times 3000 \times \log_2 4 = 12000$ bps。**注意 2W 的 2**。
4. **波特率↔比特率**：给码元率和调制方式求比特率（乘 log₂V），或反过来。
5. **问"为什么不能无限提高电平数"**：因为噪声会缩小电平间隔，$V$ 增大必然误码；实际 $V$ 由 $S/N$ 决定，这也正是香农界存在的原因。

**易错点**：
- dB 直接当代数用（最常见）；
- 奈氏漏乘 2；
- 只算一个上限；
- 把"波特率"当"比特率"（题目问 bps 时答成 Baud）。
