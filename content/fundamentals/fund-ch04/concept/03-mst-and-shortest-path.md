# 最小生成树与最短路径：贪心 vs 动态规划

## 1. 最小生成树（MST）：两个贪心，一个正确性的根基

**问题**：带权连通无向图，选 V-1 条边连通所有点，且总权最小。

### 1.1 为什么贪心是对的 —— cut 性质与 cycle 性质

这两条定理是 MST 算法的**全部理论地基**，必须理解而非背诵：

- **Cut 性质**：把顶点切成两半 (S, V−S)，横跨这个切分的**最小权边一定属于某棵 MST**。
- **Cycle 性质**：任意环上**权最大的边一定不属于某棵 MST**（对严格最大边成立）。

**Cut 性质为什么成立**（反证）：设横跨切分的最小边为 e，某 MST 不含 e。
把 e 加进这棵 MST 必然形成环，该环上一定有另一条横跨该切分的边 f（否则 S 与 V−S 不通）。
由于 w(e) ≤ w(f)，用 e 替换 f 得到总权不增的树——所以存在含 e 的 MST。∎

- **Prim** 就是「维护一个切分（已选集合 S 与未选集合），每次取横跨最小边」→ 直接应用 cut 性质。
- **Kruskal** 就是「按权升序考虑边，若不成环就收下」→ 应用 cycle 性质（成环时该边正是环上最大边）。

### 1.2 Prim vs Kruskal 怎么选

| | Prim（堆优化） | Kruskal |
|---|---|---|
| 复杂度 | O((V+E) log V) | O(E log E)（排序主导） |
| 更适合 | **稠密图**（朴素版 O(V²) 无堆开销） | **稀疏图** |
| 中间状态 | 始终是一棵树 | 是森林，逐步合并 |
| 实现依赖 | 优先队列 | **并查集** |
| 工程优势 | 可增量（加点即扩树） | **天然并行**：排序后可批量处理；适合分布式 |

直觉：**边多到接近 V² 时用 Prim 朴素版（省掉堆的 log）；边稀疏时 Kruskal 的排序代价更小且更好写。**

## 2. 最短路径：三条路线与它们的能力边界

### 2.1 Dijkstra —— 贪心，但要求**非负权**

```
dist[s]=0，其余 ∞；重复 V 次：
  取未确定中 dist 最小者 u，标记确定；
  对 u 的每条出边 (u,v,w)：若 dist[u]+w < dist[v] 则松弛
```

**正确性为什么依赖「非负权」**（这是面试必问）：
Dijkstra 的核心断言是「当前 dist 最小的未确定点 u，其 dist 就是最终值」。
证明：若存在更短路径 s→…→x→u，则路径上 x 在 u 之前被确定，且 `d(x) + w(x,u) ≥ d(x)`（因 w ≥ 0），
故 `d(x) ≤ 更短路径长度 < d(u)`，与「u 是最小者」矛盾。∎
**一旦允许负权，这个「前缀不比自己更长」的推理就断了**——因为 `d(x) + w(x,u)` 可能小于 `d(x)`。

**反例**（务必能手绘）：
```
s ──3──> a ──(-4)──> b
└─────────5──────────>┘
Dijkstra：先确定 b=5（最小），再确定 a=3；此后 b 已"确定"，不再更新 → 错误地得到 b=5。
真实最短路：s→a→b = 3 + (-4) = -1。
```

**实现要点**：
- 朴素 O(V²)：稠密图反而更快（无堆操作，循环体是纯数组）。
- 堆优化 O((V+E) log V)：稀疏图标准做法。注意用**「懒删除」**（重复入堆，出堆时判断是否已确定），
  而不是「减小键」（标准库优先队列不支持 decrease-key）。
- **堆优化版会产生 V+E 次入堆**，空间 O(E)，别写成 O(V)。

### 2.2 Bellman-Ford —— 允许负权，还能判负环

```
重复 V-1 轮：对每条边 (u,v,w) 松弛
第 V 轮若仍能松弛 ⇒ 存在从 s 可达的负环
```

- **为什么是 V-1 轮**：一条最短路在无负环时最多含 V-1 条边；每轮至少把「第 k 条边的最优值」确定下来。
- **负环判定**：最短路若含 V 条边以上，必然重复经过某顶点，即为负环，可无限松弛。
- **工程价值**：SPFA（队列优化版）在随机图上很快，但**最坏仍是 O(VE)**，
  竞赛里常因被卡而弃用。工业上更多用于**差分约束系统**（`x_v - x_u ≤ w` 转图后判可行性）。

### 2.3 Floyd —— 全源，本质是区间 DP

```
for k: for i: for j:  d[i][j] = min(d[i][j], d[i][k] + d[k][j])
```

- **k 必须在外层**：`d_k[i][j]` 表示「只允许经过前 k 个点做中转」的最短路，
  状态转移是 `d_k[i][j] = min(d_{k-1}[i][j], d_{k-1}[i][k] + d_{k-1}[k][j])`。
  k 放内层会破坏这个阶段划分——这是最常见的写错方式。
- 空间可省掉第一维（就地更新），因为 `d[i][k]` 和 `d[k][j]` 在第 k 轮不会被修改（无负环时）。
- **V ≤ 几百** 才实用；V = 10⁵ 时需改用「对每个点跑 Dijkstra」或 Johnson 算法。

### 2.4 三者选择

| 场景 | 算法 | 复杂度 |
|---|---|---|
| 单源、非负权、稀疏 | Dijkstra + 堆 | O((V+E) log V) |
| 单源、非负权、稠密 | Dijkstra 朴素 | O(V²) |
| 单源、有负权 | Bellman-Ford | O(VE) |
| 全源、V 小 | Floyd | O(V³) |
| 全源、稀疏、非负 | V 次 Dijkstra | O(V·E log V) |
| 全源、稀疏、有负权 | Johnson（重赋权 + V 次 Dijkstra） | O(VE log V) |

**Johnson 的思路值得记**：用 Bellman-Ford 求一个势函数 h(v)，令 `w'(u,v) = w(u,v) + h(u) − h(v)`，
可证明 w' 全非负且**最短路不变**，于是能对每点跑 Dijkstra。这是「把问题转化到已知能解的空间」的典范。

## 3. 并查集：Kruskal 的正确搭档

```
find(x)：沿父指针向上，同时把路径上所有点直接挂到根（路径压缩）
union(a,b)：把秩小的树挂到秩大的树下（按秩合并）
```

- 单独用路径压缩：**最坏** O(log n)（可构造），**均摊**已很好；
- 单独用按秩合并：O(log n)；
- **两者合用：O(α(n))**，α 是反阿克曼函数，**对任何现实的 n（≤ 2^65536）都有 α(n) ≤ 4**，
  即实际视为常数。这就是为什么并查集被称为「近似 O(1)」。
- **常见错误**：只写 `parent[x] = x` 的初始化忘了；或 union 时按**树高（rank）**与**按大小（size）**
  混用却都叫 rank——两者都正确但语义不同，别混。

## 4. 一句话总结

> **MST 靠 cut/cycle 两个性质撑起贪心；最短路里 Dijkstra 的贪心严格依赖「非负权」，
> 一旦有权为负就换 Bellman-Ford（代价 O(VE)），要全源且 V 小就用 Floyd（k 必须在最外层）。**

## 三视角解析

### 🧑‍💻 程序员视角
- 路由协议的分野正是这两个算法：**OSPF 用 Dijkstra**（链路状态，全局已知拓扑），**RIP 是距离向量**（Bellman-Ford 思想的分布式版本）。
- 地图导航不会只用 Dijkstra：会叠加 A*（启发式）、Contraction Hierarchies（预处理加速）等把响应压到毫秒级。
- 工程提醒：Dijkstra 用优先队列时要用**惰性删除**（弹出时若已确定则跳过）而不是改键，实现简单且足够快。

### 🎓 博士生视角
- MST 两个贪心算法的正确性都归结为**切割性质**与**环性质**：任意切割的最小跨越边必属于某棵 MST；任一环上的最大边必不属于所有 MST。
- Dijkstra 与 Bellman-Ford 的对偶：前者是「贪心 + 非负权」的产物，后者是「反复松弛」；**负权边会破坏 Dijkstra 的「已确定最优」不变量**，故失效。
- Johnson 算法用势函数（先 Bellman-Ford 求 h，再重赋权 w+h(u)−h(v) ≥ 0）把全源最短路归约为多次 Dijkstra——这是「用势能消除负权」的漂亮技术。
- Floyd 是区间 DP：`d[i][j] = min(d[i][j], d[i][k] + d[k][j])`，状态转移隐含「允许经过前 k 个点」。

### 📚 考研者视角
- **408 必考手算题**：
  1. **Prim / Kruskal 构造最小生成树**——Kruskal 按边权从小到大选，选前判是否成环（并查集）；Prim 从任一顶点起，每步选连接已选集合的最小边；
  2. **Dijkstra 手算最短路表**——逐轮从未确定点中取 dist 最小者确定，再用它松弛邻居，表格要画全；
  3. **Floyd** 的矩阵逐步更新（三重循环）。
- 高频对比题：**Prim 适合稠密图（O(V²)）、Kruskal 适合稀疏图（O(E log E)）**。
- 记忆锚点：**「Dijkstra 不能处理负权边」**是年年考的判断题；**「MST 的权值唯一与否，与最大边是否唯一有关」**是易错点。
