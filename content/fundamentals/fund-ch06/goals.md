# fund-ch06 · 排序算法与复杂度分析

> 先修：fund-ch01（线性表，数组与链表的存储差异）、fund-ch03（堆与优先队列已在 ch03 铺垫）。衔接：fund-ch02（递归与调用栈支撑快排/归并）、fund-ch05（查找与排序的判定树/ASL 同源）。
> 学科归属：408 数据结构（严蔚敏教材第 9/10 章「内部排序 / 外部排序」）。面试权重：★★★★★（几乎必问，快排/堆排/归并是算法岗敲门砖）。

## 本章目标

学完你应该能：

1. **背下八种内部排序的「复杂度 + 稳定性」对照表**：插入/希尔/冒泡/快排/简单选择/堆排/归并/基数排序，各自的最好/平均/最坏时间复杂度、空间复杂度、是否稳定，能脱口而出并解释原因（见 concept/01 对照表）。
2. **手推快排的最坏情况并给出优化**：最坏发生在「每次划分极不平衡」（已有序且选端点作枢轴），复杂度退化为 O(n²)；掌握随机化、三数取中、尾递归/小数组转插入三种优化。
3. **讲清堆排序的建堆与调整复杂度**：`sift_down` 单次 O(log n)、自底向上建堆 O(n)（不是 O(n log n)）；并说明为什么堆排空间 O(1)、但不稳定、且缓存不友好。
4. **计算二路归并的「趟数」**：⌈log₂ n⌉ 趟，每趟 O(n)，总 O(n log n)，空间 O(n)，稳定；能区分「递归深度」与「归并趟数」。
5. **写清外部排序的完整链路**：多路平衡归并、败者树（减少比较次数）、置换-选择（生成初始顺串）、最佳归并树（最小化 I/O 次数）与 I/O 次数计算口径。
6. **理解比较排序 Ω(n log n) 下界**：决策树模型证明，并说清计数/基数排序「如何突破」——它们不基于比较，代价是依赖关键字范围/位数、牺牲通用性。
7. **工程选型**：在 `std::sort`（introsort）与手写排序之间做取舍；按数据规模、稳定性需求、缓存局部性决定用哪种排序。

## 复杂度速查（面试要能脱口而出）

| 排序 | 平均时间 | 最坏时间 | 空间 | 稳定 |
|---|---|---|---|---|
| 插入排序 | O(n²) | O(n²) | O(1) | 是 |
| 希尔排序 | O(n^1.3) | O(n²) | O(1) | 否 |
| 冒泡排序 | O(n²) | O(n²) | O(1) | 是 |
| 简单选择 | O(n²) | O(n²) | O(1) | 否 |
| 快速排序 | O(n log n) | O(n²) | O(log n) | 否 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 否 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 是 |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(n+r) | 是 |

> 更精确的最好/平均/最坏三档，以及外部排序的 I/O 口径，见 concept/01、concept/02、concept/03。
