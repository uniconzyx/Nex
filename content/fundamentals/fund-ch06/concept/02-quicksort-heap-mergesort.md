# 快排、堆排与归并：三种 O(n log n) 排序的机制与代价

## 1. 快速排序：划分（partition）决定一切

快排的核心是一次**划分**：选枢轴 pivot，把小于它的放左、大于它的放右，然后递归两侧。
复杂度完全取决于划分是否平衡。

**三档复杂度**

| 情况 | 触发条件 | 复杂度 |
|---|---|---|
| 最好 | 每次划分都近乎对半 | O(n log n) |
| 平均 | 随机输入 | O(n log n) |
| 最坏 | 每次划分极不平衡（0 : n-1） | **O(n²)** |

最坏情况的具体场景：**待排序序列已有序（正序或逆序），且枢轴取首/末元素**。此时每次划分只把区间缩小 1，
递归深度 n，总比较次数 `(n-1)+(n-2)+...+1 = n(n-1)/2`，退化为 O(n²)。同时递归栈深达 O(n)，
数据量大时还会爆栈。

**三种标准优化**

1. **随机化枢轴**：随机取一个元素与首元素交换后再划分，使最坏情况不再由输入分布决定（期望 O(n log n)）。
2. **三数取中（median-of-three）**：取 `首、中、尾` 三者的中位数作枢轴，对「已有序」这种常见输入免疫。
3. **小数组转插入排序**：区间长度 < 阈值（通常 10~20）时不再递归，最后统一做一次插入排序——
   小区间上插入排序的常数因子远小于递归开销。

**空间复杂度**：递归栈 O(log n)（平均）/ O(n)（最坏）。原地划分，不需要辅助数组。
**稳定性**：**不稳定**。划分过程中的跨距离交换（如 `swap(a[i], a[j])` 且 i、j 相隔很远）会打乱等值元素的相对顺序。

### 🧑‍💻 程序员视角

工程上你几乎不会手写快排——`std::sort` 用的是 **introsort（内省排序）**：以快排为主体，
一旦检测到递归深度超过 `2·⌊log₂ n⌋` 就切换为堆排序，把最坏情况硬锁在 O(n log n)；
小区间再切插入排序。所以它同时具备「快排的缓存友好」与「堆排的最坏保证」。

排查线上排序性能问题时，先看三件事：① 数据是否已近乎有序（退化为 O(n²) 的经典诱因）；
② 比较函数是否昂贵（把复杂对象比较改成预计算 key）；③ 数据量是否超过缓存行友好区间
（大对象排序应排索引/指针数组而非对象本身，避免整块内存搬运）。

### 🎓 博士生视角

快排的平均复杂度可由递推式严格求解。设 `C(n)` 为 n 个元素的期望比较次数，枢轴落在第 k 位的概率均为 1/n：

`C(n) = (n-1) + (1/n)·Σ_{k=1}^{n} [C(k-1) + C(n-k)]`

解得 `C(n) = 2(n+1)H_n − 4n ≈ 1.386·n log₂ n`，恰好是比较排序下界（≈ n log₂ n ≈ 0.693 倍信息论下界）
的约 2 倍常数——这就是「快排常数因子优秀」的定量依据。

而最坏 O(n²) 的存在，本质上是**确定性算法在对抗性输入下无法优于其决策树的某个分支**；
随机化枢轴把「输入分布」这个对抗维度转移给随机源，使期望复杂度与输入无关。

### 📚 考研者视角

**考点一（选择/简答）**：快排的最坏时间复杂度 O(n²)、平均 O(n log n)、空间 O(log n)、**不稳定**——
这是 408 必背的八行表中的一行。

**考点二（高频陷阱）**：问「对**已有序**的序列做快排，时间复杂度是多少」——
若枢轴取首元素则为 **O(n²)**（最坏），不能答 O(n log n)。反之问「**基本有序**时用哪种排序最快」，
答案是**直接插入排序**（最好 O(n)）。

**考点三（计算题）**：给出具体序列，要求写出**第一趟划分后的结果**。必须按教材的
「双指针挖坑法」或「Hoare 左右交换法」逐步写，二者结果可能不同——答题时先声明所用划分法。

**记忆锚点**：快排是「**不稳定 + 最坏 O(n²) + 空间 O(log n)**」三件套；
「一趟划分确定一个元素的最终位置」是快排区别于其他排序的标志性特征。

## 2. 堆排序：建堆是 O(n) 而不是 O(n log n)

堆排序分两步：① 自底向上建大顶堆；② 反复「取堆顶（最大值）放到末尾」，再对剩余部分下滤调整。

**建堆复杂度为什么是 O(n)**
`sift_down` 单次是 O(log n)，但**并非所有节点都下沉 log n 层**：越靠近叶子，子树高度越小。
第 h 层（从底往上，h=0 为叶子）有约 `n/2^{h+1}` 个节点，每个最多下沉 h 层，总代价：

`Σ_{h≥0} (n/2^{h+1})·h = n·Σ h/2^{h+1} = O(n)`

（级数 `Σ h/2^h` 收敛到 2）。所以自底向上建堆是 **O(n)**，这是 408 的经典易错点——
很多人答成 O(n log n)。

**排序阶段**：执行 n-1 次「取堆顶 + 下滤」，每次 O(log n)，总 O(n log n)。
**空间 O(1)**（原地，不用辅助数组）。
**稳定性**：**不稳定**（堆顶与末尾元素的交换是跨距离交换）。
**特点**：最坏也是 O(n log n)，但**缓存不友好**——下滤路径在数组上跳跃访问（下标 2i、2i+1），
局部性差，实测常数通常不如快排。

### 🧑‍💻 程序员视角

堆排序的真正主场不是「通用排序」，而是 **Top-K 与优先级调度**：
求最大的 K 个元素只需维护一个大小为 K 的小顶堆，复杂度 O(n log K) 且内存 O(K)，
在 n 远大于 K 时（如 10 亿条日志取 Top 100）这是唯一可行的方案。

通用排序不要选堆排：它的比较次数比快排多、且跳跃访问导致缓存命中率低。
`std::sort` 只在「快排递归过深」时把堆排当兜底，正是这个道理。

### 🎓 博士生视角

堆排的分析要点是「**不同节点的下沉代价不同**」——这是它区别于「n 次 × O(log n)」粗放估计的关键。
严格地说，堆是一个**近乎完全的二叉树**，高度分布高度不均匀（半数节点是叶子），
因此聚合代价由级数 `Σ h/2^{h+1}` 的收敛性决定，而非常数乘以 log n。

另外，堆排的比较次数上界约为 `2n log n`，比快排平均的 `1.386 n log n` 差约 44%，
这从理论上解释了「堆排常数大」的经验结论。

### 📚 考研者视角

**必背**：堆排序时间 **最好/平均/最坏均为 O(n log n)**；空间 **O(1)**；**不稳定**；
**建堆 O(n)**（不是 O(n log n)）；适合 **Top-K**。

**高频计算题**：给出关键字序列，要求① 画出建成的大顶堆（数组形式即可）；
② 写出**每一趟**堆顶输出后调整为堆的结果。答题规范：
建堆从**最后一个非叶子节点 ⌊n/2⌋** 开始，向前依次下滤。

**易错口径**：「堆排序的空间复杂度是 O(1)」——注意与归并的 O(n) 对照；
「堆是**完全二叉树**」——选择题常考「堆一定是完全二叉树」为真，
反过来「完全二叉树一定是堆」为假。

## 3. 归并排序：稳定、O(n log n)，但空间 O(n)

归并排序是**分治**的典型：把序列二分，递归排序两半，再把两个有序段合并成一个有序段。

**复杂度**：时间是 O(n log n)（最好/平均/最坏一致，因为分治结构固定，与输入分布无关）；
空间 **O(n)**（合并需要辅助数组，这是它与快排/堆排的最大区别）；**稳定**
（合并时左右相等取左边，等值元素相对顺序不变）。

**「趟数」的计算（408 高频）**
二路归并的趟数 = **⌈log₂ n⌉**。每一趟处理所有元素一次（O(n)），故总 O(n log n)。
注意区分两个概念：
- **归并趟数**：自底向上归并时「一遍一遍扫」的次数 = ⌈log₂ n⌉；
- **递归深度**：自顶向下递归时栈的最大深度 = ⌈log₂ n⌉。
二者数值相同但含义不同，答题时别混用。

### 🧑‍💻 程序员视角

归并是**外部排序**的基石：当数据装不进内存时，只能「分块排序 → 多路归并」，
而归并的顺序扫描特性对磁盘 I/O 极其友好（每次只读一大块、顺序写），
这正是外排用归并而不用快排的原因。

Java 的 `Arrays.sort(Object[])` 用 TimSort（归并 + 插入的混合），因为它**必须稳定**；
而 `Arrays.sort(int[])` 用双轴快排（Dual-Pivot QuickSort），因为基本类型无所谓稳定性。
这个选型差异就是稳定性的直接体现。

### 🎓 博士生视角

归并的 O(n log n) 是**结构性保证**：递归树深度严格为 ⌈log₂ n⌉，每层合并总代价严格为 O(n)，
因此不存在「最坏输入」——这与快排形成鲜明对比（快排的复杂度依赖输入分布）。

代价是 Ω(n) 的额外空间，以及合并时的**多次内存拷贝**。
优化方向是「只归并一次」：交替使用原数组与辅助数组作为归并目标，省掉每次合并后的回拷。

### 📚 考研者视角

**必背**：归并时间 O(n log n)（三档一致）、空间 **O(n)**、**稳定**、趟数 **⌈log₂ n⌉**。

**高频计算**：「n 个记录做二路归并排序，需要多少趟？」答案 ⌈log₂ n⌉。
例如 n=100 → ⌈log₂ 100⌉ = 7 趟。

**对比题常问**：「时间复杂度 O(n log n) 且**稳定**的排序有哪些？」——只有**归并**和**基数**。
快排、堆排、希尔、简单选择都不稳定。这个组合是选择题的高频正确项。
