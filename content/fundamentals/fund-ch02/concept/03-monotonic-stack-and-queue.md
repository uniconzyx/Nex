# 单调栈与单调队列：把 O(N²) 压成 O(N)

## 一、问题的起点：为什么会退化到 O(N²)

「对每个元素，找它右边第一个更大的数」——最直白的写法是对每个 `i` 向右扫，最坏 O(N²)：

```c
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)
        if (a[j] > a[i]) { nge[i] = j; break; }
```

问题在于**重复劳动**：扫描 `i` 时看过的元素，扫 `i+1` 时又看一遍。

## 二、单调栈：一次扫描，每个元素进出各一次

换一个视角：**不是「为每个 i 找答案」，而是「某个元素什么时候成为别人的答案」**。

维护一个**从栈底到栈顶递减**的栈（存下标）：

```c
int top = 0;
for (int i = 0; i < n; i++) {
    while (top > 0 && a[stk[top-1]] < a[i]) {   /* 栈顶比当前小 → 当前就是它的解 */
        nge[stk[--top]] = i;
    }
    stk[top++] = i;                              /* 当前元素入栈，等待它的解 */
}
/* 栈中剩余的没有更大元素，nge 保持 -1 */
```

**为什么是 O(N)**：每个元素**入栈恰好 1 次、出栈至多 1 次**，while 循环的总执行次数摊还到 O(N)。这是**均摊分析**的典型样本——单个元素可能触发多次出栈，但总次数有上界。

**单调栈的本质**：它维护的是一个「还没找到答案的候选集」，并保证候选集内部有序，从而**一旦新元素进来就能批量结算**。它不是特殊数据结构，就是普通栈 + 一个维持单调性的 while。

## 三、单调队列：滑动窗口最大值

求每个长度为 k 的窗口中的最大值。暴力是 O(N·k)。用**双端队列**存下标，保持队列内值递减：

```c
int head = 0, tail = 0, q[n];
for (int i = 0; i < n; i++) {
    while (tail > head && a[q[tail-1]] <= a[i]) tail--;  /* 队尾比当前小 → 永无出头之日 */
    q[tail++] = i;
    if (q[head] <= i - k) head++;                        /* 队首过期 */
    if (i >= k - 1) result[i - k + 1] = a[q[head]];      /* 队首即窗口最大值 */
}
```

三个动作各有深意：

- **队尾淘汰**：一个更晚出现且更大的元素，会让之前所有更小的元素**永远不可能成为最大值**——直接丢掉，这就是剪枝。
- **队首过期**：窗口左边界右移，落在窗口外的下标出队。
- **队首即答案**：因为递减，队首是窗口内最大。

同样是均摊 O(N)。

## 四、二者共同的思维模式

| 特征 | 单调栈 | 单调队列 |
|---|---|---|
| 操作端 | 单端（栈顶） | 双端 |
| 典型题 | 下一个更大元素、直方图最大矩形、每日温度 | 滑动窗口最大值、窗口内最值维护 |
| 单调方向 | 递减求「下一个更大」，递增求「下一个更小」 | 递减求最大值，递增求最小值 |
| 均摊依据 | 每元素进出各 ≤1 次 | 同左 |

**识别信号**：题目里出现「下一个/上一个 更大/更小」「区间最值」「以某元素为边界的最大区间」——立刻考虑单调结构。

## 五、与程序员的对话：为什么这招在工业界很重要

- **熔断/限流**：滑动窗口统计请求量，单调队列可 O(1) 取窗口峰值。
- **股票分析**：求 N 天内「下一个更高价」用于止盈点计算。
- **直方图最大矩形**：单调栈的经典应用，等价于「以每个柱子为高的最大区间」，是很多「最大面积」问题的母题。
- **性能差异是数量级的**：N=10⁵ 时 O(N²) 要 10¹⁰ 次操作（秒级超时），O(N) 只要 10⁵ 次（微秒级）。

## 三视角解析

### 🧑‍💻 程序员视角
- 单调栈模板要背到能默写：遍历时 `while (栈非空 && 破坏单调性) 弹栈并结算答案`，然后压入当前下标。
- 典型应用：下一个更大元素、柱状图中最大矩形、接雨水、每日温度。
- 单调队列典型应用：滑动窗口最大值、限定长度的最值查询；在 DP 优化里用来把 O(n·k) 降到 O(n)。

### 🎓 博士生视角
- 均摊线性的论证是**势能/计数**：每个下标至多被压入一次、弹出一次，故总操作数 ≤ 2n。这是「嵌套循环未必是 O(n²)」的教科书反例。
- 单调栈与 **Cartesian 树**一一对应，也等价于一次「离线 RMQ」的预处理；单调队列是「滑动窗口最值」的均摊 O(1) 实现。
- 更形式化地说，单调栈求的是每个元素在「以它为一端、另一个端是首个破坏单调性者」这类区间查询中的极值，属于半群聚合的特例。

### 📚 考研者视角
- 408 中单调栈/队列**不出现在基础概念题**，但常作为**算法设计题的优化手段**或机试压轴出现。
- 标准叙述：求「下一个更大元素」时，栈内保存的是**还没有找到答案的下标**，且其对应值保持递减。
- 记忆锚点：**栈里存下标而不是值**（要算距离/宽度必须用下标）；这句话能救回一半的现场错误。
- 若题目要求「滑动窗口最大值」，先给暴力 O(n·k)，再说明单调队列如何降为 O(n)——分步作答更稳。
