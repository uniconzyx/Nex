# fund-ch09 · 操作系统：进程、线程与调度

> 先修：fund-ch01（线性表，进程控制块/队列本质是链表结构）、fund-ch06（排序，调度算法常需按优先级排序）。
> 衔接：fund-ch10（内存管理，进程是内存分配的基本单位）、fund-ch11（网络，socket 与进程/线程模型相关）。
> 学科归属：408 操作系统（汤小丹教材第 2 章「进程管理」+ 第 3 章「处理机调度与死锁」）。面试权重：★★★★★。

## 本章目标

学完你应该能：

1. **说清进程与线程的本质区别**：进程是**资源分配的基本单位**（独立地址空间、文件描述符、信号），
   线程是**CPU 调度的基本单位**（共享地址空间，独有栈/寄存器/TCB）；能解释为什么线程切换比进程切换快
   （不需要切换页表、不需要刷新 TLB）。
2. **画出进程状态机并说清每次转换的触发条件**：三态（就绪/运行/阻塞）与五态（+新建/终止），
   以及「运行→阻塞是主动的、阻塞→就绪是被动的、运行→就绪是抢占的」这一关键判据。
3. **背下并会算六种调度算法**：FCFS、SJF/SPF、HRRN（高响应比优先）、RR（时间片轮转）、
   优先级调度、多级反馈队列（MLFQ）；会手工计算**周转时间、带权周转时间、等待时间、响应时间**。
4. **讲清临界区互斥的三条准则**与实现路径：软件（Peterson）、硬件（关中断/TestAndSet/Swap）、
   信号量（P/V）、管程；能指出各自的问题（忙等、让权等待、死锁/饥饿）。
5. **手推经典同步问题**：生产者-消费者、读者-写者（读优先/写优先/公平）、哲学家进餐
   （三种防死锁解法），能写出正确的信号量伪代码。
6. **推导死锁**：四个必要条件（互斥、占有且等待、不可抢占、循环等待）；三种处理策略
   （预防、避免=银行家算法、检测与解除）；会用银行家算法做安全性检测。
7. **工程对应**：把「线程池」「协程」「IO 多路复用」与 OS 的进程/线程模型对应起来，
   能在高并发服务设计中做出正确的并发模型选型。

## 核心公式速查

| 指标 | 公式 |
|---|---|
| 周转时间 | `完成时间 − 到达时间` |
| 平均周转时间 | `Σ 周转时间 / n` |
| 带权周转时间 | `周转时间 / 服务时间`（≥1，越接近 1 越优） |
| 等待时间 | `周转时间 − 服务时间` |
| 响应比（HRRN） | `(等待时间 + 服务时间) / 服务时间` |
