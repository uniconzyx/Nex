# 总线标准与突发（Burst）传送

```text
标准之争的本质：在"带宽 / 成本 / 距离 / 拓扑"之间做不同的权衡。
  PCI/PCIe：板级、连扩展卡
  USB     ：对外、连外设、热插拔
  AXI     ：片上(SoC)、连 CPU/DMA/外设，多主多从
```

> 一句话：总线标准是"把前面讲的分类、仲裁、定时、复用落到具体产品上的工程取舍"。突发传送则是**压榨有效带宽**的关键技巧，几乎是现代总线的标配。

## 1. 背景/动机

理论讲完，落到真实总线：为什么 PCI 被 PCIe 取代？为什么 USB 用串行差分？为什么 SoC 里是 AXI 而不是 PCI？答案都在"**带宽需求涨了，但并行共享总线到头了**"。而无论哪种总线，CPU/内存之间"连续地址连续传"的 burst 都是提升有效吞吐的利器——否则每次传数都要重新发地址，地址相位把带宽吃光。

## 2. 定义/要点

### 2.1 突发（Burst）传送

普通单次传送：每传一个数据都要"地址相位 + 数据相位"：

```text
单次 ×4：  [ADDR][DATA][ADDR][DATA][ADDR][DATA][ADDR][DATA]   ← 地址相位占一半！
突发 ×4：  [ADDR][DATA][DATA][DATA][DATA]                     ← 只发一次地址
           首地址由主设备给，后续地址由从设备内部 +1 自增
```

- **收益**：省掉后续拍的地址相位，有效带宽接近"数据相位占比"。
- **边界**：① 不超过设备约定最大突发长度；② 跨页/突发边界可能强制断流重发地址；③ 读写相位不同（写：主连续推数据；读：从连续回数据）。
- **有效带宽公式**（设地址相位占 a 拍，数据相位 n 拍）：

  ```text
  有效带宽 ≈ 峰值带宽 × n / (a + n)
  例：地址相位 1 拍、突发 8 拍数据 → 利用率 8/9 ≈ 89%（对比单次仅 1/2=50%）
  ```

### 2.2 四大总线标准对比（408/面试常考）

| 总线 | 类型 | 拓扑 | 定时 | 串行/并行 | 关键特征 |
|---|---|---|---|---|---|
| **PCI** | 系统总线（板级） | 共享并行总线 | 同步（33/66MHz） | 并行（32/64 位） | 传统扩展槽；并行共享，频率上不去、负载重 |
| **PCIe** | 系统总线（对外） | **点对点交换**（Switch） | 异步/串行差分 | 串行（多 Lane） | 全双工、×1/×4/×8/×16 Lane 叠加；8b/10b(2.0前)/128b/130b 编码；替代 PCI |
| **USB** | 通信总线（对外） | 主从星型（Host→Hub→Device） | 异步、半双工 | 串行差分 | 热插拔、Host 主导枚举、轮询式；USB2.0 480Mbps / USB3.x 5-20Gbps |
| **AXI** | 片上总线（SoC） | 多主多从（交叉/NoC） | 异步（VALID/READY） | 并行（片上） | AMBA 家族；**5 通道分离**（AR/AW/R/W/B），支持乱序、突发、QoS |

**关键差异一句话**：
- **PCI → PCIe**：并行共享 → 串行点对点交换；靠 Lane 数堆带宽，不再是"所有人抢一条并行车道"。
- **USB**：专注"对外、热插拔、主从、便宜"，Host 枚举一切；不适合做片内主干。
- **AXI**：片上多主多从，把"地址/读数据/写数据/写响应"拆成独立通道 + 全互锁握手，天然支持**突发与乱序**，是 SoC 互连主流。

### 2.3 为什么现代总线都走向"串行 + 交换 + 突发 + 握手"

```text
并行共享(PCI) 的死穴：
  线间串扰 + 时钟偏移随长度/频率恶化 → 频率封顶；所有设备抢一条总线 → 带宽被平分。
串行交换(PCIe) 的解法：
  每 Lane 一对差分线跑极高频（GHz 级）+ 多 Lane 并发 + 点对点交换（不共享）→ 带宽随 Lane 线性涨。
突发 + 握手(AXI/PCIe) 的解法：
  一次地址连续传 + READY/VALID 自适应 → 有效带宽高且能跨时钟域。
```

### 2.4 三视角解析

### 🧑‍💻 程序员视角
真实工作场景：

1. **PCIe 带宽"算出来"却"用不满"**：某 GPU 训练任务，理论 x16 Gen3 = 16×~1GB/s ≈ 16GB/s（双向），实测只有 9GB/s。排查：① `lspci` 看实际协商成 **x8 还是 x16**（槽位/布线问题最常见）；② 确认是否 **Gen3 还是降速 Gen2**；③ 确认是**编码后**带宽还是**有效载荷**（128b/130b 扣 1.5%）；④ 应用是否真在连续大块 DMA（突发）还是小包频繁（地址相位吃光）。**不是带宽不够，是没跑满 burst + 协商降级**。
2. **USB 批量传输(bulk) vs 中断传输**：写固件时把"实时性要求高"的数据错用 bulk 端点，结果被 Host 轮询排在后面，延迟抖动；应改 **interrupt/Isochronous** 端点。这是"选错 USB 传输类型"的典型坑。
3. **AXI 突发长度设太大反而降速**：AXI 突发上限 16（beat），但跨 4KB 边界会断流；驱动 DMA 描述符若设 256 拍又不切边界，硬件会**强制截断重发地址**，反而比合理分段更慢。

### 🎓 博士生视角
AXI 的 5 通道（AR/AW/R/W/B）是**分离式事务 + 全互锁在片上**的工程实现：`VALID/READY` 双向握手（全互锁）解耦时钟域；读写地址/数据通道分离，使**多个未完成事务可重叠（outstanding）**且**读可乱序返回**（用 `ID` 区分），最大化互连吞吐。这等价于把 concept 02/03 的"多主仲裁 + 分离式 + 异步握手"同时落地。PCIe 的 TLP（Transaction Layer Packet）层则把突发封装成**分包、路由、流控**的报文，用 **credit-based 流控**替代硬握手，避免反压死锁——是"总线思想"向"网络思想"的演进。量化上，突发长度 `L` 与有效利用率 `U≈L/(L+α)`（α 为地址/协议开销拍数）的关系是贯穿所有总线的统一公式。

### 📚 考研者视角
408 常考：

- **突发传送**：一次地址、连续多数据，地址从设备自增；能显著提升有效带宽；选择题/大题都考"突发 vs 单次的有效带宽比"。
- **PCIe 与 PCI 区别**：PCI 并行共享同步；PCIe 串行点对点交换、全双工、Lane 叠加、异步。一句话："PCIe 不是更宽的 PCI，是架构不同的新总线"。
- **USB 特点**：串行、主从、异步、热插拔、Host 枚举；Host 主导，不支持设备间直连。
- **AXI 特点**：AMBA、片上、多主多从、通道分离、支持突发/乱序/握手；是 SoC 互连标准（了解即可，不在统考深挖）。
- 大题常把"计算突发有效带宽"与"分离式事务节约的总线时间"组合出题。
