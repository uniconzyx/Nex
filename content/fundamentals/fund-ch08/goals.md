# 学习目标 · 计组：存储系统与 CPU

> 408 考研「计算机组成原理」的重头戏。本章回答两个问题：**为什么加一层 Cache 就能快十倍？为什么流水线不能无限加速？**

## 一、知识目标

1. **说清存储层次与局部性**：时间局部性/空间局部性的来源，以及"越靠上越快越小越贵"的量化表达
   （命中率 + 缺失代价 → **AMAT**）。
2. **掌握 Cache 三件事**：
   - **映射**：直接映射、全相联、组相联的地址位划分（tag / 组号 / 块内偏移），会算各组位宽；
   - **替换**：FIFO、LRU、LFU、随机，以及 OPT 作为"理论下界"的作用；
   - **写策略**：写直达 + 写不分配 vs 写回 + 写分配，会算内存写次数。
3. **掌握三类缺失（3C）**：强制（冷启动）、容量、冲突，并能说出各组相联度对它们的影响。
4. **说清虚拟内存与 Cache 的协同**：多级页表的地址翻译过程、TLB 的作用、缺页处理后如何重执行指令。
5. **掌握指令执行与流水线**：
   - 指令周期 / 机器周期 / 时钟周期三者的关系，CPI 与 MIPS 的计算；
   - 流水线的理想加速比 $S = k$（$k$ 级），以及实际加速比受**三类冒险**限制；
   - 结构冒险 / 数据冒险 / 控制冒险的成因与对策（**旁路转发**、**分支预测**、停顿插入）。

## 二、能力目标

- 能对着给定的地址与 Cache 参数，**手算**出 tag/index/offset 位段，并逐条判定命中/缺失；
- 能读懂 `perf stat` 的 cache-misses、IPC 指标，把它和本章公式对上；
- 能对一段循环代码**预测**其缓存行为（顺序访问 vs 跨步访问 vs 转置的差异）。
