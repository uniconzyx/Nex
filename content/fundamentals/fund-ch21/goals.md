# fund-ch21 · I/O 管理与磁盘

> 一句话引出：一块 12ms 的机械盘，为什么「传输 4KB」只占 1.4%，剩下 98% 全花在「找位置」上？

## 一、知识目标

1. **说清 I/O 设备的分类**：按**使用特性**（存储设备/交互式设备）、按**传输速率**、按**信息交换单位**（**块设备** vs **字符设备**）、按**共享属性**（独占/共享/虚拟）。能解释"为什么磁盘是块设备、键盘是字符设备"，以及这个划分如何决定驱动接口。
2. **掌握 I/O 控制器的组成与端口编址**：数据寄存器/状态寄存器/控制寄存器、**独立编址**（in/out 指令、独立地址空间）与**统一编址**（内存映射 MMIO）的取舍；`/dev/mem`、`ioremap` 的由来。
3. **掌握四种 I/O 控制方式并能横向对比**：**程序查询**（忙等，CPU 占用 100%）、**程序中断**（每字节/每字中断，CPU 只花中断处理时间）、**DMA**（整块搬运，结束时中断一次）、**通道**（通道程序自主执行，CPU 只发命令）。能算"传 N 字节 CPU 被介入多少次"。
4. **掌握中断的完整流程**：中断请求 → 中断判优 → **中断响应**（关中断、保存断点/PC 与 PSW、引出中断服务程序）→ 中断服务 → 恢复现场 → 开中断返回；**中断屏蔽字**与多重中断嵌套；**向量中断**与中断向量表；中断与异常的区分（内中断/外中断）。
5. **掌握 I/O 软件层次**：用户层 I/O 软件 → 设备独立性软件 → 设备驱动程序 → 中断处理程序 → 硬件；**设备独立性**的含义（逻辑设备名 → 物理设备）、**逻辑设备表 LUT**。
6. **掌握缓冲技术**：单缓冲、双缓冲、循环缓冲、缓冲池（**空缓冲队列 / 装满输入数据队列 / 装满输出数据队列** + 四种工作缓冲区）；能算单/双缓冲的处理时间，并说清"**缓冲只能掩盖速度差，不能突破瓶颈**"。
7. **掌握设备分配与 SPOOLing**：设备控制表 DCT / 控制器控制表 COCT / 通道控制表 CHCT / 系统设备表 SDT 的关系；**SPOOLing（假脱机）** 如何用"输入井 + 输出井 + 输入进程 + 输出进程"把**独占设备虚拟成共享设备**。
8. **掌握磁盘的结构与访问时间**：盘面/磁道/扇区/柱面、**寻道时间 + 旋转延迟（平均半圈）+ 传输时间**；能算 7200rpm 下的平均旋转延迟；理解"为什么顺序读写远快于随机"。
9. **掌握磁盘调度算法**：**FCFS / SSTF / SCAN（电梯）/ C-SCAN / LOOK / C-LOOK**；会算总寻道距离、平均寻道长度，并指出 **SSTF 的饥饿问题**与 SCAN 的"来回扫"代价。
10. **掌握 RAID 与 SSD**：RAID 0/1/5/6/10 的**容量、容错、读写性能**与 RAID 5 的**写惩罚（读旧数据+读旧校验+写新数据+写新校验 = 4 次 I/O）**；SSD 的**写放大 WAF、GC、TRIM、OP、TBW 寿命**；为什么"RAID 不是备份"。

## 二、能力目标

- 线上排查 I/O 抖动时，能用 `iostat -x` 的 `%util`、`await`、`aqu-sz` 区分"**磁盘饱和**"与"**应用层排队**"，而不是一看到慢就换硬件。
- 能算清一次随机 4KB 读在 7200rpm 机械盘上的理论延迟（≈12ms），据此判断一个"读 1000 行配置"的服务为什么 P99 是秒级。
- 能解释容器里 `df` 显示磁盘没满但写入失败（inode / 磁盘配额 / 只读挂载）的三类不同原因。
- 能根据业务特征选 RAID 级别：数据库 redo 日志用 RAID 10，归档/备份用 RAID 5/6，并说清理由（写惩罚 vs 容量利用率）。
- 能给 SSD 上跑的服务做寿命估算：日写入量 × WAF → 年写入量，对照 TBW 判断是否需要换更大 OP 的盘。

## 三、三视角导航

| 视角 | 本章重点 |
|---|---|
| 🧑‍💻 程序员 | `write()` 返回不等于落盘（页缓存 + 写回）；`fsync` 的代价就是一次真实的磁盘访问；顺序写 vs 随机写的吞吐能差两个数量级；中断风暴、软中断 `ksoftirqd` 打满 CPU 都是"上半部太长"；`O_DIRECT`、`posix_fadvise` 能绕过缓存但要自己对齐。 |
| 🎓 博士生 | 中断与 DMA 的边界是"谁来搬数据"的分工演化；通道 = 早期 I/O 处理器，与今天的 DPU/SmartNIC 是同一思路；磁盘调度在现代硬件上已下移到固件（TCQ/NCQ），OS 层调度退化为"合并与排序"；SSD 的 FTL 把"随机写"变成"异地更新 + GC"，WAF 是空间放大与写放大的权衡。 |
| 📚 考研者 | 408 I/O 章是**对比题与计算题**集中区：四种 I/O 方式的 CPU 介入次数、中断响应全流程排序、单/双缓冲时间计算、磁盘访问时间三要素、FCFS/SSTF/SCAN 总寻道距离、RAID 容量与容错。概念题爱考"中断与异常""SPOOLing 为什么能把独占变共享""DMA 与中断的区别"。 |
