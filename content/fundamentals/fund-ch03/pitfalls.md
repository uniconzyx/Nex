# fund-ch03 常见坑与避坑指南

1. **递归忘写终止条件或不覆盖 `NULL` → 栈溢出 / 空指针解引用**
   `if (!root) return;` 是每个树递归的第一行，漏了就直接崩溃。
   修法：先写终止条件，再写递归体；用 `-fsanitize=address` 跑一遍边界用例。

2. **验证 BST 只比较「节点与其直接子节点」→ 漏掉跨层越界**
   ```c
   /* 错：右子树里藏一个比根小的值不会被发现 */
   if (n->left  && n->left->val  >= n->val) return 0;
   if (n->right && n->right->val <= n->val) return 0;
   ```
   根因：BST 要求的是「左子树**所有**值 < 根」，不是「左孩子 < 根」。
   修法：用**中序遍历判严格递增**；或递归时传递 `(min, max)` 上下界。

3. **BST 插入未处理重复键 → 语义不一致 / 死循环**
   到底是忽略、计数、还是挂到一侧？若不同代码路径处理方式不同，会出现「插了却查不到」。
   修法：明确约定（如「重复则计数 +1」或「重复则忽略」），并在测试里覆盖。

4. **后序释放树时先释放父节点 → 悬垂访问**
   ```c
   free(root); destroy(root->left);   /* 错：root 已释放，root->left 是脏读 */
   ```
   修法：严格后序——先递归释放左右子树，**最后**释放自己。

5. **递归求树高被重复计算 → O(N²)**
   自顶向下对每个节点都调一次 `height()`，同一子树的高度被算了多次。
   修法：改自底向上，一次后序遍历同时返回高度与平衡性（见 concept/03）。

6. **非递归中序忘记「转向右子树」→ 死循环**
   `cur = stk[--top]; visit(cur); cur = cur->right;` 少最后一句，`cur` 会一直是同一条左链的节点。
   修法：写完在纸上跑一遍三层的小树，检查每个节点的访问次数恰好为 1。

7. **堆的 `sift_down` 只比较一个孩子 → 破坏堆序**
   必须选**两个孩子中更大（大顶堆）的那个**交换，否则交换后另一个孩子仍大于父节点。
   修法：先比较左右孩子选出较优者，再与父比较；注意右孩子可能不存在（只有左孩子）。

8. **用数组表示非完全二叉树 → 空间指数级浪费**
   数组表示依赖「完全二叉树」性质（下标连续）。一般二叉树用数组会需要 `2^h` 空间。
   修法：只有**完全二叉树/堆**才用数组；一般二叉树用左右指针表示。

9. **树的深度与高度概念混用 → 边界差 1**
   有的教材「深度从 0 起（根深度 0）」，有的「深度从 1 起（根深度 1）」。混用会导致答案差 1。
   修法：**定义清楚并在代码注释里写明**（本课程统一：根深度 0，空树高 -1 或 0 需明确）。
