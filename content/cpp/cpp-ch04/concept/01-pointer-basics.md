# 指针基础

指针是"保存内存地址的变量"。通过 `&` 取地址，通过 `*` 解引用访问所指对象。

## 要点

- `int x = 42; int* p = &x;` —— `p` 存 `x` 的地址，`*p` 读/写 `x`
- 指针**必须初始化**（`nullptr` 或有效地址），未初始化指针解引用是 UB
- 指针类型要匹配：不能把 `double*` 赋值给 `int*`
- `void*` 可指向任意类型，但解引用前必须转回具体类型指针
- 现代 C++ 优先用引用/智能指针；裸指针用于"非拥有"观察或底层操作

```cpp
int x = 42;
int* p = &x;
std::cout << *p;   // 42
```

## 三视角解析

### 🧑‍💻 程序员视角
- 空指针一律用 **`nullptr`**（类型安全），不要用 `NULL` 或 `0`——后者在有 `int` 与 `T*` 两个重载时会歧义或选错。
- 指针算术按**所指类型大小**缩放；越界指针即使不解引用也是 UB。
- `delete`/`free` 之后把指针置 `nullptr`，能防住大量重复释放与 use-after-free。

### 🎓 博士生视角
- `nullptr` 的类型是 `std::nullptr_t`，可隐式转为任意指针类型但**不是整数**，因此消除了 `0`/`NULL` 带来的重载歧义——这是「用类型表达意图」的又一例证。
- 指针是实现**间接访问**与**运行时多态**的基础设施：函数指针、vtable、动态内存都建立在它之上。
- 指针与引用在多数 ABI 上实现相同，但语言语义不同（可空 vs 不可空、可重绑定 vs 不可）。**可空性是否进入类型系统**，是 C++ 与「可选类型（`optional`/`Option`）」路线的重要分野。
- 与计组交叉：指针的位宽决定可寻址空间；压缩指针、分段寻址等技巧都建立在「低位可利用对齐」这一事实上。

### 📚 考研者视角
- **408 高频**：指针的定义与运算、指针与数组、多级指针、函数指针、`const` 与指针的组合。
- 常考计算：指针加减后的地址、`&a` 与 `a` 的类型差异（`+1` 的跳距不同）。
- 记忆锚点：**用 `nullptr`**；**指针算术按元素大小缩放**；**越界指针即 UB（即使不解引用）**。
