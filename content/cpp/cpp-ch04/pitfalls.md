# 本章避坑指南

1. **内存泄漏** —— `int* p = new int; p = new int;` 第一块内存地址丢失无法释放；或函数提前 return 漏了 `delete`。→ 用 `std::unique_ptr` 自动管理。
2. **悬垂指针** —— `delete p;` 后继续用 `*p`，对象已回收，读取是 UB（值可能"看起来还对"但随时崩）。释放后及时置 `nullptr` 或改用智能指针。
3. **new/delete 不匹配** —— `int* a = new int[3]; delete a;`（漏 `[]`）是未定义行为，必须 `delete[] a;`。
4. **返回局部变量地址** —— `int* f(){ int x=1; return &x; }` 调用方拿到悬垂指针；应返回对象本身或智能指针。
5. **未初始化裸指针** —— `int* p;` 后直接 `*p`，指向随机地址，崩溃。务必初始化。
6. **异常路径漏 delete** —— `new` 之后、`delete` 之前抛异常，`delete` 永不执行。C++ 没有 `finally`，必须靠 RAII（`unique_ptr`/容器）保证清理。
7. **基类析构非虚却用基类指针 delete** —— 只调基类析构函数，派生类资源泄漏，UB。基类析构必须是 `virtual`。
8. **大数组放栈** —— `int buf[1000000]` 约 4 MB，超过默认栈上限（常见 1~8 MB）直接栈溢出。改用 `std::vector`（堆）。
9. **跨编译单元的全局初始化顺序** —— 一个 `.cpp` 的全局对象依赖另一个 `.cpp` 的全局对象，构造顺序未定义，可能读到未初始化对象。用"函数内静态变量"延迟初始化。
10. **`memcmp` 比较结构体** —— 填充字节内容未指定，两个逻辑相等的结构体字节可能不同，比较结果不可靠。逐成员比较或用 `= default` 的 `operator<=>`。
11. **`delete` 后置空只防一个变量** —— `p = nullptr` 防不住其他指向同一对象的指针副本；use-after-free 仍需靠所有权设计或 ASan 排查。
12. **强转去掉 `const` 写只读段** —— `const char* s = "abc"; *(char*)s = 'x';` 是 UB，通常立即段错误（字面量在 `.rodata`）。
13. **`sizeof(指针)` 当成「数组大小」** —— `int a[10]; int* p = a;`，`sizeof(p)` 是指针字节数（如 8），不是 `10*4`。数组退化成指针后尺寸信息永久丢失；要保留尺寸用 `std::array`/`std::span`，或显式传长度。
14. **`int* p; *p = 5;` 用未初始化指针** —— 野指针未绑定任何有效对象就解引用，写到随机地址，行为不可预测，可能立刻崩也可能很久后才崩。声明指针时立刻初始化（`nullptr` 或有效地址），解引用前必须确认它指向活着的对象。
15. **把「栈对象地址」存进全局/长生命周期结构** —— 函数返回后栈对象已析构，全局指针指向的仍是那块已回收内存；后续访问是 use-after-free。要么延长对象生命周期（堆分配/提升作用域），要么只存值不存地址，绝不跨越作用域边界保存栈地址。
