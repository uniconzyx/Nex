# 本章避坑指南

1. **默认参数重复提供** —— 声明处写了 `= "!"`，定义处又写一遍，触发"默认参数重定义"。只在声明或定义一处给。
2. **返回局部变量引用/指针** —— `int& f(){ int x; return x; }` 返回栈上对象，调用方拿到悬垂引用（未定义行为）。
3. **重载仅靠返回类型区分** —— `int f();` 与 `double f();` 非法，重载看参数列表不看返回类型。
4. **lambda 引用捕获悬空** —— 把 `[&x]` 捕获局部的 lambda 存起来延迟调用，x 已析构，访问即 UB。需延长生命周期或改值捕获。
5. **默认参数从中间断档** —— `void f(int a=1, int b)` 非法，默认参数必须连续靠右。
