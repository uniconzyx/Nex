# 本章避坑指南

1. **默认参数重复提供** —— 声明处写了 `= "!"`，定义处又写一遍，触发"默认参数重定义"。只在一处给，且应放在头文件的声明里。
2. **返回局部变量引用/指针** —— `int& f(){ int x; return x; }` 返回栈上对象，调用方拿到悬垂引用（未定义行为）。
3. **重载仅靠返回类型区分** —— `int f();` 与 `double f();` 非法，重载看参数列表不看返回类型。
4. **lambda 引用捕获悬空** —— 把 `[&x]` 捕获局部的 lambda 存起来延迟调用，x 已析构，访问即 UB。需延长生命周期或改值捕获。
5. **默认参数从中间断档** —— `void f(int a=1, int b)` 非法，默认参数必须连续靠右。
6. **虚函数带默认参数** —— 函数体动态绑定、默认值静态绑定：通过基类引用调用会执行派生类实现，但拿到基类的默认值。虚函数不要用默认参数。
7. **派生类同名函数隐藏基类重载** —— 派生类写了一个同名函数，基类的所有同名重载都被隐藏（不是重载决议的问题，是名字查找阶段就停了）。要 `using Base::f;` 拉回来。
8. **`f(NULL)` 选中 `f(int)`** —— `NULL` 是整数常量 0，同时存在 `f(int)` 与 `f(char*)` 时选前者。用 `nullptr` 表达空指针。
9. **`[=]` 在成员函数里捕获 `this`** —— 捕获的是指针不是对象副本，对象销毁后 lambda 调用即悬垂。C++20 起要求写 `[=, this]`，别忽略这个告警。
10. **循环里按引用捕获循环变量** —— `for (int i...) fns.push_back([&i]{...})` 所有闭包共享同一个 `i`，最终全部看到退出值。按值捕获 `[i]` 才每个一份。
11. **`mutable` 不能改外部变量** —— `[=]() mutable { ++x; }` 改的是闭包内的副本，外部 `x` 不变。要改外部必须引用捕获。
12. **头文件里定义非 inline 函数** —— 被两个 `.cpp` 包含即 `multiple definition`。头文件只放声明与 `inline`/模板定义。
