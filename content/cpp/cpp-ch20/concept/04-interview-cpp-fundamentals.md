# 04 · 面试冲刺：C++ 高频八股串讲

以下每节都可对应一个已验证示例，做到背结论的同时能讲原理。

## 一、虚函数表与对象模型（见 ex11）

有虚函数的类，对象头部有一个 **vptr** 指向**虚函数表（vtable）**；调用虚函数经 vptr 间接寻址实现动态绑定。
**对象切片（slicing）**：把派生类对象按值赋给基类对象，派生部分被切掉，只剩基类子对象，多态从此失效——所以多态必须经**指针或引用**。
基类析构非 `virtual` 时，经基类指针 `delete` 派生对象只调基类析构，派生资源泄漏。

### 🧑‍💻 程序员视角
- **决策顺序**：类会被继承且经基类指针释放 -> 析构 `virtual`；需要运行时多态 -> 至少一种虚函数；纯接口 -> 纯虚析构也要有定义。

### 🎓 博士生视角
- **第一性原理**：vtable 是按类型一份的函数指针数组，vptr 是对象到它的索引；动态绑定 = 运行期查表，代价是一次指针解引用 + 丧失内联。

### 📚 考研者视角
- **408 关联**：虚表位置在对象布局的头部（多数 ABI），属编译链接与内存布局考点；切片对应对象内存模型。

## 二、移动语义、RVO 与拷贝消除（见 ex09 / ex10）

移动语义把资源所有权在拷贝成本高时转移而非复制（右值引用 + `std::move`）。
**RVO/NRVO**（返回值优化）与**复制消除**是编译器允许的省略拷贝——**不要画蛇添足地 `std::move` 局部返回对象**，
那会强制走移动构造、反而丧失 NRVO 机会（见 ex10）。

### 🧑‍💻 程序员视角
- **决策顺序**：返回局部对象 -> 直接 `return obj;`；明确不再用的大对象 -> `std::move` 传给接收右值引用的接口。

### 🎓 博士生视角
- **第一性原理**：移动是浅拷贝 + 置空源，把 O(n) 拷贝降到 O(1) 指针交换；复制消除是在调用方栈帧直接构造返回对象，连移动都省了。

### 📚 考研者视角
- **标准问法**：`std::move` 做了什么、为什么 `return std::move` 是反模式。

## 三、STL 容器复杂度与迭代器失效（见 ex12）

`vector` 随机访问 O(1)、尾部插入均摊 O(1)、中间插入 O(n)；`list` 插入删除 O(1) 但访问 O(n)。
`vector::push_back` 扩容后**所有**迭代器/引用失效；`erase` 使之后元素失效，须用返回值续接。

### 🧑‍💻 程序员视角
- **决策顺序**：尾部增删多 -> `vector`；中间增删多 -> `list`/`deque`；按 key 查 -> `map`/`unordered_map`；删元素时 `it = c.erase(it)`。

### 🎓 博士生视角
- **形式化**：迭代器失效 = 底层存储重分配或元素迁移导致旧游标指向非法/错位内存；连续容器重分配使全部游标失效，节点容器（list）只使被删节点失效。

### 📚 考研者视角
- **标准问法**：`vector` 和 `list` 迭代器失效差异、`erase` 循环中怎么写。
