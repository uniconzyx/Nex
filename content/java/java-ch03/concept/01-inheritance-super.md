# 01 · 继承与 super：单继承、is-a 与构造器链

## 一、理论根基：继承是"子类型化"而非"代码搬运"

继承的第一性原理是 **Liskov 替换原则（LSP）**：子类对象必须能在任何父类出现的地方被使用，且行为不破坏父类约定。它表达的是 **is-a** 关系，而不是"把父类代码复制过来"。

- **单继承**：Java 中一个类只能 `extends` 一个父类（`class Sub extends Base`，唯一 `super_class`）。这是语言层的硬性约束（class 文件常量池里 `super_class` 只有一项），从根本上规避了 C++ 多继承的"菱形歧义"（同一份基类状态被复制多份、名字冲突）。
- **super 的本质**：`super` 不是对象引用，而是一个**编译期指令**，让编译器改发 `invokespecial` 去调用父类版本的方法/构造器，绕过动态分派。它不参与运行期对象查找。

## 二、实现机制：字节码层面的继承

- 子类 `.class` 的常量池 `super_class` 指向父类 `Class` 项；加载时 JVM 把父类的字段、方法（含 vtable 槽位）整合进子类的 `Klass` 结构。
- **构造器链（最易被坑的点）**：子类构造器体**第一条语句**必须是对父类构造器的调用（显式 `super(...)` 或隐式 `super()`）。原因——JVM 规定"父类先完全初始化，子类才初始化"。若父类**没有无参构造器**，子类必须显式 `super(实参)`，否则编译失败。见 `examples/ex01-inheritance-super.json`：`Dog()` 先 `super()` 触发 `Animal()`，再执行自身体。
- **字段隐藏（hide）vs 方法重写（override）**：子类声明与父类同名的字段只是"隐藏"父类字段（两块独立内存），**不是多态**；方法同名同签名才是重写（动态分派）。字段隐藏见 ch03 concept 02 与 `examples/ex07-field-no-polymorphism.json`。

## 三、工程实践

- **优先组合，谨慎继承**（Effective Java 第 18 条）：只有当确实是 is-a、且子类能完整遵守父类契约时才用继承；否则用"持有引用 + 转发"的组合，避免父类实现变化击穿子类。
- **永远加 `@Override`**：重写父类方法时标注，编译器会帮你校验签名是否真的一致。
- 不要把 `protected` 字段暴露给子类——应暴露 `protected` 方法，字段仍 `private`，减少耦合面。

## 四、边界与陷阱

1. 父类只有带参构造器时，子类构造器**必须**显式 `super(args)`，否则编译不过。
2. 构造器里调用**可重写方法**是高危操作：动态分派会调到子类覆写版，而那时子类字段还没初始化（见 concept 02 陷阱）。
3. 子类不能"选择性继承"——父类的 `public/protected` 成员全部可见，无法在子类里收窄可见性（与方法重写相反）。
4. 隐藏字段不会通过 `super` 自动暴露：父类引用访问到的是父类那份字段。

## 三视角解析

### 🧑‍💻 程序员视角
- **组合优于继承**：继承会绑定实现细节，父类一改子类就可能坏；接口 + 委托通常更稳。
- Java 是**单继承**（`extends` 只能一个类），但可实现多个接口——用接口组合替代多继承。
- 子类构造器一定会调用父类构造器（显式 `super(...)` 或隐式 `super()`），父类没有无参构造器时必须显式调用。

### 🎓 博士生视角
- 继承建立的是 **is-a 子类型关系**，必须满足**里氏替换原则（LSP）**：子类对象应能在任何父类出现的地方正确工作。违反 LSP 的典型症状是子类「加强前置条件或削弱后置条件」。
- Java 选择「单继承 + 多接口」是为了规避 C++ 菱形继承的复杂性（重复基类子对象与二义性），用接口来获得多重类型能力。
- **字段不发生动态绑定**：`super.field` 与 `this.field` 在字节码里是不同字段（各自解析到不同类的字段），只有方法才走动态分派。这解释了很多「为什么字段没有多态」的困惑。
- 构造器链意味着父类构造器在子类字段赋值**之前**执行，因此父类构造器中调用可重写方法是危险模式。

### 📚 考研者视角
- 与 C++ 的继承（含多继承、菱形、虚继承）对比是常见延伸题；408 本身不考 Java 继承。
- 若考程序设计语言/软件工程，常考「继承与组合的取舍」「里氏替换原则」。
- 记忆锚点：**单继承多实现**；**只有方法有动态绑定，字段没有**。
