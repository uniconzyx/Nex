# agent-ch13 · 前沿技术追踪：建立自己的信息过滤系统

> 对应图片 DAY 45（B 站李沐每周论文精读）· 先修：agent-ch08（Transformer 核心机理）· 面试权重：★★★★☆
> 说明：面试官不问你「怎么读论文」，而问「顶会每年上万篇，你的信息来源是什么、
> 凭什么判断一篇论文值不值得花一个周末、复现不出来怎么归因」。
> 本章把「追前沿」从鸡汤落成**可执行的筛选规则、可运行的复现脚本、可打分的雷达表**。

## 本章目标

学完你应该能：

1. **建立信息源分层与打分规则**：把信息源分为顶会 / 实验室博客 / 工程博客 / 社区四层，
   给出「可信度 × 时效 × 相关度」的加权打分公式与阈值，能对一周内的候选信息排序并解释排序理由。
2. **执行三遍读法并分配时间预算**：按「标题摘要 → 图表结论 → 方法与局限」三遍递进，
   每遍有固定时间盒与「是否继续」的判据，能在每周固定预算内决定每篇论文读到第几遍。
3. **用评分卡判断一篇论文值不值得复现**：从可复现性（代码/数据是否公开）、影响面
   （引用与社区讨论）、与自身问题的相关度、时效四个维度打分，给出「复现 / 精读不復现 /
   只记卡片」三档处置，而不是凭标题热度做决定。
4. **跑通复现的最小闭环**：用裁剪策略（数据集缩样、模型缩参、步数缩减）把论文核心数值实验
   缩小到单机可跑，输出指标，并用「数据 / 实现 / 评测口径」三层框架记录与原文的差异归因。
5. **维护个人技术雷达**：用 Adopt / Trial / Assess / Hold 四象限记录技术项，
   按 benchmark 口径、工程成熟度、社区活跃度、替代方案打分并随版本迭代做象限迁移，
   能向团队解释每一项为什么落在当前象限。

## 关键认知（本章最值钱的三句）

- **目标不是「读完所有论文」，而是「建立过滤与复现习惯」**：NeurIPS/ICML 一届录用
  上千篇，任何「全都要读」的策略都会在第三周崩溃。可执行的系统 = 信息源分层（先验过滤）
  + 三遍读法（逐级加深，带止损）+ 评分卡（决定投入多少时间）。**先决定不读什么，再决定读什么。**
- **复现的最小闭环是「数据 → 脚本 → 指标 → 差异归因」四步，缺一步就不算复现**：
  没有差异归因的复现只是「跑了个数」——你要能回答差几个点、差在哪一层（数据 / 实现 /
  评测口径）、哪一层是你主动裁剪造成的。**复现的价值在归因表里，不在最终数字里。**
- **技术雷达是决策语言，不是收藏夹**：每一项技术必须落在 Adopt / Trial / Assess / Hold
  四象限之一，且带打分依据与复查时间；「看起来不错先放着」的条目就是雷达里的死数据。
  雷达随版本迁移（Assess → Trial → Adopt）才是它在维护的证据。

## 技术交付物（来自 manifest.tech_load）

**交付物：3 篇论文的最小复现脚本（可跑、有指标、记录与原文差异）。**

验收口径（对应 project.json 的任务，逐条可核对）：

- 有一个统一的复现框架：每条复现脚本固定随机种子、单次运行 < 10 分钟（CPU）、
  输出至少一个数值指标（如准确率 / 误差曲线 / 达到目标损失所需步数）；
- 3 篇论文各自对应一个独立脚本，论文真实存在、复现的是其**核心数值结论**
  （如优化器的收敛行为、低秩近似的误差-秩权衡），不要求复现完整模型；
- 每篇复现附一份「差异记录」：与原文指标差多少、按「数据 / 实现 / 评测口径」
  三层归因，主动裁剪的部分（缩样 / 缩参 / 缩步数）必须单独标注；
- 复现结果能回答一个工程问题（如「LoRA 的秩取多少在我们的任务上够用」），
  而不是只打印「论文说 94.5，我跑出 91.2」；
- 3 个复现的结论汇总进一张个人技术雷达表（Adopt / Trial / Assess / Hold + 依据 + 复查日期）。
- 说明：本学科的示例环境禁网、无密钥、无外部数据文件，所有「论文复现」均为
  对真实论文核心结论的**本地缩小版验证**（合成数据 + numpy 实现），
  原始数据与完整实验配置指向论文原文与对应 GitHub 仓库。

## 与 ai 学科的分界

`ai` 学科负责模型内部的完整机理：Transformer 完整推导、LoRA 数学、优化器收敛性证明、
各类训练目标的公式与理论性质。

本章**只要求信息工程与复现工程**：信息源怎么分层、论文怎么打分、复现怎么裁剪、
差异怎么归因、雷达怎么维护。遇到「为什么 Adam 在这个 loss 面上收敛更快」
「低秩更新的误差界怎么证」这类深层机理问题，回 `ai` 学科追推导；
本章停在「够用即止的原理 + 工程判据 + 可运行产物」。
