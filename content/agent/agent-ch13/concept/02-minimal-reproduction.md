# 最小复现闭环：裁剪策略、指标对齐与差异归因

> tech_load 是「3 篇论文的最小复现脚本（可跑、有指标、记录与原文差异）」。
> 复现的第一障碍不是「看不懂论文」，而是「论文的实验你跑不起」：
> 8 卡 × 数天、TB 级语料、未公开的清洗细节。本章把复现改造成
> **数据 → 脚本 → 指标 → 差异归因** 四步闭环，每一步都可执行、可记录、可止损。

```text
最小复现四步闭环
 数据 ─▶ 脚本 ─▶ 指标 ─▶ 差异归因
   │      │       │        │
   └──── 可跑/可记录/可止损(任一步失败即停) ◀─┘
 裁剪: 三因素(算力/语料/细节)缩到可跑
 验收: 与原文指标偏差可解释
```

## 1. 从论文到可运行脚本：三因素裁剪与指标偏差

中立陈述：最小复现的核心动作是**裁剪**——把论文实验按三个正交因素缩小，
使单机 CPU 能在分钟级跑完，同时尽量保住论文的核心机制不被裁掉：

```
                    论文实验
                       │
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
   数据集缩样      模型缩参        步数缩减
   (N: 1M→1万)   (width: 4096→64) (epochs: 100→20)
        │              │              │
        ▼              ▼              ▼
   估计量方差 ↑    假设空间容量 ↓   优化欠收敛
   （偏差方向不定） （系统性偏低）    （系统性偏低）
```

三个因素的**代价结构不同**（经验判断，量化见下方实验）：缩样同时推高方差并通常拉低均值——
指标变噪声，不同种子的复现结果能差几个点；缩参会系统性压低上限——假设空间小了，
但小任务上有时反而接近原论文（原论文可能本来就 overkill）；
缩步数导致欠收敛——loss 曲线还在降就被截断，但方向已知、最可控。因为代价结构不同，
**裁剪必须逐因素记录**，否则指标对不上时你无法判断差在哪：

| 裁剪因素 | 主要影响 | 指标偏差方向 | 归因记录要点 |
|---|---|---|---|
| 数据集缩样 | 方差 ↑、罕见模式丢失 | 通常偏低且波动大 | 记录缩样比例与采样方式 |
| 模型缩参 | 容量 ↓ | 系统性偏低、跨种子不稳定 | 记录原参数量与保留比例 |
| 步数缩减 | 欠收敛 | 系统性偏低 | 记录 loss 是否已平台化 |

统计上有个可用的标尺：估计量的标准误大致按 `1/√N` 收缩——训练样本从 100 万缩到
1 万（1/100），标准误放大约 10 倍；如果论文报的是多次实验均值，你还丢了平均的方差缩减。
这就是「复现指标低 2 个点」最常见的无辜解释：**你的不确定性根本没论文那么小**。

```python
import numpy as np

def make_data(rng, n, d=32, flip=0.05, noise=0.7):
    """四簇 XOR：类0 = (±2,0)，类1 = (0,±2)——线性不可分但簇结构明确。"""
    y = rng.integers(0, 2, n)
    offs = np.array([[2.,0.],[-2.,0.],[0.,2.],[0.,-2.]])
    X = rng.normal(size=(n, d))
    X[:, :2] = offs[y * 2 + rng.integers(0, 2, n)] + rng.normal(scale=noise, size=(n, 2))
    return X, np.where(rng.random(n) < flip, 1 - y, y)

def train_mlp(rng, n, hidden=8, epochs=100, d=32, lr=0.01):
    """one-hidden-layer MLP + 全批量 Adam，返回固定测试集上的准确率。"""
    X, y = make_data(rng, n, d)
    W1 = rng.normal(0, np.sqrt(2/d), size=(d, hidden)); b1 = np.zeros(hidden)
    W2 = rng.normal(0, np.sqrt(2/hidden), size=(hidden,)); b2 = 0.0
    ps = [W1, b1, W2, b2]; ms = [np.zeros_like(p) for p in ps]; vs = [np.zeros_like(p) for p in ps]
    for t in range(1, epochs + 1):
        H = np.maximum(0, X @ W1 + b1)
        P = 1 / (1 + np.exp(-(H @ W2 + b2)))
        G = (P - y) / n
        dH = np.outer(G, W2) * (H > 0)
        for p, g, m, v in zip(ps, [X.T @ dH, dH.sum(0), H.T @ G, G.sum()], ms, vs):
            m[...] = 0.9*m + 0.1*g; v[...] = 0.999*v + 0.001*g*g
            p -= lr * (m/(1-0.9**t)) / (np.sqrt(v/(1-0.999**t)) + 1e-8)
    Xte, yte = TEST
    Pte = 1 / (1 + np.exp(-(np.maximum(0, Xte @ W1 + b1) @ W2 + b2)))
    return float((((Pte > 0.5).astype(int)) == yte).mean())

TEST = make_data(np.random.default_rng(999), 1000)   # 固定测试集
for n in (200, 1000, 2000):                          # 5 个种子报均值±标准差
    accs = [train_mlp(np.random.default_rng(s), n) for s in range(5)]
    print(f"训练 N={n:5d}: 平均准确率 {np.mean(accs):.4f}，跨种子标准差 {np.std(accs):.4f}")
# 训练 N=  200: 平均准确率 0.5960，跨种子标准差 0.0291
# 训练 N= 1000: 平均准确率 0.8518，跨种子标准差 0.0106
# 训练 N= 2000: 平均准确率 0.8832，跨种子标准差 0.0023
```

上面这组数字就是缩样的账本：N 从 2000 缩到 200，平均指标掉 **28.7 个点**、
**标准差放大约 12.7 倍**（与 `1/√N` 的估计一致：√(2000/200)≈3.2 的理论值之上，
还有「罕见模式丢失」的额外损失）——单次复现的噪声已经和信号同量级。
所以最小复现的纪律是：**宁可缩参与缩步数（偏差可控、方向已知），也不要随意缩样还不报方差**；
一定要缩样时，跑多个种子报均值 ± 标准差，而不是报一个「最好成绩」。

## 2. 指标对齐与差异归因：三层框架与止损规则

中立陈述：指标对齐（alignment）要先于复现跑分——同一篇论文里，
「准确率」可能指宏平均、微平均或某个子集；「收敛步数」可能按不同 loss 阈值定义；
「训练成本」可能不含数据加载。对齐清单（跑分前逐项打勾）：

```
□ 测试集：同划分还是同数据不同划分？划分种子是否公开？
□ 指标：精确定义（macro/micro、top-1/top-5、是否去停用词）？
□ 平均方式：单次跑分还是多次平均？报均值还是报最好？
□ 预处理：归一化、分词、清洗规则是否写全？未写全的按常见默认先试并记录
```

差异归因用三层框架，把「差几个点」拆成可行动的项：

| 层 | 查什么 | 典型差异源 |
|---|---|---|
| 数据层 | 划分、预处理、缩样 | 测试集泄漏/缺失、清洗规则不同、缩样比例 |
| 实现层 | 初始化、正则、优化器细节 | 权重初始化尺度、dropout、warmup 有无 |
| 评测口径层 | 指标定义、平均方式 | macro vs micro、单次 vs 均值、单位换算 |

控制变量法归因（不要一次改多个）：以「最接近原文」的配置为基线，
**每个因素各做一次单因素实验**（只改这一个、其他全部保持原文配置），记录各自的 Δ；
再和自己完整配置的总差相减：`残差 = 总差 − Σ单因素Δ`。
残差显著不为零说明存在交互效应——多个差异叠在一起的效果不等于各自效果之和，
此时任何单因素解释都是过度归因，正确动作是做 2×2 网格实验隔离交互。

```python
def attribute_gap(single_factor_deltas, reported, mine):
    """single_factor_deltas: [(因素, 单因素实验的 Δ)]；残差 = 总差 − ΣΔ = 交互效应。"""
    total = mine - reported
    residual = total - sum(d for _, d in single_factor_deltas)
    return total, residual

# 三个因素各自从「原文配置」出发做单因素实验，只改自己这一个
deltas = [("数据划分", -0.7), ("初始化", -0.4), ("评测口径", -0.3)]
total, residual = attribute_gap(deltas, reported=94.5, mine=91.2)
print(f"总差 = {total:+.1f}；单因素合计 = {sum(d for _,d in deltas):+.1f}；残差（交互） = {residual:+.1f}")
# 总差 = -3.3；单因素合计 = -1.4；残差（交互） = -1.9
```

注意残差 −1.9 的幅度比任何单因素都大——三个「小差异」叠出 1.9 个点的交互效应
（例如小初始化 × 少步数在小模型上尤其致命）。此时把差距摊到三个因素头上
各写一句「略有影响」就是编故事；**正确动作是承认交互存在，补一组 2×2 网格实验**，
或者把「存在交互」本身作为复现结论记录下来——它回答了「论文的哪个设置最脆弱」，
这比一个对齐的数字更有信息量。
**复现失败的常见原因排序（经验判断）**：① 论文漏写实现细节（初始化、学习率 schedule）；
② 数据预处理未写全；③ 评测口径不一致（最常见也最容易发现）；
④ 代码 bug（建议：先用极小配置过拟合测试——能背下训练集说明前向反向没断）；
⑤ 环境与版本差异（框架版本、随机数生成器变化）。止损规则：归因阶段耗时超过
复现预算 50% 且差距仍 > 2 个点，降级为「部分复现」——只记录已验证的部分与存疑清单，
这也算完成 tech_load（差异记录本身就是交付物）。

## 三视角解析

### 🧑‍💻 程序员视角 程序员视角

- 【裁剪策略】裁剪顺序有讲究：先缩步数（只要 loss 平台化，指标几乎不掉），
  再缩参（小任务上常常够用），最后才缩样（方差爆炸且不可逆）。
  「过拟合测试」是复现的第一道门：用 100 条样本训练，验证集准确率能否到 99%+
  ——不能说明你的数据流或模型实现有 bug，别急着调大。
- 【指标对齐】把对齐清单写进复现脚本的注释里，跑分前逐项确认；
  尤其小心「论文报的是验证集还是测试集」——拿验证集调参、报测试集是基本纪律，
  复现时混用会得到虚高指标，比虚低更危险。
- 【差异归因】差异记录就是资产：每次复现存「配置快照 + 指标 + 归因结论」，
  下次同类论文直接复用差异模板。工程上把复现脚本参数化（`--data-frac --width --steps`），
  裁剪因素就是三个 CLI 参数，归因表自动生成。
- 【止损】止损不是失败是纪律：设「归因工时上限」，超了就把复现降级为
  「精读 + 差异清单」，把省下的时间投到评分卡里更高分的论文上。

### 🎓 博士生视角 博士生视角

- 【裁剪策略】裁剪与统计功效是一体两面：样本量 N 决定标准误 ~ 1/√N，
  复现实验前应先算「我的 N 能分辨多大的效应」——如果论文提升小于你的噪声水平，
  这个复现在设计上就不可能确认原结论，要么加样本要么换更敏感的指标。
- 【指标对齐】评测口径差异属于「构念效度」问题：macro 与 micro 平均在类别不均衡时
  可以差出数量级；top-1 与 top-5 衡量不同的失败容忍度。跨论文比较前先对齐
  操作定义，否则比较的是两个不同的构念。
- 【差异归因】控制变量归因在实验科学里是标准方法，残差项对应「交互效应」：
  常见的是「初始化 × 步数」交互（小初始化需要更多步才展开），
  报告残差不是失败而是发现了非线性结构，值得单独做一组 2×2 网格实验。
- 【历史视角】复现危机（reproducibility crisis）在多学科被反复研究，
  ML 领域「代码 + 数据 + 环境」三件套公开是缓解手段；「复现不出」往往不是
  学术不端而是信息不完整——这正是「差异归因表」存在的理由：
  把不完整显式化，而不是互相指责。

### 📚 考研者视角 考研者视角

- 【裁剪策略】必会关系：**样本量与估计量方差**（`Var ∝ 1/N`）、
  **模型容量与偏差-方差权衡**（缩参 ↑偏差 ↓方差，缩样 ↑方差）、
  **欠拟合与过拟合的 loss 曲线判别**（训练/验证 loss 同高 = 欠拟合；
  训练低验证高 = 过拟合）。这是「复现指标偏低」类论述题的标准分析框架。
- 【指标对齐】常考口径题：宏平均 vs 微平均 F1 的区别与适用场景；
  top-1 / top-5 准确率定义；「收敛步数」必须声明按什么 loss 阈值判定。
  答题时先写「指标的操作定义」再比较，是区分背过书与真懂的标准动作。
- 【差异归因】常见失分点：把「复现指标低」直接归因为「论文造假」——
  正确分析路径是数据 → 实现 → 评测口径逐层排查，并说明每层的可检测信号
  （如评测口径可用「同一预测、两种口径」直接验证）。
- 【易混概念】**复现（reproducibility）与可重复性（repeatability）**：
  同环境同代码重跑得到同结果叫可重复；换环境换实现得到同结论叫复现。
  论文里常说前者，工程上要的是后者——两类「对不上」的解法完全不同。
