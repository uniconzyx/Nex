# 信息过滤：信息源分层、三遍读法与论文价值判断

> 前沿追踪的第一性问题不是「读得快」，而是「读得完」：一届顶会录用上千篇，
> 实验室博客、工程复盘、社区热帖每天还在源源不断地来。**任何试图全读的策略都会在
> 第三周崩溃**，所以本章把「追前沿」改造成一个两级过滤系统：
> 第一级用信息源分层做先验过滤（什么来源默认值得看），第二级用三遍读法做逐级加深
> （每遍带时间盒与止损判据）。本章 tech_load 是 3 篇论文的最小复现，
> 复现对象就是从这套过滤系统的出口选出来的。

## 1. 信息源分层与可信度排序：先验过滤的量化规则

中立陈述：把信息源按「生产机制」分四层——顶会/期刊论文（同行评审）、
实验室博客（发布方自述，有动机偏差）、工程博客（一线实践者的复盘，通常带失败细节）、
社区讨论（论坛/群聊，信噪比最低但时效最快）。分层的本质是**给每条信息一个可信度先验**：
顶会论文默认 0.9+，社区热帖默认 0.4 以下。但可信度不是唯一维度——一篇半年前的顶会论文
对「今天要解决的问题」可能毫无价值，而时效（freshness）与相关度（relevance）
必须同时进入打分。工程上用一个加权分数把三维合一：

```
score = w_c · credibility + w_f · freshness(days) + w_r · relevance
freshness(days) = 0.5^(days / 14)      # 半衰期 14 天：两周前的信息价值减半
```

| 层级 | 来源类型 | 可信度先验 | 时效权重 | 典型用途 | 主要风险 |
|---|---|---|---|---|---|
| L1 | 顶会/期刊论文 | 0.9–1.0 | 中 | 精读与复现对象 | 评审也不总靠谱； benchmark 口径要核 |
| L2 | 实验室博客 | 0.75–0.9 | 高 | 快速了解发布方能力边界 | 选择性披露（只报好的） |
| L3 | 工程博客 | 0.6–0.8 | 高 | 复现坑位与线上教训 | 个案偏差，不可直接外推 |
| L4 | 社区/群聊 | 0.2–0.5 | 极高 | 热点嗅探，仅作线索 | 以讹传讹，二手三手信息 |

```python
def source_score(cred, days, rel, w=(0.5, 0.3, 0.2)):
    """信息源打分：可信度（先验）× 时效（半衰期 14 天）× 相关度。"""
    freshness = 0.5 ** (days / 14)
    return w[0] * cred + w[1] * freshness + w[2] * rel

# 同一条「重大发布」在不同层级、不同天数下的分数对比
for tier, cred in [("L1 顶会论文", 0.95), ("L2 实验室博客", 0.85),
                   ("L3 工程博客", 0.70), ("L4 社区热帖", 0.40)]:
    s_new = source_score(cred, days=1, rel=0.8)
    s_old = source_score(cred, days=60, rel=0.8)
    print(f"{tier}: 当天 {s_new:.3f} / 60 天后 {s_old:.3f}")
# L1 顶会论文: 当天 0.921 / 60 天后 0.775
# L2 实验室博客: 当天 0.821 / 60 天后 0.675
# L3 工程博客: 当天 0.671 / 60 天后 0.525
# L4 社区热帖: 当天 0.371 / 60 天后 0.225
```

注意两组数字的交叉：60 天后的 L1（0.775）仍高于当天的 L4（0.371）——**层级差是时效
追不回来的**，这就是「先看来源、再看日期」的量化理由。反过来，L1 里一条与你手头问题
相关度 0.1 的论文，分数会被 relevance 项直接压到底，说明分层不是唯一起点，
相关度是每个工程师私有的先验。

## 2. 三遍读法与论文价值判断：逐级加深，带止损

中立陈述：三遍读法把「读透一篇论文」拆成三个有明确输入输出的阶段
（经验方法，多个论文阅读指南均有类似表述）：

```
第一遍（5–10 min）  标题 + 摘要 + 结论          →  判断「与我的问题相关吗」
        │  不相关 → 记入卡片库，止损（不读正文）
        ▼ 相关
第二遍（20–40 min）  图表 + 结论 + 实验设置      →  判断「结论可信、值得细读吗」
        │  存疑 → 记下存疑点，止损（只读存疑章节）
        ▼ 可信
第三遍（1–3 h）      方法 + 公式 + 局限 + 复现细节 →  产出精读笔记 + 复现计划
```

每遍都是一次**止损点**：第一遍的产出是一张卡片（标题/一句话结论/相关度），
第二遍的产出是「读 / 不读」的决策与存疑清单，只有第三遍才允许产生复现工时。
与之配套的是**论文价值评分卡**——决定第三遍之后是否投入复现的四个维度：

| 维度 | 权重（经验判断） | 看什么 | 低分信号 |
|---|---|---|---|
| 可复现性 | 0.30 | 有无代码/数据、配置是否写全 | 只说「代码后续开源」 |
| 影响面 | 0.25 | 引用、社区跟进复现、榜单采用 | 无人跟进的孤文 |
| 与自身问题相关度 | 0.30 | 结论能否回答你当前项目的疑问 | 方向热但用不上 |
| 时效 | 0.15 | 是否已被后续工作超越 | 半年前已被新 SOTA 取代 |

总分 ≥ 3.5（满分 5）进入复现候选，2.5–3.5 只做精读笔记，< 2.5 只留卡片——
**阈值是经验判断，应按你自己的时间成本标定**，但「必须有阈值」比「阈值是多少」重要。

```python
def paper_scorecard(repro, impact, relevance, recency):
    """论文价值评分卡：0-5 分 × 权重，返回总分与处置档位。"""
    w = {"repro": 0.30, "impact": 0.25, "rel": 0.30, "rec": 0.15}
    total = (w["repro"] * repro + w["impact"] * impact
             + w["rel"] * relevance + w["rec"] * recency)
    if total >= 3.5:
        action = "复现候选"
    elif total >= 2.5:
        action = "精读不復现"
    else:
        action = "只记卡片"
    return total, action

# 一篇「有代码、被广泛跟进、正好解决我们的检索延迟问题」的论文
print(paper_scorecard(repro=5, impact=4, relevance=5, recency=4))   # (4.45, '复现候选')
# 一篇「很热但与我们无关、且无代码」的论文
print(paper_scorecard(repro=1, impact=5, relevance=1, recency=5))   # (2.50, '精读不復现')
```

anti-hype 是这套系统的隐含目标：标题里的「首个 / 碾压 / 革命性」与实质内容
（有无 baseline 对比、有无失败案例、指标口径是否写全）的比值，本身就是一层过滤
（示例 ex06 给出可执行的规则版）。**hype 词密度高而实质信号少的条目，一律降层处理。**

## 三视角解析

### 🧑‍💻 程序员视角 程序员视角

- 【信息源分层】把分层落成代码：给每个 RSS/ newsletter 源配 `(tier, cred)` 元数据，
  进池先过 `score = 0.5·cred + 0.3·freshness + 0.2·rel`，低于阈值直接进「稍后读」而不进
  「本周读」——你的注意力是本周最稀缺的资源，排序就是分配（示例 ex01 的实现口径）。
- 【三遍读法】三遍读法的工程版是「时间盒」：第一遍 10 分钟闹钟响就停，
  逼自己只读摘要和结论；第二遍只看图表，图表看不懂的公式先跳过；
  第三遍才打开附录。**每遍设止损，是防止「读了两小时还在第 2 节」的唯一办法。**
- 【价值判断】评分卡先看「有没有代码」：无代码的论文复现成本高三到五倍，
  默认降一档处置；有代码也要看 license 与数据许可，商用前先过一眼。
- 【anti-hype】工程博客里「我们上线了」比论文里「我们 SOTA 了」信息量高一个数量级：
  前者被迫谈失败与成本，后者没有这个机制。看到热文先找它的「局限」与「失败案例」段落，
  没有这两个段落的，经验判断：信息量减半。

### 🎓 博士生视角 博士生视角

- 【信息源分层】分层本质是贝叶斯先验：同行评审是「至少两人认为有新意与正确性」的
  弱信号，实验室博客有发布方动机偏差（选择性披露），社区信息经过多层转述后
  与原始事实的偏差按转述链放大。可信度先验 + 时效衰减 + 私有相关度，
  正好对应「先验 × 似然 × 任务相关」的结构。
- 【三遍读法】三遍读法对应科研阅读的三种认知负荷：第一遍是**分类**（相关 / 不相关），
  第二遍是**验证**（结论是否被证据支持），第三遍是**重构**（能否自己推出来）。
  认知科学上这三步不可跳过——直接进入第三遍的「公式硬啃」是初入科研最常见的时间浪费。
- 【价值判断】影响面要用「引用结构」而非引用数看：被后续工作当作 baseline 反复对比的，
  才是领域承认的贡献；高引但无人跟进的（通常是综述或工具文），复现价值要重新评估。
- 【历史演进】论文过滤手段本身在演进：从「顶会录用即权威」到「开放评审 + 公开复现」
  （如 Papers with Code 把「有没有人跑出来」变成一等信号），
  复现率正在成为新的分层维度——这是「可信度」概念在领域内的演化。

### 📚 考研者视角 考研者视角

- 【信息源分层】常考概念：**同行评审（peer review）的定义与局限**——它是质量控制机制
  不是正确性保证；**一次文献与二次文献**的区别（原始论文 vs 综述/转述），
  答题时引用社区二手结论是典型失分点。
- 【三遍读法】按「输入 → 输出」记忆：第一遍输入标题摘要、输出「相关性判断」；
  第二遍输入图表结论、输出「可信度判断」；第三遍输入方法细节、输出「复现计划」。
  常见题：「为什么读论文要从摘要开始而不是正文？」标准答案：先分类再深读，
  避免在无关论文上消耗认知资源。
- 【价值判断】指标口径是高频考点：SOTA 要在「同一测试集、同一划分、同一指标」
  下比较；跨 benchmark 的数值不可直接对比（如不同 few-shot 设置下的准确率）。
  答题遇到「某论文声称 SOTA」先问「在哪个数据集、什么设置、与哪些基线比」。
- 【易混概念】**时效性 vs 经典性**：半衰期衰减适用于「技术动态」类信息，
  不适用于基础工作（如 "Attention Is All You Need" 的方法论部分多年有效）——
  两类信息用两套筛选规则，别用同一个时间阈值一刀切。
