# ai-ch08 常见陷阱

1. **把 TTFT 与 TPOT 混成一个「延迟」** —— 以为优化延迟就是换更快的卡。正确：先分清是首 token 慢（Prefill/排队）还是逐 token 慢（Decode/带宽），两阶段药方完全不同（见 ex03）。

2. **只看平均延迟做 SLA** —— 均值掩盖长尾，1% 的 10 秒请求会让体验崩坏而仪表盘「很健康」。正确：用 P95/P99 定义 SLO，并按阶段拆出 TTFT/TPOT 分位。

3. **估算显存时只算权重、不算 KV Cache** —— 7B fp16 权重约 14 GB，但 4096 长上下文 × 大 batch 的 KV 常比权重还大。正确：用 `2×L×H_kv×d_head×S×B×字节` 先算 KV 再选卡（见 ex01）。

4. **把「注意力头数」当「KV 头数」** —— GQA/MQA 下二者不等，误用注意力头数会把 KV 显存估大数倍。正确：查模型 config 里的 num_key_value_heads。

5. **KV Cache 公式漏乘 2** —— K 与 V 各存一份，漏掉即少算一半显存，直接导致上线 OOM。正确：公式首项恒为 2。

6. **认为「batch 越大吞吐越高」** —— 静态批处理下批越大，长尾请求越拖累整批，槽位空转越严重。正确：改用连续批处理，并以迭代为粒度补位（见 ex04）。

7. **量化只看显存下降、不看质量回归** —— 以为 4-bit 白拿。正确：量化后必须跑评测集对比准确率/合规率，并看相对误差长尾。

8. **只评估量化误差的均值** —— 平均误差很小就放心。正确：必须看最大/高分位相对误差，实测 NF4 在小权重上相对误差可达 1.0（见 ex02）。

9. **直接用 INT8 per-tensor 量化激活** —— 激活中的离群值会把整个张量的量化尺度拉爆。正确：激活用 per-channel/per-group 量化或只量化权重。

10. **把 GGUF 当成量化算法** —— 它是文件格式（llama.cpp 生态），内部可承载多种量化类型。正确：区分「格式」与「量化方案」。

11. **语义缓存不设阈值/TTL/版本** —— 图省钱直接返回最相似历史答案，结果命中到相近但不同的问题，返回错误答案。正确：阈值 + TTL + 结果版本三件套，且时效/个性化内容禁用（见 ex06）。

12. **优化顺序倒置：先上推理加速框架** —— 跳过度量直接换框架/开投机，往往只有个位数收益。正确：先度量 → 砍上下文 → 分模型 → 加缓存 → 最后才是推理加速。

13. **前缀缓存被动态 system 提示毁掉** —— 在 system 里插时间戳/随机 ID，导致缓存 100% miss，还误以为「缓存没效果」。正确：system 必须逐字节稳定，动态内容移到 user 侧。

14. **可观测性只记 token 数、不记 Trace** —— 出了慢请求无法定位是检索、重排还是 LLM 慢。正确：用 trace_id 串 span，span 内记模型版本、token、耗时、成本。

15. **只用准确率评测、忽略格式合规率** —— 下游要 JSON，模型返回自然语言，准确率再高也挂。正确：准确率与格式合规率分开统计、分开告警（见 ex10）。

16. **LLM-as-Judge 未校准就拿来做门禁** —— 位置偏差/长度偏差/自我偏好会让分数系统性偏移。正确：随机化位置、长度归一、异构 judge + 与人工标注算 Kappa（见 ex07）。

17. **A/B 只看涨跌、不看显著性** —— 小样本波动被当成收益，提前全量上线。正确：先定样本量，用两比例 z 检验判 p<0.05，小样本延长观测（见 ex12）。

18. **影子模式把实验流量写回生产库** —— 影子请求与真实请求混写，污染线上数据。正确：影子链路只读、只记录到独立通道。

19. **只防直接提示注入、忽略间接注入** —— RAG 检索到的文档或工具返回里藏着恶意指令。正确：把外部内容一律视为不可信数据，入上下文前净化并明确标注，永不作为指令执行（见 ex08）。

20. **把提示注入防御当成一层过滤器** —— 认为过滤了关键词就安全。正确：纵深防御（净化 + 通道隔离 + 最小权限 + 输出校验 + 监控），关键词过滤只是第一层。

21. **RAG 文档含 PII 未脱敏就入库** —— 检索时把用户隐私直接喂给模型并写进向量库与日志。正确：入库与日志前置脱敏，向量条目与原文一并管理（见 ex11）。

22. **认为「删主表 = 删干净」** —— 缓存、向量库、日志、备份仍留有副本。正确：给每条数据打主体 ID，删除时级联到全部派生副本。
