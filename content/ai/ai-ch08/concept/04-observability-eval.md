# 可观测性与线上评测

## 主题一：可观测性三件套与 AI 特有维度

**Trace**：一次请求的端到端调用链（检索 → 重排 → LLM → 工具 → LLM），每个 span 带输入/输出/耗时/token；
**Log**：结构化事件日志（请求参数、模型版本、错误、脱敏后的输入输出）；
**Metric**：可聚合的时间序列（QPS、延迟分位、错误率、成本）。
传统 APM 只覆盖后两者且只看延迟/错误/流量。LLM 系统必须新增四个**AI 特有维度**：
**幻觉率**（无依据/与证据矛盾的输出占比）、**格式合规率**（结构化输出的可解析率，见 ex10 实测 0.875）、**单请求成本**（token×单价，见 ex09）、**Agent 步数**（一次任务的工具调用/循环轮数，步数暴涨是死循环的早期信号）。

### 🧑‍💻 程序员视角
- **Trace 是一等公民**：没有 span 级 token 与成本，就无法回答「为什么这个请求花了 3 毛钱」；主流做法是 OpenTelemetry 语义约定 + LLM 专用属性（model、prompt_tokens、completion_tokens）。
- **成本要按请求打标**：按租户/功能/模型维度聚合，否则账单异常时无从归因。
- **Agent 步数设熔断**：max_steps 超限即中断并上报；步数分布的长尾通常就是成本失控点。
- **日志脱敏**：日志与 Trace 里的用户输入同样要过 PII 脱敏（见 ex11），别只脱主库。

### 🎓 博士生视角
- 可观测性的理论骨架是**分布式追踪的因果模型**：以 trace_id 串联 span 构成有向无环的因果图，采样策略决定观测完整性与成本的权衡（头部采样 vs 尾部采样）。
- AI 特有维度的难点在于**不可直接测量**：幻觉率没有 ground truth，只能用代理指标（LLM-as-Judge、引用支撑度、自一致性投票），因此任何「幻觉率」都带测量误差，必须报告其置信区间。
- 成本维度是把「资源消耗」折算为货币：输入/输出 token 的价差（常见 1:3~1:4）意味着输出侧观测更重要，长输出是隐性成本炸弹。

### 📚 考研者视角
- **笔面定义**：可观测性三支柱 = Metrics / Logging / Tracing；Metrics 适合聚合告警，Logging 适合事后取证，Tracing 适合定位单请求瓶颈。
- **常考口径**：QPS、P50/P95/P99、错误率、饱和度（RED / USE 方法）；LLM 场景扩展为 token 吞吐、TTFT/TPOT、单请求成本、幻觉率、格式合规率。
- **易错点**：把「日志全量采集」当可观测性（成本高且无聚合）；只做均值告警（长尾被掩盖）。

## 主题二：线上评测与 LLM-as-Judge 校准

离线评测与线上表现常有落差，因此需要**线上评测四法**：
**影子模式（shadow）**——新版本与线上并行跑同一批真实请求、只记录不返回，零风险但耗双份算力；
**A/B 实验**——按流量随机分流，看指标差异是否**统计显著**（见 ex12：样本 10000、转化 4.0% vs 4.7% 时 z≈2.43、p≈0.015 显著；100/100 的小样本 z≈1.55、p≈0.12 不显著）；
**离线回放（replay）**——用固定的评测集重放，聚合准确率/合规率（见 ex10）；
**人工抽检**——对高价值/高风险样本做人工标注，作为金标准。
**LLM-as-Judge** 可大幅降低评测成本，但必须先**校准**：它存在位置偏差（偏好靠前选项）、长度偏差（偏好长回答）、自我偏好（偏好同族模型输出）。用与人工标注的**Cohen's Kappa** 量化一致性（见 ex07 实测 Kappa=0.624，属「实质性一致」），Kappa 过低的 judge 不能用来做上线门禁。

### 🧑‍💻 程序员视角
- **组合使用**：影子模式测风险、A/B 测因果、回放测回归、抽检校准 judge，四者补位而非互替。
- **A/B 别提前偷看**：样本量与观测周期要先定，否则「看三天有显著就上线」会制造假阳性。
- **Judge 校准清单**：随机化选项位置、做长度归一、用异构模型当 judge、定期与人工标注对齐 Kappa。
- **上线门禁**：准确率不降 + 格式合规率不降 + P95 延迟与单请求成本不升，四项同时满足才放行。

### 🎓 博士生视角
- A/B 的统计基础是**两比例假设检验**：H0 为两组转化率相等，z = (p2−p1)/√(p̄(1−p̄)(1/n1+1/n2))，双侧 p 值由正态近似给出；样本量不足时频派方法把握度不够，可转贝叶斯或序贯检验。
- Cohen's Kappa 剔除随机一致：κ = (Po − Pe)/(1 − Pe)，其中 Pe 为按边际分布算出的期望一致率；κ 对类别不平衡敏感，极端偏斜时可用 PABAK 或 Gwet's AC1 替代。
- 影子模式的价值与代价：它避免了对用户的伤害（无因果风险），但**观测到的是反事实**——新模型在旧模型的流量分布上评测，存在分布偏移，不能完全等价于真实 A/B。

### 📚 考研者视角
- **笔面口径**：四类线上评测（影子/A-B/回放/抽检）各自的适用场景与风险；A/B 的显著性判断（p<0.05）；Kappa 的分级（<0 差，0~0.2 轻微，0.21~0.4 一般，0.41~0.6 中等，0.61~0.8 实质性，>0.8 几乎完全一致）。
- **常考计算**：给 n1,x1,n2,x2 判显著性；给混淆矩阵算 Po、Pe、Kappa。
- **易错点**：把「离线指标提升」直接等同于线上收益；把小样本波动当显著；用单一 judge 的分数当绝对真值。
