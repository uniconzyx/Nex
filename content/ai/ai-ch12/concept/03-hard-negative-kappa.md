# 难例挖掘与标注一致性：hard negative 与 Cohen's Kappa

数据工程做到中段，容易样本已经很多，继续堆它们边际收益趋零。两件事能让数据「更值钱」：
**难例挖掘**（把模型易错的样本找出来重点练）和**标注一致性量化**（用 Kappa 衡量两个标注员
到底有没有在「同一套标准」下工作）。

## hard negative / 难例挖掘

在检索、分类、对齐任务里，「难例」指那些靠近决策边界、模型容易判错的样本。以对比学习为例：
锚点（anchor）的正样本是它自己这类的，负样本应挑「离锚点最近的异类」，这叫 hard negative——
它逼模型学更细的判别边界。做法：对每个锚点算它到所有候选负样本的距离，取最近的几个当 hard
negative。益处是训练信号更「硬」，但风险是 hard negative 里可能混进「其实本该是正样本」的
标注错误，所以要配一致性校验。难例挖掘不仅用于构造，也可用于「数据巡检」：把当前模型高置信
判错的样本挑出来人工复核，往往能挖出标注 bug。

## 为什么需要 Kappa：一致率会骗人

两个标注员，各标 100 条，一致 85 条，一致率 85%——看起来很高？错。如果任务本身 90% 的样本
都是「类别 0」，两人都瞎猜「全标 0」也能有 90% 一致。需要扣除「瞎蒙也能撞上的概率」，
这就是 Cohen's Kappa。公式：先算观察到的一致率 `po`，再算「两人独立随机按各自频率标注」时
期望的一致率 `pe`，`kappa = (po - pe) / (1 - pe)`。`kappa=1` 完全一致的，`0` 等于随机，
`<0` 比随机还差（说明两人标准相反）。工程上：`kappa>=0.8` 优秀，`0.6–0.8` 可接受，
`<0.6` 必须重写规范。

## 用 Kappa 驱动标注指南迭代

典型流程：第一轮标注 → 算每对标注员的 Kappa → 找出分歧最大的样本类型 → 在 rubric 里补判据、
加边界示例 → 第二轮重标分歧样本 → 再算 Kappa。我们看到：第一轮 `kappa=0.000`（两人几乎
各标各的），补了规范后第二轮 `kappa=1.000`（完全一致）。Kappa 把「规范好不好」从主观感受
变成可追踪的数字，这是数据工程「可迭代」的关键。

## 一致性与难例的闭环

难例往往正是一致性最低的地方——模糊样本两人最容易标不同。所以「难例挖掘」和「一致性提升」
是同一枚硬币两面：把难例挑出来、统一标准、重标，既补了数据质量，又抬高了 Kappa。数据工程
不是一次性生产，而是「挖难例 → 查分歧 → 修规范 → 重标」的循环。

## 三视角解析

### 🧑‍💻 程序员视角
- hard negative 挑「离锚点最近的异类」当负样本，训练信号更硬；但里面可能混进标错的，必须配一致性校验。
- 别只看一致率，用 Cohen's Kappa 扣掉「瞎蒙也能撞上」的 pe。kappa<0.6 直接重写 rubric。
- 标注指南迭代闭环：第一轮算 Kappa → 找分歧最大样本 → 补判据加示例 → 第二轮重标 → 再算 Kappa，把它当数字追踪。
- 难例和分歧是一件事：模糊样本两人最易标不同，把难例挑出来统一标准重标，既补质量又抬 Kappa。

### 🎓 博士生视角
- Kappa 是 Cohen 1960 提出的 Chance-Corrected 一致性系数，属于分类可靠性（reliability）度量。它假设标注员独立且按边缘频率随机，由此估计 pe；当类别极不平衡时 Kappa 会失真，衍生出 Fleiss' Kappa（多标注员）与加权 Kappa（有序类别）。
- hard negative mining 与 curriculum learning 互补：前者在固定难度分布里挑难的，后者动态调整难度课程。过度挖掘 hard negative 会引入 label noise 与优化不稳定，需配合 Semi-hard negative（只挑中等难度的）做折中。
- 从统计视角，标注一致性低意味着「目标变量本身有噪声」，此时即便模型容量无限，经验风险最小化的解也会偏向噪声，这就是数据质量比模型结构更决定上限的理论根源。

### 📚 考研者视角
- 记忆锚点：**hard negative 挑最近异类；Kappa=(po-pe)/(1-pe)，扣掉瞎蒙概率；kappa<0.6 重写规范**。
- 与 408 的「混淆矩阵/准确率陷阱」对照：一致率像准确率，在类别不平衡时虚高，Kappa 像考虑到基线的修正指标。
- 面试常问「怎么评估标注质量」：答 Cohen's/Fleiss' Kappa + 分歧样本复盘 + 规范迭代，而不是「我们人工核对过」。
