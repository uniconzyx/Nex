# ai-ch02 · 视觉与序列建模 —— 高频陷阱

1. **把深度学习的「卷积」当成严格数学卷积** —— 框架里的 Conv 实际是**互相关**（cross-correlation，核不翻转）。因为核可学习，翻转与否不影响拟合，但推导公式/和信号处理对账时要清楚这点，否则尺寸与梯度推导会差一个翻转。正确写法：把它当作互相关来理解，论文公式若写翻转卷积要手动对应。

2. **输出尺寸公式漏掉向下取整** —— out = floor((n + 2p − k)/s) + 1 是**整数下取整**。padding=same 且 stride>1 时输出是 ceil(n/s) 而非 n/s（可能非整数），直接整除会算错甚至张量对不齐。正确写法：用 floor 计算 valid，用 ceil 计算 same；写代码用 `(n + 2p − k) // s + 1`。

3. **感受野误算成 (k−1)×L 直接相加** —— 堆叠卷积的感受野随 **stride 跳跃放大**：RF_l = RF_{l-1} + (k_l−1)·jump_{l-1}，jump 每遇 stride>1 就乘上去。忽略 stride 会让感受野算小。正确写法：严格按递推式逐层累加，或把 stride=1 的层先合并成等效 stride 再算。

4. **padding='same' 在 stride>1 时以为输出等于输入** —— 'same' 只保证**输入输出尺寸比例**为 1/s（向上取整），并不保证等于 n；当 n 不能被 s 整除时输出是 ceil(n/s) < n。正确写法：明确 'same' = ceil(n/s)，'valid' = floor((n−k)/s)+1。

5. **参数量把 Cin 省掉或漏算偏置** —— 单层卷积 Params = Cout·Cin·k·k + Cout（注意乘 Cin，不是只算 Cout·k²）。分组/深度可分离卷积的算法不同，更要小心。正确写法：先区分普通卷积（乘 Cin）与 depthwise（Cin=分组数）再套公式。

6. **RNN 初始隐藏态不初始化或初始化成常数陷阱** —— 不传初始 h0 时框架常默认全零，首步无历史信息；更糟的是把 h0 设成可学习的常数却不随 batch 重置，导致批次间泄漏。正确写法：训练时 h0 通常取零或学习，但务必在 batch 维度独立、在 time 维度置首。

7. **以为 LSTM 彻底解决了梯度消失** —— LSTM 只是**缓解**：遗忘门让梯度可走恒等通路，但若遗忘门长期接近 0 或 1、或梯度仍经 tanh 压缩，长程仍可能消失/爆炸。正确写法：把它当「减轻」而非「消除」，长序列仍靠残差/归一化/截断 BPTT 兜底。

8. **把 Truncated BPTT 当成「不反向」** —— 截断只是**只回传 k 步**梯度，不是断开计算图；k 的选择影响长程记忆与显存。正确写法：理解截断是时间维度的梯度截断，前面 k 步之前的历史不再传梯度，但前向状态仍保留。

9. **注意力里忘记除以 sqrt(d_k)** —— Q·K^T 的方差随 d_k 线性增长，d_k 大时点积值过大使 softmax 进入饱和区、梯度趋零。正确写法：永远除以 sqrt(d_k)（自注意力标准缩放），这是「缩放点积注意力」名字的由来。

10. **多头注意力头数不整除 d_model** —— 拆分时 d_k = d_model / num_heads 必须为整数，否则 reshape 直接报错。正确写法：选 d_model 为 num_heads 的整数倍（如 512/8=64），或在实现里显式 assert。

11. **因果掩码用 0 而非 -inf 填充未来位置** —— 把未来位置置 0 后 softmax 仍会给它分一个非零概率（被「看见」）。正确写法：加性掩码用 `-inf`（或足够大的负数），使 exp 后为 0；实现里常 `scores = np.where(mask, -1e9, scores)`。

12. **位置编码加错位置或加错对象** —— 正弦/可学习位置编码应**加到 token 嵌入上**（在进注意力前），而非加到 Q/K/V 之后；加错会丢失顺序信息或破坏注意力对称性。正确写法：在 embedding 层之后、第一个注意力之前把位置编码相加（广播到 batch）。
