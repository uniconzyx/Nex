# RNN、BPTT 与梯度消失；LSTM/GRU 门控
> 序列建模的第一性困境：要让远端信息影响当前输出，梯度必须沿时间反向穿越很多步。RNN 的连乘结构让这几乎不可能——这正是注意力要解决的痛点。

## 1. RNN 与 BPTT 的梯度消失（数学推导）

RNN 的隐藏态递归：h_t = tanh(W_hh h_{t-1} + W_xh x_t + b)。反向传播沿时间展开即 BPTT：损失对 h_k 的梯度要穿越 (t−k) 步，每步乘上雅可比 ∂h_t/∂h_{t-1} = diag(1 − h_t²)·W_hh^T。

### 🧑‍💻 程序员视角
- 量化：长程梯度 ≈ (W_hh^T · diag(1−h²))^(t−k) 连乘；用谱半径 ρ 判断：ρ<1 指数衰减（消失），ρ>1 指数放大（爆炸）。
- 工程解法：梯度裁剪只治**爆炸**；要治消失靠 LSTM/GRU、残差连接、层归一化、以及 Truncated BPTT（限制回传步数 + 保留前向状态）。
- 调试：实际跑一下「把末步梯度反传到首步」的范数衰减比（见 examples），比空谈更直观；初始化用正交/小方差让初始 ρ≈1。

### 🎓 博士生视角
- 严格推导：∂L/∂h_k = Σ_{t≥k} (∂L/∂h_t) · Π_{τ=k+1}^{t} [diag(1−h_τ²) W_hh^T]。当 t−k 很大，连乘矩阵的特征值决定衰减速率，这正是「 vanishing gradient 」的线性代数本质。
- tanh 导数最大值为 1（在 0 处），但乘积常 <1；而 W_hh 的谱半径若 <1，则连乘 → 0。两者耦合决定了有效记忆长度。
- 这与 ai-ch01 的「雅可比连乘谱半径」是同一机理，只是这里多了一个时间维的连乘。

### 📚 考研者视角
- 推导大题：写出 BPTT 下 ∂h_t/∂h_{t-1} 并说明梯度消失条件（谱半径 < 1）。
- 易错：把「梯度消失」说成「梯度变小」这种含糊话；应点出**连乘的谱半径**决定指数行为。
- 对比：RNN vs LSTM 的记忆能力差异、为何 LSTM 缓解但不根治——是常考简答。
## 2. LSTM / GRU 门控机制

LSTM 引入细胞态 c_t 与三个门（遗忘 f、输入 i、输出 o）：f = σ(W_f·[h_{t-1},x_t]+b_f)，i = σ(...)，o = σ(...)，g = tanh(...)，c_t = f⊙c_{t-1} + i⊙g，h_t = o⊙tanh(c_t)。GRU 用重置门 r、更新门 z 把 c/h 合并：h_t = (1−z)⊙h_{t-1} + z⊙tanh(W·[r⊙h_{t-1}, x_t])。

### 🧑‍💻 程序员视角
- 门控直觉：遗忘门决定「保留多少旧记忆」，输入门决定「写入多少新信息」，输出门决定「暴露多少给隐藏态」——这是可微的「记忆读写」。
- 缓解消失：c_t 的梯度有恒等通路 c_t += f⊙c_{t-1}，当 f≈1 时梯度原样回传，不像 RNN 那样每步都过 tanh 压缩。
- 工程默认：序列任务优先 GRU/LSTM；遗忘门偏置常初始化为较大正值（如 1~3）让训练初期多记；pytorch 里用 nn.LSTM 的 batch_first 要注意维度顺序。

### 🎓 博士生视角
- 恒等通路是缓解 vanishing 的关键：∂c_k/∂c_t 含连乘 Π f_τ，若遗忘门接近 1，该乘积接近 1，长程梯度得以保留；这比 RNN 的「每步必过压缩非线性」好得多。
- GRU 是 LSTM 的参数精简版（少一个门、少一组参数），在多数任务上表现接近，因此更省算力；二者都不改变「连乘」本质，只是把连乘可控化。
- 注意门控仍是可微的软选择，不是硬路由；所以只是「减轻」长程遗忘，超长序列仍受限。

### 📚 考研者视角
- **门控公式必须会写**：f/i/o 三个 sigmoid 门 + 候选 g + c_t + h_t 五式；GRU 的 z/r 两门公式。
- 概念题：「LSTM 三个门分别干什么」「为什么能缓解梯度消失」「LSTM 与 GRU 区别」。
- 易错：把 c_t 当成 h_t，或忘记遗忘门让梯度走恒等通路这一关键点。
