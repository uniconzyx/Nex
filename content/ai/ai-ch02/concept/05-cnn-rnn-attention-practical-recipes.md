# 凯喵实战手记 · 卷积、循环与注意力的「形状与顺序陷阱」

> 凯喵说：深度学习模型出问题，十次有八次不是算法错，而是「形状对不上」「顺序搞乱了」「掩码加错了」。卷积的通道维、循环的序列维、注意力的掩码，每一个都能让你训出一个「看起来在学、其实啥也没学到」的模型。这一章我们把它们拉到现场，对着张量形状一个个看。

### 现场 1：卷积的通道维是最容易搞错的一维

图像张量的通行约定是「批次、通道、高、宽」，但很多框架内部或某些数据加载器会给成「批次、高、宽、通道」。凯喵见过最典型的错误：把 HWC 直接喂给期望 CHW 的卷积层，模型不报错，只是把通道当成高度在卷，训出来的结果完全是噪声。动手前先打印一次 shape，确认通道在哪一维，能省掉一整天的迷茫。

```python
import torch
x = torch.randn(8, 3, 32, 32)   # NCHW：批次 8、通道 3、32x32
conv = torch.nn.Conv2d(3, 16, 3, padding=1)
print(conv(x).shape)            # (8, 16, 32, 32)
```

### 现场 2：卷积输出尺寸的公式要背熟

输出边长等于输入边长减去卷积核大小加两倍填充，再除以步长，最后加一。凯喵的现场经验：只要步长大于一，就一定要在纸上算一遍，否则很容易出现「最后一层特征图变成零或负数」的报错。与其反复试错，不如把公式写在注释里，让尺寸推导变成可验证的过程。

```python
def out_size(n, k, p, s):
    return (n - k + 2 * p) // s + 1
print(out_size(32, 3, 1, 2))  # 16
```

### 现场 3：池化与步长卷积的区别被混为一谈

最大池化取局部最大值，步长卷积学一个下采样核，两者都能降分辨率，但后者带参数、能学习，前者不带参数、更省。凯喵提醒：现代网络越来越多用步长卷积替代池化，因为它保留了可学习性；但如果你只是想要「抗小位移」，池化依然简单有效。别把它们当成可以随意互换的黑盒。

### 现场 4：RNN 的序列维与批次维要对齐

RNN 默认输入是「序列长度、批次、特征」，而很多人习惯「批次、序列长度、特征」，于是把时间步和样本混在一起，模型照样能跑，只是每个「样本」其实是跨样本拼出来的怪东西。凯喵的规矩：进 RNN 前显式转置并打印形状，或者用 `batch_first=True` 明确告诉框架你的约定，绝不靠猜。

```python
rnn = torch.nn.RNN(input_size=16, hidden_size=32, batch_first=True)
x = torch.randn(8, 10, 16)      # 批次 8、序列 10、特征 16
out, h = rnn(x)
print(out.shape)                # (8, 10, 32)
```

### 现场 5：LSTM 的门控不是「三个开关」那么简单

LSTM 有遗忘门、输入门、输出门，还有候选记忆。很多人以为门就是简单相乘，忽略了它们各自经过 sigmoid 或 tanh 激活，值域不同、作用不同。凯喵提醒：遗忘门决定丢弃多少旧记忆，输入门决定写入多少新信息，输出门决定暴露多少给下一步。理解这三个门的分工，你才知道为什么它能缓解梯度消失，而不是死记公式。

### 现场 6：注意力的缩放因子不能省

点积注意力的分数要除以根号下维度，否则维度一大，点积数值爆炸，softmax 直接饱和成 one-hot，梯度几乎为零。凯喵见过有人为了「简化」去掉缩放，结果训练完全不收敛，还以为是学习率问题。这个根号不是装饰，是让方差归一到一的数学必需。

```python
import math
scores = q @ k.transpose(-2, -1) / math.sqrt(q.size(-1))
```

### 现场 7：因果掩码要用负无穷，不是零

自回归模型里，未来位置必须被遮住，但如果你把未来位置的分数置零，softmax 仍然会给它一个非零概率，等于「偷看」了未来。正确做法是填负无穷（或足够大的负数），让指数后变成零。凯喵的现场教训：这个错误不会报错，只会让模型在训练集上表现好得离谱、推理时一塌糊涂。

```python
mask = torch.triu(torch.ones(L, L), diagonal=1).bool()
scores = scores.masked_fill(mask, float('-inf'))
```

### 现场 8：位置编码要加在嵌入上，不是加在 QKV 上

顺序信息必须在进入注意力之前注入，通常是把位置编码加到 token 嵌入上，再送进第一层注意力。凯喵见过把位置编码加到 Q、K、V 之后的写法，结果破坏了注意力的对称性，顺序信息也丢了。记住：位置编码是「输入的一部分」，不是「注意力内部的修正」。

### 现场 9：多头注意力是「分头再拼」，不是「多算几遍」

多头注意力的做法是把特征维切成若干头，每头独立做注意力，再把结果拼回来。凯喵提醒：头的数量必须整除特征维，切分后每头维度变小，计算量和单头差不多，但表达力更强。如果你把「多头」理解成「跑多个独立的注意力再相加」，那就完全跑偏了。

### 现场 10：批次维与头维要分清

多头注意力的张量通常形如「批次、头数、序列、每头维度」，转置时最容易把头和序列搞混。凯喵的排查方法：打印形状，确认第二维是头数、第三维是序列长度。一旦搞反，注意力会在错误的位置上做加权，模型依然能跑，只是学不到东西。

### 现场 11：梯度裁剪是 RNN 的标配

循环网络容易梯度爆炸，尤其序列长、层数深时。凯喵的习惯是训练循环里加梯度裁剪，把范数限制在一个阈值内。这不是可选项，而是让 RNN 稳定训练的基本操作。没有它，你会看到损失突然变成 NaN，然后怀疑人生。

```python
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

### 现场 12：序列填充与掩码必须成对出现

变长序列要填充到同一长度才能批处理，但填充的位置不能参与注意力与损失计算。凯喵强调：有填充就必须有掩码，否则模型会把填充当成真实 token 学习，评估指标也会被稀释。填充值和掩码要一起设计，不能只做一半。

### 现场 13：训练与推理的 dropout 行为不同

dropout 只在训练时生效，推理时必须关掉。凯喵见过有人忘了 `model.eval()`，推理结果随机抖动，还以为是模型不稳定。记住：训练前 `train()`、推理前 `eval()`，这是每个 PyTorch 使用者的肌肉记忆。

### 现场 14：注意力可视化不是「看热闹」

把注意力权重画出来，是为了验证模型是否关注到了合理的位置。如果注意力均匀分布或者全压在填充上，说明掩码或训练出了问题。凯喵：可视化是诊断工具，不是炫技，看它能不能解释「模型为什么这么预测」，比看准确率更能发现问题。

> 凯喵总结：卷积、循环、注意力的坑九成在「形状」「顺序」「掩码」三件事。通道维、序列维、头维各就各位，掩码用负无穷，位置编码加在嵌入上，把这些刻进手感，模型才真的在学东西。

> 一句话收尾：深度学习的调试，本质是和张量形状与信息流做斗争——看懂每一维代表什么，比调任何超参数都更能救你的模型。

### 凯喵叮嘱：先怀疑形状，再怀疑参数

最后再强调一次：模型不收敛时，先怀疑形状和掩码，再怀疑超参数。把每一层的输入输出形状打印出来逐一核对，绝大多数问题在这一步就现形了。凯喵见过太多人一上来就调学习率、换优化器、加正则，折腾几天才发现是把通道维和序列维搞反了。形状对了、掩码对了，再去谈训练技巧，才是正确的排查顺序。

## 三视角解析
### 🧑‍💻 程序员视角
卷积的输入是 `(N, C_in, H, W)`，权重是 `(C_out, C_in, kH, kW)`——通道维对不上是新手第一坑。输出尺寸公式 `out = ⌊(H + 2p - k) / s⌋ + 1` 必须背熟，算错一次整条网络的特征图尺寸全错。池化与步长卷积的区别常被混为一谈：池化没有参数、只做聚合；步长卷积有可学习权重，能同时降采样与提特征，现代网络更倾向后者。RNN 的序列维与批次维顺序在 PyTorch 里是 `(seq, batch, feature)`，和 CNN 的习惯相反。

### 🎓 博士生视角
卷积的本质是「局部连接 + 权重共享」，这两条先验把参数量从全连接的 O(n²) 降到 O(k²·C_in·C_out)，同时带来平移等变性。注意力的本质是「内容寻址的软检索」：query 与 key 做相似度、softmax 归一化成权重、对 value 加权求和，它放弃局部性先验换取全局依赖建模。三者的演进线索是「先验强度递减、数据需求递增」——CNN 强先验少数据可用，Transformer 弱先验但需要大规模预训练。

### 📚 考研者视角
AI 岗面试高频：
1. **卷积参数量与计算量**：`k²·C_in·C_out` 与 `k²·C_in·C_out·H·W`，深度可分离卷积如何降到 1/C_out + 1/k²。
2. **感受野计算**：逐层递推 `RF = RF_prev + (k-1)·stride_prod`。
3. **RNN 的梯度问题**：BPTT 的连乘导致梯度消失，LSTM 用门控与细胞状态缓解。
4. **注意力复杂度**：`O(n²d)`，长序列的瓶颈与稀疏/线性注意力的动机。
