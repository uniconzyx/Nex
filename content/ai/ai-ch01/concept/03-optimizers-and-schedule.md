# 优化器演进：SGD → Momentum → RMSProp → Adam → AdamW

## 1. 先明确问题：SGD 的三个痛点

```
θ ← θ − η · ∇θ L
```

1. **峡谷地形震荡**：某些方向梯度大、某些方向小，统一学习率会导致
   在大梯度方向来回震荡、在小梯度方向前进极慢（病态曲率问题）；
2. **鞍点停滞**：鞍点附近梯度接近 0，SGD 会长时间卡住（高维空间鞍点远比局部极小多）；
3. **噪声大**：mini-batch 梯度是真实梯度的有噪估计，单步方向不可靠。

## 2. Momentum：用指数滑动平均「记住方向」

```
v ← μ · v + ∇θ L
θ ← θ − η · v
```

**物理类比**：把参数想成小球在损失面上滚动，梯度是力，v 是速度。
- 在**一致方向**上，动量累加 → 加速；
- 在**震荡方向**上，正负梯度相互抵消 → 减速。

这就是它解决「峡谷震荡」的机制。**μ 通常取 0.9**（相当于约 10 步的记忆）。

## 3. RMSProp：给每个参数不同的步长

```
s ← β · s + (1−β) · (∇θ L)²
θ ← θ − η · ∇θ L / (√s + ε)
```

**动机**：频繁更新的参数（梯度大）应该有**更小**的步长，稀疏更新的参数应该有**更大**的步长。
`s` 是梯度平方的滑动平均，`√s` 作为自适应分母。

它解决的是**病态曲率**：每个维度被单独缩放后，更新方向接近「各维度步长一致」，
等效于对 Hessian 做了对角近似。

## 4. Adam = Momentum + RMSProp（加偏差修正）

```
m ← β1 · m + (1−β1) · g          # 一阶矩（方向，动量）
v ← β2 · v + (1−β2) · g²         # 二阶矩（幅度，自适应步长）
m̂ = m / (1 − β1^t)               # 偏差修正
v̂ = v / (1 − β2^t)
θ ← θ − η · m̂ / (√v̂ + ε)
```

**为什么要偏差修正**：初始化 m=v=0，训练初期 m̂、v̂ 被系统性低估（偏向 0）。
除以 `(1−β^t)` 后成为无偏估计。**没有这一步，训练初期步长会异常大**。
默认 β1=0.9，β2=0.999，ε=1e-8。

## 5. AdamW：修正了 Adam 里一个真实的错误

这是面试最爱问的细节。**Adam 里加 L2 正则 ≠ 权重衰减**：

```
Adam + L2:   g ← ∇L + λθ          然后 θ ← θ − η · m̂/(√v̂+ε)
             ↑ λθ 也被自适应分母缩放了！

AdamW:       θ ← θ − η · λθ − η · m̂/(√v̂+ε)
             ↑ 权重衰减独立于自适应机制
```

**为什么这很重要**：在 Adam 中，梯度大的参数其 `√v̂` 也大，
于是 `λθ / √v̂` 变小 —— **正则化强度被自适应学习率削弱了**。
结果是：Adam 里的 L2 对大梯度参数几乎不起作用，泛化能力显著差于 SGD+Momentum。

**AdamW 把权重衰减从梯度中解耦**，直接作用在参数上，恢复了正则化的本意。
这也是为什么**现代大模型（GPT/BERT/LLaMA）清一色用 AdamW**。

## 6. 学习率调度：warmup + cosine 为什么成了标配

| 策略 | 做法 | 解决什么 |
|---|---|---|
| Step decay | 每 N 轮 ×0.1 | 简单，但阶跃点需要调 |
| Cosine annealing | η = η_min + (η_max−η_min)·(1+cos(π·t/T))/2 | 末期精细收敛 |
| **Warmup** | 前 k 步从 0 线性升到 η_max | **训练初期稳定性** |
| OneCycle | 升 → 降，配合动量反向调度 | 收敛快，超参鲁棒 |

**Warmup 为什么必要**（大模型尤其）：
- 训练初期 `v̂`（二阶矩）估计极不可靠，除以一个很小的 `√v̂` 会让**步长爆炸**；
- 初始时参数是随机的，梯度方向混乱，大步长会直接把模型推坏。
- 经验：batch size 越大，warmup 步数应越多（大 batch 前期方差更小但更容易不稳定）。

## 7. 一句话总结

> **Momentum 解决震荡、RMSProp 解决病态曲率、Adam 合并二者并加偏差修正、
> AdamW 修正了「L2 被自适应分母削弱」这个真实缺陷。
> 大模型标配 = AdamW + warmup + cosine decay。**

## 三视角解析

### 🧑‍💻 程序员视角
- 默认起点是 **Adam(lr=1e-3)**，但要知道它**不等于**带权重衰减的 SGD——要真切权重衰减请用 **AdamW**。
- 大模型训练的标准配置是 **warmup + cosine 衰减**：warmup 防早期梯度噪声炸参数，cosine 让后期步长平滑收敛。
- 调参经验：loss 抖动大→降 lr 或增大 warmup；收敛慢→检查是否忘记 `zero_grad()` 或 lr 太小。

### 🎓 博士生视角
- 优化器本质是**对损失曲面做不同的预处理**：Momentum 用一阶矩平滑方向（重球法/共轭梯度的随机版本），RMSProp/Adam 用二阶矩做**对角 Hessian 近似**的缩放。
- Adam 的偏差修正来自「指数滑动平均在初始化时低估真实矩」，除以 (1 − β^t) 才能得到无偏估计——这是它早期收敛稳定的关键。
- **AdamW 修正的是一个真实错误**：在 Adam 中把 L2 正则写进梯度，会被自适应分母削弱，导致衰减强度依赖于梯度尺度；解耦权重衰减后正则才真正等效。
- 收敛性理论对 β 有要求（一般需 β2 足够大），这也是「自适应方法未必收敛到最优」的理论讨论来源。

### 📚 考研者视角
- **考研数学（最优化）直接对应**：梯度下降、动量法（重球法）、学习率对收敛性的影响在数值分析与最优化章节有严格证明。
- 若专业课含机器学习，常考「SGD / Momentum / AdaGrad / RMSProp / Adam 的递推公式与差异」——Adam 的公式建议背到能写出偏差修正项。
- 记忆锚点：**Adam = 一阶矩 + 二阶矩 + 偏差修正**；**AdamW = Adam + 解耦权重衰减**。
