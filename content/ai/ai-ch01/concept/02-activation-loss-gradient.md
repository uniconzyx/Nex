# 激活函数、损失函数与梯度消失/爆炸

## 1. 为什么必须要有激活函数

**没有非线性的多层网络等价于单层线性模型**。证明只需一行：

```
y = W2 (W1 x + b1) + b2 = (W2 W1) x + (W2 b1 + b2) = W' x + b'
```

线性变换的复合仍是线性变换。所以激活函数的**唯一使命是注入非线性**，
让网络的表达能力随深度指数增长（而非线性叠加）。

### 三个主力激活函数的导数与取舍

| 激活 | 公式 | 导数 | 优点 | 缺点 |
|---|---|---|---|---|
| Sigmoid | 1/(1+e^{-x}) | σ(x)(1−σ(x)) | 输出 (0,1) 可当概率 | **饱和区梯度≈0**；输出非零中心 |
| Tanh | (e^x−e^{-x})/(e^x+e^{-x}) | 1−tanh²(x) | **零中心**，收敛更快 | 仍会饱和 |
| ReLU | max(0, x) | 1 if x>0 else 0 | 计算极简、**正区间梯度恒为 1** | **死亡 ReLU**（负区间永久失活） |

**ReLU 为什么能缓解梯度消失**：正区间的导数恒为 1，连乘不会衰减。
这是深度学习在 2012 年后爆发的**关键技术转折之一**（AlexNet 用 ReLU）。

**死亡 ReLU 的机制与对策**：若某神经元输入恒为负（学习率过大导致偏置被推到很负），
梯度恒为 0，参数永远不再更新 → 该神经元「死亡」。对策：
- **Leaky ReLU**：负区间给一个小斜率（如 0.01），保证梯度不为 0；
- **ELU / GELU**：负区间平滑过渡（GELU 是 BERT/GPT 系列的默认选择）；
- 降低学习率、合理初始化。

## 2. 损失函数的选择是「输出分布假设」的体现

| 任务 | 损失函数 | 隐含假设 |
|---|---|---|
| 回归 | MSE `(y−ŷ)²` | 噪声服从**高斯分布** |
| 二分类 | BCE | 伯努利分布 |
| 多分类 | 交叉熵 CE | **互斥单标签**，分布为 Categorical |
| 多标签分类 | BCE per class | 各类独立伯努利 |

**MSE 用于回归 = 极大似然估计在高斯噪声下的等价形式**。理解这一点，
你就会知道为什么异常值会严重损害 MSE 回归（高斯分布的尾部概率极低，模型被迫大幅调整），
此时应改用 MAE（对应拉普拉斯分布）或 Huber（分段，兼顾两者）。

## 3. Softmax 的数值稳定性（必会写法）

朴素实现 `exp(x_i) / Σ exp(x_j)` 在 x 较大时会**上溢为 inf**（float32 在 x > 88 时溢出）。
正确写法是利用 Softmax 的**平移不变性**：

```
softmax(x)_i = exp(x_i − max(x)) / Σ_j exp(x_j − max(x))
```

减去最大值后，最大项为 `exp(0) = 1`，分母 ≥ 1，绝不上溢；
同时避免了除零。

**交叉熵与 Softmax 应当融合计算**：

```
log_softmax(x)_i = x_i − logsumexp(x)
CE = −log_softmax[label]
```

`logsumexp` 用同样的 max 减法技巧。分开算 Softmax 再取 log 会先丢精度再放大误差
（当 softmax 输出接近 0 时，log 的梯度爆炸）。所有主流框架都把二者融合成一个算子。

## 4. 梯度消失/爆炸：从「连乘的谱半径」看

设 L 层网络，每层的雅可比为 J_l，则：

```
∂L/∂W_1 = J_L · J_{L-1} · ... · J_2 · (∂L/∂h_2)
```

**这是 L 个矩阵的连乘**。设每个 J 的谱半径（最大奇异值）为 ρ：
- ρ < 1 → 连乘结果 **指数级趋于 0**（梯度消失）；
- ρ > 1 → **指数级发散**（梯度爆炸）；
- ρ ≈ 1 → 稳定（这是**残差连接、LSTM 门控、BatchNorm** 的共同目标）。

**为什么 sigmoid 特别容易消失**：σ'(x) = σ(1−σ) 的**最大值只有 0.25**，
且只有在 x=0 附近才取到。L 层连乘后梯度上界是 `0.25^L`：
L=10 时约 1e-6 —— **梯度早已归零**。

### 四大对策，各自修的是不同的东西

| 对策 | 修复的机制 |
|---|---|
| **好初始化**（Xavier/He） | 让每层的输出方差保持 ~1，使初始 ρ ≈ 1 |
| **ReLU 类激活** | 正区间导数恒为 1，去掉连乘的衰减因子 |
| **残差连接** | 引入恒等通路，使 J = I + （小扰动），ρ 天然接近 1 |
| **BatchNorm / LayerNorm** | 每层强行把分布拉回零均值单位方差，稳定 ρ |
| **梯度裁剪** | 只治**爆炸**不治消失：按范数截断 |

**Xavier vs He 的区别要能说清**：
- Xavier（Glorot）假设激活**对称且近似线性**（tanh），取 `Var(W) = 2/(fan_in + fan_out)`；
- He 初始化专为 **ReLU**（会把一半输入置零，方差减半）设计，取 `Var(W) = 2/fan_in`。
  **用 ReLU 却配 Xavier，会导致方差逐层减半**——这是常见但隐蔽的错误。

## 5. 一句话总结

> **梯度消失的本质是雅可比连乘的谱半径小于 1。所有对策都在做同一件事：让 ρ 回到 1 附近——
> 初始化控制初始 ρ、ReLU 去掉衰减因子、残差给一条 ρ=1 的恒等通路、归一化强行稳定分布。**

## 三视角解析

### 🧑‍💻 程序员视角
- 默认组合：隐藏层 **ReLU/GELU**，输出层按任务配损失（多分类 softmax+交叉熵、二分类 sigmoid+BCE、回归 MSE/Huber）。
- 数值稳定性必须用 **log-sum-exp 写法**：直接对 exp 求和再取 log 会溢出；框架的 `cross_entropy` 已内置，但手写实现时必须自己稳住。
- ReLU 的「死亡神经元」在实践中真实存在（学习率过大导致输出恒负），可用 LeakyReLU/GELU 兜底。

### 🎓 博士生视角
- **没有激活函数，多层线性模型会坍缩成单层线性模型**——这是「必须有非线性」的形式化理由。
- 损失函数的选择等价于**对输出分布做假设**：softmax + 交叉熵 ↔ 类别分布；sigmoid + BCE ↔ 伯努利分布。交叉熵就是该分布下的**负对数似然**，最大化似然 ⇔ 最小化交叉熵。
- 梯度消失要看**连乘雅可比的谱半径**：ρ(J) < 1 则沿层数指数衰减。sigmoid 导数上界 0.25 给出的是**悲观上界**（0.25^L），实际衰减取决于权重矩阵的谱范数，因此「初始化得好就不会那么糟」。
- 交叉熵 = 信息熵 + KL 散度，这一分解解释了「模型再强也有下界（熵），只能把 KL 压到 0」。

### 📚 考研者视角
- **概率论直接考点**：**最大似然估计（MLE）** 是交叉熵的来源；写出似然函数 → 取对数 → 最大化，就是交叉熵的推导过程，这是考研大题的常客。
- **计组交叉**：sigmoid/softmax 里的指数运算涉及浮点溢出与精度——`float32` 的 exp(100) 直接 inf，这正是「log-sum-exp 技巧」在计组层面的必要性。
- 记忆锚点：**交叉熵 = 信息熵 + KL 散度**；**「梯度消失源于连乘、梯度爆炸源于谱半径 > 1」**。
