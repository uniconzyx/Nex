# ai-ch09 · 核心概念（二）：生成对抗网络

> 视角覆盖：程序员（工程决策）/ 博士生（第一性原理）/ 考研者（笔面口径）。三者互补、不重复。

## 1. 对抗训练的目标：minimax 与 JS 散度

GAN 把「学会数据分布」变成一个**二人零和博弈**：生成器 $G$ 试图骗过判别器，判别器 $D$ 试图分辨真假。

$$\min_G\max_D\ V(D,G)=\mathbb{E}_{x\sim p_{\text{data}}}[\log D(x)]+\mathbb{E}_{z\sim p_z}[\log(1-D(G(z)))]$$

固定 $G$ 时，这个泛函对 $D$ 逐点可解。令 $x$ 处的密度为 $p_{\text{data}}(x)$ 与 $p_g(x)$，对 $D(x)$ 求导置零得

$$D^*(x)=\frac{p_{\text{data}}(x)}{p_{\text{data}}(x)+p_g(x)}$$

把 $D^*$ 代回目标函数，经过一步整理（每项拆成两个 $\frac{1}{2}\log\frac{1}{2}$）：

$$V(D^*,G)=-\log 4+2\,D_{\mathrm{JS}}\big(p_{\text{data}}\,\|\,p_g\big)$$

这条式子是整个 GAN 理论的地基：**最优判别器下，生成器的目标等价于最小化 JS 散度**。它同时解释了 GAN 的两个根本毛病：

1. **JS 散度在分布支撑集不重叠时是常数 $\log 2$**，梯度恒为 0 → 训练早期 $p_g$ 与 $p_{\text{data}}$ 几乎无交集时，生成器**拿不到方向**。这就是 WGAN 出场的理由。
2. **JS 散度是对称且有界的**，它不区分「差一点」和「差很多」——只要不重叠，惩罚一样大。

工程上还必须知道**原始生成器目标的饱和问题**：$\log(1-D(G(z)))$ 在 $D(G(z))\to 0$（生成器很差、判别器很确信）时梯度趋零，训练会卡死。所以实践一律改用**非饱和（non-saturating）目标**：

$$\min_G\ -\mathbb{E}_{z}[\log D(G(z))]$$

两者在最优 $D$ 附近梯度方向一致，但后者在「生成器很差」时提供大得多的梯度——这是 Goodfellow 原始论文里就给出的实用修正，不是后人发明的技巧。

### 🧑‍💻 程序员视角

- **判别器不是越强越好**。$D$ 训到「一眼识破」时，$G$ 的梯度消失，loss 曲线看起来「D 的 loss 很低很稳」，实际训练已死。监控应该看**生成样本的多样性**与 $D$ 对真假样本的打分差，而不是只看 D loss。
- **把 GAN 训稳的成套配方**（缺一个都可能崩）：① 生成器用非饱和损失；② $D$ 用谱归一化或梯度惩罚，别用 BatchNorm（会因 batch 内真假混算统计量而泄漏信息，改用 InstanceNorm/LayerNorm 或不归一化）；③ TTUR（$D$ 学习率大于 $G$，如 $4\times10^{-4}$ vs $1\times10^{-4}$）；④ 对 $G$ 做 EMA（指数滑动平均）取权重，生成质量显著更稳；⑤ 标签平滑（真标签取 0.9）。
- **模式崩塌的工程诊断**：固定一组 $z$，看生成结果是否高度雷同；或算生成样本的两两距离分布，若方差异常小即崩塌。对策：minibatch discrimination、unrolled GAN、或干脆换扩散模型。
- **别在生产里用 GAN 做「需要覆盖全分布」的任务**（如数据增广、密度估计）：GAN 只保证样本逼真，不保证覆盖。做增广宁可要一点模糊也要覆盖。

### 🎓 博士生视角

- $D^*=\frac{p_{\text{data}}}{p_{\text{data}}+p_g}$ 的形式可以直接读出「最优判别器是一个**密度比估计器**」：$D^*/(1-D^*)=p_{\text{data}}/p_g$。这条恒等式是**密度比估计**这条技术线的起点——f-GAN、对抗式重要性采样、以及扩散模型里「用分类器引导」都能回溯到它。
- f-GAN（Nowozin et al., 2016）把 JS 换成任意 $f$-散度：只要取不同的凸函数 $f$，就得到 KL、reverse-KL、$\chi^2$ 等不同目标。这解释了「为什么 GAN 的目标函数可以随便换」——换散度就换了优化偏好（mode-covering vs mode-seeking）。
- mode collapse 的严格刻画不是「G 输出重复」，而是「$p_g$ 的支撑集是 $p_{\text{data}}$ 支撑集的**真子集**」。reverse-KL（$D_{\mathrm{KL}}(p_g\|p_{\text{data}})$）天然 mode-seeking，这从散度的定义就能推出：$p_{\text{data}}=0$ 而 $p_g>0$ 处惩罚无穷（禁止生成假样本），反之则惩罚很小（允许漏模式）。GAN 的 JS 行为介于两者之间，因此也会漏模式。
- 从博弈论看，GAN 训练不是梯度下降而是**同时梯度下降**（simultaneous gradient descent），它一般不收敛到纳什均衡而进入极限环（limit cycle）。这是「GAN 训练不稳定」的数学根源，不是实现 bug。

### 📚 考研者视角

- **必考推导**：给定 $G$，证明最优判别器 $D^*=\frac{p_{\text{data}}}{p_{\text{data}}+p_g}$，并代入得 $V=-\log4+2D_{\mathrm{JS}}$。这两步是深度学习课程的标准大题。
- **高频问法**：① GAN 与 VAE 的生成机制差异（隐式 vs 显式密度、对抗 vs 变分下界、样本锐利 vs 模糊）；② 为什么 GAN 难训练（JS 散度在支撑不重叠时梯度消失、博弈不保证收敛、模式崩塌）。
- **易错点**：把 GAN 的损失说成「生成器最小化 $D$ 的分类误差」——严格说是**最小化判别器把假样本判真的难度**，且实践用非饱和形式；把 $D$ 输出说成「概率」——它是**密度比的可微代理**，未校准。
- **口径提醒**：GAN 属于**隐式生成模型**（不显式建模 $p(x)$），这是与 VAE/扩散（显式似然）分类题的标准答案。

## 2. 训练动力学：为什么会崩，以及怎么稳住

GAN 的失败模式可以按「谁压过谁」分类：

| 现象 | 机制 | 观测信号 | 处理 |
|---|---|---|---|
| 梯度消失 | $D$ 太强，$D(G(z))\approx0$，$\log$ 梯度趋零 | $G$ loss 长期不变、样本不改善 | 降低 $D$ 容量/步数、换非饱和损失、加噪声 |
| 模式崩塌 | $G$ 找到某个「骗过 D 的单一模式」 | 样本高度雷同，多样性指标塌陷 | minibatch 判别、TTUR、换散度/换模型 |
| 振荡/发散 | 同时梯度下降进入极限环 | loss 周期震荡、样本忽好忽坏 | 加正则（GP）、降低步长、$D$ 更新用 EMA |
| 统计量泄漏 | $D$ 用 BatchNorm，真假样本同批统计 | 训练集指标虚高、换 batch 就崩 | 改用 InstanceNorm/LayerNorm/无归一化 |

其中**统计量泄漏**最隐蔽，值得单独说：判别器用 BatchNorm 时，一个 batch 里真假样本的统计量被混在一起计算，$D$ 能通过「这批里有没有真样本」这个信号间接作弊，而不是学真正的真假判据。训练集上看起来完美，换到单样本推理就崩。这是工程事故级的坑。

### 🧑‍💻 程序员视角

- 训练 GAN 的**最小可控流程**：先跑 1 个 epoch 只用 $D$（相当于二分类），确认 $D$ 能把真假分开；再开 $G$，从 $D$ 准确率 ~70%-80% 的区间开始（太低说明 D 学不动，太高说明 D 太强）。
- 生成结果要做 **EMA + 截断技巧**：EMA 权重（decay 0.999）比最新权重质量高得多；StyleGAN 系列的 truncation trick（$w'=\bar{w}+\psi(w-\bar{w})$，$\psi<1$）用多样性换质量，是产品里默认开启的。
- 图像 GAN 的评估别只看眼睛：固定 seed 生成 5 万张算 FID，比人眼看 20 张靠谱。FID 要**同分辨率、同预处理、同 Inception 权重**才可比，跨论文比 FID 是最常见的错误结论来源。
- 如果目标是「可控生成」（改属性、换风格），GAN 的隐空间编辑（StyleGAN 的 $W$/$W^+$ 空间、GAN inversion）至今仍比扩散的免训练编辑快一个数量级，实时换脸/风格化产品仍在用。

### 🎓 博士生视角

- 为什么 $D$ 太强会让 $G$ 梯度消失，可以说得更精确：在 $D=D^*$ 附近，$G$ 的梯度范数正比于 $D_{\mathrm{JS}}$ 对参数的导数，而当两个分布支撑不交时 $D^*$ 在真假区域内**恒为 0 或 1**（分段常数），导数处处为 0——不是「小」，是**几乎处处为零**。
- 训练稳定性的现代解释指向**谱**：$G$ 与 $D$ 的 Jacobian 谱半径决定迭代是否收敛。谱归一化把 $D$ 的 Lipschitz 常数钉在 1，等价于限制 Jacobian 谱范数，从而抑制振荡。这和「控制动力系统增益」是同一件事。
- 极限环（limit cycle）是双线性博弈的典型行为：$\dot{\theta}_D=\nabla_D V$、$\dot{\theta}_G=-\nabla_G V$，在纯策略下系统守恒量存在，轨迹围绕均衡点旋转而不收敛。加正则（如梯度惩罚）等价于给系统加阻尼。
- 从最优传输看，WGAN 的目标不是「让分布像」，而是「用最小搬运代价把 $p_g$ 搬成 $p_{\text{data}}$」，它对支撑不重叠的情形仍给出有意义的距离（Kantorovich-Rubinstein 对偶），这是它能缓解梯度消失的理论根据。

### 📚 考研者视角

- **必考对比**：「GAN 相比 VAE 的优缺点」标准答法：优点——样本锐利、无需显式似然、可处理复杂分布；缺点——训练不稳定、模式崩塌、难评估、难算似然。
- **常考问法**：① 解释模式崩塌的成因（$G$ 找到单一高回报模式、散度的 mode-seeking 倾向）；② 为什么 $D$ 太强会导致 $G$ 训练失败（梯度消失）；③ 为什么 GAN 的判别器不能用 BatchNorm（统计量泄漏）。
- **易混**：模式崩塌（mode collapse，$G$ 漏模式）≠ 模式遗忘（catastrophic forgetting）；「GAN 的 loss 不收敛」不等于「训练失败」，GAN 的 loss 本来就没有单调下降的保证。

## 3. Wasserstein 距离与 Lipschitz 约束：换一个「有梯度」的度量

WGAN 的核心动作：把 JS 散度换成 **Earth Mover's（Wasserstein-1）距离**。用 Kantorovich-Rubinstein 对偶，它可写成

$$W(p_{\text{data}},p_g)=\sup_{\|f\|_L\le 1}\Big(\mathbb{E}_{x\sim p_{\text{data}}}[f(x)]-\mathbb{E}_{y\sim p_g}[f(y)]\Big)$$

其中上确界取遍所有 **1-Lipschitz** 函数 $f$。把 $f$ 参数化成判别器（此时叫 critic，输出不再是概率而是实数分数），目标变成

$$\max_{\|D\|_L\le1}\ \mathbb{E}[D(x)]-\mathbb{E}[D(G(z))],\qquad \min_G\ -\mathbb{E}[D(G(z))]$$

关键收益：**即使两个分布支撑不重叠，$W$ 距离仍随「搬运距离」连续变化**，梯度不会消失。而且 $W$ 与生成质量**单调相关**——这让 loss 第一次有了「可监控」的意义（JS 的 loss 没有这个性质）。

难点在于「怎么强制 1-Lipschitz」。三条路线：

| 方案 | 做法 | 问题 |
|---|---|---|
| 权重裁剪 | 每步把 $w$ 裁到 $[-c,c]$ | 粗暴，容量被压，$c$ 敏感 |
| 梯度惩罚（WGAN-GP） | 罚 $(\|\nabla_{\hat{x}}D(\hat{x})\|_2-1)^2$，$\hat{x}$ 在真假连线采样 | 贵（二阶导）、对 batch 内插值敏感 |
| 谱归一化（SN-GAN） | 每层 $W\leftarrow W/\sigma(W)$，$\sigma$ 用幂迭代估 | 只是上界约束、实现最省，工业默认 |

### 🧑‍💻 程序员视角

- **选型结论**：做研究复现 WGAN-GP；做产品用**谱归一化**（每层加一次幂迭代，开销 <5%，不用二阶导，分布式友好）。真正的 1-Lipschitz 不需要严格满足，方向对就够。
- 幂迭代实现细节：每次前向用 1 次迭代更新 $u\leftarrow Wv/\|Wv\|$、$v\leftarrow W^\top u/\|W^\top u\|$，跨 step 复用 $u,v$ 即可收敛，不必每步重算。
- critic 的更新次数常设为 $G$ 的 3-5 倍（WGAN 论文用 5），因为 critic 需要更准的距离估计。这也是 WGAN 训练慢的原因之一。
- 判断 W 距离估计是否可信：看 critic 输出在真假样本上的**均值差**是否稳定增长；若一直抖动，说明 Lipschitz 约束没生效或学习率过大。

### 🎓 博士生视角

- Kantorovich-Rubinstein 对偶成立的前提是 $p,q$ 为概率测度且代价是度量 $d$；此时 $W_1(p,q)=\sup_{\|f\|_L\le1}\mathbb{E}_p[f]-\mathbb{E}_q[f]$。这与最优传输的原始形式（最小化耦合的期望代价）是强对偶关系。
- 1-Lipschitz 约束等于「梯度的对偶范数 ≤ 1」，WGAN-GP 用**软约束**（罚偏离 1）而非硬约束，理论上只能近似；SN 约束的是每层谱范数，乘积给出网络 Lipschitz 的上界，可能过紧（过度限制容量）。
- W 距离的拓扑性质优于 JS：$W_1$ 度量弱收敛（在紧空间上正好刻画弱* 收敛），而 JS 只在绝对连续情形下有效。这就是「参数化分布族在低维流形上时 JS 恒为常数、W 仍敏感」的严格原因（Arjovsky et al., 2017 的核心论证）。
- 现代视角：扩散模型的目标也可写成**去噪得分匹配**，它优化的是加噪分布之间的 KL，天然避开了「支撑不重叠」的问题——这是 GAN 用对抗、扩散用加噪两条路线解决同一个困难的两种办法。

### 📚 考研者视角

- **必背**：Wasserstein 距离的定义（把一堆土搬成另一堆的最小代价）、KR 对偶形式、WGAN 的三个工程改动（去掉 sigmoid、权重裁剪/GP、换优化器为 RMSprop/Adam 不带动量）。
- **高频问法**：① WGAN 为什么能缓解梯度消失（$W$ 在分布不重叠时仍提供连续梯度）；② 权重裁剪的问题（导致参数集中在边界、容量下降）；③ WGAN-GP 的惩罚为什么在「真假连线」上采样（沿最优传输路径最需要满足 Lipschitz）。
- **易错点**：critic 输出不是概率，**不要加 sigmoid**；WGAN 的 loss 值越小不代表样本越好（只能横向比较同一设置下的相对趋势）。

## 4. 条件生成：把「控制」变成输入

无条件 GAN 只能随机采样，产品要的是「按标签/文本/姿态生成」。条件 GAN（cGAN）把条件 $c$ 同时喂给 $G$ 与 $D$：

$$\min_G\max_D\ \mathbb{E}_{x,c}[\log D(x,c)]+\mathbb{E}_{z,c}[\log(1-D(G(z,c),c))]$$

判别器必须**同时看到 $c$**，否则它无法判断「图与条件是否匹配」，生成器就会忽略 $c$（这是实现里最常见的错误：只给 $G$ 加条件、忘了给 $D$）。

投影判别器（projection discriminator）是当前主流做法：$D$ 输出 $D(x)$ 与条件嵌入 $e(c)$ 的内积，$\text{score}=D(x)+\langle e(c), v(x)\rangle$。它比 concat 更强，因为条件与特征做了双线性交互。

### 🧑‍💻 程序员视角

- **条件被忽略的检测**：固定 $z$、换 $c$ 生成，若结果几乎不变即条件没生效。原因通常是 $D$ 没看 $c$，或 $G$ 的条件注入太弱（如只在输入端 concat）。
- 强条件注入手段：$G$ 用 AdaIN/FiLM（把条件转成每层的 scale/shift）、或 cross-attention（文本条件）；$D$ 用 projection。
- 多条件（类别 + 姿态 + 风格）时做**条件 dropout**（训练时随机丢条件），可支持推理时部分条件缺失——这是产品里「只给风格不给姿态」能工作的前提。

### 🎓 博士生视角

- cGAN 的目标可理解为**条件 JS 散度**的估计：对每个 $c$，$D^*(\cdot,c)=\frac{p(x|c)}{p(x|c)+p_g(x|c)}$，条件独立地做散度最小化。这要求每个 $c$ 下有足够样本，否则长尾类会退化。
- 条件 dropout 等价于训练一个**条件边缘的混合**：$p(x\mid c\text{ dropped})$ 是 $p(x)$ 的边缘，故模型学到的是「条件 → 无条件」的连续插值族。这与 classifier-free guidance 的训练方式（随机丢条件）完全同源——后者在扩散模型里成了主流。
- 从信息论看，条件生成要求 $I(c;x)$ 被保留，而对抗训练只保证 $p_g(x|c)\approx p(x|c)$；若 $c$ 与 $x$ 的互信息小（条件本身弱），生成器倾向忽略 $c$ 是**贝叶斯最优**的，不是 bug。

### 📚 考研者视角

- **标准定义**：条件生成模型建模 $p(x\mid c)$，与无条件模型的区别在于目标分布被条件化；训练时条件必须同时进入生成器与判别器。
- **高频问法**：① cGAN 的判别器输入是什么（$(x,c)$ 对）；② 条件生成与「风格迁移」的区别（前者建模条件分布，后者是确定性的图像变换）。
- **易混**：conditioning（条件输入）≠ guidance（引导）；前者改的是模型输入，后者改的是采样时的梯度方向（见扩散章的 CFG）。

## 可运行代码：饱和损失为什么没梯度

「D 太强会让 G 学不动」可以在 5 行里量化：把判别器对假样本的 logit 依次设为 -8 到 4，
看两种 G 损失对同一输入的梯度大小：

```python
import torch
import torch.nn.functional as F

def g_saturating(logit_fake):        # 原始 GAN：min log(1 - D(G(z)))
    return F.binary_cross_entropy_with_logits(logit_fake, torch.zeros_like(logit_fake))

def g_nonsaturating(logit_fake):     # 非饱和替代：max log D(G(z))
    return F.binary_cross_entropy_with_logits(logit_fake, torch.ones_like(logit_fake))

for d in (-8.0, -2.0, 0.0, 4.0):
    t1 = torch.tensor([d], requires_grad=True)
    g_saturating(t1).backward()
    t2 = torch.tensor([d], requires_grad=True)
    g_nonsaturating(t2).backward()
    print(f"logit={d:5.1f}  饱和梯度={t1.grad.item():+.6f}  非饱和梯度={t2.grad.item():+.6f}")
```

`logit=-8` 时饱和损失的梯度是 **-0.000335**，比 `logit=0` 时小三个数量级——这就是「G 完全骗不过
D 时反而学不动」的数学形态。非饱和版本在同一处的梯度接近 -0.9997，把「判别器太强」这个困境
转成了「信息更充分的学习信号」。注意二者在 logit 较大时都会变小，所以真正的瓶颈仍在
「D 与 G 的能力平衡」，换损失只是把**梯度消失的那一端**补上了。

## 三视角小结

| 主题 | 程序员要会 | 博士生要会 | 考研/笔面要会 |
|---|---|---|---|
| minimax 与 JS | 非饱和损失、D/G 平衡诊断 | 最优 D 是密度比估计、f-GAN 换散度 | $D^*$ 推导、$2D_{JS}-\log4$ |
| 训练动力学 | 谱归一化、TTUR、EMA、禁 BN | 同时梯度下降的极限环 | 模式崩塌成因、BN 泄漏 |
| WGAN | 谱归一化优先、critic 多步 | KR 对偶、$W_1$ 的拓扑优势 | $W$ 距离定义、GP 采样位置 |
| 条件生成 | 条件注入到 D 与 G、条件 dropout | 条件 JS、CFG 同源 | $(x,c)$ 输入、条件 vs 引导 |
