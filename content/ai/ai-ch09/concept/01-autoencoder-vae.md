## 1. 自编码器：把「重建」当成学习信号

自编码器（AutoEncoder, AE）是一对函数的组合：编码器 $f_\phi:\mathbb{R}^D\to\mathbb{R}^d$ 把输入压到低维隐表示 $z$，解码器 $g_\theta:\mathbb{R}^d\to\mathbb{R}^D$ 把 $z$ 还原回 $\hat{x}$，训练目标就是让重建误差最小：

$$\min_{\phi,\theta}\ \mathbb{E}_{x\sim p_{\text{data}}}\big[\|x-g_\theta(f_\phi(x))\|^2\big]$$

关键认知：**AE 的隐空间没有任何概率约束**。它只保证「能解码回来」，不保证隐空间连续、不保证从先验采样能得到有意义的样本。这就是为什么「拿 AE 做生成」通常失败——你从 $N(0,I)$ 里随机采一个 $z$，解码器可能从没见过这个点，输出是噪声。

按瓶颈性质分三类：

| 类型 | 隐维度 | 学到什么 | 典型问题 |
|---|---|---|---|
| 欠完备（undercomplete） | $d<D$ | 主成分式的压缩表示 | 只能做降维/去噪，不能生成 |
| 过完备（overcomplete） | $d\ge D$ | 恒等映射（偷懒） | 不加正则就学不到结构 |
| 正则化 | 任意 | 去噪 AE / 稀疏 AE / 收缩 AE | 需要额外正则项或噪声注入 |

去噪自编码器（DAE）的动机值得记住：给输入加噪 $x\to\tilde{x}$，但要求还原**干净**的 $x$，网络就必须学到「数据流形的方向」，而不能靠恒等映射作弊。这是后来**掩码自编码器（MAE）**与**扩散模型去噪**思想的直系祖先。

### 🧑‍💻 程序员视角

- **AE 在工业里的真实用途不是生成，而是「表示 + 异常检测」**：正常样本训练 AE，推理时看重建误差，误差高即异常。这是设备故障检测、日志异常、工业质检的经典基线，比孤立森林稳、比监督学习省标注。
- 判定阈值不要拍脑袋取固定值：用**训练集重建误差的分位数**（如 P99）或**按特征分组标定**，否则换批次/换传感器就得重调。
- 过完备 AE 一定要有正则（去噪/稀疏/权重衰减），否则训练 loss 秒降到 0，但隐表示毫无信息——排查时先看「隐层是否近似恒等映射」（线性探针准确率能测出来）。
- 卷积 AE 做图像时，解码器的上采样用 `ConvTranspose2d` 容易出棋盘格伪影（stride 与 kernel 不整除），工程上更稳的是 `Upsample + Conv`。

### 🎓 博士生视角

- AE 的目标函数与 PCA 的关系可以精确说清：若编码/解码都是**线性**、损失是平方误差，则最优解张成的子空间与 PCA 的主子空间**一致**（Baldi & Hornik, 1989）；一旦引入非线性激活，这个等价性破裂，AE 才能捕捉流形而非线性子空间。
- 「重建」作为自监督信号的理论意义在于：它把**边缘分布的估计**转成了**条件期望的回归**。平方损失下最优解码器是 $g^*(z)=\mathbb{E}[x\mid z]$，即后验均值——这解释了 AE 重建结果为什么天然偏模糊（均值回归），也是 VAE/GAN 要引入别的损失的原因。
- 恒等映射的「偷懒」本质是：过完备下存在零损失的平凡解族，梯度下降的隐式正则（偏向小范数解）不一定能排除它们，所以必须显式加噪或加稀疏约束。
- 与流形假设的关系：AE 学的是数据流形的**坐标卡**（chart），但坐标卡之间不保证兼容、不保证全局连续——VAE 的先验约束正是在补这个缺口。

### 📚 考研者视角

- **标准定义口径**：自编码器是「以重构输入为目标、由编码器与解码器组成的无监督神经网络」，属于**无监督/自监督学习**，不要写成「生成模型」（严格说 AE 不是生成模型，这是简答题常见扣分点）。
- **常考题型**：① 简述 AE 与 PCA 的关系与区别（线性 AE ≈ PCA；非线性 AE 可学非线性流形）；② 为什么 AE 不能直接用于生成（隐空间无先验分布约束、采样点落在训练分布外）；③ 去噪 AE 的原理（学到鲁棒表示、等价于 score matching 的一种形式）。
- **易混概念**：自编码器 ≠ 稀疏编码（后者优化的是**给定字典下的稀疏系数**，字典可学习）；欠完备 ≠ 欠拟合（前者是结构设计，后者是训练结果）。

## 2. VAE：用 ELBO 把「生成」变成可优化目标

VAE 的核心动作是引入隐变量 $z$，并假设生成过程 $p_\theta(x)=\int p_\theta(x\mid z)p(z)\,dz$。这个积分对神经网络参数化的解码器**不可解**，所以转而优化它的下界。

用 Jensen 不等式推导（一行也别跳）：

$$\log p_\theta(x)=\log \mathbb{E}_{q_\phi(z\mid x)}\Big[\frac{p_\theta(x,z)}{q_\phi(z\mid x)}\Big]\ \ge\ \mathbb{E}_{q_\phi(z\mid x)}\Big[\log\frac{p_\theta(x,z)}{q_\phi(z\mid x)}\Big]=\mathcal{L}(\theta,\phi;x)$$

把联合分布拆开 $p_\theta(x,z)=p_\theta(x\mid z)p(z)$，立刻得到工程上真正在优化的两项：

$$\mathcal{L}=\underbrace{\mathbb{E}_{q_\phi(z\mid x)}[\log p_\theta(x\mid z)]}_{\text{重建项}}\ -\ \underbrace{D_{\mathrm{KL}}\big(q_\phi(z\mid x)\,\|\,p(z)\big)}_{\text{正则项}}$$

- **重建项**：给定 $x$ 采一个 $z$ 再解码，要求还原得好（高斯解码器下等价于 MSE）。
- **正则项**：要求后验接近先验 $N(0,I)$，这才让「从先验采样 → 解码」有语义。

两项必须**同时**才有生成能力：只留重建项退化成 AE；只留 KL 项隐空间塌成先验、重建全是噪声。

**重参数化技巧**是 VAE 能训练的关键。采样 $z\sim q_\phi(z\mid x)=\mathcal{N}(\mu_\phi(x),\sigma_\phi^2(x))$ 这一步本身不可导（随机节点挡住了梯度），改写为

$$z=\mu_\phi(x)+\sigma_\phi(x)\odot\varepsilon,\qquad \varepsilon\sim\mathcal{N}(0,I)$$

随机性被挪到与参数无关的 $\varepsilon$ 上，梯度就能穿过 $\mu,\sigma$ 回传。这不是数学技巧的炫技，而是「让随机采样变成确定性函数 + 外部噪声」这一条工程范式，后来所有重参数化变分方法（如扩散模型的 reparameterized sampling）都在复用。

当 $q$ 取对角高斯、先验取标准正态时，KL 有**闭式解**，不必蒙特卡洛：

$$D_{\mathrm{KL}}=\frac{1}{2}\sum_{j=1}^{d}\Big(\mu_j^2+\sigma_j^2-1-\log\sigma_j^2\Big)$$

（`examples/ex02` 会把这条闭式解与蒙特卡洛估计对账，误差应随样本数 $O(1/\sqrt{n})$ 收敛。）

### 🧑‍💻 程序员视角

- **实现口径**：网络输出 `mu` 与 `logvar`（不是 `sigma`），因为 $\log\sigma^2$ 无下界约束、数值更稳，$\sigma=e^{0.5\log\sigma^2}$。KL 直接写成 `0.5 * (mu**2 + logvar.exp() - 1 - logvar).sum(1).mean()`。
- **后验坍塌（posterior collapse）**是 VAE 训练最常见的失败模式：解码器太强（如自回归解码器），它干脆忽略 $z$，KL 项被压到 0，模型退化成普通语言模型。信号很明确——**KL 项从训练早期就贴着 0**。解法：KL 退火（warm-up）、free bits、skip connection、或换 β 调度。
- **β-VAE 的取舍**：$\beta>1$ 加强 KL 得到更解耦的隐空间，但重建变糊；$\beta<1$ 重建清晰但隐空间不规整。生产里做表征学习常取 $\beta\in[4,10]$，做生成常取 $\beta<1$。
- **解码器输出分布要与数据匹配**：连续归一化数据用高斯（损失 MSE）；二值/像素用伯努利（BCE）；离散计数用泊松。选错损失会让重建永远糊或永远过曝，这是新手最常见的「模型没问题、损失选错」。

### 🎓 博士生视角

- ELBO 的两项可以严格解读为「**压缩率 vs 失真**」的率失真（rate-distortion）权衡：KL 项是编码 $x$ 所需比特（rate），负重建项是失真（distortion）。β 就是拉格朗日乘子。这个视角能直接推出「β 越大 → rate 越小 → 隐表示越少信息 → 重建越差」的单调关系，而不是靠调参感觉。
- ELBO 与真实对数似然的差距恰好是 $D_{\mathrm{KL}}(q_\phi(z\mid x)\|p_\theta(z\mid x))$。**这个 gap 无法用 ELBO 本身监控**，所以「ELBO 涨了但样本变差」是可能发生的（后验拟合变好但生成模型没变好）。
- 重参数化梯度的方差分析：$\nabla_\phi \mathbb{E}_{q}[f]\;=\;\mathbb{E}_{\varepsilon}[\nabla_\phi f(\mu+\sigma\varepsilon)]$ 是无偏的，但方差通常比 REINFORCE 低几个数量级——这正是它成为默认做法的原因。代价是要求 $q$ 是**可重参数化的连续分布**，离散隐变量（如 VQ-VAE）需要 Gumbel-Softmax 或直通估计器。
- VQ-VAE 的意义：用**离散码本 + 直通估计**绕开连续先验，得到更接近「token」的表示——这条线直接通向今天多模态模型的图像 tokenizer（如 VQGAN、Stable Diffusion 的 VAE 编码器）。

### 📚 考研者视角

- **必背推导**：ELBO = 重建项 − KL 项；写出 Jensen 那一步，并说明「最大化 ELBO = 最大化似然的下界」。
- **高频问法**：「VAE 与 AE 的本质区别是什么？」标准答法三条：① VAE 的隐空间有显式先验约束（KL 项），AE 没有；② VAE 可直接采样生成，AE 不能；③ VAE 的损失是似然下界，AE 只是重建误差。
- **必考计算**：高斯 KL 闭式解（给出 $\mu,\sigma$ 让手算数值）；KL 项在 $\mu=0,\sigma=1$ 时恰为 0 这一点常被用作验算。
- **易错点**：把「重参数化」说成「把随机性去掉」——错，随机性仍在，只是**与参数解耦**；把 ELBO 说成「近似似然」——它是**下界**，$\log p(x)\ge \mathcal{L}$。

## 3. 隐空间的性质：连续、解耦与「先验不匹配」

VAE 承诺的是「隐空间连续且近似先验」，工程上要验证三件事：

1. **插值是否平滑**：$z_1,z_2$ 线性插值解码，中间帧应语义连续（AE 常常不连续）。
2. **采样是否在支撑集内**：从 $N(0,I)$ 采样解码，应生成合理样本——若出现大量垃圾样本，说明聚合后验（aggregate posterior）与先验错位。
3. **是否有解耦结构**：改变单个维度应只改一个语义因子（β-TCVAE / FactorVAE 用总相关分解来量化）。

「先验不匹配」（prior hole）是常见现象：所有 $q_\phi(z\mid x)$ 的并集（聚合后验）往往比 $N(0,I)$ 小得多，导致从先验采样落到「空洞区」，解码出模糊样本。这不是训练不足，而是 ELBO 的**结构性缺陷**——它只约束每个 $x$ 的后验靠拢先验，不约束聚合后验填满先验。

### 🧑‍💻 程序员视角

- 判断「是不是先验空洞」的实操手段：把训练集所有 $x$ 过一遍编码器取 $\mu$，看其**分布范围**（每维的均值/方差、PCA 投影）；若远小于 $N(0,I)$，采样质量差就是预期行为，别再去调网络结构。缓解手段：加大 β、用 VampPrior、或在采样时用「截断/温度缩放」的先验（$\sigma$ 乘 0.7 之类）。
- 生产里 VAE 更常做**编码器**（把图像压成 latent 供扩散/自回归模型使用），而不是端到端生成器：Stable Diffusion 的 VAE 把 $512\times512\times3$ 压成 $64\times64\times4$，训练时冻结它，这能省一个数量级的算力。
- 隐维度不是越大越好：一般取 $d\approx D/8\sim D/64$（图像），过大反而让 KL 项难以压住、训练变慢。

### 🎓 博士生视角

- 聚合后验 $q(z)=\mathbb{E}_{p_{\text{data}}}[q_\phi(z\mid x)]$ 与先验的 KL 可以分解为三项：**总相关（TC）+ 各维 KL + 互信息**。这个分解（Watanabe 的信息瓶颈视角）解释了 β-TCVAE 为什么要**只惩罚 TC 项**才能拿到解耦表示，而不是整体加大 β。
- 「VAE 生成的样本偏糊」有严格解释：最优解码器输出后验均值，而均值在多峰条件分布下会落在峰之间。要生成锐利样本，必须改变目标（对抗项、感知损失、或换成扩散式的迭代去噪）。
- 与扩散模型的关系：扩散模型可以看成**层级 VAE**（$T$ 层隐变量、每层高斯、共享参数、固定前向过程），ELBO 也逐层分解。区别在于扩散的后验是**固定的加噪过程**而非学习得到的编码器，因此没有后验坍塌、也不用对抗训练。

### 📚 考研者视角

- **概念辨析题**：「VAE 的隐变量分布为什么要假设为高斯？」答题要点：可重参数化、KL 有闭式解、独立维度便于解耦、与「连续表示」假设匹配；高斯不是唯一选择（离散用 Gumbel、混合用 GMM 先验），但高斯在可解性与表达力之间取了平衡。
- **计算题**：给定一批 $x$ 的 $\mu,\sigma$，求平均 KL；再问「β 加倍后 KL 项与重建项如何变化」（KL↓、重建误差↑，给单调方向即可，不必给精确值）。
- **易混**：VAE 是**有向图模型 + 变分推断**，不是「加了噪声的 AE」——这个说法在笔试里常被判为不准确。

### 自编码器前向与参数量

```python
import numpy as np
rng = np.random.default_rng(0)
D, d = 8, 3                     # 输入 8 维，瓶颈 3 维
W1 = rng.normal(0, 0.3, (D, d)); b1 = np.zeros(d)
W2 = rng.normal(0, 0.3, (d, D)); b2 = np.zeros(D)
X = rng.normal(size=(5, D))
Z = np.tanh(X @ W1 + b1)        # 编码
Xhat = Z @ W2 + b2              # 解码
mse = ((X - Xhat) ** 2).mean()
print(f"输入形状 {X.shape} -> 隐表示 {Z.shape} -> 重建 {Xhat.shape}")
print(f"压缩比 d/D = {d}/{D} = {d/D:.3f}")
print(f"参数量 = {W1.size + b1.size + W2.size + b2.size}  (W1 {W1.size} + W2 {W2.size})")
print(f"随机初始化下重建 MSE = {mse:.4f}（未训练，只验证形状与参数量口径）")
```

```text
随机初始化下重建 MSE = 1.0673（未训练，只验证形状与参数量口径）
```

### 重参数化与高斯 KL 闭式解对账

```python
import numpy as np
rng = np.random.default_rng(1)
mu = np.array([0.5, -1.2, 0.0])
logvar = np.array([0.0, -1.0, 0.7])
sigma = np.exp(0.5 * logvar)
# 闭式解: 0.5 * sum(mu^2 + sigma^2 - 1 - logvar)
kl_closed = 0.5 * (mu ** 2 + sigma ** 2 - 1.0 - logvar).sum()
print(f"sigma = {np.round(sigma, 4)}")
print(f"KL 闭式解 = {kl_closed:.6f}")
print("蒙特卡洛估计（重参数化 z = mu + sigma*eps）：")
for n in (100, 1000, 10000, 100000):
    eps = rng.normal(size=(n, 3))
    z = mu + sigma * eps                       # 梯度可穿过 mu/sigma
    log_q = -0.5 * (((z - mu) / sigma) ** 2 + logvar + np.log(2 * np.pi)).sum(1)
    log_p = -0.5 * (z ** 2 + np.log(2 * np.pi)).sum(1)
    est = (log_q - log_p).mean()               # E_q[log q - log p]
    print(f"  n={n:>6d}  KL_MC = {est:.6f}  |误差| = {abs(est - kl_closed):.6f}")
print("结论：误差量级约 sigma/sqrt(n)（n=100 时约 0.09，n=10000 时约 0.002），")
print("      不严格单调是随机波动的正常表现；闭式解与采样估计在同一量级即为一致")
```

实际输出：

```text

  n=  1000  KL_MC = 1.205819  |误差| = 0.020003

      不严格单调是随机波动的正常表现；闭式解与采样估计在同一量级即为一致
```

## 三视角小结

| 主题 | 程序员要会 | 博士生要会 | 考研/笔面要会 |
|---|---|---|---|
| AE | 异常检测阈值标定、上采样伪影 | 线性 AE ≡ PCA 的条件、均值回归 | AE 不是生成模型、与 PCA 的关系 |
| VAE | logvar 参数化、KL 退火、损失匹配数据 | ELBO 的率失真解释、聚合后验分解 | ELBO 推导、高斯 KL 闭式解 |
| 重参数化 | $\varepsilon$ 采样与梯度直通 | 方差分析、离散情形的替代方案 | 「解耦随机性」的准确表述 |
| 隐空间 | 先验空洞的诊断与缓解 | prior hole 的结构性成因 | VAE vs AE 三条差异 |
