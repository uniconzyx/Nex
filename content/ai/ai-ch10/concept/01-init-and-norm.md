> 视角覆盖：程序员（工程决策）/ 博士生（第一性原理）/ 考研者（笔面口径）。三者互补、不重复。
> 本章所有数值结论都能用 `examples/ex01~ex04` 复现（NumPy，固定种子）。

## 1. 初始化：让信号在层间既不放大也不衰减

一个 $L$ 层网络，若每层把激活的方差乘以 $c$，则第 $L$ 层方差是 $c^L$ 倍。$c=1.1$ 且 $L=50$ 时放大 $1.1^{50}\approx117$；$c=0.9$ 时衰减到 $0.005$。**这就是「深网络训不动」最朴素的解释**，也是初始化唯一要解决的问题：让 $c\approx1$。

对线性层 $h_l=W_l h_{l-1}$，$W$ 的元素独立同分布、均值 0、方差 $\sigma_w^2$，则

$$\mathrm{Var}(h_l)=n_{\text{in}}\cdot\sigma_w^2\cdot\mathrm{Var}(h_{l-1})$$

要求 $\mathrm{Var}(h_l)=\mathrm{Var}(h_{l-1})$，就得 $\sigma_w^2=1/n_{\text{in}}$。这就是 **LeCun 初始化**。两个修正决定了工程默认值：

- **ReLU 砍掉一半**：负半轴输出 0，等效把方差减半，故需 $\sigma_w^2=2/n_{\text{in}}$ → **He 初始化**（Kaiming）。
- **反向也要稳**：反向传播的梯度方差正比于 $n_{\text{out}}\sigma_w^2$，同时兼顾前向与反向的折中是 $\sigma_w^2=2/(n_{\text{in}}+n_{\text{out}})$ → **Xavier/Glorot 初始化**（配 tanh 用）。

工程上的取值不必纠结：**tanh/sigmoid 用 Xavier，ReLU/GELU 用 He**，这是两条无脑可用的规则。真正重要的是「方差保持」这个判据——它可以用一次前向就验证（`ex01`/`ex02` 就是做这件事）。

还有一类被低估的初始化：**正交初始化**（用于 RNN/深线性链），它让 Jacobian 的奇异值全为 1，从而梯度既不爆炸也不消失。这也是「谱半径 = 1」这条主线的最直接实现。

### 🧑‍💻 程序员视角

- 框架默认值已经够好：PyTorch 的 `nn.Linear` 用 U(-1/√n, 1/√n)（方差 $1/(3n)$，比 He 小），对深网偏保守；**深网显式改成 `kaiming_normal_(a=0, mode='fan_out')`** 是低成本高收益的改动。
- **Embedding 与输出层不要同分布初始化**：输出层常用小方差（如 std=0.02）以稳定初始 logits，否则初始 softmax 接近均匀但梯度爆炸。
- 残差网络的最后一层（每个 block 的第二个卷积/线性）要**额外缩小**（如乘 $1/\sqrt{2N}$，$N$ 为 block 数），否则残差分支累加会让方差随深度线性增长——GPT-2 的「scaled init」就是这个。
- 诊断手段：训练前跑一次前向，打印每层激活的均值/方差/零比例。**方差逐层指数级变化 = 初始化或归一化有问题**，别急着调学习率。

### 🎓 博士生视角

- 方差分析的前提是「线性 + 独立 + 零均值」，一旦有非线性，只能保证**近似**保持；He 初始化的 $2/n$ 正是把 ReLU 的「保留一半」精确补偿后的结果（假设输入对称分布）。
- 更严格的判据是**动力学等距**（dynamical isometry）：要求前向与反向的 Jacobian 奇异值都接近 1。正交初始化精确满足，He/Xavier 只在方差意义下近似。这条判据解释了为什么「正交 + 残差」能训到上千层，而「He + 无残差」不能。
- 均值场理论（mean-field）把宽度 $n\to\infty$ 的极限写成核（NTK）或微分方程；在这个极限下，初始化方差决定网络处于「有序相/混沌相」，而**临界初始化**（方差恰好使信号既不衰减也不爆炸）正是可训练性的相变点（Poole et al., 2016）。
- 初始化与优化的关系可以更精确：初始化的尺度决定了初始 NTK 的谱，从而决定梯度下降的有效步长。这不是「调参玄学」，而是「优化问题的条件数」问题。

### 📚 考研者视角

- **必背**：Xavier 的 $\sigma^2=2/(n_{in}+n_{out})$ 与 He 的 $\sigma^2=2/n_{in}$，以及各自适配的激活函数（tanh / ReLU）。
- **常考问法**：① 为什么全零初始化不行（对称性不破，所有神经元学到相同的特征，等价于一个神经元）；② 初始化过大/过小分别导致什么（爆炸 / 消失）；③ Xavier 与 He 的差别从哪来（ReLU 的方差减半）。
- **易混**：初始化不是正则化（不改损失函数），但它与归一化一起决定「信号能否穿过深度」——很多面试官会追问「有 BN 了还要不要讲究初始化」，答案是**要**（BN 只稳前向统计量，不保证反向 Jacobian）。

## 2. 归一化：把「每层的输入分布」钉住

归一化的统一形式是「标准化 + 仿射」：

$$\mathrm{Norm}(x)=\gamma\odot\frac{x-\mu(x)}{\sqrt{\sigma^2(x)+\epsilon}}+\beta$$

差别全在**统计量沿哪些维度算**：

| 方法 | 统计维度 | 适用 | 关键性质 |
|---|---|---|---|
| BatchNorm | 跨 batch（每通道） | CNN 大 batch | 依赖 batch，训练/推理行为不同 |
| LayerNorm | 跨特征（每样本） | Transformer/RNN | 与 batch 无关，训练/推理一致 |
| RMSNorm | 跨特征，但不减均值 | LLM（LLaMA 系） | 少一次 reduction，快 ~5-10%，效果几乎不掉 |
| GroupNorm | 通道分组 | 小 batch 视觉 | 不依赖 batch，检测/分割常用 |
| InstanceNorm | 单样本单通道 | 风格迁移/生成 | 抹掉对比度信息 |

BatchNorm 的「训练/推理不一致」是必须掌握的点：训练用当前 batch 的均值方差，同时用滑动平均维护全局统计量；推理用滑动平均。若推理时用错（比如忘了 `model.eval()`），结果会随 batch 大小漂移——这是线上事故的高频来源。

**Pre-LN 与 Post-LN** 是 Transformer 训练稳定性的分水岭。原始 Transformer 用 Post-LN（$x_{l+1}=\mathrm{LN}(x_l+F(x_l))$），梯度必须穿过 LN，深层时梯度范数随层数增长，必须靠 warmup 才能训起来；GPT-2 之后改为 Pre-LN（$x_{l+1}=x_l+F(\mathrm{LN}(x_l))$），残差是恒等路径，梯度可以直通到底层，因此**不需要长 warmup 也能训深**。代价是表达力略降（深层等效于浅层集成），可用 final LN 补偿。

### 🧑‍💻 程序员视角

- 选型决策树：**CNN 大 batch → BN；Transformer → LN/RMSNorm；小 batch 检测 → GN；生成模型 → IN/AdaIN（或不用）**。选错归一化是「训练能跑但效果差一档」的典型原因。
- BN 的 batch 统计量在**分布式训练**下要跨卡同步（SyncBN），否则等效 batch 变小、精度下降；这一步常被忽略，是「单卡复现不了多卡结果」的原因之一。
- LN 的 $\epsilon$ 不能太小：fp16 下 $\epsilon=10^{-5}$ 会因下溢变成 0 除；LLM 常用 $10^{-5}$（fp32 内部计算）或 $10^{-6}$（bf16）。
- RMSNorm 实现要点：只算 $\sqrt{\text{mean}(x^2)+\epsilon}$，不减均值，因此不能用「零均值」假设去推等价性；它的收益主要在 kernel 层面（少一次 all-reduce/归约）。
- **归一化层不参与 weight decay**（LN/BN 的 $\gamma,\beta$ 与 bias 一般排除），这是「无脑可用的训练配方」之一。

### 🎓 博士生视角

- BN 的原论文把效果归因于「减少内部协变量偏移（ICS）」，但后续工作（Santurkar et al., 2018）证明 ICS 与性能提升**不构成因果**：真正起作用的是 BN 让损失面更平滑（Lipschitz 常数变小），从而使梯度更可预测、允许更大步长。这个「被推翻的解释」是很好的批判性思维案例。
- BN 在 batch 维度的归一化等价于对每个样本的特征做「跨样本的中心化」，它引入的梯度耦合使训练动力学不再是逐样本独立的——这解释了「BN 与梯度累积/小 batch 不兼容」（BN 需要足够大的 batch 才有稳定统计量）。
- Pre-LN 的梯度分析可以写成：残差流的 Jacobian 是 $I+\partial F$，梯度范数按 $\prod\|I+\partial F_l\|$ 增长，Pre-LN 把 LN 放在分支内，保证 $\partial F$ 的量级被归一化，因此深层不发散；Post-LN 则让每个 block 的输出被重新标准化，梯度在早期层会被反复缩放，导致「深层好训、浅层难训」。
- 归一化与「谱」的关系：LN 把激活限制在球面上（$\|x\|$ 与 $\gamma$ 相关），等价于对每层的 Lipschitz 常数加上界；这是它稳定训练的真正机制（与 BN 的损失面平滑解释同源）。

### 📚 考研者视角

- **必背对比**：BN（跨 batch、每通道）/ LN（跨特征、每样本）/ IN（单样本单通道）/ GN（分组），以及各自「训练与推理是否一致」。
- **常考计算**：给定一个 $2\times3$ 的输入，分别按 BN（沿 batch）与 LN（沿特征）计算归一化结果；考「BN 的滑动平均更新公式」$ \hat\mu\leftarrow(1-m)\hat\mu+m\mu_{\text{batch}}$。
- **高频问法**：① 为什么 Transformer 用 LN 不用 BN（序列长度可变、batch 小、推理逐 token）；② BN 为什么能加速收敛（允许更大学习率/平滑损失面）；③ Pre-LN 与 Post-LN 的区别（梯度路径与 warmup 需求）。
- **易混**：LN 不改变「样本间的相对关系」（每个样本独立），BN 会（同 batch 内样本互相影响）——这决定了两者在分布式与小 batch 场景的取舍。

## 3. 残差与梯度路径：深层网络的「高速公路」

残差连接 $x_{l+1}=x_l+F(x_l)$ 的作用不只是「缓解梯度消失」，它给出的是一条**恒等路径**：

$$\frac{\partial x_L}{\partial x_l}=\prod_{k=l}^{L-1}\Big(I+\frac{\partial F_k}{\partial x_k}\Big)$$

展开这个乘积，除最高阶项外，**每一项都含若干 $I$**。这意味着即使某些 $\partial F$ 很小，梯度仍能沿「全 $I$ 项」无损回传。这就是「千层网络可训」的结构性原因，比「加法让梯度变大」这种说法精确得多。

残差还带来一个工程后果：**残差分支的初始化要小**。若 $\partial F$ 的初始量级为 1，则 $L$ 个 block 后方差按 $L$ 增长（不是指数，但线性增长已足够让深网不稳）；把分支末层乘 $1/\sqrt{2L}$ 可把它压回 $O(1)$。

### 🧑‍💻 程序员视角

- 残差不是「加了就有效」：**Pre-LN + 残差 + scaled init** 三件套一起才有稳定的深网训练。只加残差但用 Post-LN，仍然需要长 warmup。
- 检查残差是否真的在传递信息：打印每层输出的范数 $\|x_l\|$，健康情况下应**缓慢增长**（Pre-LN）或基本平稳；若逐层翻倍，说明分支太大；若逐层减半，说明分支被抑制过度。
- 梯度检查的实操：对每层算 `grad.norm()`，健康分布应跨层**同量级**（差 1-2 个数量级可接受）；若首层比末层小 3 个数量级以上，就是「深网浅层学不动」，优先查归一化位置与初始化。

### 🎓 博士生视角

- 把残差网络看成**常微分方程的离散化**（Neural ODE）：$x_{l+1}=x_l+F(x_l)$ 就是 $dx/dt=F(x)$ 的显式 Euler 步。这解释了为什么「残差 + 小步长（小初始化）」等价于一个良态的连续动力系统，也解释了为什么层数可以连续化（Neural ODE）。
- 梯度乘积的谱分析：若 $\partial F_k$ 的特征值集中在 0 附近，乘积的谱半径接近 1（恒等项主导），梯度不衰减；若集中在负实轴且模长 >1，则出现振荡式爆炸。这是「残差让深网可训」的谱解释。
- 残差与「隐式正则」：多个研究表明残差网络倾向学出「小范数的增量」，等价于对 $\|F\|$ 的隐式惩罚——这解释了为什么残差网络的泛化往往好于同参数量的无残差网络。

### 📚 考研者视角

- **必背**：残差块的公式与「恒等映射」的梯度路径解释；ResNet 解决退化问题（degradation）而非过拟合——这是必考辨析。
- **高频问法**：① 残差为什么能缓解梯度消失（恒等路径 + 连乘中含 $I$）；② 残差与 highway network 的区别（后者有门控）；③ 为什么 ResNet 用 1×1 卷积做维度匹配（shortcut 的投影）。
- **易混**：退化问题（深层训练误差反而更高）≠ 过拟合（训练误差低、测试高）。ResNet 的动机是前者。

## 4. 三件套的联合作用：一次「能否训起来」的判断

把初始化、归一化、残差放在一起，就得到一张可用的判断表：

| 症状 | 最可能的原因 | 第一动作 |
|---|---|---|
| 前向激活方差逐层爆炸/消失 | 初始化尺度错、无归一化 | 打印各层方差，换 He/Xavier |
| 反向梯度首层比末层小 3 个量级 | Post-LN + 无 warmup、残差分支过大 | 改 Pre-LN、缩分支初始化 |
| loss 前几百步剧烈震荡后崩 | 初始化 + 学习率过大 | 加 warmup、降 lr、加梯度裁剪 |
| 训练正常但推理结果漂移 | BN 统计量/`eval()` 错 | 检查 eval 模式与 SyncBN |
| 深层比浅层差（退化） | 无残差或残差被抑制 | 加残差、检查 $\|x_l\|$ 曲线 |

这张表的用法是：**先看信号（方差/梯度范数），再看超参**。绝大多数「训不起来」在前向/反向统计里就有信号，调学习率只是掩盖问题。

### 🧑‍💻 程序员视角

- 建立「训练前体检」脚本：一次前向打印每层 `mean/std/zero_ratio`，一次反向打印每层 `grad_norm`。这套体检 5 分钟能省掉几天的盲调。
- 把体检结果存成日志（不是只看一次），因为**归一化层插入后信号会变**，重构模型时要重跑。

### 🎓 博士生视角

- 三个组件的作用可以统一到「控制 Jacobian 谱」：初始化控制初始谱、归一化控制每层谱的上界、残差保证谱不退化到 0。三者是**同一个目标（可训练性）的三个杠杆**，不是三个独立技巧。
- 深层网络的可训练性问题在理论上仍未完全解决（尤其无归一化的深网），这也是「架构搜索」与「训练稳定性」研究持续活跃的原因。

### 📚 考研者视角

- **综合题风格**：「一个 50 层的网络训练 loss 不下降，列出至少四种可能原因及排查顺序」。标准答法按「数据 → 初始化 → 归一化 → 学习率 → 梯度」排序，并说明每一步的观测指标。
- **易混**：梯度消失（连乘衰减）与梯度爆炸（连乘放大）在深层网络里常同时出现（不同层表现不同），不要假设「要么消失要么爆炸」。

### 三种初始化下 50 层前向的激活方差

```python
import numpy as np
rng = np.random.default_rng(0)
d, L, n = 256, 50, 1024

def run(mode):
    x = rng.normal(size=(n, d))
    stds = []
    for l in range(L):
        if mode == "naive":
            std = 1.0
        elif mode == "xavier":
            std = np.sqrt(2.0 / (d + d))
        else:  # he
            std = np.sqrt(2.0 / d)
        W = rng.normal(0, std, (d, d))
        x = np.maximum(x @ W, 0)          # ReLU
        if (l + 1) % 10 == 0:
            stds.append(x.std())
    return stds

print(f"每层 std（d={d}, ReLU, 50 层）：")
print("层数      " + "".join(f"{i:>10d}" for i in (10, 20, 30, 40, 50)))
for mode in ("naive", "xavier", "he"):
    s = run(mode)
    print(f"{mode:<9s}" + "".join(f"{v:10.2e}" for v in s))
print()
print("理论：Xavier std=sqrt(2/(nin+nout))={:.5f}, He std=sqrt(2/nin)={:.5f}".format(
    np.sqrt(2.0 / (2 * d)), np.sqrt(2.0 / d)))
print("结论：naive 初始化逐层指数爆炸；Xavier 配 ReLU 会指数衰减；")
print("      He 是唯一让 50 层后激活仍与输入同量级的选项（0.45~0.74 vs 1e52 / 1e-8）")
```

### 随机矩阵 vs 正交矩阵的谱半径

```python
import numpy as np
rng = np.random.default_rng(1)
n = 256

G = rng.normal(0, 1.0 / np.sqrt(n), (n, n))     # He 缩放后的高斯矩阵
sv = np.linalg.svd(G, compute_uv=False)
Q, _ = np.linalg.qr(rng.normal(size=(n, n)))    # 正交矩阵
sv_q = np.linalg.svd(Q, compute_uv=False)

print(f"Gaussian/sqrt(n): max sigma = {sv.max():.4f}, min = {sv.min():.4f}, 条件数 = {sv.max()/sv.min():.2f}")
print(f"正交矩阵:          max sigma = {sv_q.max():.4f}, min = {sv_q.min():.4f}, 条件数 = {sv_q.max()/sv_q.min():.2f}")
print(f"理论上高斯缩放矩阵 max sigma -> 2（Marchenko-Pastur 上界 2*sqrt(n)*1/sqrt(n)=2）")
print("结论：即使按 1/sqrt(n) 缩放，高斯矩阵的谱范数仍约 2（每层放大 2 倍），")
print("      正交初始化把奇异值全钉在 1，才是真正的『等距』，因而深链/RNN 更稳")
```
