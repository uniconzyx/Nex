# OCR→VLM 流水线：文档理解链路与失败模式

让模型读懂一张「带版式的文档」（发票、合同、报表、论文），最务实的落地链路不是端到端一步到位，
而是 **OCR → VLM** 的分段流水线：先让文档「变成文字」，再让语言模型「理解文字」。它把难题拆成
两个被分别验证过的环节，工程上更可控。

## 一、链路拆解与成本口径

### 链路拆解：版面检测 → 文本识别 →

```text
   图像 → 版面检测(版心/表格) → 文本识别(OCR) → VLM 问答
            │                      │
            └── 失败模式：漏检/错认 ─┘ → 答案幻觉的来源
   成本：识别 + VLM 各算一次；延迟预算要拆成「预处理 / 推理 / 回传」
```
 问答

1. **版面检测（layout detection）**：检测出文档里的版面块——标题、段落、表格、页脚、印章的位置与
   类型。它是后续处理的「地图」，决定先读哪块、表格要不要单独处理。
2. **文本识别（text recognition / OCR）**：对每个版面块做 OCR，把图像里的字变成字符串。表格块
   通常要走「表格结构识别」而不是普通 OCR，否则行列关系会乱。
3. **问答/理解（VLM 或直接交给 LLM）**：把结构化出来的文字（含版面顺序）喂给 VLM/LLM，回答
   「营收多少」「第三行合计是多少」这类问题。这里往往不需要再把原图送进大模型，纯文本就够了。

### 用固定耗时理解成本（而非实测计时）

部署时要给每段配预算。以一张文档图为例，版面检测约 120ms、文本识别约 300ms、后处理/纠错约
80ms，端到端 500ms——文本识别占 60%，是优化重点（上更强的识别模型或并行化）。用**固定预算值**
做容量规划，而不是每次 time.perf_counter()（那会引入不可复现、也掩盖结构性瓶颈）。

## 二、失败模式与工程判据

### 失败模式：这条链路在哪崩

- **版面检测失败**：多栏、旋转、水印、印章压字时，块切错，后续全错。检测模型要覆盖这些分布。
- **OCR 低置信度/乱码**：模糊、艺术字、手写、盖章遮挡，识别出 `##########` 或 `✱✱✱✱✱` 这类
  乱码。必须做**置信度过滤**：conf<0.5 或含乱码字符的样本标记人工复核，不能直接进 VLM 当真值。
- **表格结构错乱**：普通 OCR 把表格读成连续文本，行列丢失。要用表格结构识别或把表格区块单独裁剪
  送专用模型。
- **长文档截断**：版面块排序错了，问答时上下文缺关键段。排序要按阅读顺序（reading order）而非
  检测框的 y 坐标简单排序。
- **VLM 幻觉**：文字识别对了，但模型基于错误先验编造答案。要约束它「只基于给定文本作答」。

### 工程判据

OCR→VLM 的价值在于「可解释、可单点优化、可降级」。某段识别差就只换识别模型，不必动整体；识别
置信度低就走人工复核兜底。它不如端到端 VLM 时髦，但在「准确率与可追溯」优先的文档场景，是今天
最稳的落地形态。

## 三视角解析

### 🧑‍💻 程序员视角
- 落地文档理解优先 OCR→VLM 分段链路：版面检测→文本识别→问答，比端到端 VLM 更可控、可单点优化、可降级。
- 容量规划用固定预算值（如检测120ms/识别300ms/后处理80ms），别用 time.perf_counter() 做结构性评估，那不可复现也掩盖瓶颈。
- OCR 结果必须做置信度过滤：conf<0.5 或含乱码字符的样本标记人工复核，不能直接当真值喂给 VLM。
- 表格别走普通 OCR——行列会乱；要表格结构识别或单独裁剪送专用模型。版面块按阅读顺序排序，别只按 y 坐标。

### 🎓 博士生视角
- OCR→VLM 是「模块化多模态」的代表：把感知（OCR）与认知（VLM）解耦，每个模块可独立替换与评估，符合软件工程的关注点分离。代价是误差会沿链路传播（cascading error），所以每步都要有置信度/质量检测做兜底。
- 从信息论看，OCR 把高熵的图像信号压缩成离散符号序列，VLM 再在符号空间推理。这条链路成立的前提是「图像中的语义能被无损/低损符号化」——对手写、艺术字、复杂版式，这一前提会崩，正是失败模式的来源。
- 端到端 VLM（直接读图）与 OCR→VLM 的取舍，本质是「表示学习 vs 符号化中间表示」的权衡：前者上限高但难追溯、难单点优化；后者透明可控但受 OCR 天花板限制。近期趋势是二者融合（OCR 作为 VLM 的辅助 token）。

### 📚 考研者视角
- 记忆锚点：**OCR→VLM 链路=版面检测→文本识别→问答；优化重点在识别(占60%)；失败模式=检测错/乱码/表格乱/截断/幻觉**。
- 与 408 的「流水线/模块化」对照：OCR→VLM 就是感知-认知两段式流水线，误差沿链路传播，所以每级要质检兜底。
- 面试常问「文档理解怎么落地」「OCR 结果能直接信吗」：答分段链路 + 置信度过滤 + 表格单独处理 + 阅读顺序排序。
