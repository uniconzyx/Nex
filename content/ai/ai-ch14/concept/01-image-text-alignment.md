# 图文对齐与表征：CLIP 式对比学习、投影层、跨模态检索

让模型「看懂图又能聊图」，第一步是让图像和文本**住在同一个向量空间里**——同一张猫图和「猫」
这句话，在这个空间里离得很近；猫图和「汽车」离得很远。这件事叫**图文对齐（image-text alignment）**，
是多模态一切的地基。

```text
对比学习：一个 batch 内 N 图 × N 文，构成 N×N 相似度矩阵
                  t1    t2    t3   …  tN
        i1      [ ✔     ✘     ✘        ✘ ]   对角线 = 正确配对（正样本）
        i2      [ ✘     ✔     ✘        ✘ ]   其余全为 in-batch 负样本
        i3      [ ✘     ✘     ✔        ✘ ]
         ⋮
    图->文、文->图 两个方向各做 softmax，对称损失：配对拉近、他配推远

投影层：两个塔维度不同，映射到同一空间才能算余弦
    f_img(224d) ─▶ W_i(224×512) ─┐
                                  ├─▶ 同一 512 维空间 ─▶ 跨模态最近邻检索
    f_txt(768d) ─▶ W_t(768×512) ─┘

模态鸿沟仍在：抽象词、细粒度计数、空间关系 -> 对齐明显变弱
```

## 一、对比学习与投影层

### CLIP 式对比学习：用「配对」教模型对齐

CLIP 的做法极其简洁：拿海量「(图片, 文本)」配对数据，训练两个编码器——图像编码器（ViT/CNN）
和文本编码器（Transformer）。训练目标是**对比损失（InfoNCE）**：在一个 batch 里，让「正确的
图文对」相似度最高，让「错误的配对」相似度低。也就是说，正样本是 batch 里本就配对的 (I_i, T_i)，
负样本是同一 batch 里其他文本 T_j（j≠i）。模型被迫学会：把成对图文拉近、把不成对推远。训练完，
图像和文本就共享了同一个嵌入空间，无需任何标注框，纯靠「配对」信号。

### 投影层：把不同模态映射到同一维度

图像编码器和文本编码器的原始输出维度往往不同，且各自带着「模态偏置」。常见做法是各接一个
**投影层（projection / adapter）**：把图像嵌入线性映射到文本嵌入空间（如 `proj = W @ img`），
或在两侧各接一个 MLP 投影头，对齐到统一的 `hidden_dim`。投影层参数量小、训练快，是「冻结大模型、
只训适配器」范式（如 LoRA/adapter）在多模态上的直接应用。对齐质量很大程度取决于投影层是否把
模态偏置抹平——否则图像和文本虽然维度一致，语义却没对齐。

## 二、检索与模态鸿沟

### 跨模态检索：空间里的最近邻

对齐后，检索就退化成「向量最近邻」。给一句文本查询，编码成向量，在图像向量库里算余弦相似度，
取 Top-K 即「以文搜图」；反过来编码图像、搜文本即「以图搜文」。关键是**度量要一致**：检索时
图和文都必须过各自的编码器 + 投影层，落到同一空间再用同一相似度（余弦/点积）比较，否则跨模态
比较毫无意义。实践中还要做向量归一化，让点积等价于余弦，避免模长干扰排序。

```python
import numpy as np

def l2norm(x):
    return x / np.linalg.norm(x, axis=-1, keepdims=True)

def topk_text_for_image(img_emb, text_embs, k=5):
    """img_emb: (D,)；text_embs: (N, D)；两者都已通过各自的投影层"""
    sims = l2norm(text_embs) @ l2norm(img_emb)      # 余弦相似 = 归一化后内积
    idx = np.argsort(-sims)[:k]
    return idx, sims[idx]

# 批量检索时不要逐条循环：一次矩阵乘得到 (N_text, N_image) 的相似度矩阵
sims = l2norm(text_embs) @ l2norm(img_embs).T
```

实践中归一化必须在**投影之后**做——投影层不保范数，先归一化再投影等于换了一个空间。

### 对齐不是万能：模态鸿沟仍在

对齐解决了「能不能检索」，没解决「细粒度对不对」。比如「黑猫坐在红沙发上」，全局对齐可能只抓住
「猫+沙发」，忽略颜色与空间关系。弥补靠更细的对比信号（region-text、细粒度 caption）或多阶段
对齐。但作为多模态系统的第一块基石，CLIP 式全局对齐性价比极高——它让「图文互搜」「以图生文」
成为可工程化的一行向量检索。

## 三视角解析

### 🧑‍💻 程序员视角
- 落地先对齐再检索：图像/文本各自编码器 + 投影层落到同一 hidden_dim，检索时都过投影、用同一相似度（余弦/点积），别跨空间直接比。
- 投影层参数量小、训练快，是「冻结大模型只训 adapter」在多模态上的直接应用；它要抹平模态偏置，否则维度对齐了语义没对齐。
- 检索前对向量归一化，让点积等价于余弦，避免模长干扰排序——这是跨模态检索最容易踩的坑。
- 全局对齐抓的是「有没有」，细粒度（颜色/空间关系）要靠 region-text 或多阶段对齐补，别指望一句 caption 对齐解决一切。

### 🎓 博士生视角
- CLIP 的 InfoNCE 本质是「在配对构造的分类任务上做对比」：把 batch 内其他样本当负例，等价于在 N 类（N=batch size）的软分类上优化，温度系数 τ 控制分布的锐度。这是自监督/对比学习的经典目标函数。
- 图文对齐可视为学习一个共享的模态无关流形：图像与文本编码器作为两个视图（views），投影层把异构表示映射到同一流形坐标。理论上它假设「配对即语义等价」，这一弱监督信号足以涌现零样本迁移能力，是表征学习的重要发现。
- 模态鸿沟（modality gap）指即使对齐后，图像与文本向量在统计上仍可分（如存在可线性分离的偏移）。近期工作通过对比损失的正则、对齐投影的对称性设计来缩小 gap，说明「维度一致」与「分布一致」是两件事。

### 📚 考研者视角
- 记忆锚点：**CLIP 式=双编码器+InfoNCE 对比损失；投影层把图/文映射到同一 hidden_dim；检索=跨模态最近邻（同一空间同度量）**。
- 与 408 的「向量空间/最近邻检索」对照：跨模态检索就是高维向量最近邻，只是向量来自不同模态编码器，本质一致。
- 面试常问「CLIP 怎么训的」「图文对齐怎么做」：答双塔编码器 + 配对对比损失 + 投影层对齐空间，零样本检索靠共享嵌入。
